# Idea 001. ShotFlow

## 제품
웨딩·행사 사진작가를 위한 AI 컬링(선별)·납품 자동화 + 스트릭 게임화 도구. 세션당 400~2000장을 업로드하면 AI가 블러·눈감음·중복 제거 후 납품 갤러리를 생성한다.

## Target Customer
웨딩·포트레이트·행사 사진작가. 세션당 400~2000장 촬영, 월 4~15건 처리. 편집 포함 세션 1건 = 8~14시간 소요하는 전업 사진작가.

## Market Evidence (실제 조사 결과)
- 글로벌 웨딩 포토그래피 시장: 2026년 $28.2B, CAGR 지속 성장 (Straits Research, Verified Market Reports)
- AI 사진 컬링 시장: 2026년 $12.5B, 2030년까지 22.5% CAGR
- 전업 웨딩 사진작가의 64%가 AI 도구를 1개 이상 사용, 도입 후 컬링 시간 50~80% 단축 보고 (Dataconomy)
- Imagen AI, Aftershoot 등 경쟁 도구 2026년 기준 왕성히 성장 중 — 시장 존재 명백

## Existing Competitors (실제 서비스명, 가격 포함)
| 서비스 | 가격 | 특징 |
|---|---|---|
| Imagen AI | $0.05/장, 최소 $7/월 | 컬링+편집 통합, 고볼륨시 비쌈 |
| Aftershoot | $120~$480/년 | 컬링 특화, 무제한 플랫 요금 |
| ShootProof | $10~$75/월 | 납품 갤러리 + 클라이언트 포털 |
| Pixieset | 무료~$25/월 | 갤러리 공유 |

## Alternative Solutions
- Adobe Bridge 수동 컬링 (무료, 8~14시간)
- Lightroom 내장 기능 (CC 구독 포함)
- 스프레드시트 수동 납품 관리

## Pricing Evidence (실제 확인한 가격)
- Imagen AI: $0.05/장. 웨딩 1세션 1500장 = $75 (filterpixel.com)
- Aftershoot Select: $120/년 컬링만, $480/년 컬링+편집 (aftershoot.com)
- ShotFlow 제안가 $19/월 Pro: 경쟁사 대비 낮은 가격 포지셔닝 가능

## Customer Acquisition (처음 10명 확보 방법)
1. 한국/일본 웨딩 포토그래퍼 Facebook 그룹, 커뮤니티 "무료 3세션 체험" 제공
2. Imagen AI 비싸다고 불만인 고볼륨 작가 타겟 — 가격 경쟁
3. 인스타그램 "My Season Report" 카드 공유 — 기존 사용자가 홍보 역할
4. YouTube 웨딩 포토그래피 채널 협업 리뷰

## MVP Cost
- 클라우드 Vision API (컬링): 월 5~10만원
- Vercel + Supabase 인프라: 월 3만원
- 초기 마케팅 (커뮤니티): 30만원
- **총 초기 비용: 약 150만원**

## Development Feasibility
1인 개발 가능. Google Cloud Vision API(블러 감지, 얼굴 품질) + 자체 랭킹 로직으로 MVP 구현. 납품 갤러리는 Cloudinary 연동으로 2~3주 내 완성 가능.

## Monetization
- Freemium: 월 3세션/세션당 500장 무료
- Pro $19/월: 무제한 세션, 자동 이메일 납품
- Studio $49/월: 3인 팀, 클라이언트 포털

## Scalability
사용자 증가 = 클라우드 API 비용 증가, 단 마진 구조 유지 가능. 팀 플랜($49) 업셀로 ARPU 상승 경로 존재.

## Major Risks
1. Imagen AI, Aftershoot의 기능 확장으로 차별화 희석 — 납품 관리 + 게임화가 유일한 호자
2. 컬링 AI 정확도 불만 시 작가들의 이탈 속도 빠름
3. 한국/일본 로컬 시장 규모 제한 — 글로벌 영어 마케팅 필요

## Critical Assumptions
- "납품 관리 + 스트릭 게임화"가 단순 컬링 대비 충분한 차별점인가
- AI 컬링 정확도가 작가 기대치(90%+)를 충족하는가

# Idea 002. TrainerOS

## 제품
PT 트레이너를 위한 음성 기록 + 회원 재등록 스트릭 앱. 수업 후 15초 음성으로 세션 기록, 회원 이탈 전 자동 알림.

## Target Customer
헬스장 소속 또는 프리랜서 PT 트레이너. 회원 10~30명 관리, 하루 4~8세션 진행.

## Market Evidence (실제 조사 결과)
- 보스몬 서비스 2026년 7월 종료 확정 — 실제 수요 공백 발생 중
- 보스몬 종료 발표 후 7일 내 대체 서비스 '가치업' 신규 사용자 3배 증가 (디지털데일리, 2026-06-12) — 이탈 사용자 적극 대안 탐색 중
- PT 트레이너 관리 앱 '핏하니(Fit하니)' Google Play 등록 확인 — 시장 존재

## Existing Competitors (실제 서비스명, 가격 포함)
| 서비스 | 가격 | 특징 |
|---|---|---|
| Fit하니 | 미확인 | PT 트레이너 전용 관리앱 |
| 가치업 | 무료 | 근태관리 (PT 특화 아님) |
| Notey / 카카오 노트 | 무료 | 비구조화 메모 |
| 시프티 | 2,000원/인/월 | 직원 근태 (PT 특화 아님) |

## Alternative Solutions
- 종이 노트 (대부분의 PT 트레이너 현재 사용)
- 카카오톡 채팅으로 회원 관리
- 구글 스프레드시트

## Pricing Evidence (실제 확인한 가격)
- 시프티 Basic: 2,000원/인/월, Standard: 4,000원/인/월 (play.google.com/shiftee)
- PT 특화 앱 월 9,900원은 트레이너의 월 수입(200~500만원) 대비 충분히 낮은 비중

## Customer Acquisition (처음 10명 확보 방법)
1. 보스몬 종료 관련 커뮤니티 글 타겟 — "보스몬 대안 찾고 있다"는 게시물에 직접 답변
2. 헬스장 사장·트레이너 네이버 카페(헬스 PT 창업 커뮤니티) 직접 DM
3. 트레이너 유튜버/인플루언서 협업 리뷰
4. 서울 주요 헬스장 직접 방문 영업 (오프라인)

## MVP Cost
- Whisper API + GPT: 월 5만원
- Supabase: 무료~월 2만원
- 카카오 알림톡: 월 2만원
- **총 초기 비용: 약 120만원**

## Development Feasibility
1인 개발 가능. 음성 → Whisper → GPT 파싱 → Supabase 저장 파이프라인은 2주 이내 MVP 완성. 한국어 운동 용어 NER 튜닝이 핵심 난관.

## Monetization
- Free: 회원 5명 (영구 무료)
- Pro 월 9,900원: 무제한 회원, 음성 기록, 재등록 알림, 회원 공유 리포트
- 연 99,000원 할인 옵션

## Scalability
한국 PT 트레이너 수 추정 10만명+. 전체 5% 전환 시 5,000명 × 9,900원 = 월 4,950만원. 필라테스·요가 강사로 수평 확장 가능.

## Major Risks
1. 음성 인식 전문 운동 용어 오류율 — 신뢰 훼손 시 즉시 이탈
2. PT 트레이너의 앱 학습 비용 거부감 (현재 종이 노트로 충분하다는 인식)
3. Fit하니 등 기존 앱이 이미 유사 기능을 무료 제공 중일 가능성

## Critical Assumptions
- 보스몬 종료 이탈 사용자 중 PT 트레이너 비중이 유의미한가
- 음성 15초 입력이 종이 메모보다 더 편하다고 트레이너가 느끼는가

# Idea 003. LogMate

## 제품
소프트웨어 개발자를 위한 의존성 변경사항 자동 추적 + "오늘 확인할 항목 0개" 달성 앱. Anki 간격반복을 changelog에 이식.

## Target Customer
1인 개발자·소규모 팀. npm/pip/gem 의존성 10개 이상 관리, GitHub 사용.

## Market Evidence (실제 조사 결과)
- Dependabot (GitHub 내장, 무료) + Renovate (무료 오픈소스) — 이미 시장 지배자 존재
- Snyk 유료 플랜: per-developer 과금. 보안 취약점 우선순위 기반
- 개발자 도구 시장은 B2B2C 구조, 팀 단위 결정이 일반적

## Existing Competitors (실제 서비스명, 가격 포함)
| 서비스 | 가격 | 특징 |
|---|---|---|
| Dependabot | 무료 (GitHub 내장) | 자동 PR 생성 |
| Renovate | 무료 (셀프호스팅 가능) | 멀티 플랫폼, 30+ 패키지 매니저 |
| Snyk | 무료 티어 + 유료 | 보안 취약점 특화 |
| Socket.dev | $12~/월 | 공급망 보안 |

## Alternative Solutions
- GitHub Dependabot (기본 제공, 무료)
- Renovate Bot (무료 셀프호스팅)
- 수동 npm outdated / pip list --outdated 확인

## Pricing Evidence (실제 확인한 가격)
- Dependabot: 무료 (GitHub Actions 포함)
- Renovate: 무료 오픈소스 (Mend hosted도 무료)
- LogMate 제안가 $9/월 Pro: 무료 대안 대비 가격 정당화가 핵심 도전

## Customer Acquisition (처음 10명 확보 방법)
1. Hacker News "Show HN" 포스팅 — 개발자 커뮤니티 직접 접근
2. Product Hunt 론칭
3. "AI 릴리스 노트 요약" 무료 크롬 확장 → 유료 전환
4. 오픈소스 프로젝트 유지보수자 타겟 DM

## MVP Cost
- OpenAI API: 월 3만원
- Vercel + PlanetScale: 월 5만원
- **총 초기 비용: 약 100만원**

## Development Feasibility
1인 개발 가능. GitHub App 등록 + package.json 파싱 + GPT 요약은 기술적으로 가장 쉬운 카테고리.

## Monetization
- Free: 저장소 1개, 의존성 50개
- Pro $9/월: 무제한 저장소, Slack 통합
- Team $19/월: 팀 대시보드, 보안 리포트

## Scalability
개발자 SaaS 전형적 구조. 팀 플랜 전환 시 ARPU 증가 가능. 단, 무료 대안 대비 가격 정당화 어려움.

## Major Risks
1. **핵심 리스크**: Dependabot + Renovate가 무료로 동일 기능 제공 — 유료 전환 설득 극히 어려움
2. AI 요약의 정확도 미달 시 개발자 신뢰 즉시 소실
3. 개발자는 도구에 돈 안 내는 문화 강함 (특히 1인 개발자)

## Critical Assumptions
- 무료 Dependabot을 사용 중인 개발자가 AI 요약 기능에 $9/월을 낼 의사가 있는가 (높은 불확실성)

# Idea 004. StaffStamp

## 제품
