# Idea 001. Return Express (반품 자동화 & 환불 추적)

## 제품
온라인 쇼핑의 반품 배송비 부담과 환불 지연을 없애고, 실시간 환불 추적과 배송비 무료화를 보장하는 자동화 플랫폼

## Target Customer
온라인 쇼핑 월 2회 이상 하는 직장인 (25~45세, 월 소득 ₩400만원 이상)

## Market Evidence
국내 온라인 쇼핑 반품 시장이 존재하고, 반품 배송비 부담은 심각한 pain point. 쿠팡은 Wow 멤버십(₩7,890/월)으로 무료 반품 제공하며, 이는 고객들이 반품 배송료를 줄이기 위해 "구독"을 선택함을 증명함.

## Existing Competitors
1. **Coupang Rocket Delivery Returns** - FREE for Wow members (₩7,890/month membership required)
   - 시장 점유율 높음, 쿠팡 생태계 내 완결
2. **Naver Smartstore Return Label** - FREE built-in feature
3. **11st Return Service** - Platform-specific, FREE

## Alternative Solutions
- 쿠팡의 Wow 멤버십으로 무료 반품 이미 제공
- 각 판매처별 자체 반품 정책 (무신사, 롯데 등 프리미엄 배송료 무료)
- 사용자가 배송비를 판매처에 직접 협상

## Pricing Evidence
**UNVERIFIED** - 구체적인 return express 유형 서비스 가격 정보 없음. 경쟁사 대부분 FREE.

## Customer Acquisition
**경쟁이 심한 방법들**:
1. 판매처 파트너십 (쿠팡, 무신사, 11번가에 반품 제휴)
2. SNS 마케팅 ("이번주 배송료 ₩2,500 절약!")
3. 첫 사용자 반품비 보조 (first month free)

**비용**: ₩0 예산으로 첫 10명 획득 어려움. 이미 쿠팡/무신사가 더 나은 솔루션 제공.

## MVP Cost
₩4,000,000 (manager estimate) - BUT 판매처 API 연동 거부 시 심각한 기술적 장벽

## Development Feasibility
**리스크**: 판매처 API 개방 거부 가능성 높음. 쿠팡은 경쟁이 되므로 협력 거부 가능성 높음.
- 기술적으로는 가능 (OCR, 배송사 API 연동)
- BUT 파트너십 확보 필수 (VC 자금 필요)

## Monetization
- 기본: 무료 (배송사 제휴 수수료 1%)
- 프리미엄: $4.99/월 (우선 환불 처리)
- B2B: 판매처 대시보드 (₩999,000/월)

**문제**: 배송사들이 수수료 1%를 주려고 할까? 반품 프로세스는 이미 최적화됨.

## Scalability
**저평가 가능성**: 
1. 사용자가 이미 쿠팡을 선택하면 쿠팡의 무료 반품 서비스로 충분
2. 멀티 플랫폼 반품 통합은 "nice-to-have" (must-have X)
3. 반품 빈도 낮음 (월 1회 정도) → 일일 사용 불가능

## Major Risks
1. **쿠팡 경쟁사**: 쿠팡 Wow 멤버십이 이미 대부분 커버 (월 ₩7,890)
2. **판매처 거부**: API 개방 거부 (경쟁 우려)
3. **법적 리스크**: 배송비 보조금의 법적 지위 불명확
4. **배송사 협력 부재**: 배송사가 왜 이 앱을 통해 정보를 노출할까?

## Critical Assumptions
- H1: 사용자가 배송료 비교를 위해 새 앱을 설치할까? (쿠팡이 더 쉬움)
- H2: 판매처들이 API를 개방할까? → **거부 가능성 매우 높음**
- H3: 배송사 제휴가 가능할까? → **마진율 1%는 너무 낮음**

# Idea 002. Ride Reliability Shield (신뢰도 기반 카풀 매칭)

## 제품
카풀 기사 취소를 줄이기 위해 신뢰도 스코어와 "취소 0 스트릭"을 시각화하는 카풀 오버레이 플랫폼

## Target Customer
출퇴근 직장인 (25~50세, 주 2회 이상 카풀/택시 이용), 정시 도착 중요

## Market Evidence
카풀/택시 취소는 명백한 pain point. 카카오맵, 네이버맵 모두 기사 평가 기능 제공. BUT 현재 평가는 "별점" 중심이고 "취소율"에 특화되지 않음. 신뢰도 기사 선택의 수요는 존재함.

## Existing Competitors
1. **Kakao Map/Kakao T** - Built-in driver rating (기사 평가 1~5점)
   - 취소율 데이터 제공하지 않음
2. **Naver Map/Naver Taxi** - Driver rating + Reviews
3. **Tata (타다)** - Driver scoring system
4. **Uber (Seoul pilot)** - Driver rating + Reliability metrics

## Alternative Solutions
- 카카오맵 자체 "기사 평가" 기능 사용
- 사용자가 직접 좋은 기사 선택 (경험 누적)
- 택시 기사 커뮤니티 (오프라인 입소문)

## Pricing Evidence
**UNVERIFIED** - 카카오맵, 네이버맵 기사 평가 기능은 모두 FREE. 타다, 우버의 신뢰도 점수도 FREE.

## Customer Acquisition
1. 카카오맵 사용자에게 overlay로 제시 (push notification)
2. 기사 신뢰도 데이터 먼저 축적 (3개월 쌓임)
3. SNS 공유 ("우리 동네 최고의 기사 TOP 3")

**₩0 예산**: 카카오맵 API 파트너십만으로 사용자 획득 가능 (IF API 개방)

## MVP Cost
₩2,500,000 (manager estimate) - reasonable

## Development Feasibility
**기술 리스크**: 카카오맵 API 개방이 필수. 카카오는 자체 기사 평가 강화 중이므로 경쟁으로 인식 가능.

## Monetization
- 기본: 무료 (카풀앱 광고 수익 공유)
- 프리미엄: $2.99/월 (우선 신뢰도 기사 예약)
- B2B: 카풀사 데이터 제공 (기사 성과 관리)

**문제**: 광고 수익 공유는 미미. 프리미엄 ₩3,500/월은 사용자가 지불할까? (주 2회 카풀이면 월 비용 큼)

## Scalability
**제한 요인**:
1. 카카오맵이 자체 취소율 추적 시작하면 경쟁력 상실
2. 기사 신뢰도 데이터 축적에 최소 3개월 필요
3. 한국만 사용 가능 (국내 카풀 시장)

## Major Risks
1. **카카오 경쟁**: 카카오가 자체 "취소율" 추적 시작 → Shield 가치 0
2. **기사 신뢰도 조작**: 기사가 다른 계정으로 자신 평가 올리기
3. **API 거부**: 카카오가 API 개방 거부 가능
4. **법적 문제**: 기사 평가 공개 (개인정보 논란)

## Critical Assumptions
- H1: 취소율 정보가 실제 기사 선택에 영향을 미칠까? → **의문**, 사용자는 이미 카카오 평가 신뢰
- H2: 카카오가 API 개방할까? → **거부 가능성 높음**
- H3: 사용자가 프리미엄 ₩3,500/월을 지불할까? → **아니오**

# Idea 003. Expense Auto-Logger (영수증 자동 인식 & 경비 분류)

## 제품
출장 경비의 영수증 스캔·입력·분류를 완전 자동화하고, 월별 경비 추이를 대시보드로 시각화하는 AI 앱

## Target Customer
출장 월 2회 이상 직장인 (30~55세), 기업 경비 담당자

## Market Evidence
**STRONG POSITIVE SIGNAL**: 
- Expensify: $5-9/user/month로 **이미 시장에 존재하며 사용자 선호**
- Concur: $7-18/user/month (SAP의 enterprise 솔루션)
- FreshBooks: $15-65/month (invoicing + expense)
- 모든 경쟁사가 **PAID** 구독 모델 → 사용자가 지불 의사 입증됨

**시장 크기**: 글로벌 경비 관리 시장 ~$5B, 국내 출장 경비 처리자 ~300만명

## Existing Competitors
1. **Expensify** - $5-9/user/month (가장 강력)
   - OCR 자동 인식 이미 제공
   - 기업 통합 강화됨
   - 시장 점유율 높음
2. **SAP Concur** - $7-18/user/month 또는 $5-12/report
   - Enterprise 강점
   - 자동 분류 + 예산 추적
3. **FreshBooks** - $15-65/month
   - 소규모 사업가용
   - 자동 분류 제한적

## Alternative Solutions
- 수동 엑셀 입력 (많은 기업이 여전히 사용)
- 직원이 영수증을 종이로 제출 (ERP 팀이 수동 입력)
- 경비 담당자 고용

## Pricing Evidence
**VERIFIED - HIGH CONFIDENCE**:
- Expensify: $60-108/user/year = $5-9/month
- Concur: $84-216/user/year = $7-18/month
- 모두 **PAID 구독** → 사용자가 지불 의사 있음

## Customer Acquisition
1. 기업 경비 담당자 타게팅 (LinkedIn, HR conference)
2. 첫 달 무료 체험
3. Expensify 대비 가격 경쟁 (더 저렴한 가격, 다국어 강조)
4. 기업 구매 프로세스 (VC funding necessary)

**₩0 예산으로 첫 10명**: 어렵지만 가능 (product hunt 런칭, 온라인 마케팅)

## MVP Cost
₩5,000,000 (manager estimate) - 합리적 (OCR API 비용 포함)

## Development Feasibility
**가능**: OCR API (Google Cloud Vision, AWS Textract) 사용으로 6주 내 MVP 가능
- 1인 개발자로 가능 (if 충분한 AI API 활용)
- 다국어 지원은 challenge (하지만 해결 가능)

## Monetization
- 기본: 무료 (기업 경비 정산 시 1% 수수료) → **수익성 낮음**
- 프리미엄: $7.99/월
- B2B: 기업 대시보드 $2,000/월

**현실적인 모델**: Expensify처럼 **$5-10/user/month 구독**

## Scalability
**강한 확장성**:
1. 글로벌 경비 시장 매우 큼 ($5B)
2. Expensify이 이미 증명한 시장 (unicorn 도달)
3. 다국어 + 지역화로 한국/일본 특화 가능
4. 기업 수가 증가함에 따라 수요 증가

## Major Risks
1. **Expensify 경쟁**: 이미 강력한 시장 점유 (가장 큰 위협)
2. **OCR 정확도**: 손글씨, 영어 이외 언어 인식 어려움 (BUT 개선 가능)
3. **기업 통합 복잡성**: 각 회사 ERP 다름 (integration 비용 높음)
4. **구매 주기 길음**: B2B 영업 6개월 이상

## Critical Assumptions
- H1: OCR 정확도 95% 이상 달성 가능? → **YES, 가능** (Google Vision 95%+)
- H2: 기업이 Expensify에서 이탈할까? → **가능, IF 가격/기능 경쟁**
- H3: 다국어 지원이 강점이 될까? → **YES, 한국/일본 특화**

# Idea 004. Real-Time Reservation Sync (레스토랑 테이블 통합 예약)

## 제품
배민·다이닝코드·점메뉴 모든 플랫폼의 테이블 정보를 실시간으로 동기화하고, 이중예약을 완전히 제거하는 통합 예약 플랫폼

## Target Customer
직장인 (25~45세), 점심 시간 정해진 회사, 주 3회 이상 외식

## Market Evidence
점심 시간 예약 pain은 실제. BUT:
- Coupang Eats, Baedal Minjok 등 음식 배달은 **FREE 테이블 조회**
- Diningcode 같은 예약 앱도 대부분 **FREE**
- 이중예약은 "자체 실수" (여러 앱 접근)

## Existing Competitors
1. **Coupang Eats** - FREE table reservation
2. **Baedal Minjok (배민)** - FREE (commission 5.8%)
3. **Diningcode** - FREE table lookup
4. **CatchTable** - FREE reservation platform
5. **점메뉴** - FREE

## Alternative Solutions
- 배민 앱 하나에서 테이블 예약 + 주문 (완결성)
- 전화로 직접 예약
- 식당 방문 시 대기

## Pricing Evidence
**UNVERIFIED - ALL COMPETITORS FREE**
- 모든 경쟁사가 FREE 제공
- 수익은 배달 commission 또는 광고에서 발생
- 예약 자체로는 수익 창출 안 함

## Customer Acquisition
1. SNS 마케팅 ("이중예약 방지")
2. Baedal Minjok 사용자에게 리타겟팅
3. 점심 시간 push notification

**₩0 예산**: App store 최적화, 온라인 마케팅

## MVP Cost
₩3,500,000 (manager estimate) - reasonable

## Development Feasibility
**기술 리스크 높음**:
- 배민 API: 개방할까? (경쟁으로 인식)
- 다이닝코드 API: 개방 여부 불명확
- 실시간 동기화: API 폴링 비용 높음

## Monetization
- 기본: 무료 (예약 수수료 없음)
- 프리미엄: $3.99/월 (우선 예약 + 특가 쿠폰)
- B2B: 식당 대시보드 $500/월

**현실**: 무료 경쟁이 심해서 수익 모델 약함

## Scalability
**제한 요인**:
1. 예약 앱은 배민이 이미 통합 (배민 + 배달 + 예약 = 완결)
2. 이중예약은 "앱 선택" 문제지, 앱 내 문제 아님
3. 식당 다중 시스템 운영에 거부감 (복잡성)

## Major Risks
1. **배민이 자체 강화할 수 있음**: 배민 내에서 "다른 앱 예약 동기화" 기능 추가
2. **API 거부**: 각 플랫폼이 API 개방 거부 가능
3. **식당 협력 부족**: 식당들이 여러 예약 시스템 운영에 피로
4. **법적 문제**: 다른 플랫폼 데이터 수집 (약관 위반 가능)

## Critical Assumptions
- H1: 사용자가 이미 아는 배민 대신 새 앱을 설치할까? → **아니오**
- H2: API 개방 가능할까? → **거부 가능성 높음**
- H3: 이중예약 방지가 실제로 작동할까? → **동기화 지연 문제**

# Idea 005. Insurance Claim Speedrun (보험 청구 자동화)

## 제품
복잡한 보험 청구 서류를 AI가 자동으로 작성·제출하고, 청구 진행 상황을 실시간 추적하는 플랫폼

## Target Customer
전세금 미반환·보험금 청구 필요 사람 (35~65세), 의료·손해보험 사용자

## Market Evidence
보험 청구는 심각한 pain point (3개월 이상 대기, 서류 복잡함). BUT:
- **기존 경쟁사 없음** (unique market gap)
- 보험사들은 각자 청구 시스템 보유 (폐쇄형)
- 개인이 직접 청구 (법무사 고용하거나)

## Existing Competitors
1. **법무사 상담** - 수수료 수백만원 (PAID)
   - 자격 있는 전문가
   - 신뢰 높음
2. **보험사 자체 시스템** - FREE
   - 직관성 낮음
   - 전화 확인 필수
3. **LawTech 스타트업** - 국내 거의 없음

## Alternative Solutions
- 법무사 직접 상담 (수백만원, 하지만 정확함)
- 보험사 고객센터 (FREE, 느림)
- 인터넷 자료 검색 + 수동 작성

## Pricing Evidence
**UNVERIFIED - 기존 경쟁 서비스 없음**
- 법무사 수수료: $500-2,000 (one-time)
- 보험사 청구: FREE

## Customer Acquisition
1. 전세금 미반환 커뮤니티 (당근마켓, 오늘의집)
2. SNS 마케팅 ("서류 자동 작성")
3. 법무사 파트너십

**₩0 예산**: 커뮤니티 마케팅, 입소문

## MVP Cost
₩4,500,000 (manager estimate) - reasonable BUT 법무사 협력 필수

## Development Feasibility
**법적 리스크 높음**:
- AI 자동 서류 작성 = "법적 조언"인가? (법조계 거부 가능)
- GDPR/개인정보보호 복잡
- 보험사 제휴 필수

## Monetization
- 기본: 무료 (보험사 제휴 수수료)
- 프리미엄: $19.99/회 청구 (법무사 상담 포함)
- B2B: 보험사 제휴 (청구 접수 시스템)

**현실**: 보험사가 자체 시스템 강화할 것 → 제휴 어려움

## Scalability
**제한 요인**:
1. 보험 상품별로 필요 서류 다름
2. 법률 변경 시 자동 업데이트 필수
3. 보험사 제휴 확보 어려움
4. 낮은 사용 빈도 (일생 1~3회)

## Major Risks
1. **법적 리스크**: AI가 "법적 조언" 제공하는 것 아닌가? (변호사협회 이의 가능)
2. **성공률**: 자동 작성 실패 시 신뢰도 추락
3. **보험사 거부**: 보험사들이 제휴 거부 가능
4. **저빈도**: 사용자가 생애 1~3회만 사용 → 중복 사용 없음

## Critical Assumptions
- H1: 자동 작성 서류 성공률 95% 이상? → **의문스러움** (법률 복잡)
- H2: 보험사 제휴 가능? → **아니오, 거부 가능성 높음**
- H3: 사용자가 자동 생성 서류 신뢰? → **낮음, 법무사 상담 선호**

# Idea 006. Supplier Payment Guardian (납품업체 대금 추적 & 자동 알림)

## 제품
중소기업의 공급업체 대금을 통합 추적하고, 지급 기한 전에 자동 알림으로 미지급·분쟁을 방지하는 B2B 플랫폼

## Target Customer
중소기업 회계담당자·경영자 (35~60세), 공급업체 10개 이상

## Market Evidence
**STRONG POSITIVE SIGNAL**:
- Xero: $25-90/month (invoicing + supplier tracking)
- FreshBooks: $15-65/month (invoice + expense)
- 모두 PAID → 기업이 지불 의사 입증됨
- 글로벌 supply chain 자동화 시장 $10B+

## Existing Competitors
1. **Xero** - $25-90/month
   - Supplier invoice tracking 포함
   - 강력한 시장 점유
2. **FreshBooks** - $15-65/month
   - Invoice tracking + invoicing
3. **NetSuite** - Custom pricing (Enterprise)
4. **SAP Ariba** - Custom pricing (Enterprise)

## Alternative Solutions
- 엑셀 수동 관리 (많은 중소기업 현재 상황)
- ERP 시스템 (SAP, Oracle - 비쌈)
- 보조금융 (factoring - 비쌈)

## Pricing Evidence
**VERIFIED - HIGH CONFIDENCE**:
- Xero: $25-90/month = supplier + accounting
- FreshBooks: $15-65/month = invoicing + expense

## Customer Acquisition
1. 중소기업 회계담당자 타게팅 (LinkedIn, Chamber of Commerce)
2. 첫 달 무료 체험
3. Xero보다 저렴한 가격 ($15-20/month) + 한국 특화
4. 은행 연동 (계좌 자동 연결)

**₩0 예산**: 온라인 마케팅, 제휴 (은행, 신보)

## MVP Cost
₩3,500,000 (manager estimate) - reasonable

## Development Feasibility
**기술 가능**:
- PDF invoice 파싱: Google Cloud Vision
- 은행 연동: 한국 오픈뱅킹 API
- 알림: 카톡, 이메일 API

**1인 개발 가능** (if using AI APIs)

## Monetization
- 기본: 무료 (은행 연동 수수료 0.5%)
- 프리미엄: $29.99/월 (무제한 자동 지급)
- B2B: API 연동 (ERP와 자동 동기화, $2,000/월)

**현실적 모델**: **$15-25/month 구독** (Xero와 경쟁)

## Scalability
**강한 확장성**:
1. 글로벌 공급망 자동화 시장 $10B+
2. Xero가 이미 시장 검증 (지불 의사 증명)
3. 한국/일본 특화로 차별화
4. B2B SaaS로 높은 확장성

## Major Risks
1. **Xero 경쟁**: 이미 강력한 시장 점유 (가장 큰 위협)
2. **OCR 정확도**: 다양한 invoice 양식 (해결 가능)
3. **은행 보안**: 은행 계정 연동 사용자 거부감
4. **통합 비용**: 각 회사 ERP 다름

## Critical Assumptions
- H1: OCR 정확도 98% 이상? → **YES, 가능**
- H2: 기업이 Xero에서 이탈할까? → **가능, IF 가격/기능 경쟁**
- H3: 은행 계정 연동에 동의할까? → **YES, SMB는 자동화 선호**

# Idea 007. Freelancer Escrow Safe (프리랜서 계약금 보호)

## 제품
프리랜서 선급금 분쟁을 완전 차단하기 위해 자동 에스크로 + 계약서 자동 분석 + 분쟁 중재를 제공하는 플랫폼

## Target Customer
프리랜서·개발자·디자이너 (25~45세), 선급금 거래 경험 있음

## Market Evidence
**경쟁사 부분 검증**:
- CrowdWorks: Commission-based (5-20%) + 에스크로 기능 포함
- Lancer.jp: Commission (5-20%)
- 모두 **PAID commission** → 사용자가 이미 지불 중

BUT:
- 에스크로는 "기본 기능"이지 "차별화 포인트" 아님
- 프리랜서 플랫폼 자체가 이미 에스크로 제공

## Existing Competitors
1. **CrowdWorks** - FREE (commission-based)
   - 에스크로 이미 포함
   - 일본 시장 점유율 높음
2. **Lancer.jp (Lancers)** - 5-20% commission
   - 에스크로 포함
3. **Upwork** - Commission 5-20%
   - 에스크로 + 분쟁 중재 포함

## Alternative Solutions
- CrowdWorks/Lancer.jp 자체 에스크로 사용
- 은행 에스크로 (수수료 비쌈)
- 신뢰 기반 선금 (위험)

## Pricing Evidence
**UNVERIFIED - 에스크로는 FREE in CrowdWorks/Lancer**
- Commission 모델이므로 subscription 없음
- $9.99/월 premium은 검증되지 않음

## Customer Acquisition
1. 프리랜서 커뮤니티 (Reddit, Facebook groups)
2. CrowdWorks/Lancer 사용자 리타게팅
3. SNS 마케팅 ("선금 보호")

**₩0 예산**: 커뮤니티 마케팅

## MVP Cost
₩5,000,000 (manager estimate) - BUT 금융 라이센스 필수

## Development Feasibility
**규제 리스크 매우 높음**:
- 에스크로 관리 = "금융 라이센스" 필수 (한국: 전자금융감독규제)
- 자금 보관 = 신탁 계약 필수
- 변호사 협력 필수
