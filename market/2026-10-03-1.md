# Idea 001. MeetCredit — 회의 시간을 보상 크레딧으로

## 제품
직장인이 회의에 참석하면 크레딧을 획득하고 월말에 현금화/선물카드로 환급하는 플랫폼

## Target Customer
대기업/중견기업 직장인, 특히 회의 많은 화이트칼라 (20~50대)

## Market Evidence
- Pain: 직장인 61% 번아웃, 월 40~60시간 회의 (Manager 보고)
- 보상 심리는 검증된 수요 (라이브 커머스, Duolingo 스트릭 성공)
- 한국 회사원 문화에서 회의 과부하는 만연

## Existing Competitors
- **Pointagram**: Slack/Teams 내 게임화 보상 앱 (무료/저가)
- **SweetKudos**: 직원 인정 플랫폼 (무료/저가)
- **Asante Bot**: Slack 보상 게임화 (무료)
- Matter: $0 (기본) ~ 소액 수수료

## Alternative Solutions
- Slack/Teams 기본 이모지 (무료)
- 회사 인트라넷 (무료, 내부)
- 카페 음료 쿠폰 (오프라인, 기업이 직접 관리)

## Pricing Evidence
경쟁 솔루션들이 **무료 또는 저가($10 이하)**로 포지셔닝
→ CEO Directive 반영: **부정적 신호** (시장 검증이 아니라, 저가 대체재 존재)

## Customer Acquisition
- 기업 IT/HR 담당자 대상 B2B 영업 (1인 가능)
- Slack/Teams 앱마켓 노출 (낮은 획득 비용)
- 직원 추천 (내부 바이럴 가능)

## MVP Cost
200만원 (Manager 보고) → **300만원 이내 달성** ✓

## Development Feasibility
- Slack/Teams API 활용
- 음성 API (Google/Azure) 사용
- 결제 (Stripe) 통합
→ **1인 개발 충분함** ✓

## Monetization
- B2B 구독: 월 직원당 2,000~5,000원
- 크레딧 현금화 수수료: 10~15%
- 제휴 수익 (카페 상품권)
→ **현실적이나**, 고객이 실제로 크레딧을 현금화할지 불명확

## Scalability
- Slack/Teams 의존도 높음 (플랫폼 정책 변화 위험)
- B2B 모델이므로 계정 당 높은 LTV 가능
- 글로벌 확장 가능 (다국어 지원 필요)

## Major Risks
1. **기업 정보보안**: 음성 기록 거부 (규정상 문제)
2. **플랫폼 의존도**: Slack/Teams 정책 변화에 취약
3. **사용자 참여도**: 실제 크레딧이 동기 부여가 될지 검증 필요
4. **무료 경쟁자 다수**: Pointagram 등이 이미 무료로 제공

## Critical Assumptions
1. 직장인이 회의 크레딧에 실제로 동기 부여되는가?
2. 기업이 "직원 회의 참석 유도"를 위해 라이선스 구매하는가?
3. 음성 기록에 대한 보안/프라이버시 우려를 해결할 수 있는가?

# Idea 002. SafeJeonse — 부동산 사기자 블랙리스트 커뮤니티

## 제품
전세/월세 거래 시 집주인/중개사의 신뢰도를 커뮤니티가 평가하는 플랫폼

## Target Customer
전월세 계약자, 특히 2030 세입자

## Market Evidence
- Pain: 전세 사기 연 1,000건+, 사기자 신원 확인 부족 (실제 데이터)
- 이미 안전집사(HUG 보증보험), 집품(리뷰) 등 경쟁 솔루션 존재
- 전세 사기는 계속 발생하는 반복적 Pain

## Existing Competitors
- **안전집사**: HUG 보증 보험 기반 (무료/저가)
- **집품**: 부동산 거주후기 + 보증금 리포트 (무료)
- **당근마켓**: 부동산 매물 + 평판 (무료)
- **다방**: 부동산 앱 (무료)
- **네이버 부동산**: 평판 기능 (무료)

## Alternative Solutions
- 경찰청 신고 (무료, 느림)
- 변호사 상담 (유료, 비쌈)
- 공인중개사협회 (기존 제도)
- 신용조회 회사 수동 검색 (유료)

## Pricing Evidence
경쟁 솔루션 **모두 무료** → **강한 부정적 신호** (CEO Directive 반영)
사용자가 무료 대안이 충분할 때 유료로 전환할 유인 매우 약함

## Customer Acquisition
- 부동산 커뮤니티 (오늘의집, 당근) 크로스 프로모션
- 부동산 관련 SNS (부동산 관심층)
- 세입자 커뮤니티 (대학가, 신혼부부 커뮤니티)

## MVP Cost
250만원 (Manager 보고) → **가능**

## Development Feasibility
- 부동산 DB 크롤링 (공개 정보)
- 리뷰 + 평점 시스템 (표준 구현)
- 신고 폼 + 검증 로직
→ **1인 개발 충분** ✓

## Monetization
- 기본 무료 (신고 기반)
- 프리미엠: 월 9,900원 (상세 이력, 법률 상담)
- B2B: 중개사 평판 관리 (월 30,000원)

**문제**: 사용자가 이미 무료 대안 사용 중일 때, 월 9,900원 결제 전환율 5% 이상 달성 어려움

## Scalability
- 사용자 수 ↑ = 신고 수 ↑ = 신뢰도 ↑
- 지역별 확장 가능 (부동산은 지역 중심)
- 그러나 초기 데이터 부족 문제 (cold start)

## Major Risks
1. **무료 경쟁자**: 안전집사, 집품이 이미 무료로 제공
2. **허위 신고**: 악의적 신고로 명예훼손 소송 위험
3. **법적 책임**: 신고 정보의 정확성 보증 문제
4. **냉시작(Cold Start)**: 초기 신고 데이터 없으면 가치 0

## Critical Assumptions
1. 무료 대안(안전집사, 집품)이 존재할 때, 사용자가 유료 프리미엄으로 전환하는가?
2. 커뮤니티 신고가 실제로 정확한가? (오류율 < 10%)
3. 월 신고 100건 이상 지속적으로 축적 가능한가?

# Idea 003. ClaimAI — 의료보험 자동 이의제기 어시스턴트

## 제품
의료보험 거절 통지를 자동 분석하고 이의제기 편지를 AI가 생성해주는 서비스

## Target Customer
의료보험 가입자, 특히 중증질환/수술 환자 (40~70대)

## Market Evidence
- Pain: 의료보험 청구 거절 85.8%, 평균 미지급액 1,618만원
- **경쟁자 성공 사례**: Claimable (80-87% 성공률, 10일 이내 해결, $30M 회수)
- 미국: 1인 5명 중 1명이 청구 거절 경험, 그러나 **1% 미만만 항소** → 큰 기회
- 한국: 의료분쟁 조정 건수 연 증가

## Existing Competitors
- **Claimable** (미국): 87% 성공률, 무료 또는 $40 (성공 수수료 기반)
  - 이미 $30M+ 회수 → **강한 검증된 경쟁자**
- **AppealIt**: 무료 (비영리 지원)
- **MARSHALL**: AI 법률 자동화
- **Overturn**: 보험 청구 분쟁

## Alternative Solutions
- 개인 변호사 상담 (월 $500~5,000)
- 의료 소비자 보호 단체 (무료, 느림)
- 보험사 내부 항소 절차 (무료, 매우 낮은 승률)

## Pricing Evidence
경쟁자 Claimable이 **무료 또는 $40/건** (성공 수수료 모델)
→ CEO Directive: **중립~약간 긍정** (성공 수수료는 고가에 준함)

## Customer Acquisition
- 병원/의료기관 제휴 (환자 소개)
- 보험사 커뮤니티/포럼 (SEO)
- Reddit/SNS 의료 상담 커뮤니티 (오가닉)
- Google Ads (높은 CPA 예상)

## MVP Cost
300만원 (Manager 보고) → **한계에서 달성**

## Development Feasibility
- 의료 서류 OCR (Google Vision API)
- 보험사 기준 DB 구축 (수작업, 변호사 자문 필요)
- 이의제기 템플릿 (법률 검토 필수)
→ **1인 개발 가능하나**, 법률 검토 비용 추가 필요

## Monetization
- 성공 수수료: 회수액의 20~30%
- 월 구독: 9,900원 (무제한 분석)
- B2B: 의료기관 (환자 상담용)

**긍정 신호**: Claimable의 성공 사례로 시장 검증됨
**부정 신호**: 성공 수수료는 높지만, 실패 시 수익 0

## Scalability
- 의료 분쟁은 계속 발생 (recurring)
- 성공 사례 ↑ = 입소문 ↑ (바이럴 가능)
- AI 모델 개선 → 성공률 ↑ → 더 높은 수수료 가능
- 미국 성공 후 다국가 확장 가능

## Major Risks
1. **법적 책임**: 부당한 이의제기로 인한 손해배상 (변호사 보험 필수)
2. **규제**: 의료 AI 규제 미정, 금감원 승인 필요할 수도
3. **보험사 API 미개방**: 자동화의 한계
4. **성공률 보증**: 실제 성공률이 50% 미만일 경우 비즈니스 붕괴

## Critical Assumptions
1. 한국 의료보험사도 미국처럼 항소에 대해 **50% 이상 승인**하는가?
2. 이의제기 AI의 성공률이 **50% 이상** 달성 가능한가?
3. 사용자가 성공 수수료 **20~30%를 지불**하는가? (회수액의 ⅓ 상실)
