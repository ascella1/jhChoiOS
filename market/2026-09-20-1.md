# Idea I001 펫닥터 프라이스

## 제품
반려동물 진료 영수증을 익명 업로드해 지역·시술별 가격 분포를 비교하는 커뮤니티형 가격 투명화 서비스.

## Target Customer
반려동물 보호자, 특히 수술·중증 진료 전 병원을 비교하려는 사람. 1차 결제자는 개인 소비자(B2C), 2차 수익원은 펫보험사·병원 제휴.

## Market Evidence
- 정부(농식품부)가 동물병원 진료비 현황 공개시스템(animalclinicfee.or.kr)을 이미 운영 중 — "가격 비교"라는 니즈 자체는 정부도 인정한 실수요다.
- 한국 반려동물 의료 시장은 2024년 약 2조원 → 2027년 약 3.3조원 전망(연 10% 내외 성장), 반려가구 평균 의료비는 2년 새 57.7만원 → 102.7만원으로 급증. [이투데이/마켓인]
- 반려가구 수는 약 591만(2024년 말, 전체 가구의 26.7%), 넓게는 "반려동물 양육 인구" 1500만명 수준으로 언급됨.

## Existing Competitors
- **펫트라슈(PetRaschu)**: 위치 기반 평균가·최저가·최고가 조회, 증상별 검색, AI 후기 — 이 아이디어와 기능이 거의 동일한 선발 앱. 앱스토어에 실존.
- **마이펫플러스**: 동물병원 가격비교 + 용품 판매 앱.
- **정부 공개시스템(animalclinicfee.or.kr)**: 11개 표준 항목의 최저/최고/평균/중간가를 전국·시도·시군구 단위로 무료 공개.

## Alternative Solutions
병원에 직접 전화해 견적 문의, 네이버 카페·맘카페 후기 검색, 지인 추천. 이미 "발품 비교"가 관행으로 자리잡음.

## Pricing Evidence
펫트라슈·마이펫플러스 모두 검색 결과상 유료 구독 요금이 확인되지 않음(광고/제휴 기반 무료 앱으로 추정). **경쟁사의 실제 유료 가격을 확인하지 못함 → 지불 의사 점수 상한 8점 적용.**

## Customer Acquisition
"바가지 쓸 뻔했다" 경험 공유는 맘카페·펫 커뮤니티에서 자연 확산 가능성이 있음(이타적 공유 동기). 다만 이미 펫트라슈가 유사 포지션을 선점해 신규 진입 시 차별화 메시지가 필요.

## MVP Cost
슬개골 탈구·스케일링 등 소수 시술 항목 + 지도 기반 가격 비교 웹앱. 약 250만원 이내(OCR API 사용) — 검증 가능한 범위.

## Development Feasibility
OCR API(Upstage/Naver Clova 등) + 표준화 룰 엔진으로 1인 개발 가능. 기술 난이도는 낮음.

## Monetization
프리미엄 히스토리, 병원 리스팅 광고, 펫보험사 리드 제휴 — 모두 간접적(광고/제휴) 수익원이며 구독료를 직접 받을 근거는 약함.

## Scalability
전국 단위 데이터가 쌓일수록 가치가 커지는 네트워크 효과형 구조지만, 콜드스타트(초기 영수증 확보)를 넘지 못하면 확장 자체가 시작되지 않음.

## Major Risks
1. 펫트라슈라는 사실상 동일 컨셉의 선발주자 존재 — 차별화 실패 시 "미투" 앱으로 전락.
2. 정부 공개시스템이 이미 무료로 유사 기능 제공 — "왜 이 앱을 또 써야 하는가"에 대한 답이 약함.
3. 콜드스타트: 영수증 데이터 없이는 가격 비교 자체가 불가능.

## Critical Assumptions
- 사람들이 실명 없이도 영수증을 자발적으로 업로드할 만큼 이타적 동기가 강하다(미검증).
- 펫트라슈·정부시스템 대비 "이 앱만의" 차별점(OCR 자동화, 과잉진료 하이라이트)이 실제 전환을 만든다(미검증).
- **가격 정보 미검증**: 경쟁 앱들의 유료화 여부/가격을 확인하지 못함.

# Idea I002 관리비 감사관

## 제품
K-APT 공공데이터로 우리 단지 관리비를 유사 단지와 비교하고 이상 항목을 하이라이트하는 월간 확인형 서비스.

## Target Customer
아파트·오피스텔 입주민(자가·임차 무관). 결제 주체는 개인 소비자, 잠재 B2B는 이의제기 대행업체 제휴.

## Market Evidence
- 전국 아파트 관리비 총액은 약 1066만 가구가 연간 24조원을 지출 — 시장 자체는 거대하다. [이투데이]
- 국토교통부·한국부동산원이 K-APT(공동주택관리정보시스템)를 통해 **이미 "인근 단지와 관리비 비교" 기능을 무료로 제공** 중이며, 최근 GIS 기반 지도 비교 서비스까지 추가함. [edaily, 부동산114]

## Existing Competitors
- **K-APT 공공시스템**: 관리비 비교, 공사·용역 사업비 비교, 유지보수 이력까지 무료 공개 — 이 아이디어가 하려는 핵심 기능을 정부가 이미 하고 있음.
- **아파트아이**: "국내 1위 아파트앱"으로 관리비 조회 등 생활 서비스 통합 제공.

## Alternative Solutions
K-APT 웹사이트 직접 조회, 관리사무소 문의, 입주자대표회의를 통한 이의제기.

## Pricing Evidence
K-APT는 무료 공공서비스이며, 관리비 비교를 유료로 파는 민간 서비스의 가격을 확인하지 못함. **경쟁 가격 미확인 → 지불 의사 상한 8점 적용.**

## Customer Acquisition
"우리 단지 관리비 랭킹" 캡처를 입주민 단톡방에 공유하는 바이럴 루프는 그럴듯하나, K-APT를 그냥 검색해도 같은 정보를 무료로 얻을 수 있어 설치 유인이 약함.

## MVP Cost
공공데이터 API 무료 활용 시 약 200만원 이내로 검증 가능.

## Development Feasibility
공공 API 연동 + 비교 UI 정도로 1인 개발 난이도는 낮음.

## Monetization
프리미엄 리포트, 이의제기 대행 제휴 수수료 — 그러나 원본 데이터와 비교 기능 자체가 무료로 이미 존재하므로 "무엇에 돈을 낼 것인가"가 불명확.

## Scalability
전국 단지로 손쉽게 확장 가능(공공데이터 기반)하지만 수익화 상한이 낮아 사용자 수 증가가 매출 증가로 잘 이어지지 않음.

## Major Risks
1. 정부가 이미 무료로 거의 동일한 비교 기능을 제공 — 가장 큰 리스크.
2. 이상탐지가 실제 위법 여부를 보장하지 못해 이의제기 시 신뢰성 문제.
3. "재미로 한 달에 한 번 보는" 정도의 동기로는 유료 전환이 어려움.

## Critical Assumptions
- UX/자동알림이 K-APT 직접 조회보다 충분히 낫다는 차별점이 실제 설치·재방문으로 이어진다(미검증).
- **가격 정보 미검증**: 프리미엄 리포트에 실제로 얼마를 낼지 확인된 사례 없음.

# Idea I003 Dependency Digest

## 제품
GitHub Dependabot이 쏟아내는 개별 PR을 AI가 위험도별로 그룹핑·요약해 주간 다이제스트로 만들어주는 GitHub App.

## Target Customer
GitHub 저장소를 운영하는 개발팀·오픈소스 메인테이너. B2B(팀/조직) 구독 또는 개인 유료 사용자.

## Market Evidence
- Dependabot PR 노이즈는 실존하는 문제: Microsoft의 오픈소스 라이브러리 GCToolkit은 2026년 7월 기준 578개 커밋 중 92개(약 1/6)가 Dependabot 버전업 커밋이었고, 최근 12개월간 61건 발생. [dev.to 사례]
- 그러나 **GitHub이 2026년에도 계속 네이티브 기능으로 이 문제를 직접 해결 중**: 2023년 그룹 업데이트 베타 → 2026년 2월 "여러 디렉터리에 걸친 동일 의존성 그룹핑" 정식 출시 → 2026년 중반 기본 쿨다운(cooldown) 기능까지 롤아웃. [github.blog changelog]

## Existing Competitors
- **Renovate(Mend.io)**: 무료 오픈소스 CLI + 무료 호스팅 Community 버전 + 유료 Enterprise. 사실상 이 아이디어와 동일한 기능(그룹핑, 자동 병합 규칙)을 무료로 제공하는 가장 강력한 경쟁자.
- **GitHub 자체 네이티브 기능**: 그룹 업데이트, 쿨다운 — 플랫폼이 직접 기능을 흡수 중.
- **Snyk**: 의존성 보안/리스크 평가 인접 카테고리에서 **$25/개발자/월**(연간 청구, "기여 개발자" 기준)의 확인된 가격 — 개발자가 의존성 관련 도구에 실제로 지불한다는 증거이자, 동시에 이 가격대가 이미 시장에 형성돼 있다는 것을 보여줌. [Snyk 공식 요금 페이지 인용]

## Alternative Solutions
매일 PR을 수동으로 훑어보기, Dependabot 설정 파일(dependabot.yml)로 스케줄·그룹 규칙 직접 관리, GitHub Actions로 자동 병합 워크플로우 직접 작성.

## Pricing Evidence
Renovate는 무료(가격=$0, 확인됨), Snyk는 $25/개발자/월(확인됨, 인접 카테고리). **직접 경쟁 제품(그룹핑 다이제스트)의 가격은 정확히 일치하지 않지만, 카테고리 내 실제 유료 가격(Snyk)과 무료 기준선(Renovate)이 모두 확인되어 지불 의사 상한 규칙(8점 캡)은 적용하지 않는다.**

## Customer Acquisition
GitHub Marketplace 리스팅 + README 배지를 통한 오픈소스 커뮤니티 자연 확산 — 개발자 대상 self-serve 채널로는 1인 개발자에게 상대적으로 우호적.

## MVP Cost
GitHub App으로 Dependabot PR을 읽어 요약 코멘트를 다는 최소 기능. 약 150만원 이내(LLM API 비용 위주)로 검증 가능.

## Development Feasibility
GitHub API + LLM 요약만으로 구현 가능해 1인 개발 난이도는 낮음.

## Monetization
GitHub Marketplace 결제 연동 저장소당/조직당 구독 — 결제 인프라는 이미 존재하나, 핵심 경쟁자(Renovate)가 무료라는 점이 구독 전환율을 구조적으로 제한.

## Scalability
사용량 기반 인프라(리포지토리 수)로 한계비용이 낮아 확장 자체는 쉽다. 문제는 확장의 "질"이 아니라 "가격을 받을 수 있는가"이다.

## Major Risks
1. **플랫폼 리스크가 매우 현재진행형**: GitHub이 2026년에도 계속 이 문제를 무료로 직접 해결 중 — Manager 문서도 인지했지만, 실제 조사 결과 이미 상당 부분 흡수됐음이 확인됨.
2. Renovate라는 무료 오픈소스 강자가 유사 기능을 선점.
3. "AI 요약"이라는 차별점이 GitHub 네이티브 기능 개선 속도를 계속 앞서야 존속 가능.

## Critical Assumptions
- GitHub 공식 기능이 계속 개선돼도 "AI 위험도 요약·설명"이라는 부가가치에 개발자/팀이 별도로 지불한다(부분 검증 — Snyk 사례로 카테고리 지불 의사는 확인되나 정확히 이 기능에 대해서는 미검증).
- 오픈소스 확산 전략이 유료 조직 고객 전환으로 이어진다(미검증).

# Idea I006 클레임 워치

## Target Customer
반려동물보험 가입자(미국 중심).

## Market Evidence

## Existing Competitors
- **Fetch**: 자체 앱에서 청구 제출·상환 추적 기능 제공(앱스토어 평점 4.8 — 경쟁 펫보험사 대비 최고 평점으로 인용됨).
- **Pumpkin**: 계정 내 "Claims" 메뉴에서 청구 상태를 실시간 추적 가능.
- **Trupanion**: 온라인 제출 시 실시간 진행 상황 추적, 청구의 70% 이상이 24시간 내 지급.

## Alternative Solutions
보험사 앱/웹사이트 직접 확인, 고객센터 전화 문의.

## Pricing Evidence
Fetch·Pumpkin·Trupanion의 청구 추적 기능은 모두 보험료에 포함된 무료 기본 기능이며, 이를 대체하는 3rd-party 유료 트래커의 가격을 찾지 못함. **경쟁 가격 미확인 → 지불 의사 상한 8점 적용.**

## Customer Acquisition
펫 커뮤니티·포럼을 통한 접근은 가능하나, 대상 자체가 "보험 가입 + 청구 경험" 교집합이라 좁음.

## MVP Cost
수동 입력 트래커 + 랭킹 게시판. 약 200만원 이내로 검증 가능.

## Development Feasibility
보험사 API 연동이 없어 수동 입력 의존 — 기술 난이도는 낮으나 데이터 신뢰성이 구조적으로 약함.

## Monetization
보험 비교·가입 제휴 수수료 모델은 이미 Pawlicy Advisor류의 펫보험 비교 사이트가 선점 중이며, "청구 트래커"라는 좁은 기능이 그 자체로 리드 획득 채널이 되기엔 트래픽이 제한적.

## Scalability
청구는 반려동물이 아플 때만 발생하는 저빈도 이벤트라 재방문·확장의 자연스러운 동력이 약함.

## Major Risks
1. 주요 보험사들이 이미 자사 앱에서 청구 추적 기능을 무료로, 심지어 고평점으로 제공 중 — 대체할 이유가 약함.
2. 보험사 API 연동 부재로 데이터가 수동 입력에 의존해 신뢰도가 낮음.

# Idea I010 노콜 견적

## 제품
전화 없이 채팅/폼으로만 표준화된 차량 매입·견적을 받고 검증된 매물만 노출하는 서비스(한국 중고차 + 일본 자동차 견적).

## Target Customer
중고차를 사거나 팔려는 소비자(한국), 차량 매각/차검 견적을 받으려는 소유자(일본).

## Market Evidence
- 한국 중고차 시장 규모는 2026년 약 35조원(달러 기준 약 251.6억 달러), 2026년 상반기 실거래 111만 5,333대. 거대한 TAM.
- 하지만 이 정확한 pain(전화 없이 비대면으로 딜러 경쟁입찰)은 **이미 한국에서 지배적 사업자가 해결 중**: 헤이딜러는 "7년 연속 중고차판매플랫폼 브랜드 선호도 1위", 월 5만대 경매 출품, 40만 건 이상의 딜러 입찰이 진행되는 국내 1위 서비스이며, 연락처는 판매 요청 전까지 비공개(전화 없는 비대면 구조)로 이미 운영 중.
- 일본에서도 유카팩이 "복수 업체로부터의 영업 전화 없음"을 명시적으로 내세운 서비스로 이미 존재.

## Existing Competitors
- **헤이딜러(한국)**: 이 아이디어와 사실상 동일한 컨셉의 압도적 시장 1위. 딜러 낙찰 수수료는 셀프 방식 기준 차량가 500만원 이상 23.5만원, 3001만원 이상 34.5만원, Zero 방식은 1000만원 이하 29만원~4001만원 이상 49만원까지 구간별로 확정돼 있으며, 거래 성사 시에만 청구.
- **유카팩(일본)**: "영업 전화 없음"을 명시한 일괄 견적 서비스.

## Alternative Solutions
지인을 통한 직거래, 동네 중고차 매매상사 방문, 카센서 등 기존 일괄 견적(전화 다수 발생형).

## Pricing Evidence
헤이딜러의 딜러 낙찰 수수료 체계(거래액 구간별 23.5만~49만원, 성사 시에만 청구)가 **구체적 금액으로 확인됨(캡 미적용)** — 이는 소비자가 아닌 딜러 측 과금이지만, "성과보수형 매칭 수수료"라는 이 아이디어의 수익 모델이 동일 시장에서 실제로 작동 중임을 보여주는 직접적 증거다.

## Customer Acquisition
소비자 채널은 검색 유입이 가능하나, 이미 압도적 브랜드 인지도를 가진 헤이딜러와 정면 경쟁해야 한다는 근본적 장벽이 있다.

## MVP Cost
전화번호 비공개 채팅 견적 폼 + 이미지 역검색 최소 구현. 약 250만원이나, **딜러/업체 네트워크 확보를 위한 영업 비용은 별도**이며 이 비용이 실제로는 훨씬 클 가능성이 높다.

## Development Feasibility
기술 자체(폼, 채팅, 이미지 역검색)는 1인 개발 가능하나, 이 서비스의 핵심은 기술이 아니라 **공급측(딜러) 네트워크 확보**이며 이는 1인 개발자에게 구조적으로 어렵다(Manager도 동일 지적).

## Monetization
업체(딜러·매입업체) 리드당 과금 또는 성사 수수료 모델은 헤이딜러 사례로 시장에서 검증됐다. 문제는 이 모델이 통하려면 이미 헤이딜러가 확보한 규모(월 5만대, 40만 건 입찰)의 딜러 네트워크가 전제돼야 한다는 점.

## Major Risks
1. **헤이딜러가 이미 이 아이디어의 한국 버전을 정확히, 그것도 압도적 시장 지위로 실행 중** — 이번 조사의 가장 명확한 "레드오션" 사례.
2. 공급측(딜러) 네트워크 확보에 필요한 영업력이 1인 개발자에게 부재.

## Critical Assumptions

1. **Manager 순위와 Market 순위가 크게 다르다.** Manager 1위(I003, 76점 A)는 Market에서 1위를 유지했지만 B(68)로 강등됐고, Manager 최하위권(I005, C/57)은 Market에서 2위(B/65)로 뛰어올랐다 — "제품이 좋은가"와 "사업이 되는가"는 실제로 다른 질문임을 보여주는 사례.
2. **"이미 존재하는 무료/공공 대안"이 이번 조사에서 가장 반복적으로 등장한 리스크다.** I002(K-APT), I006(보험사 자체 앱), I010(헤이딜러), I011(정부24)은 모두 핵심 가치를 이미 무료로 제공하는 강력한 대체재가 확인되어 Manager 평가 대비 Market 점수가 크게 낮아졌다.
3. **가격이 확인된 아이디어(I004, I005, I007, I009, I010)일수록 반드시 등급이 높지는 않았다** — 가격이 확인됐다는 것은 "그 시장에 돈이 돈다"는 뜻이지 "내가 그 돈을 가져올 수 있다"는 뜻은 아니다(특히 I004, I009는 확인된 경쟁사 가격이 오히려 매우 낮아 신규 진입 마진을 좁힌다).
4. **1회성/저빈도 아이디어(I005, I006, I008, I010)에 대한 재검토 결과**: I005(헬스장 해지)만 성과보수 단가가 충분히 높을 수 있어(Rocket Money 사례) 사업성이 성립할 여지가 있었고, 나머지(I006 클레임워치, I008 이사, I010 중고차)는 저빈도 문제에 더해 이미 강력한 무료/기존 경쟁자까지 겹쳐 사업성이 더 낮게 평가됐다.
