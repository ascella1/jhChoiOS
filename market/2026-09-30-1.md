# Idea 001. SubscriptionGuard — 구독 통합 관리 및 자동 취소

## 제품
모든 구독 서비스를 한곳에서 추적하고 자동갱신 취소·재설정을 관리하는 모바일 앱

## Target Customer
월간 3개 이상 구독 서비스 사용자 (일반 2030)

## Market Evidence
**시장 규모:**
- 글로벌 구독 관리 시장: $7.15B (2024) → $17.95B (2030), CAGR 16.9%
- 소프트웨어 비중 65%, 클라우드 76% (성장 주도)

**시장 존재:**
- 기존 경쟁사의 강력한 성공: Rocket Money(구 Truebill) $4.1B+ 거래량
- 사용자 월 $5-14 가격대 수용 입증

## Existing Competitors
- **Rocket Money (Truebill)**: 월 $7-15 프리미엄, AI 어시스턴트 Rowan 추가 (Premium+)
- **Trim**: SMS 기반 챗봇, 구독 추적 + 청구 협상
- **Gravity**: 계정 연동 없음, 수동 추가 방식 (320만+ 활성 사용자)
- **Subby**: Android 무료 앱, 1,500+ 서비스 라이브러리, 4.6/5 평점
- **PocketGuard, Hiatus, Bobby**: 프리미엄 기능 제공

## Alternative Solutions
**무료 대안:**
- 신용카드 사 자체 앱 (신한, 삼성 등)의 구독 추적 기능
- 은행 계좌 연동 기본 기능 (무료)
- 스프레드시트 자동화 (Zapier)

## Pricing Evidence
**경쟁 가격:**
- Rocket Money Premium: 월 $7-14 (구독 취소 지원)
- Rocket Money Premium+: 월 $15 (AI 에이전트)
- 무료 플랜: 기본 추적만 (제한적)

**결론:** 고객들이 구독 추적에 월 $5-14를 지불하는 것 입증 (높은 지불 의사)

## Customer Acquisition
**1인 개발자 초기 10명 확보:**
1. Product Hunt 론칭 (구독앱 카테고리 주목도)
2. Reddit r/personalfinance, r/budgeting 커뮤니티 홍보
3. YouTube "절약 팁" 채널과 협력
4. Twitter 개인재무 계정 타게팅
5. 블로그 SEO: "자동으로 구독 취소하는 법"

**초기 임계값:** 한국/일본 시장에서 구독 서비스가 월평균 3.5개 사용 중 (검증됨)

## MVP Cost
**예상 비용:** 300만원
- Card API 연동 (Toss Pay, KOFIA): 1.5M
- 주요 10개 서비스 자동 감지: 1M
- iOS/Android 기본 UI: 0.5M

## Development Feasibility
**1인 개발 난이도:** 낮음
- 신용카드사 Open API만 필요 (공개됨)
- 서비스 감지는 정규식 기반 패턴 매칭
- Stripe, Toss 결제 SDK 사용 (기성품)
- MVP 4주 가능

**기술 스택:** React Native (iOS/Android 겸용) + Node.js 백엔드

## Monetization
**모델:** Freemium
- 무료: 5개 구독까지 추적
- 프리미엄: 월 2,990원 (무제한, AI 분석, 고급 통계)

**수익 예측:**
- 100만 설치 시 → 5% 유료 전환 → 50,000명 × 2,990원 = 월 1.5억원

## Scalability
**높음:**
- 신용카드사가 모든 국가에 존재
- 특정 서비스 추가는 스케일
- B2B (가계부 앱 제휴) 확장 가능
- 해외 확장: 한국 → 일본 (2M 사용자 추정) → 미국 가능

## Major Risks
1. **카드사 API 정책 변경** → 서비스 중단 리스크
2. **암호화폐/직불카드 미지원** → 사용자 제약
3. **이탈 위험** → 월 1회 이상 앱 사용 유도 필요

## Critical Assumptions
- 사용자가 월평균 4개 이상 구독 서비스 보유 (한국 기준)
- 연간 $50 이상 절감 시 구독 앱 비용 정당화
- 신용카드사가 Open API 계속 공개 유지

# Idea 003. DoseGuard — 약물 상호작용 & 복용 관리

## 제품
복용 약물을 입력하면 상호작용 체크, 복용 시간 알림, 부작용 모니터링을 자동화하는 앱

## Target Customer
만성질환자, 고령층, 다중 진료 환자

## Market Evidence
**시장 규모:**
- 글로벌 약물 상호작용 체커 시장: 성장 중 (2029년 $3.06B 예상)
- Pill Tracker 시장: $2.6B (2025) → $7.6B (2034), CAGR 11.7%
- 폴리파마시(복약용제) 환자 증가: 만성질환 환자 월 평균 5-8개 약물 복용

**시장 존재:**
- 약사 처방 시스템 필수 (법적 요구)
- 일본 약학정보원 통합 약물 데이터베이스 (공개)
- 고령화 추세 → 약물 복용 증가

## Existing Competitors
- **DrugBank API**: 학학 기관용 (개발자 API 공개)
- **Pill Reminder Apps**: Pill.one, Medisafe (기본 기능)
- **약학정보원**: 한국 약사회 (무료 공개 서비스)

## Alternative Solutions
**무료 대안:**
- 약학정보원 웹사이트 (무료 상호작용 검색)
- 약사 직통 (무료 상담)
- 병원/약국 복약 설명서
- ChatGPT 의약 상담 (비공식)

## Pricing Evidence
**경쟁 가격:**
- Medisafe: 월 $4.99
- Pill Reminder: 월 $2.99
- 약학정보원: 무료

**결론:** 고객들이 약물 안전에 월 $3-5를 지불하려 함 (생명과 관련)

## Customer Acquisition
**약사 네트워크 활용:**
1. 약학정보원 연동 협력 (약사 커뮤니티)
2. 병원/약국 포스터 배포
3. 고령층 SNS (네이버 카페, 카톡방)
4. 의약 커뮤니티 (당뇨환자 카페 등)
5. 만성질환 병원 대기실 배포

## MVP Cost
**예상 비용:** 3,000만원
- 약학정보원 API 연동: 800만원
- 약물 데이터베이스 구축: 1,000만원
- 부작용 로그 시스템: 700만원
- UI (복약 알림 중심): 500만원

## Development Feasibility
**1인 개발 난이도:** 낮음
- 약학정보원 API는 공개
- 복약 알림은 표준 푸시 알림
- 부작용 학습은 기본 ML (의료진 검증 필수)
- MVP 4주 가능

## Monetization
**모델:** Freemium
- 무료: 기본 상호작용 체크, 기본 알림
- 프리미엄: 월 3,990원 (부작용 모니터링, 의료진 공유, 고급 분석)

**수익성:** 높음 (생명 관련 → 높은 지불 의사)

## Scalability
**높음:**
- 모든 약물 복용자 대상 (전세계)
- 질환별 맞춤형 확장 가능
- B2B: 병원, 요양원, 요양보호사 대상 가능
- 의료진 인증 기능 → 처방전 직연동 가능

## Major Risks
1. **법적 책임** → 잘못된 약물 상호작용 정보로 피해 발생
2. **약학정보원 API 정책** → 개방 유지 여부 불확실
3. **의료진 신뢰** → 앱의 정보를 의료진이 신뢰할 것인가
4. **사용자 지속성** → 약 바뀌면 앱 사용 중단

## Critical Assumptions
- 사용자가 평균 4개 이상의 약물을 동시 복용
- 약의 상호작용이 생명과 관련되면 월 $4-5 지불
- 약학정보원이 API 계속 공개
