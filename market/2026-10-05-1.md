# Idea 001. 약가 경매 플랫폼 (Prescription Auction)

## 제품
처방약 가격을 약국과의 실시간 경매로 확인·예약하는 시스템

## Target Customer
만성질환자, 월 2회 이상 정기 처방약 사용자 (20~60대)

## Market Evidence
**시장 규모 추정**
- 한국 국민건강보험 약제비: 연 8~9조원 규모 (2025년)
- 월 정기 처방약 사용자: 약 1,200만명 (국민 26%)
- 처방약 평균 월 지출: 3~10만원 (대상 고객 중앙값 5만원)

**시장 존재 증거**
- 약국 매출의 15~20%가 경쟁성 높은 약제 (제네릭, 병용약)
- 환자들의 약가 비교 수요: 온라인 커뮤니티/지식in에서 월 2,000+ 검색

## Existing Competitors
| 서비스 | 기능 | 가격 | 비고 |
|-------|------|------|------|
| 약술(Yaksul) | 약국별 가격 비교 | 무료 | 2023년 런칭, 수동 입력 기반 |
| OK약국 | 가격 검색 + 배송 | 무료 | 대형 약국 체인 중심 |
| 365약국 | 약국 검색 | 무료 | 단순 검색 기능만 제공 |
| **비교 앱 부재** | 경매 구조 | - | 실시간 경매 시스템 경쟁자 없음 |

**핵심 발견**: 무료 비교 앱만 존재 → 고객이 경매 구조 가치를 인식하면 프리미엄 모델 가능성

## Alternative Solutions
| 해결책 | 비용 | 점유율 |
|-------|------|--------|
| 수작업 (전화 문의) | 시간 비용 | 70% (기존 방식) |
| 건강보험공단 약가 정보 | 무료 웹사이트 | 15% (고급 사용자만) |
| 약국 배송 앱 (쿠팡, 당근마켓) | 무료~3,000원/배송 | 15% (편의성 우선) |

**무료 대안 평가**
- 건강보험공단 "약가정보" 공식 데이터 → 무료 공개
- 약술 앱 → 수동 가격 입력, 정확성 낮음
- 약국 직접 전화 → 가장 정확하지만 시간 소비

## Pricing Evidence
**경쟁사 가격 분석**
- 약술: 완전 무료 (광고 수익 모델)
- OK약국: 무료 (체인 자사 앱)
- 해외 비교: GoodRx (미국) 무료 → 약국 수수료 모델

**고객 지불 의사 신호**
- 약국 가격 비교로 월 2~5만원 절감 가능성
- 기존 약술 사용자 있음 → 시장 검증됨 (낮은 수준)
- **문제**: 무료 대안(약술)이 이미 존재하고 기능이 충분 → 프리미엄 전환 어려움

## Customer Acquisition
**초기 10명 전략**
1. 만성질환 커뮤니티 (당뇨병 카페 등) 직접 모집
2. 약사 커뮤니티 설득 (약국 경매 참여 유도)
3. 시니어 온라인 커뮤니티 (50~60대 커뮤니티)
4. 온라인 상담 포럼 (건강 관련 Q&A)

**단계별 비용**: SNS 광고 ₩500K, 약사 인센티브 ₩1M

## MVP Cost
**₩2M~₩3M 예상 비용**
- 약국 API 연동 (공시 약가 데이터): ₩800K
- 실시간 경매 시스템 기초 구축: ₩1.2M
- 약국 50~100곳 모집/협력: ₩500K (수수료율 협상)
- 앱 기본 개발 (카메라 인식 제외): ₩500K

**비용 범위 내 가능성**: ✓ 가능

## Development Feasibility
**1인 개발 가능도**: 7/10 (중간 수준)
- 기초 기능: 앱 + 약국 매칭 시스템 (개발 가능)
- 어려운 부분: 약국 협력 모집 (비즈니스 영역), 카메라 약명 인식 (AI/ML)
- 초기 MVP는 수동 입력으로 대체 가능

## Monetization
**수익 모델**
1. 약국 예약 수수료: 건당 300~500원 (약국이 부담)
2. 프리미엄 (월 3,990원): 가격 알림, 자동 예약
3. 약국 광고 패키지

**첫 3개월 수익 추정** (100명 사용자 기준)
- 월 100명 × 2회 예약 × ₩400 = ₩80K
- 프리미엄 전환율 5% × ₩3,990 = ₩20K
- **월 수익**: ₩100K (매우 낮음)

**문제**: 수수료 기반 모델은 약국 협력이 필수이지만, 약국 참여 동기 약함

## Scalability
**확장성 평가**
- 약국 참여 모델: 1개 약국 확보 시 5~10명 추가 가능
- 지역 확대: 서울(100) → 경기(200) → 전국(2,000) 가능
- 약국 수수료 모델은 약국 수 증가에 선형 확장 가능

**제약**: 약국의 변화 저항이 주요 병목

## Major Risks
1. **약국 참여 동기 부족** (가장 큰 위협)
   - 약국은 경매 참여로 마진 압박 우려
   - 기존 수익 구조 변화 저항
   
2. **무료 대안(약술) 경쟁**
   - 약술 앱이 경매 기능 추가 시 경쟁 불가
   - 수익 모델 단순화 필요
   
3. **규제 위험**
   - 약사법상 약가 공개 범위 제약 가능성
   - 환자-약국 중개 수수료 규제 가능성

## Critical Assumptions
1. 약국이 월 2~3명의 추가 고객 확보로 마진 손실 상쇄 가능할 것
2. 경매 구조 자체가 무료 비교 앱과는 차별화될 것
3. 만성질환자의 지불 의사가 월 4,000원 이상일 것

# Idea 002. 환율 거래 게임 (Forex Game Arena)

## 제품
실제 환율 변동을 기반으로 환전 타이밍을 예측하고, AI가 최적 환전 시점을 추천하는 앱

## Target Customer
해외 거래 사업가, 글로벌 프리랜서, 온라인 쇼핑 판매자

## Market Evidence
**시장 규모**
- 글로벌 환율 거래량: 일 6조달러 (2025년 BIS 통계)
- 한국 국제 송금액: 연 300억달러 규모
- 대상 고객 추정: 글로벌 프리랜서 50만명 + 온라인 판매자 200만명

**시장 존재 증거**
- 환율 변동으로 월 3~8% 손실하는 사용자군 명확히 존재
- Wise, Revolut 같은 서비스 연 성장 40%+ (환전 최적화 수요 확인)

## Existing Competitors
| 서비스 | 기능 | 가격 | 비고 |
|-------|------|------|------|
| Wise (TransferWise) | 실시간 환율 + 송금 | 0.4~2% 수수료 | 시장 선도, 미국/EU 중심 |
| Revolut | 멀티 통화 앱 | 무료~€7.99/월 | 유럽 중심, 게임화 없음 |
| PayPal | 환전 기능 | 2~4% 수수료 | 수수료 높음 |
| XE Money Transfer | 환전 추천 | 무료 + 수수료 | 정보만 제공 |
| **환율 게임/AI 추천**: 경쟁자 없음 | - | - | 게임화+AI 조합 차별화 |

**경쟁사 가격 분석**
- Wise: 무료 정보 + 0.4% 이상 실거래 수수료
- Revolut Premium: €7.99/월 (한국 미지원)
- 한국: 은행 환전 (1~2% 수수료), 무료 정보 앱

## Alternative Solutions
| 해결책 | 비용 | 현황 |
|-------|------|------|
| 은행 환전 | 1~2% 수수료 | 60% (기존 방식) |
| Wise 사용 | 0.4% + 송금비 | 20% (가성비 우선) |
| 수작업 환율 확인 | 시간 비용 | 20% (무료 선호) |

**무료 대안**
- XE.com, OANDA: 무료 환율 정보
- 네이버, 카카오: 환율 계산기 무료 제공
- 은행 앱: 무료 환율 정보

## Pricing Evidence
**지불 의사 신호**
- Wise는 월 ₩2,000 이상 비용으로도 사용자 증가 중
- 환전 손실 월 1~2% = 월 100만원 거래량 기준 ₩20K 손실 가능
- → 프리미엄 ₩10K/월은 경제적 타당성 있음

**중요**: Wise는 유의미한 가격(송금 수수료 기반) → 고객 지불 의사 신호 긍정적

## Customer Acquisition
**초기 10명 전략**
1. Upwork, Fiverr 크리에이터 커뮤니티 직접 홍보
2. 한국 온라인 판매자 커뮤니티 (쿠팡 셀러, 아마존 한국인 판매자)
3. 해외 거래 프리랜서 페이스북 그룹
4. 환율 트레이더 온라인 커뮤니티

**획득 채널 비용**: SNS 광고 ₩800K

## MVP Cost
**₩1.5M~₩2.5M 예상 비용**
- 환율 실시간 API (OANDA, XE): ₩600K/연간
- 기본 AI 예측 모델 (이동평균선): ₩800K
- 게임화 UI (포인트, 랭킹): ₩500K
- 앱 개발: ₩1M

**비용 범위**: ✓ 가능

## Development Feasibility
**1인 개발 가능도**: 8/10 (높음)
- 환율 API는 공개, 기초 ML은 단순 모델로 시작 가능
- 게임화는 표준 패턴 (점수, 랭킹)
- 복잡한 부분: 72시간 환율 예측 모델 정확도 (초기 단순 모델로 충분)

## Monetization
**수익 모델**
1. 프리미엄: 월 ₩10,000 (실시간 알림 + AI 추천)
2. 거래소/은행 제휴 수수료 (Wise, Revolut)
3. 광고 (환전 서비스 광고)

**첫 3개월 수익 추정** (1,000명 사용자 기준, 10% 프리미엄 전환)
- 월 100명 프리미엄 × ₩10K = ₩1M
- 거래소 제휴 CPA: 1명당 ₩5K × 50명 = ₩250K
- **월 수익**: ₩1.25M (초기 가능 수준)

## Scalability
**확장성**: 7/10
- 사용자 증가 시 서버 비용만 증가 (거의 가변)
- 국가별 환율 자동 추가 가능
- 국제 확장 용이 (언어 번역만 필요)

**제약**: AI 예측 정확도 개선 필요 (지속적 학습)

## Major Risks
1. **AI 예측 정확도 문제**
   - 환율은 외부 변수(정책, 금리) 민감
   - 사용자가 손실 경험 시 신뢰 하락
   
2. **Wise 경쟁**
   - Wise는 이미 0.4% 수수료로 시장 지배 중
   - 게임화만으로는 차별화 약함
   
3. **규제 위험**
   - 환율 예측 서비스의 법적 지위 불명확
   - 투자 조언 규제 가능성

## Critical Assumptions
1. 사용자가 AI 예측이 60~70% 정확도여도 신뢰할 것
2. 게임화가 Wise 사용보다 매력적일 것
3. 월 ₩10K 프리미엄에 대한 전환율이 10% 이상일 것

# Idea 003. 회원권 의도적 연장 게임 (Commitment Arena)

## 제품
체육관/요가 회원이 일일 목표 달성 게임으로 의도적으로 계속 이용하도록 유도하는 시스템

## Target Customer
체육관 회원, 특히 "결석 패턴"이 있는 사용자 (20~50대)

## Market Evidence
**시장 규모**
- 한국 체육관 시장: 연 2조원 이상
- 회원 수: 약 300만명 (체육관, 요가, PT)
- 월 회원권 평균 가격: ₩50K~₩150K

**시장 존재 증거**
- 회원 이탈률: 월 15~20% (높음)
- 결석 패턴: 회원 50%가 월 2회 이상 결석
- "취소율 감소" 수요: 체육관 업계 최대 과제

## Existing Competitors
| 서비스 | 기능 | 가격 | 비고 |
|-------|------|------|------|
| 네이버 피트 | 헬스 로그 기록 | 무료 | 기록만, 게임화 없음 |
| 지피엠(GPM) | 체육관 앱 | 체육관 제공 | 예약, 출석 관리 |
