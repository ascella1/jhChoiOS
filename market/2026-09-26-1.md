# Market Agent — 2026-09-26

## 제품 001. AutoRefund

### 제품
해외직구 관세 환급을 자동으로 추적·신청하는 앱

### Target Customer
- 월 1~3회 반품하는 해외직구 이용자
- 1만원 이상의 관세를 납부한 사용자
- 자동화를 선호하는 2030대

### Market Evidence
시장 존재함. 2026년 4월부터 한국 관세청이 해외직구 반품 관세 환급권의 전자 양도를 허용하기로 규정 개정. 이는 정부가 공식적으로 환급 필요성을 인정했다는 의미. 반품하는 해외직구 이용자들이 실제 돈을 내고(관세) 있으며, 반품 후 환급을 신청하는 행동이 명확함. 6개월 환급 기한 규제가 있으므로 자동 추적의 필요성 존재.

### Existing Competitors
- 현재 직접 경쟁 서비스 발견 안 됨
- 간접 경쟁: 관세청 공식 포털(무료), 배송사 자체 환급 추적 기능(무료)

### Alternative Solutions
- 관세청 공식 웹사이트에서 수동으로 환급 신청 (무료)
- 배송사(쿠팡, DHL 등)의 반품 추적 앱 (무료)
- 세관사 또는 통관업체 수동 대행 (1~5만원 일회성)

### Pricing Evidence
직접 경쟁자가 없으나, 기존 수작업 대행 서비스가 1~5만원 수준. 평균 환급액 1~5만원 × 월 1~3회 반품 기준, 월 수수료 모델은 어려울 것으로 예상. 구독 수익화는 약함.

### Customer Acquisition
- 초기 고객 확보 난제: 해외직구 커뮤니티(클리앙, 오늘의집 등)에서 입소문
- 쿠팡/아마존 반품 흐름 중 자연 유입 가능하나, API 협력 필요
- B2B: 반품 택배 대행사와 제휴 가능성

### MVP Cost
300만원 초과 가능성 높음. 쿠팡·아마존 API 연동(100만원), 관세청 데이터 크롤링/API(50~100만원), 배송사별 추적 API(50~100만원), 개발(300만원). 총 500만원 이상 예상.

### Development Feasibility
1인 개발 어려움. 배송사별 반품 추적 형식이 다르고, 관세청 규제 데이터 통합이 필요함. API 협력 난제.

### Monetization
- 기본 무료(관세청 환급 신청)
- 프리미엄 수익화 약함: 월 2,900원 구독으로는 LTV 낮음
- B2B 전환: 배송 보험 제휴 수수료 (불명확)

### Scalability
사용자 증가 시 확장성 제한적. 환급액이 고정되어 있고, 1인 사용자당 LTV가 낮음. 정부 정책 변화에 민감.

### Major Risks
1. **정부 규제 의존**: 관세청 API 공개 여부 확실하지 않음
2. **낮은 지불 의사**: 월 평균 환급액 2만원 × 월 1~3회 = 삶의 질 개선이 약함
3. **기존 무료 대안 존재**: 관세청 포털 자체가 무료로 제공 중
4. **환급율 보장 어려움**: 규정에 따라 환급 불가 상품 존재

### Critical Assumptions
- 관세청 또는 배송사 API 협력 가능성 (미확인)
- 자동 신청만으로 환급율 98% 이상 달성 가능한가?
- 실제 고객이 월 ₩2,900 프리미엄을 낼 의사 있는가?

## 제품 002. CreditFlowX

### 제품
여러 카드사 영수증을 한곳에서 통합·자동 분류하는 회계 대시보드

### Target Customer
- 카드 2개 이상 보유한 프리랜서 (세금 신고 대비)
- 소규모 사업 주인 (월 영수증 정리)
- 회계 담당자

### Market Evidence
시장 존재함. **토스, 뱅크샐러드가 이미 비슷한 기능을 대규모로 제공** 중이며, 사용자 수 백만 단위. 프리랜서들의 "월말 영수증 정리" pain은 실제로 존재. 하지만 이미 토스 앱을 통해 무료로 사용 가능한 상태.

### Existing Competitors
**직접 경쟁:**
- 토스 (신한·현대·국민·BC·농협 카드 자동 연동, 무료)
- 뱅크샐러드 (무료 기본, 프리미엄 $4.99/월 또는 연 $49.99)

**간접 경쟁:**
- 핀다 (무료 영수증 관리)
- 토스페이먼츠 (결제 내역 조회, 무료)

### Alternative Solutions
- 수동 엑셀 관리 (시간 소요)
- 각 카드사 개별 앱 로그인 (번거로움)
- 회계 사무소 대행 (월 10~50만원, 고가)

### Pricing Evidence
**토스는 무료로 모든 기능 제공**. 뱅크샐러드 프리미엄도 월 $4.99 수준으로 저가. 이는 매우 부정적 신호. 같은 기능을 새로운 앱에서 **유료로 받을 의사 매우 낮음**.

### Customer Acquisition
- 기존 대규모 경쟁사(토스) 사용 중인 사용자를 전환하기는 극히 어려움
- 토스 미사용자만 타겟하면 시장 크기 매우 제한적

### MVP Cost
약 400만원 예상. 카드사 API 협상은 무료지만, OCR 정확도 95% 이상, 자동 분류 정확도 95% 이상이 필요. 초기 개발 후 지속적 개선 필요.

### Development Feasibility
1인 개발 가능하나, 카드사 API 접근 정책이 변경될 수 있으며, 각 카드사마다 정책이 다름. 개인 로그인만 허용하는 카드사도 있음.

### Monetization
- 무료 기본(월 1회 조회)은 낮은 수익화
- 프리미엄 월 $4.99는 매우 저가
- B2B(회계 사무소) 수익화가 최대 기대값이나, 이미 회계 소프트웨어 생태계 존재

### Scalability
사용자 증가 시 인프라 비용 증가. 카드사 데이터 의존도 높아 확장 제약 존재.

### Major Risks
1. **토스라는 거대 경쟁사**: 이미 무료로 더 나은 사용자 경험 제공
2. **금융 규제**: 카드사 API 접근 제한, 보안 이슈
3. **차별화 약함**: 토스보다 나은 가치제안이 불명확
4. **고객 신뢰**: 금융 데이터 보안 신뢰 구축 어려움

### Critical Assumptions
- "기존 토스 사용자가 새 앱으로 전환할 이유가 뭔가?"
- 세금 AI, B2B 회계 연동 등 차별화 기능이 실제 가치인가?
- 카드사 API 정책이 장기적으로 유지되는가?

## 제품 003. DeliveryUnified

### 제품
배민·요기요·쿠팡이츠를 하나의 대시보드에서 관리하는 음식점 점주 도구

### Target Customer
- 배달앱 2~3개 운영하는 음식점 점주
- POS 시스템을 쓰지 않는 소규모 음식점 (200만원 이상 비용 부담)
- 월 매출 2000만원 이상

### Market Evidence
시장 매우 명확함. **배달 앱 30개 시대**로 불리는 2026년 상황에서, 소규모 음식점 점주들이 여러 배달앱을 동시에 관리하는 pain이 극심. 포스피드, 오터포스, 토스포스 등 **기존 POS 솔루션들이 배달앱 통합 관리를 이미 지원** 중이며, 점주들이 이를 구매 중. 시장 수요 명확.

### Existing Competitors
**직접 경쟁:**
- 포스피드 (배달앱 주문 통합관리 프로그램, 유료)
- 오터포스 (배달 앱 30개 통합 관리 가능)
- 토스포스 (배달앱 연동)
- 메타포스 (배달앱 연동)

**가격 정보:**
정확한 월정액 공시 정보 미공개, 하지만 기존 POS 솔루션 수준으로 월 5~15만원 예상.

### Alternative Solutions
- 각 배달앱 웹 대시보드를 따로 열기 (무료, 시간 낭비)
- 기존 POS 시스템 사용 (초기 비용 200만원 이상)
- 음식점 점주 대행 서비스 (월 10~20만원)

### Pricing Evidence
기존 POS 솔루션들이 배달앱 연동을 월 5~15만원 수준으로 제공 중. 이는 **유의미한 가격대**이며, 실제 점주들이 이 가격을 지불하고 있다는 점은 **긍정적 신호**. 새로운 서비스가 이보다 낮은 가격으로 진입할 가능성 있음.

### Customer Acquisition
- 초기 10명: 배달앱 점주 커뮤니티(배달앱 점주 포럼, 배민 비즈니스 커뮤니티 등)에서 직접 모집
- 참고: 배달앱 점주는 약 50만명 규모(한국)이며, 점주 커뮤니티 활동 활발
- B2B: 배달앱 협회, POS 솔루션 회사와 제휴

### MVP Cost
약 350만원. 배민, 요기요 API 협상은 무료이거나 공개 포트 존재하나, 실시간 동기화 구현이 핵심 난제. 초기에 배민+요기요만 지원하는 것이 현실적.

### Development Feasibility
1인 개발 가능하나, 배달앱 API 정책 변경 리스크 있음. 배민, 요기요의 점주 API 공식 지원 여부가 핵심. 공식 지원이 아니면 크롤링 기반 개발이 필요하며, 이는 불안정함.

### Monetization
- 기본 무료(1개 배달앱 관리) → 무료 사용자 많음
- 프리미엄 월 $9.99 (약 ₩13,000) → 유료 전환율 추정 5~10%
- B2B 제휴(POS 회사, 배달대행사) → 장기 수익원

### Scalability
사용자 증가 시 배달앱별 연동 규모 증가. 배달앱이 API를 열어주는 한 확장 가능. 하지만 배달앱의 정책 변경에 민감.

### Major Risks
1. **배달앱 API 협력 불확실**: 배민, 요기요가 공식 점주 API를 공개하지 않을 수 있음
2. **기존 경쟁사 존재**: 포스피드, 오터포스 등이 이미 시장 점유 중
3. **배달앱 자체가 기능 추가 가능**: 배민, 요기요가 자체 통합 기능을 추가할 수 있음
4. **실시간 동기화 기술**: 메뉴 가격 변경이 5분 지연되면 고객 불만

### Critical Assumptions
- 배민, 요기요의 점주 API가 공식적으로 이용 가능한가?
- 메뉴 변경이 정말 실시간으로 3개 앱에 반영될 수 있는가?
- 음식점 점주 100명이 월 ₩9,900 프리미엄 + B2B 계약으로 충분한 매출인가?

## 제품 004. ScopeGuard

### 제품
계약 범위를 정의하고, Scope Creep을 추적·거절하는 프리랜서 보호 앱

### Target Customer
- Upwork, Fiverr, Toptal 프리랜서
- 월 매출 $2,000 이상인 개발자, 디자이너, 라이터
- Scope Creep으로 손실을 경험한 경험자

### Market Evidence
시장 명확함. **프리랜서들이 Scope Creep으로 연 $15,000~$25,000 손실**하고 있으며, 이는 실제 금전 손실. 52%의 에이전시 프로젝트가 원래 예산을 초과 중. Upwork, Fiverr 포럼에서 "거절하기 어렵다"는 불만이 많음. 심리적 pain이 크지만, 실제 금전 손실은 더 큼.

### Existing Competitors
**직접 경쟁:**
- Upwork 자체 "disputed work" 기능 (무료, 내장)
- Fiverr 자체 "resolution" 기능 (무료, 내장)

**간접 경쟁:**
- Bonsai (프리랜서 계약서 템플릿, 월 $19)
- Proposify (제안서 작성, 월 $49)
- 일반 계약서 템플릿 (무료, 법률 전문성 낮음)

### Alternative Solutions
- Upwork/Fiverr의 기본 분쟁 기능 (무료)
- 변호사 상담 (고가)

## 핵심 인사이트

### 1. "무료 대안의 위력"
- Wave, Zoho, YouTube, Clipchamp의 무료 제공이 **새로운 유료 서비스의 진입을 거의 불가능**하게 만듦
- 예: CreditFlowX, InvoiceGuard, VideoAutoCaption 모두 C등급
- 결론: **기존 무료 대안이 없거나, 무료 대안의 기능이 미진한 분야만 진입 가능**

### 2. "경쟁사의 유의미한 가격 = 긍정적 신호"
- DeliveryUnified: 기존 POS 솔루션 월 5~15만원 → 시장 검증됨 (A등급)
- ScopeGuard: Bonsai 월 $19 → 프리랜서의 지불 의사 증명 (A등급)
- Wealthfront: 0.25% 수수료 → 자산가의 지불 의사 증명 (B등급)

### 3. "Pain의 크기"
- 크기 큼: DeliveryUnified(월 10~20시간 절감) → A등급
- 크기 중간: ScopeGuard(연 $15K~$25K 손실) → A등급
- 크기 작음: InvoiceGuard(월 30분) → C등급

### 4. "시장 크기의 함정"
- SalaryCalcJP: 경쟁사 없음(긍정적)이지만, 시장 크기 극히 작음(유학생 30만명) → C등급
- 결론: **경쟁사 없음 ≠ 좋은 시장. 수요가 없을 수 있음**

### 5. "B2B 수익화의 중요성"
- DeliveryUnified: B2B(POS 회사, 배달대행사) 제휴 → 안정적 수익
