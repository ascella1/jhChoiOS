## Idea 001. MoneyStorm — 프리랜서 자동 정산 & 세금 게임화

**제품**: 프리랜서 수입 정산 자동화 + 세금 계산 + 게임화

**Target Customer**: 
- 프리랜서, 개인사업자, N잡러
- 월 수입 변동 큰 사용자 (당신의서재, 크몽 등 여러 플랫폼)
- 세금 신고를 자동화하고 싶은 사람

**Market Evidence**:
프리랜서 세금 신고 시장이 존재함. 2026년 한국에서 프리랜서는 3.3% 원천징수 대상이며, 연간 5월 종합소득세 신고가 의무화되어 있음. 검색 결과에 따르면 프리랜서 세금 계산기, 세무 처리 앱이 이미 여러 개 존재함.

**Existing Competitors**:
- 삼쩜삼 (누적 가입자 2,300만 명): 세금 환급 전문 플랫폼, 무료 기본, 수수료 기반
- 경리나라: 월 9,900원 요금제, 기본 기능 제공
- 모바일택스: 전자세금계산서 자동 수집, 세무전문가 1:1 배정
- 이음세무: 프리랜서 대상

**Alternative Solutions**:
- Excel 수작업 정산
- 세무사 상담 (월 수십만원)
- 플랫폼 자체 정산 시스템 (하지만 복잡함)

**Pricing Evidence**:
- 삼쩜삼: 무료 기본, 환급액 기반 수수료 (구체적 비율 미공개)
- 경리나라: 월 9,900원
- 모바일택스: 월 약 10,000원대로 추정
- 프리랜서 평균 월 지출: 세금 설명서 > 세무 도구 구독

**Customer Acquisition**:
- 당신의서재, 크몽 등 플랫폼 커뮤니티 직접 마케팅 가능
- SEO: "프리랜서 세금 계산기", "정산액 확인"
- 바이럴: 프리랜서 커뮤니티 (인스타그램, 유튜브)
- 초기 고객 10명: 프리랜서 포럼, 당신의서재 커뮤니티에서 직접 모집 가능

**MVP Cost**:
- API 연동 1~2개 (당신의서재, 크몽): 1~2개월
- 엑셀 임포트 기능: 1주
- 간단한 세금 계산기: 2주
- 월별 차트: 1주
- 예상 비용: 200~300만원 (외주 최소화, 오픈소스 활용)

**Development Feasibility**:
- 1인 개발 가능: 중간 수준
- API 연동이 핵심 (API 개방 협력 필요)
- 세무 정확성 검증 필요 (세무사 자문 필수)

**Monetization**:
- 무료: 기본 정산 + 세금 계산
- Pro (월 2,990원): 고급 분석 + 세무사 1:1 상담 5회/년 (기존 경리나라보다 저가)
- B2B: 소상공인 가맹점주 bulk pricing

**Scalability**:
- 플랫폼 API 연동 확대 가능 (당신의서재 → 크몽 → 오늘의집 → ...)
- 세무 정확성 확보 후 B2B 확대
- 지역 세무사 네트워크 구축

**Major Risks**:
- 플랫폼이 API 개방하지 않을 수 있음
- 세무 정확성 책임 (법적 리스크)
- 초기 보수적인 프리랜서들의 신뢰 부족

**Critical Assumptions**:
- 프리랜서들이 실제로 월별 세금 예측을 원하는가? (검증 필요)
- 무료 기본 기능으로 충분한가?

## Idea 002. SegmentKeeper — 편의점 택배 자동 알림 & 성취감 게임화

**제품**: 편의점 택배 수령 기한 자동 추적 + 성취감 게임화

**Target Customer**:
- 편의점 택배 자주 이용하는 사람 (월 2~4회)
- 기한을 자주 놓치는 사람

**Market Evidence**:
편의점 택배는 한국에서 매우 일반적 (GS25, CU, 이마트24 등). 하지만 "기한 놓친 택배"라는 pain point의 심각도가 낮음 (대부분 1~2주 여유가 있음). 

당근마켓, 클리앙에서 "편의점 택배 기한" 관련 게시물 검색 시 월 5~10개 정도 (낮은 빈도). 기존 택배사 앱이 이미 알림 기능을 제공 중.

**Existing Competitors**:
- 배송 (앱): 모든 택배사 통합 추적
- 택배 (앱): 편의점 도착 알림
- 택배사 자체 앱 (CJ, 로젠, 한진 등)

**Alternative Solutions**:
- 택배사 앱 기본 알림
- SMS 알림 (배송사에서 제공)
- 수작업 확인

**Pricing Evidence**:
- 기존 택배 추적 앱: 무료
- 편의점 제휴 할인: 편의점 자체에서 포인트 제공

**Customer Acquisition**:
- 택배 앱 사용자 (높은 진입 장벽, 스위칭 비용 높음)
- SEO: "편의점 택배 기한"

**MVP Cost**:
- 배송사 API 연동 (1~2개): 2주
- 알림 시스템: 1주
- 포인트 카운터: 1주
- 예상 비용: 200만원 내

**Development Feasibility**:
- 1인 개발 가능: 높음

**Monetization**:
- 무료: 기본 알림 + 포인트 적립
- 프리미엄: 편의점 제휴 할인 (수수료 모델)

**Scalability**:
- 사용 빈도가 낮음 (월 1~2회) → 일일 사용 불가능
- 스트릭 시스템으로 해결 시도 하지만, pain이 약함

**Major Risks**:
- Pain 심각도 낮음 (기한이 충분함)
- 기존 택배사 앱으로 충분
- 사용 빈도 낮음 = Retention 약함

**Critical Assumptions**:
- "편의점 택배 기한을 놓친 경험"이 실제로 많은가? (매우 의심스러움)

| 고객 지불 의사 (15점) | 3 | 무료 택배 앱 사용자가 유료 전환할 동기 없음 |

## Idea 003. ContractVault — 프리랜서 계약서 자동 만료 추적 & 법적 보호

**제품**: 계약서 중앙 관리 + AI 분석 + 법적 위험도 감지

**Target Customer**:
- 온라인 프리랜서 (디자이너, 개발자, 라이터)
- 여러 클라이언트와 계약하는 사람
- 법적 분쟁 경험이 있는 사람

**Market Evidence**:
- 프리랜서 계약 분쟁: 한국에서 연간 1,000건 이상 (추정)
- 법적 문제 인식: 프리랜서 커뮤니티에서 "계약서" 관련 질문 월 20~30개
- 기존 도구 사용: 대부분 기본 계약서 템플릿만 사용

**Existing Competitors**:
- DocuSign: 전자서명 특화, B2B 중심 (월 $12~)
- PandaDoc: 계약서 템플릿 + 전자서명 (월 $25~)
- 로스쿨/변호사 상담: 시간당 10만원 이상

**Alternative Solutions**:
- Google Drive 폴더 관리
- 종이 계약서 보관
- 변호사 상담

**Pricing Evidence**:
- DocuSign, PandaDoc: 월 $12~25 (고가)
- 한국 시장: 유사 도구 거의 없음
- 법적 상담료: 매우 높음 (시장 수요 있음)

**Customer Acquisition**:
- 프리랜서 커뮤니티 (당신의서재, 크몽)
- 프리랜서 법률 상담 포럼
- SEO: "프리랜서 계약서 관리"

**MVP Cost**:
- 계약서 PDF 수작업 입력
- AI 없이 기본 기능만
- 300만원 내 가능

**Development Feasibility**:
- 1인 개발 가능: 중간 (PDF 처리, OCR은 외부 API 사용)

**Monetization**:
- 무료: 5개 계약서까지
- Pro (월 2,990원): 무제한 + AI 분석 + 변호사 상담

**Scalability**:
- 지역별 법률 차이 있음 (확장성 제한)
- 변호사 네트워크 구축 필요

**Major Risks**:
- 법적 조언 책임 (규제 리스크)
- 변호사 협력 필요 (비용 높음)

## Idea 004. RepoMirror — 한국 프리랜서/소상공인 다중 플랫폼 정산 통합기

**제품**: 당신의서재, 크몽, 오늘의집 등 여러 플랫폼의 정산액을 자동으로 모아서 통합 관리

**Target Customer**:
- 여러 플랫폼에서 동시에 일하는 프리랜서
- 소상공인 (다채널 판매자)
- N잡러 (월 수입 추적)

**Market Evidence**:
- 프리랜서/소상공인 멀티 플랫폼 사용: 당신의서재 + 크몽 + 오늘의집 동시 사용자 추정 20~30% (높음)
- 플랫폼별 정산 관리 불편: 프리랜서 커뮤니티에서 "여러 플랫폼 정산 통합" 요청 월 5~10개
- 시장 수요: 매우 높음 (검증됨)

**Existing Competitors**:
- 삼쩜삼: 세금 환급만 (정산 통합 아님)
- 경리나라: 기업 회계 중심 (프리랜서용 아님)
- 플랫폼 자체: 통합 정산 기능 거의 없음

**Alternative Solutions**:
- Excel 수작업 통합
- 스프레드시트 자동화 (Zapier)
- 각 플랫폼 앱 별도 확인

**Pricing Evidence**:
- 프리랜서 월 평균 관리 시간: 1~2시간
- Pro 가격: 월 4,990원 (시급 3만원 × 2시간 = 6만원 > 월 구독료 4,990원)
- 고객 지불 의사: 매우 높음

**Customer Acquisition**:
- 당신의서재, 크몽 커뮤니티 직접 마케팅
- 프리랜서 SNS 커뮤니티 (인스타그램, 유튜브)
- SEO: "프리랜서 정산 통합", "여러 플랫폼 정산"

**MVP Cost**:
- 크몽 + 당신의서재 API 연동: 2개월
- 기본 통계 차트: 2주
- 세금 계산기 간단 버전: 1주
- 예상 비용: 250~300만원

**Development Feasibility**:
- 1인 개발 가능: 중간
- API 연동이 핵심 (플랫폼 협력 필요)

**Monetization**:
- 무료: 기본 정산 (2개 플랫폼까지)
- Pro (월 4,990원): 무제한 플랫폼 + AI 분석
