# Idea 001. 배달점주 실시간 손실 게임화 "마진 미션"

## 제품
배달점주의 주문단가 하락/배달료 인상에 대응하는 일일 미션 게임 — 손익분기점 달성 시 보상

## Target Customer
한국 배달앱 가맹점주 (치킨, 피자, 한식) 약 10만 가맹점

## Market Evidence
**배달앱 시장 규모:**
- 2017년: 2.7조원 → 2020년: 17.4조원 (3년간 536% 증가)
- 가맹점주 부담: 실효 수수료율 **30.6%** (중개료 10.8% + 배달료 + 부가세)
- 점주 인식: 79%가 수수료를 "과도하다"고 평가

**점주의 실제 손실:**
- 배달 수수료가 매출 8.4% 차지하지만, 순수익은 5% 수준에 불과
- 점주들이 실제로 손익분기점 추적을 원함 (기존 연구)

## Existing Competitors
1. **크몽 배달기장 서비스**: 월 50만원 (2026년 할인가, 정상가 70만원)
   - 기능: 배달 주문 기준 기여이익 분석, 월간 영업손익 추정
   - 가격: **월 50만원 = 매우 높은 수준**

2. **글래스월렛 (GlassWallet)**: 무료 계산기
   - 기능: 수수료 자가진단, 절감 전략 제시
   - 가격: **무료**

3. **배달앱 자체 기능**: 매출 분석 대시보드 (기본 제공)

## Alternative Solutions
- 배달앱의 기본 매출 분석 대시보드 (무료)
- Excel 수동 계산
- 회계사무소 상담 (월 20~50만원)
- 모코플렉스 '큐로 딜리버리' (자체 배달 전환, 비용 불명)

## Pricing Evidence
크몽 경쟁자: 월 50만원 (3개월 계약 최소)
→ **가격 지불 의사 신호: 높음** (경쟁자가 유의미한 가격 책정)

## Customer Acquisition
- 배달점주 커뮤니티 (네이버 밴드, 카톡 그룹)
- 배달앱 내 광고
- 점주 협회 제휴
- **초기 10명 확보 난이도: 중간** (점주 네트워크 필요)

## MVP Cost
Manager의 예상: 2,000~2,500만원
- 배달앱 API 개발 (2주)
- 프론트엔드 (3주)
- 백엔드 (2주)
→ **300만원 초과, 1인 개발 어려움**

## Development Feasibility
**난이도: 높음**
- 배달앱 API 접근 정책이 불명확 (공식 개발자 계정 필요)
- 3개 플랫폼(요기요, 배민, 쿠팡이츠) 동시 연동 필요
- 원가 DB 구축 및 업데이트 자동화
- **1인 개발자의 경우 API 협상 단계에서 6개월 이상 소요 가능**

## Monetization
- 프리미엄 기능 (월 9,900원): 가격 최적화 AI
- 점주 커뮤니티 광고
- 배달앱 제휴 수수료
→ **기본은 무료/저가, 프리미엄 비중 불명확**

## Scalability
높음: 배달점주 시장 규모가 크면 네트워크 효과 기대
낮음: 배달앱의 자체 기능 고도화로 대체 가능

## Major Risks
1. **API 접근 불가**: 배달앱이 API를 공개하지 않거나 제한할 수 있음
2. **경쟁자 선점**: 크몽 경쟁자 이미 시장 진입 (월 50만원 고가)
3. **점주 행동 변화 미흡**: 정보 제공만으로는 실제 가격 조정으로 이어지지 않을 수 있음
4. **배달앱의 기능 고도화**: 배민/쿠팡이츠가 자체 손익 분석 추가하면 차별성 상실

## Critical Assumptions
- 배달점주가 실제로 게임화된 미션으로 동기부여되는가? (Duolingo는 학습, 마진은 다름)
- 원가 입력이 정확한가?
- 가격 최적화 추천이 점주가 실제로 실행 가능한가?

# Idea 002. 프리랜서 신용도 네트워크 "프리버디"

## 제품
프리랜서들이 클라이언트 연체/신용도를 실시간 공유하는 커뮤니티 + 마이크로 크레딧

## Target Customer
글로벌 프리랜서 (Upwork, Fiverr 활동), 월 $500~$5,000 수익 / 약 1,000만명+ (글로벌)

## Market Evidence
**프리랜서 미수금 문제의 규모:**
- 미국 B2B 송장 약 50%가 기한을 넘겨 결제 (민간 자료)
- 뉴욕 프리랜서 62%가 미지급 경험 (단체 조사)
- 미국 프리랜서 중 약 500만명이 연체 대금 때문에 고금리 대부로 돌아선 상황
→ **명확한 시장 고통**

**한국 데이터 부재**: 한국 금융당국 통계 없음 (조사 불가능)

## Existing Competitors
1. **Upwork 자체 기능**:
   - 에스크로 시스템 (선결제, 작업 완료 후 지급)
   - Trust & Safety 팀 (분쟁 해결)
   - 결제 보장 제도
   - 신원 확인 시스템
   - **가격: 무료** (Upwork 수수료 5~20%에 포함)

2. **Fiverr**: 비슷한 에스크로 기능 (무료)

3. **신용도 커뮤니티**: 경쟁자 찾지 못함 (미검증 가정)

## Alternative Solutions
- Upwork의 에스크로 시스템 (문제 해결의 70%)
- 선결제 요구
- 변호사 상담 (고비용)
- 정부 소상공인 대출 (느린 심사)

## Pricing Evidence
**가격 확인 불가**:
- Upwork는 이미 무료로 신용 보호 제공
- 프리랜서 신용도 커뮤니티의 경쟁 가격 찾지 못함
- 마이크로 크레딧: 해외 금리 월 3~16% (한국 미확인)

→ **CEO DIRECTIVE 적용: 가격 확인 불가 → 지불 의사 점수 상한 8점**

## Customer Acquisition
- Discord 커뮤니티 구축 (초기 관리 어려움)
- Upwork 커뮤니티 내 마케팅 (Upwork이 차단할 가능성)
- Reddit, Hacker News
→ **초기 10명 확보 난이도: 매우 높음** (글로벌, 신뢰 필요)

## MVP Cost
Manager 예상: 1,500~1,800만원
- Upwork API 1주
- 백엔드 (신용도 계산, 투표) 2주
- Discord 자동화 1주
- 금융사 협력 계약 2주
→ **300만원 초과**

## Development Feasibility
**난이도: 매우 높음**
- Upwork/Fiverr API 접근 (개발자 계정 승인 필요)
- 금융사 협력 (마이크로 크레딧 파트너) — **가장 큰 장애물**
- 규제 준수 (각국 금융감독, 반기금 세탁)
- Discord 자동화는 가능하나 커뮤니티 구축은 6개월+

## Monetization
- 마이크로 크레딧 수수료 (3~5%) — **기금 조달 필요**
- 프리미엄 신용도 분석 (월 $9.99)
- B2B (기업의 "프리랜서 평가") 판매

→ **기금 조달 또는 금융사 제휴 없이 시작 불가**

## Scalability
높음 (글로벌 1,000만명 시장)
낮음 (Upwork가 자체 신용도 기능 추가하면 대체)

## Major Risks
1. **Upwork의 에스크로가 이미 문제 해결**: 신뢰도 커뮤니티는 추가 가치 검증 필요
2. **금융사 파트너 불가능**: 마이크로 크레딧 없으면 사업 모델 붕괴
3. **규제**: 각국 금융감독청의 대출 라이센스 필요 (불가능한 경우 많음)
4. **신뢰도 정보의 정확성**: 잘못된 평가로 인한 법적 책임
5. **API 접근 불가**: Upwork이 제한하면 데이터 수집 불가

## Critical Assumptions
- 프리랜서가 Upwork의 에스크로 시스템만으로는 충분하지 않은가?
- 커뮤니티 투표 기반 신용도가 정확한가? (조작 가능성)
- 마이크로 크레딧 금융사가 B2B 프리랜서 대출을 원하는가?

# Idea 003. 미용실 AI 예약 비서 "스타일링 AI"

## 제품
미용실 노쇼 고객에게 AI 음성으로 1시간 전 친절한 리마인더 + 예약 자동 변경

## Target Customer
미용실 점주 (헤어샵, 매니큐어, 왁싱) / 한국 미용실 약 12만개

## Market Evidence
**미용실 노쇼 문제:**
- 서울 미용실 노쇼율: 19.2% (2016년 조사, 한국서비스산업진흥원)
- **점포당 연간 손실: 약 6,000만원** (노쇼 5명/일 × 평균 30만원 × 200일)
- 점주 인식: 84.1%가 선결제 필요성에 공감

## Existing Competitors
1. **SimplyBook.me**: 온라인 예약 시스템 (전 세계)
   - 기능: 기본 예약, 리마인더 이메일/SMS
   - 가격: **불명** (경제성 불명)

2. **Schedulingkit**: AI 대기자 관리
   - 기능: 취소된 슬롯을 대기 고객에 자동 연결
   - 가격: **불명**

3. **해외 AI 전화 응대 서비스**:
   - Goodcall: **월 $79** (에이전트당, 무제한 통화)
   - 3Ruby: **월 $250~$1,725** (분당 요금, 50분/월 기준)
   - Dialzara (미용실 전용): 가격 불명

4. **한국 예약 시스템 (당신의비즈니스, 네이버 예약 등)**: 기본 리마인더 기능 일부 제공, 가격 5~10만원/월 추정

## Alternative Solutions

건설 프로젝트 팀이 매일 1분 예산 상태 확인 미션 + 팀원 협력

## Target Customer
건설팀 (작은 협력사, 현장 관리자) / 약 5,000~10,000개 팀

## Market Evidence
**건설 예산 추적의 필요성:**
- 건설 프로젝트 관리 소프트웨어 시장 존재
- **구체적 손실 통계 없음**

## Existing Competitors
1. **Harvest**: 프로젝트 시간 추적 + 예산
   - 가격: **불명** (일반 SaaS 기준 월 $15~)

2. **ClickUp**: 건설 관리 템플릿
   - 가격: **월 5~$25** (팀 크기별)

3. **Bauwise**, **Contractor+** 등: 건설 예산 추적 소프트웨어
   - 가격: **모두 불명**

## Alternative Solutions
- 기존 건설 관리 소프트웨어 (예산 기능 포함)
- Excel 수동 관리

## Pricing Evidence
**ClickUp: 월 $5~$25** (저가)
→ **게임화 추가 가치로 프리미엄 가격 책정 가능한가? 불명**

# Idea 007. 환전 최적화 게임 "환율 매직"

## 제품
프리랜서가 매일 최적 환전 경로를 선택하는 게임 + 일주일 연속 선택 보너스

## Target Customer
글로벌 프리랜서 (환전 경험) / 약 500만명 (추정)

## Market Evidence
**프리랜서 환전 수수료 문제:**
- 환율 마크업: 은행/플랫폼이 중간 시장 환율 대비 2~5% 마크업 (체감하기 어려움)
- **수수료 절감 욕구는 있으나, 게임화로 얼마나 개선되는가? 불명**

## Existing Competitors
1. **Wise (구 TransferWise)**: 중간 시장 환율 기반 투명한 저수수료
   - 가격: **환율 마크업 0%, 수수료만 $2~** (매우 저가)
   - 강점: 이미 최적화된 솔루션

2. **Payoneer**: 마켓플레이스 편의성
   - 가격: **환율 마크업 2% + 수수료** (Wise보다 비쌈)

3. **MoneyTis**: 송금 서비스 비교 플랫폼
   - 기능: 실제 수령액 비교
   - 가격: **일부 서비스 무료**

## Pricing Evidence
**Wise: 환율 마크업 0%** (업계 최저)
→ **이미 최적화되어 있음**

# Idea 008. 온라인 튜터 신뢰 네트워크 "튜터봉드"

## 제품
튜터-학생 신뢰도 매칭 + 노쇼율 낮은 학생 커뮤니티

## Target Customer
온라인 튜터 (개발, 언어, 과목 등) / 글로벌 약 100만명 + 학생 수천만명

## Market Evidence
**온라인 튜터링 시장:**
- 글로벌 시장규모: 60~80억달러 (2024년), CAGR 13~22%
- **한국 시장규모: 통계 없음**
- 성장산업이나 신뢰/품질 문제는 여전함

## Existing Competitors
1. **Udemy**: 온라인 강좌 플랫폼
   - 기능: 수만개 강좌, 강사 평점 시스템
   - 가격: **코스당 $10~200** (1회성)
   - 신뢰도 메커니즘: 리뷰 기반

2. **Preply**: 1:1 튜터 매칭 플랫폼
   - 기능: 튜터 프로필, 평점, 샘플 수업
   - 가격: **시간당 $5~$100** (튜터별)
   - 신뢰도: 별점 기반 매칭

3. **VIPKid**: 영어 튜터 플랫폼
   - 가격: **월 $10~$40** (패키지)
   - 신뢰도: 튜터 배경 조사 + 학부모 평점

4. **Skillshare**: 크리에이티브 스킬 플랫폼
   - 가격: **월 $32** (구독)

## Alternative Solutions
- 기존 플랫폼 (Udemy, Preply, VIPKid)
- 학교 tutoring (오프라인)
- 개인 튜터 (word-of-mouth)

## Pricing Evidence
**경쟁자 가격 확인됨**:
- Preply: 시간당 $5~$100
- VIPKid: 월 $10~$40
- Skillshare: 월 $32
→ **지불 의사 신호: 높음** (이미 경쟁자가 성공적으로 수익화)

## Customer Acquisition
- 기존 플랫폼에서 튜터/학생 획득 (어려움, 경쟁자와 동일)
- 학교/학원 제휴
- SNS 마케팅
→ **초기 10명 확보 난이도: 높음** (경쟁자 먼저 점유함)

## MVP Cost
Manager 예상: 상세 비용 없음, 추정 1,500만원+
- 매칭 알고리즘
- 결제/수익 분배 (Stripe 등)
- 튜터/학생 앱
→ **300만원 초과**

## Development Feasibility
**난이도: 중간**
- 매칭 알고리즘은 기존 기술 (협업 필터링)
- 결제는 Stripe API 사용 가능
- **1인은 어려움** (튜터/학생 앱 동시 개발 필요)

## Monetization
불명확 (Manager 문서에 없음)
예상: 튜터 수수료 (15~30%) 또는 학생 구독료
→ **경쟁자들은 이미 수익화 중**

## Scalability
높음: 글로벌 시장 크다
낮음: 경쟁자 (Preply, VIPKid) 강하고 먼저 점유함

## Major Risks
1. **경쟁자 강함**: Preply/VIPKid 이미 신뢰도 기반 매칭 제공
2. **노쇼 문제 해결 방법 불명**: 선결제로 해결하면 게임 불필요
3. **튜터/학생 네트워크 효과**: 초기 3년 적자 가능성 높음

## Critical Assumptions
- 기존 플랫폼 (Preply)과 무엇이 다른가?
- 신뢰도 기반 매칭이 새로운가? (이미 Preply가 제공)

# Idea 009. SaaS 창업팀 이탈률 모니터링 "천이 감지기"

## 제품
실시간 이탈 신호 감지 + 자동화된 대응 제시

## Target Customer
SaaS 스타트업 (Series A~C) / 약 5,000~10,000개 (글로벌)

## Market Evidence
**SaaS 이탈 문제:**
- 평균 월 이탈률: 3.5% (SaaS 산업 평균)
- 대기업: 월 1.2%, 중견기업: 월 2.8%
- **이탈 예측은 매우 높은 가치** (LTV 영향 크다)

## Existing Competitors
1. **Mixpanel**: 분석 플랫폼 (이탈 예측 일부 포함)
   - 가격: **월 $999~** (고가)

2. **Amplitude**: 디지털 분석 플랫폼
   - 가격: **월 $995~** (고가)

3. **학술 연구**: 이탈 예측 모델은 논문 수준 (상용 제품 찾기 어려움)

## Alternative Solutions
- Mixpanel, Amplitude 기존 분석 도구 (이탈 기능 일부)
- 직접 구현 (데이터 엔지니어 필요)

## Pricing Evidence
**Mixpanel, Amplitude: 월 $1,000~**
→ **이탈 예측은 높은 가치, 그러나 기존 분석 도구에 포함**

# Idea 010. 소상공인 원가율 AI 어드바이저 "원가지원관"

## 제품
영수증 OCR → AI가 비용 인상 감지 → 더 싼 공급처 자동 추천

## Target Customer
소상공인 (식당, 카페, 소매점) / 한국 약 600만명

## Market Evidence
**소상공인 원가 관리:**
- 영수증을 상자에 모아두고 정리 못하는 문제 (일반적)
- **원가 추적은 기본 회계 기능**
- 구체적 손실 통계는 없음

## Existing Competitors
1. **페이히어 (PayHire) "AI 지출장부"**:
   - 기능: 영수증 사진 → OCR → 카테고리 분류
   - 가격: **무료** (앱 통합)
   - 추가 기능: 카테고리별 지출 분석
   - **이미 원가 관리 기본 기능 제공**

2. **기존 회계 소프트웨어** (직방, 더치페이, 오더카운트 등):
   - 기능: 영수증 OCR + 카테고리 분류
   - 가격: **일부 무료, 일부 유료** (수천원/월)

3. **Google Vision, Naver Clova OCR**: 범용 OCR API (기술 수준)

## Alternative Solutions
- 페이히어 무료 AI 지출장부
- 기존 회계 소프트웨어 (직방, 더치페이)
- 회계사무소 상담 (월 5~20만원)

## Pricing Evidence
**페이히어: 무료**
**기존 회계 소프트웨어: 월 5,000~30,000원**

→ **CEO DIRECTIVE 적용: 무료 대안(페이히어) 강함 → 고객 지불 의사 낮음**

## Customer Acquisition
- 소상공인 협회 제휴
- 카카오톡 비즈니스, 네이버 플레이스 제휴
→ **초기 10명 확보 난이도: 중간** (소상공인은 온라인 도구에 관심 낮은 편)

## MVP Cost
Manager 예상: 영수증 OCR + AI 추천
→ **1,500만원+ (300만원 초과)**

## Development Feasibility
**난이도: 중간**
- 영수증 OCR: 기존 API 사용 가능 (Google Vision, Upstage)
