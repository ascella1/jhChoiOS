## 1. CreatorSync — 다중플랫폼 영상 콘텐츠 자동화

### 제품 설명
YouTube, TikTok, Instagram에 1개 영상을 업로드할 때, 플랫폼별로 최적화된 제목·설명·태그를 AI가 자동으로 생성해주는 도구.

### Target Customer
- 인디 크리에이터 (2개 이상 플랫폼 운영, 주 2회+ 업로드)
- 소규모 콘텐츠 스튜디오 (3~10명)
- 개인 브랜드 운영자
- 글로벌 규모 (500M 월 YouTube 업로드)

### Market Evidence
- YouTube: 월 500M+ 영상 업로드 (실제 데이터)
- TikTok: 일일 활동사용자 10억명
- 다중플랫폼 운영 크리에이터의 메타데이터 최적화 수작업 시간: 월 20~40시간

### Existing Competitors
**직접 경쟁자:**
- Hootsuite: $99-$399/월 (Professional~Advanced) ✓ 유의미한 가격
- Buffer: $5-$12/채널/월 (Essentials~Team) ✓ 유의미한 가격
- Later: $25-$110/월 (Starter~Scale) ✓ 유의미한 가격

**간접 경쟁자:**
- CapCut: AI 자동 편집 (최근 확대)
- Opus Clip: AI 쇼츠 생성
- TikTok's Symphony: AI 디지털 스포크스퍼슨

### Alternative Solutions
- 수작업 (현재 대부분의 1인 크리에이터)
- YouTube AI 자막/썸네일 (무료 기본 기능)
- 각 플랫폼의 자체 메타데이터 제안 도구

### Pricing Evidence
**경쟁사가 월 $25~$399를 받고 있음** = 긍정적 신호 (시장 검증됨)
- Buffer: 채널당 월 $5-$12 (연간 $60-$144)
- Later: 월 $25-$110
- Hootsuite: 월 $99-$399

→ CEO Directive: 경쟁사 가격대가 높음 = 실제로 사람들이 이 문제에 대해 돈을 내고 있다는 증거

### Customer Acquisition
- Product Hunt 출시 (Tech 커뮤니티)
- Reddit r/CreatorEconomy, YouTube Creator Forum
- TikTok #ContentCreator 해시태그 사용자 다이렉트 아웃리치
- 초기 고객 10~20명: 소규모 크리에이터 Facebook 그룹 + Fiverr 크리에이터 네트워크

### MVP Cost
- **예상**: 300만원
- 기술 스택: Python + OpenAI GPT-4 API + YouTube/TikTok/IG API
- 인프라: AWS (초기 저비용, 사용량 기반)
- 개발 기간: 6주

### Development Feasibility
- **난이도**: 낮음~중간
- 공개 API 사용 가능 (YouTube, TikTok, Instagram 모두 공식 API 제공)
- OpenAI API로 텍스트 생성 가능
- 1인 개발자 충분히 가능
- 초기 MVP: "제목·설명·해시태그" 최적화에만 집중 (영상 생성/편집은 추후)

### Monetization
- **Freemium**: 월 3개 영상까지 무료 (기본 메타데이터만)
- **Pro**: 월 9,900원 - 무제한 영상, AI 썸네일 생성, 성과 분석
- **Creator+**: 월 29,000원 - 팀 계정, 다중 채널, 경쟁사 분석

### Scalability
- ⭐⭐⭐⭐⭐ (매우 높음)
- 글로벌 모든 크리에이터 대상 (규모 거의 무제한)
- 플랫폼 API 제약 위험 있음 (TikTok, Instagram 정책 변화)
- 고객 확장성: 사용자가 많을수록 커뮤니티 효과 (성공 콘텐츠 가이드 공유)

### Major Risks
🔴 **Critical:**
- 플랫폼 API 변경/중단 (YouTube, TikTok 정책 변화 위험)
- 플랫폼에서 자체 AI 메타데이터 도구 추가 가능성

🟡 **Medium:**
- 경쟁사 (Hootsuite, Buffer) 비디오 최적화 기능 추가 가능
- AI 생성 메타데이터가 항상 좋은 성과를 보장하지 않음

🟢 **Low:**
- 크리에이터의 가격 민감도

### Critical Assumptions
1. AI가 생성한 메타데이터가 크리에이터 손 수정 없이 바로 사용 가능한가? (정확도 80% 이상)
2. 자동 생성 메타데이터로 실제 조회수·클릭율이 향상되는가? (검증 필수)
3. 크리에이터가 월 10,000원을 낼 의향이 있는가?

### Market Score

## 2. TaxBot — AI 세무신고 자동 어시스턴트

### 제품 설명
개인사업자, 프리랜서를 위해 영수증 사진 1장으로 AI가 자동 분류·계산·작성해주는 세무신고 모바일 앱.

### Target Customer
- 개인사업자·프리랜서 (강사, 디자이너, 개발자)
- 소규모 자영업자 (카페, 학원, 트레이너)
- 소규모 기업 경리담당자
- 주로 한국 시장 (세무신고 규정 국가별 다름)

### Market Evidence
- 개인사업자 세무신고 수작업 시간: 월 8~16시간
- 연말정산 스트레스: 개인사업자 79%가 "세무신고 복잡도" 불만
- OCR 기술 성숙도: 80% 이상 정확도 달성 가능

### Existing Competitors
**직접 경쟁자:**
- QuickBooks Online: $20-$275/월 (5개 등급) ✓ 유의미한 가격
- TurboTax: $0-$209 (1회, 연간) ✓ 유의미한 가격 (해외)
- Wave: Free - $19/월 ✓ 무료~저가
- Shoeboxed: $23-$71/월 (Receipt scanning) ✓ 유의미한 가격

**간접 경쟁자:**
- 연말정산앱 (무료)
- Zoho Expense (무료~유료)
- Expensify ($5+/월)
- CentSense: Free - $5/월

### Alternative Solutions
- 세무사 상담 (월 30~100만원, 높은 비용)
- 회계사무소 (월 50~300만원)
- 수작업 엑셀 정리
- 국세청 간단신고 시스템 (무료)

### Pricing Evidence
**경쟁사가 월 $20~$275를 받고 있음** = 긍정적 신호
- QuickBooks: $20-$275/월
- Wave: 무료 - $19/월 (freemium 모델 성공)
- Shoeboxed: $23-$71/월

**BUT:** 무료 앱도 많음 (연말정산앱, 국세청)

→ CEO Directive: 경쟁사 가격대가 높음 = 시장 검증되었으나, 무료 대안이 풍부함

### Customer Acquisition
- 국세청 홍보 (세무신고 시즌: 1~3월, 7~9월)
- Reddit 개인사업자 커뮤니티
- 세무사·회계사 추천
- 프리랜서 플랫폼 (탈잉, 크몽, Upwork)

### MVP Cost
- **예상**: 280만원
- 기술 스택: Python + OpenAI GPT-4 Vision (OCR) + React
- OCR 정확도 개선: Custom fine-tuning 필요
- 국세청 API 연동 (간단신고 양식)

### Development Feasibility
- **난이도**: 중간~높음
- OCR 정확도 80% 이상 달성 필수 (실패 시 신뢰도 급락)
- 국세청 규정 준수 복잡함 (각 나라별로 다름)
- 1인 개발 가능하지만 OCR 모델 학습이 시간 소요

### Monetization
- **Freemium**: 월 5장까지 무료 스캔 (기본 리포트)
- **Pro**: 월 4,900원 - 무제한 스캔, 주별 리포트
- **Business**: 월 19,000원 - 다중 직원, 세무사 연동

### Scalability
- ⭐⭐⭐ (중간)
- 국가별 세무신고 규정 다름 (글로벌 확장 어려움)
- 한국 시장에만 집중 가능
- 고객 확장성: 개인사업자 300만명 (대한민국)

### Major Risks
🔴 **Critical:**
- OCR 정확도 미달 (80% 미만) → 신뢰도 완전 붕괴
- 세무신고 결과가 틀렸을 때 법적 책임 문제 (사용자 vs 회사)
- 국세청 규정 변경에 빠른 대응 필요

🟡 **Medium:**
- Wave, Zoho 등 무료 앱과의 경쟁
- 초기 OCR 학습 데이터 부족

🟢 **Low:**
- 가격 저항도 낮음 (월 5,000원은 충분히 지불 가능)

### Critical Assumptions
1. **OCR 정확도 80% 이상 달성 가능한가?** (검증 필수)
2. 실제 세무신고 자동화가 사용자의 시간 절감으로 이어지는가?
3. 세무신고 결과의 정확도가 세무사 수준인가? (법적 보호 필요)
4. 사용자가 AI 세무신고를 신뢰할 것인가?

## 3. PlatformSync — 플랫폼별 정산 통합 대시보드

### 제품 설명
온라인 강사, POS 점주를 위해 여러 플랫폼(탈잉, 유튜브, Fiverr, 배달앱)의 정산 내역을 한 곳에서 추적하고, AI가 예상 수령액을 실시간 계산해주는 도구.

### Target Customer
- 온라인 강사 (탈잉, 튜터닷컴, 클래스101, 유튜브)
- 소규모 카페·학원 점주 (POS·배달앱 연동)
- 다중 플랫폼 프리랜서 (Fiverr, Upwork, 크몽)

### Market Evidence
- 온라인 강사: 한국 ~100만명 이상
- 배달앱 가맹점: 한국 ~500만개
- Freelancer 플랫폼 사용자: 글로벌 2,000만명+
- 현금흐름 예측 불가능: 프리랜서/점주의 #1 Pain

### Existing Competitors
**직접 경쟁자 (거의 없음, 틈새 시장):**
- Stripe Connect: 거래액의 2.9% + 30¢ (결제 플랫폼, 정산 기능 부분 제공)
- Wise: 다중통화 계좌 ($5-$20/월 추정)
- 기존 세무신고 앱 (PlatformSync 기능 없음)

**간접 경쟁자:**
- 각 플랫폼의 자체 대시보드 (탈잉, 유튜브, Fiverr 각각)
- 수작업 엑셀 관리

### Alternative Solutions
- 각 플랫폼의 개별 대시보드 (분산된 관리)
- 세무사·회계사 상담 (월 10~50만원)
- 엑셀 수작업

### Pricing Evidence
**경쟁 정산 도구가 $5~$20/월 범위** = 중간 수준
- Stripe Connect: 수수료 기반 (거래액의 2.9%)
- Wise: 월 $5-$20 추정
- 무료 대안: 각 플랫폼의 자체 대시보드

→ CEO Directive: 경쟁사 가격대가 중간 수준 = 시장 존재하지만 경쟁 약함

### Customer Acquisition
- 온라인 강사 커뮤니티 (탈잉 강사 포럼, Reddit)
- 카페·학원 점주 커뮤니티
- 프리랜서 플랫폼 (Upwork, Fiverr)
- SEO: "정산 통합", "플랫폼별 수익"

### MVP Cost
- **예상**: 250만원
- 기술 스택: Node.js + React + PostgreSQL
- API 통합: 탈잉, YouTube, Fiverr, 카카오페이 4개
- 개발 기간: 4주

### Development Feasibility
- **난이도**: 중간
- 각 플랫폼 API의 거래 처리량 제한 (실시간 동기화 어려움)
- 배달앱(배민, 쿠팡)은 공개 API 부재 (어려움)
- 1인 개발 가능

### Monetization
- **Freemium**: 플랫폼 2개까지 무료
- **Pro**: 월 2,900원 - 3개 이상, AI 예측
- **B2B**: 월 29,000원 - 다중 직원, 관리자 대시보드

### Scalability
- ⭐⭐⭐ (중간)
- 국가별로 플랫폼이 다름 (글로벌 확장 어려움)
- 한국: 탈잉, 배달앱 (특화)
- 글로벌: Upwork, Fiverr (가능)

### Major Risks
🔴 **Critical:**
- 각 플랫폼의 API 접근 제약 (특히 배달앱)
- 플랫폼이 자체 정산 통합 기능 추가 가능성

🟡 **Medium:**
- 실시간 동기화 지연 (API 거래 처리량 제한)
- 국가별 플랫폼 다양성 (글로벌 확장 난제)

🟢 **Low:**
- 가격 저항도

### Critical Assumptions
