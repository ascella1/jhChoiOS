# CEO DIRECTIVE — 2026-10-02

## 문제 진단
2026-10-01 UNSATISFACTORY 판정 원인: **아이디어 혁신성 부족**
- 수금쌤, 야근팍팍, 영상쌤 모두 기존 경쟁사의 직접 복제 또는 피처 조합
- "차별화가 무엇인가?"에 명확한 답이 없는 아이디어만 생성됨

## 해결 방향

### Target Agent: Negative-Agent + Positive-Agent + Manager-Agent

### Objective
기존 시장의 "obvious solution"이 아닌, **예상 밖의 교차점**을 찾아 새로운 구조의 아이디어 생성

### New Search Strategy

#### 1. 교차 도메인 (Cross-Domain)
- Pain: 한국 야근비 미지급
- Positive: 일본 가챠가챠 (반복구매 심리)
→ **아이디어**: 야근비 "뽑기" (매달 월급 일부를 미지급액 추첨으로) — 게임화된 청구

#### 2. 역전 (Inversion)
- 기존: 시간을 절감해주는 앱
- 새로운: 시간을 **의도적으로 늘리는** 앱 (예: 문제 풀이를 여러 단계로 분해)

#### 3. 자동화 + 커뮤니티 (Automation + Community)
- Pain: 프리랜서 미수금
- Positive: 커뮤니티 신뢰도 (S006, S011, S020)
→ **아이디어**: 미수금 추적 + 블랙리스트 커뮤니티 (클라이언트 평판 시스템)

#### 4. 개인화 (Personalization)
- 기존: "모든 프리랜서에게 동일한 리마인더"
- 새로운: "이 클라이언트의 결제 패턴 학습 후 맞춤형 추론"

#### 5. 반복 행동의 재정의 (Redefine Frequency)
- Pain: 배달앱 점주 (매일)
- Positive: 앱테크 (매일)
→ **아이디어**: 배달점주가 "매일 1분 미니게임"으로 마진율 컨설팅 받기

### Exclude (반드시 제외)

- ❌ "X + Y의 단순 조합"
- ❌ "기존 경쟁사 + 약간의 AI"
- ❌ "저가 경쟁으로만 차별화"
- ❌ "기존 템플릿을 다른 산업에 적용"

### New Manager Scoring Rules

**혁신성 점수 추가 (신규)**
- 기존 경쟁사와 **구조적으로 다른가**: 0~10점 (필수)
  - 0~3: 거의 동일한 구조
  - 4~6: 약간 다름
  - 7~10: 새로운 구조

**기존 점수 중 조정**
- "첫 사용 가치" 재정의: 경쟁사 대비 **명백히 다른 경험**
- "Personalization" 강화: AI로 예측하는 새로운 차원 필요

### Expected Outcome

내일 Top 3은:
1. 기존 아이디어와 **구조적으로 다른** 제품
2. 명확한 차별화 포인트 ("왜 기존 서비스 대신 이것?")
3. 혁신성 점수 7/10 이상
