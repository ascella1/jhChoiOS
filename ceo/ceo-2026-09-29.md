### 🥈 #2: Part-Time Wage Automation (시간제 급여 자동화)

**Score: 85/100 (A)** | Negative: KR006 (7/10) | Positive: S008 | Manager: 85

#### 핵심 가치
- **Customer**: 한국 소상공인 200만 명 (식당, 카페, 편의점 점주)
- **Pain**: 매달 시간제 직원 급여 수작업 계산 (월 1~2시간) + 법적 오류 위험
- **Current**: 엑셀 + 회계사 비용 (월 10~50만원)
- **Solution**: 최저임금법 자동 반영 + 수당 자동 계산 + 세금 자동 처리

#### 비즈니스 케이스
| 항목 | 수치 | 근거 |
|---|---|---|
| **TAM** | **8.4조원** | 200만 × ₩3,500/월 × 12 |
| **한국 시장** | **200만 소상공인** | 식당/카페/편의점 |
| **월 절감액** | **₩3,500** | 회계사 비용 대체 |
| **연 절감액** | **₩420만원** | 점주당 |
| **MVP 비용** | **₩6,500만원** | 급여 계산 엔진 |
| **ROI** | **850-1,428%** | (₩420만 / ₩650만) × 100 |
| **1인 개발** | **✅ 가능** | 최저임금법 API + 계산 엔진 |

#### 왜 경쟁사가 없을까?
- ✅ **기존 솔루션**: 미래엔, UI 등 일반 POS (시간제 전문 X)
- ✅ **HR 소프트웨어**: 정규직 기준 (시간제 복잡도 미지원)
- ✅ **Market Gap**: "최저임금법 변화 → 점주 행정 부담" 은 해결되지 않음
- ✅ **일본**: S008에서 부분 경쟁이 보이지만, 입소문 낮음 (완전 독점 가능)

#### MVP 계획
1. **Phase 1** (3주): 급여 계산 엔진
   - 최저임금법 자동 업데이트
   - 야간/휴일/초과 수당 자동 계산
   - 4대 보험 자동 처리

2. **Phase 2** (2주): UI + 타임카드 연동
   - 점주용 대시보드
   - 직원 급여 명세서 자동 생성

3. **비용**: MVP ₩6,500만원

#### 비용 절감 시뮬레이션
```
점주가 매달 급여 계산에 드는 시간:
- 6명 직원 × 월 1시간 = 월 1시간

앱 도입 후:
- 타임카드 입력 5분 + 자동 계산 1분 = 월 6분

절감: 월 54분 → 연 10.8시간
가치: 10.8시간 × ₩30,000/시간 = 연 ₩324,000
+ 회계사 비용 절감: 월 ₩30,000 × 12 = ₩360,000
= 총 연 ₩680,000 절감

MVP 비용 ₩6,500만원 대비 ROI: 1,046%
```
