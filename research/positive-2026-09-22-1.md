## S001. Cursor AI 탭 자동완성 — "VS Code로 못 돌아간다"

- **지역:** 글로벌
- **국가:** 미국 중심, 국제
- **타깃 고객:** 소프트웨어 개발자 (풀스택, 백엔드, 스타트업 엔지니어)
- **사람들이 좋아하는 행동:** 코드를 타이핑하는 도중 AI가 다음 줄·함수를 예측해 완성해주는 Tab 자동완성을 수용/거절하는 행위. Codebase Indexing을 통해 "파일을 열지 않아도 프로젝트 전체를 이해한 동료와 대화하는 느낌"으로 질문하는 행위.
- **핵심 경험:** 코드 작성 흐름이 끊기지 않으면서 반복적 보일러플레이트가 사라지는 경험. "실험이었다가 4개월 후 없으면 안 됨"으로 전환.
- **핵심 감정:** 생산성 증폭 만족감, 통제감 유지(AI가 쓰되 내가 승인), "VS Code로 못 돌아간다"는 의존감
- **사용 빈도:** 코딩하는 매 순간 (하루 수백 회 탭 완성)
- **반복 사용 이유:** 탭을 누르는 행위 자체가 즉각 보상. 리팩토링·테스트 작성에서 주 15~20시간 절감 경험.
- **공유 이유:** 팀원에게 "이 도구 써봐"라고 추천, 블로그·Reddit 후기 다수
- **지불 이유:** $20/월. "한 시간 절약분도 안 되는 가격"이라는 ROI 인식
- **개인화 가능성:** Codebase Indexing으로 프로젝트가 쌓일수록 제안 품질 향상
- **AI 활용 가능성:** 이미 핵심 가치가 AI

### 실제 근거
- 4개월 사용팀: "interesting experiment → can't imagine going back to VS Code." (credentials.substack.com, 2026)
- Tab 완성이 "addictive" — 자동 보일러플레이트이면서도 개발자가 통제권을 유지 (dev.to review, 2026)
- 2026년 900명 개발자 설문: Claude Code와 함께 가장 많이 사용·가장 사랑받는 AI 코딩 도구 (codegen.com)
- 자율 에이전트로 주 15~20시간 절감 (nocode.mba 6개월 리뷰)

### 왜 사람들이 좋아하는가
코드를 쓰는 **행위 자체**에서 마찰이 사라지는 경험. 탭 한 번이 즉각 보상이기 때문에 이 루프가 매우 빠르게 습관화된다. 기존 AI 도구가 "창문 밖에서 보조"였다면 Cursor는 "편집기 안에 앉아 있는 동료"에 더 가까워 이탈 장벽이 높다.

### 다른 제품으로 확장할 수 있는 요소
- **행위 내 즉각 보상** 구조 → 글쓰기·법률문서·의학차트 등 다른 전문직 에디터에 동일 UX 적용 가능
- 프로젝트 컨텍스트 누적 → 쓸수록 좋아지는 강화 루프

### 가정
- 탭 완성 중독은 보고된 경험이나 사용 중단 시 생산성 저하 통계는 미확인

## S002. Strava 세그먼트 & Kudos — 혼자 뛰어도 경쟁 중인 느낌

- **지역:** 글로벌
- **국가:** 미국, 유럽, 일본, 한국 포함 전세계
- **타깃 고객:** 러너·사이클리스트 (캐주얼~아마추어 경쟁자)
- **사람들이 좋아하는 행동:** 달리기·라이딩을 기록하고, 특정 구간(세그먼트)에서 순위를 확인하고, 팔로워에게 Kudos(엄지척)를 받고 보내는 피드 순환
- **핵심 경험:** "혼자 뛰는데 경쟁이 있다." 매 달리기가 리더보드에 반영되는 순간 게임화됨.
- **핵심 감정:** 경쟁 쾌감, 소속감(클럽·친구), 동기 유지
- **사용 빈도:** 운동 후 즉시 + 팔로워 피드 확인 (하루 1~2회)
- **반복 사용 이유:** 세그먼트 KOM/QOM 순위 갱신 욕구. "매 달리기가 의미 있다"는 구조.
- **공유 이유:** Kudos 요청·클럽 경쟁이 내재화. 달린 경로·시간 기록이 소셜 자본.
- **지불 이유:** $11.99/월 혹은 $79.99/년. 레이스 참가자·클럽 소속자에게 "가장 사랑받는 사회적 레이어"가 프리미엄 잠금.
- **개인화 가능성:** 트레이닝 플랜, 심박수 기반 제안이 쌓일수록 맞춤화
- **AI 활용 가능성:** 세그먼트 개인 예측, 피로도 분석, 코스 추천

### 실제 근거
- "I live for segments. Every run feels like a race—even when I'm alone." (independent-app-reviews.org, Strava Review 2026)
- "The social feed is where Strava becomes habit-forming" — Kudos와 세그먼트이 없으면 폐쇄 생태계가 따라잡을 수 없는 모트 (strava review 2026)
- 세계 100M+ 사용자. 일본 App Store/Google Play 양쪽 상위권 유지.

### 왜 사람들이 좋아하는가
운동은 원래 고독하다. Strava는 **기록을 공개 리더보드에 즉시 반영**함으로써 혼자 뛰는 행위에 사회적 의미를 부여한다. Kudos는 "좋아요"보다 문맥이 풍부하고(달리기 완료), 세그먼트는 내가 이미 아는 길에서 매번 새로운 경쟁을 만든다.

### 다른 제품으로 확장할 수 있는 요소
- 실적 기록 → 즉시 리더보드 → 커뮤니티 반응의 3단계 루프를 헬스·수영·클라이밍 등에 이식
- 지역 기반 커뮤니티 + 기록 공유를 다른 취미(사진 산책, 독서 산책 등)에 적용

### 가정
- 일본·한국 유료 전환율 미확인

## S003. Duolingo 스트릭 상실 회피 — "배우는 게 아니라 잃기 싫어서 한다"

- **지역:** 글로벌
- **국가:** 전세계 (미국, 한국, 일본 모두 대규모 사용)
- **타깃 고객:** 어학 학습자 (언어 목적보다 루틴 목적 포함)
- **사람들이 좋아하는 행동:** 매일 최소 1레슨을 완료하여 스트릭을 유지하는 행위. 365일+ 스트릭을 SNS에 공유하는 행위.
- **핵심 경험:** "오늘 안 하면 스트릭이 끊긴다"는 손실 회피. 달성 시 작은 의례감.
- **핵심 감정:** 상실 두려움(loss aversion), 정체성 투자("나는 365일 학습자")
- **사용 빈도:** 매일 (스트릭 유지 목적으로)
- **반복 사용 이유:** 손실 회피. 스트릭이 공공 정체성이 되면 사회적 비용도 추가됨.
- **공유 이유:** 365일·500일·1000일 스트릭 스크린샷. "Streak Society" 배지.
- **지불 이유:** Streak Freeze(스트릭 보험), 무제한 하트 → 스트릭 보호를 위한 지불
- **개인화 가능성:** AI 예측 넛지(피로도 기반 알림 타이밍 조정)
- **AI 활용 가능성:** 현재 AI 음성·작문 피드백 도입 중

### 실제 근거
- 365일 이상 스트릭 유지자 1,000만 명 이상 (2026 초 기준, Duolingo 블로그)
- 유지율 12% → 55%로 상승. 스트릭 없는 앱 대비 (StriveCloud 인용, academicjobs.com)
- "사람들이 더 이상 배우러 로그인하지 않는다—잃지 않으려고 로그인한다." (Quora 다수 응답 요약)
- 최장 스트릭 4,982일 (2026 기준, unanswered.io)

### 왜 사람들이 좋아하는가
인간의 손실 회피 편향을 정확히 겨냥한 메커니즘. 스트릭이 길어질수록 그 자체가 정체성이 되어 외부에서도 사회적 비용이 발생한다. 이는 앱 내 게임이 아니라 자아 이미지가 된 상태로, 이탈 장벽이 매우 높다.

### 다른 제품으로 확장할 수 있는 요소
- 손실 회피 스트릭을 어떤 일일 루틴에도 이식 가능 (운동, 명상, 코딩 챌린지)
- "스트릭 보험" 유료화 모델 → 루틴 SaaS의 수익 모델로 직접 적용

### 가정
- 스트릭이 실제 언어 능력 향상과 상관관계가 있는지는 별개 문제

## S004. Spotify Wrapped 연간 공유 — "취향 데이터가 정체성 명함"

- **지역:** 글로벌
- **국가:** 전세계 (소셜 미디어 활성국 중심)
- **타깃 고객:** Spotify 사용자 (특히 SNS 활동적인 10~30대)
- **사람들이 좋아하는 행동:** 연 1회 Wrapped 공개 시 자신의 음악 데이터를 Instagram Story에 공유하고, 친구 것과 비교하는 행위. Discover Weekly를 매주 기다리는 행위.
- **핵심 경험:** "내 취향이 데이터로 증명된다." 음악 정체성의 연례 의식.
- **핵심 감정:** 자기 표현, 정체성 확인, 친구와 비교하는 재미 (소속감 + 차별화 동시)
- **사용 빈도:** Wrapped는 연 1회 폭발적. Discover Weekly는 매주.
- **반복 사용 이유:** 매주 신곡 발견 쾌감. 연말 Wrapped 기대감이 연중 청취 동기.
- **공유 이유:** Wrapped 2025년 기준 5억 회 이상 공유 (전년 대비 41% 증가). "내 Listener Personality가 뭐야?" 대화 유도.
- **지불 이유:** 광고 없는 청취 + 오프라인 저장 → Wrapped는 무료 기능이지만 청취 기반이 프리미엄 전환을 촉진
- **개인화 가능성:** 전 청취 기록 Recap 기능 출시(2026년 5월), Listening Age 등 새로운 정체성 지표 추가
- **AI 활용 가능성:** Prompted Playlist (자연어로 플리 생성) 베타 확장 중

### 실제 근거
- Wrapped 2025: 5억 회 이상 공유, 전년 대비 41% 증가 (digitalmusicnews.com, 2026)
- "Spotify turned passive data into identity—your Wrapped isn't just what you listened to, it's proof you have taste." (nogood.io)
- Wrapped 출시일 인스타그램에서 지인 게시물 중 Wrapped 비중이 가장 높아지는 날 (UVA research)
- 2026년 5월: 전체 청취 기록 Recap 기능 출시 (TechCrunch)

### 왜 사람들이 좋아하는가
**수동적 행동(듣기)**을 **능동적 정체성(취향 명함)**으로 변환하는 메커니즘. 별도 입력 없이도 "나를 설명하는 데이터"가 자동 생성되고, 연 1회 폭발적으로 공유된다. Optimal Distinctiveness Theory — 소속감(나도 Wrapped 했어)과 차별화(내 취향은 이래)를 동시에 충족.

### 다른 제품으로 확장할 수 있는 요소
- 수동 데이터 → 자동 리포트 → 연간 공유 카드 구조는 독서·운동·코딩·지출 어디에도 이식 가능
- "내 한 해 독서 Wrapped" 같은 연말 공유 의식 설계

- **개인화 가능성:** 개인 스타일로 카드 커스터마이징, 누적 기록 대시보드

## S020. AI 코딩 도구 병행 — "복잡한 건 Claude Code, 인라인은 Copilot"

- **지역:** 글로벌
- **국가:** 미국, 한국, 유럽 등 개발자 집중 지역
- **타깃 고객:** 시니어 개발자, 프로덕트 엔지니어 (연봉 높은 전문직)
- **사람들이 좋아하는 행동:** Copilot($10/월) + Claude Code($20/월) 두 개를 동시에 사용. 일상적 자동완성은 Copilot, 복잡한 리팩토링·새 기능은 Claude Code 에이전트로 역할 분담하는 행위.
- **핵심 경험:** "하나만 쓰면 뭔가 아쉽다" — 두 도구가 보완적으로 작동하는 시너지 인식.
- **핵심 감정:** 최고 성능에 대한 욕구 충족, "나는 최고 도구를 쓴다"는 자부심
- **사용 빈도:** 코딩하는 매 순간
- **반복 이유:** 둘 중 하나만 써도 부족하다는 경험이 쌓임. 병행이 표준화됨.
- **공유 이유:** "나는 이렇게 쓴다" 블로그·Reddit·YouTube 워크플로 공유
- **지불 이유:** Copilot $10 + Claude Pro $20 = $30/월. "한 시간 절약해도 본전"이라는 ROI 인식.
- **개인화 가능성:** 각 도구가 프로젝트 컨텍스트 누적으로 점점 정확해짐
- **AI 활용 가능성:** 이미 핵심 가치

### 실제 근거
- "I run both. Copilot finishes my lines while I type. Claude Code handles the refactors I would have spent a Saturday on." (2026 개발자 인용, superblocks.com)
- "Senior engineers tend to land on Claude Code for hard work and Copilot for easy work, and a growing number simply pay for both." (eesel.ai, 2026)
- 2026년 고성능 엔지니어링 팀의 다수가 두 도구를 동시 사용 (superblocks.com)
- 900명 설문: Claude Code 46%가 "가장 좋아하는 AI 코딩 도구" 1위, Copilot은 여전히 2위 (codegen.com)

### 왜 사람들이 좋아하는가
$30/월이 개발자 시급 대비 매우 저렴해 "두 개 다 구독"이 합리적 선택이 됐다. 도구마다 잘하는 게 달라 하나로 통일하면 손해라는 인식이 병행 구독을 정당화한다.

### 다른 제품으로 확장할 수 있는 요소
- "역할 분담 병행 구독" 패턴 → 법률(조사 AI + 문서 AI), 의료(진단 AI + 기록 AI) 등 전문직에 적용
- 두 도구 워크플로를 통합 오케스트레이션하는 레이어 제품

### 가정
- $30/월 병행 지불자 비율 정확한 수치 없음. 질적 증언 기반.
