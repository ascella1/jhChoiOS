## P001. 직장인 부당 야근비 미지급 및 법적 증거 수집 어려움

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 직장인, 특히 중소기업 및 비정규직
- 핵심 문제: 근로기준법상 야근수당은 강행규정이지만, 83%의 직장인이 야근하는 반면 상당수가 미지급 상태. 포괄임금제를 이유로 거부하거나, 청구 과정에서 법적 증거 부족으로 어려움
- 사람들이 실제로 싫어하는 것: "월 20시간 야근을 해도 기본급에만 포함된다고 함", "미지급 야근비를 청구하려면 출퇴근 기록을 직접 증명해야 함", "회사 내에서 야근비 요청 시 낙인 우려"
- 현재 해결 방법: 출퇴근 시간 수동 기록(카드, 이메일), 엑셀로 야근시간 정리, 3년 내 소송 추진, 고용노동부 진정
- 발생 빈도: 주 4~5회 (일상적 야근)
- 시간 비용: 월 20~40시간 (무보상 야근 + 증거 수집)
- 금전 비용: 월 50만~200만원 손실
- 문제 심각도 (0~10): 7
- 현재 지출: 월 300~500만원 (기본급만)
- 소프트웨어 해결 가능성: 높음 (자동 출퇴근 추적 + 야근비 계산)
- AI 해결 가능성: 높음 (포괄임금제 위반 감지 + 법적 조언)
- 1인 개발 가능성: 중간 (기업 근태 시스템 연동 필요)

### 실제 근거

### 왜 중요한 문제인가
직장인의 생존 이슈. 월 50만~200만원의 정기적 손실은 개인 재정에 심각한 영향. 법적 보호가 있지만 증거 수집 과정이 수작업으로 시간 낭비.

### 스크리닝 결과

② 업계 무료 자료: No — 각 회사별로 다른 포괄임금 규정  
③ SaaS 부가기능: No — 야근비 자동추적 솔루션 거의 없음  
④ 반복 빈도: 주 4~5회 (일상적)

## P002. 가계부 앱 은행 연동 부족으로 수작업 입력 강요

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 개인재정 관리자, 월급생활자, 프리랜서
- 핵심 문제: 가계부 앱(편한가계부, 꼬박가계부 등)이 은행 자동 연동 기능 부족. 카드 연동되어도 현금 소비는 수동 입력 필수. 매일 거래내역을 검토해서 일일이 입력해야 함
- 사람들이 실제로 싫어하는 것: "계좌 연결했는데도 자동 입력이 안 됨", "매번 수동으로 입력하다 보니 며칠 지나면 기록 누락", "카드 거래만 나오고 현금은 수동해야 함"
- 현재 해결 방법: 네이버 가계부 (SMS 자동 입력), 전자금융 API 제한적 제공, 수동 입력에 익숙해지기
- 발생 빈도: 매일 (매일 거래 발생)
- 시간 비용: 월 3~5시간 (거래 입력 및 분류)
- 금전 비용: 없음
- 문제 심각도 (0~10): 5
- 현재 지출: 무료~월 3,000원 (프리미엄)
- 소프트웨어 해결 가능성: 높음 (은행 API 통합)
- AI 해결 가능성: 중간 (거래 카테고리 자동 분류)
- 1인 개발 가능성: 낮음 (은행 API 승인 필요)

### 실제 근거
- 사용자 실제 불만: "가계부 앱을 쓰는데도 은행 앱을 번갈아 봐야 함"
- 네이버 가계부의 SMS 자동 입력 기능이 이미 존재 → 현금 처리는 여전히 수동

### 왜 중요한 문제인가
월 3~5시간의 반복적 시간 낭비. 현금 거래가 많은 한국에서 자동화 부족으로 기록 누락 발생.

### 스크리닝 결과
① 정부 제공: No  
② 업계 무료 자료: No  
③ SaaS 부가기능: Partial — 네이버 가계부, 토스 등에서 부분 해결  
④ 반복 빈도: 매일  

→ **신중채택** — 무료 대안(네이버 가계부)이 부분 해결하지만, 현금 통합이 미흡한 점은 실제 pain

### 가정
- 은행권 API 개방 범위 확인 필요
- 현금 거래 자동 추적 기술의 현실성 (영수증 카메라 등)

### 출처
- 가계부 앱 분석 (편한가계부, 꼬박가계부, 네이버 가계부 비교)

### 다음 조사 방향
- 한국 가계부 사용자 50명: 월평 수동 입력 시간 및 현금거래 비율
- 네이버 가계부의 은행 연동율 및 현금 기능 조사

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 자동차 렌탈 이용자, 특히 단기 렌탈 후 변심자
- 핵심 문제: 렌탈 약관에 중도해지 수수료가 불명확하게 기재되거나 잔존가치를 포함해 과다 청구. 공정거래위원회가 현대캐피탈, KB캐피탈, 롯데렌탈, SK네트웍스 등 14개사의 불공정 약관 적발

- 현재 해결 방법: 약관 꼼꼼히 읽기, 계약 전 수수료 확인 전화, 공정거래위원회 신고

- 시간 비용: 1~2시간 (약관 검토 + 계산)
- 금전 비용: 중도해지 시 20~600만원 손실
- 문제 심각도 (0~10): 6
- 현재 지출: 렌탈료 (일반적 비용)
- 소프트웨어 해결 가능성: 높음 (투명한 수수료 계산기)
- AI 해결 가능성: 중간 (약관 해석 및 예상 비용 안내)

## P004. 어린이집 보육료 환불 절차 복잡 및 지연

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 영유아 부모, 특히 보육료 지원 이용자
- 핵심 문제: 보육료 환불이 정부 이용권, 어린이집 규정, 지자체 지침이 모두 다르게 적용되어 혼란. 등원 기준, 결제 항목별 환불이 복잡함
- 사람들이 실제로 싫어하는 것: "환불 기준이 어린이집마다 다름", "정부 이용권 부분과 현금 부분 환불이 꼬임", "1~2시간 소비하고도 결과 불명확"
- 현재 해결 방법: 어린이집 환불 규정 직접 문의, 지자체 보육 담당 부서 상담, 한국소비자원(1372) 상담
- 발생 빈도: 아동 입·퇴원 시 1~2회
- 시간 비용: 1~2시간 (절차 확인 및 서류 작성)
- 금전 비용: 월 보육료의 50~100% 환불 가능성 (기준에 따라 0원일 수도)
- 문제 심각도 (0~10): 4
- 현재 지출: 월 보육료 (평균 20~30만원)
- 소프트웨어 해결 가능성: 중간 (지역별 규정 통합 DB)
- AI 해결 가능성: 중간 (규정 해석 및 환불 예측)
- 1인 개발 가능성: 낮음 (지자체별 규정 수집 필요)

### 실제 근거
- 대법원 2014년 판결: 보육료 결제 구조 (정부 지원금과 보호자 부담의 혼재)
- 82cook.com 커뮤니티 (2006년): 실제 사용자 사례 — "규정상 1주일 이전 50% 환불, 그 이후는 안 된다는 설명 받음" → 소비자고발센터에 확인한 결과 "등원일 기준으로 계산 가능"

### 왜 중요한 문제인가
부모의 시간 낭비와 명확하지 않은 환불로 인한 재정 손실. 정부 지원 사업이지만 운영 기준이 복잡.

### 스크리닝 결과
① 정부 제공: Partial — 정부 이용권 + 지자체 규정 존재하지만 통합 정보 부족  
② 업계 무료 자료: No

## P018. 소프트웨어 개발자 산재 보험 서류 관리 복잡

- 지역: 전세계
- 국가: 주로 미국, 호주
- 타깃 고객: 프리랜서 개발자, 소규모 스튜디오

- 사람들이 실제로 싫어하는 것: "어떤 서류를 제출해야 하는지 명확하지 않음", "일하던 시간을 증명해야 하는데 기록이 없음", "보험사마다 요구 서류가 다름"
- 현재 해결 방법: 노무사/변호사 상담, 노동청 진정, 보험사 직접 문의
- 발생 빈도: 상해 발생 시 (개인마다 다름, 연 1회 미만)
- 시간 비용: 10~20시간 (서류 수집 + 정리)
- 금전 비용: 노무사/변호사 비용 ($500~$5,000)
- 문제 심각도 (0~10): 6
- 현재 지출: 산재 보험료 (변동)
- 소프트웨어 해결 가능성: 중간 (서류 관리 + 체크리스트)
- AI 해결 가능성: 낮음 (보험 규정이 지역별로 상이)
- 1인 개발 가능성: 낮음 (보험/법 지식 필요)

## P019. 유튜브 크리에이터 자막 편집 시간 소비 및 번거로움

- 지역: 전세계
- 국가: 주로 한국, 미국, 일본
- 타깃 고객: 유튜브 크리에이터, 콘텐츠 제작자
- 핵심 문제: 1시간 영상의 자막 편집에 4시간이 소비됨. YouTube의 자동 자막은 정확도가 낮고(기술 용어, 억양 인식 오류), 수작업으로 각 자막의 시간코드, 띄어쓰기, 문법을 수정해야 함
- 사람들이 실제로 싫어하는 것: "25분 영상 = 25시간 자막 편집", "자동 자막이 너무 부정확함", "타이밍 조정만 해도 몇 시간", "자막이 겹치거나 빨리 지나감"
- 현재 해결 방법: Descript($12~30/월), YouTube 자체 자막 + 수정, Whisper 음성 인식 후 수정, 자막 전문가 외주

- 금전 비용: 월 $12~30 (Descript) 또는 외주비 $100~500/영상
- 문제 심각도 (0~10): 7
- 현재 지출: Descript 또는 유사 서비스 (월 $0~50)
- 소프트웨어 해결 가능성: 높음 (AI 음성→자막 + 번역)
- AI 해결 가능성: 높음 (Whisper API + 타이밍 자동 조정)
- 1인 개발 가능성: 중간 (OpenAI API 활용 가능)

## P020. 가족 공유 캘린더 동기화 오류 및 충돌 반복

- 지역: 전세계
- 국가: 주로 미국, 유럽, 일본, 한국
- 타깃 고객: 가족 또는 소규모 팀 일정 관리자
- 핵심 문제: Google Calendar, Apple iCloud, Outlook Calendar 간 공유 캘린더 동기화 오류. 한 사람이 추가한 일정이 다른 사람의 기기에 나타나지 않음. 중복 일정 또는 "좀비 일정"이 남음
- 사람들이 실제로 싫어하는 것: "남편이 추가한 일정이 아내 iPhone에 안 보임", "같은 일정이 두 번 나타남", "일정을 삭제했는데 자꾸 부활함", "며칠 뒤에야 동기화됨"
- 현재 해결 방법: 캘린더 켜고 끄기(토글), 기기 재시작, Google/Apple 계정 다시 로그인, 써드파티 도구(CalendarBridge, OneCal)
- 발생 빈도: 주 1~3회 (일정 추가/변경 시)
- 시간 비용: 월 1~3시간 (동기화 문제 해결)
- 금전 비용: 없음 (무료 또는 $5~10/월 써드파티)
- 문제 심각도 (0~10): 4
- 현재 지출: 캘린더 앱 (대부분 무료)
- 소프트웨어 해결 가능성: 높음 (통합 캘린더 플랫폼)
- AI 해결 가능성: 낮음 (프로토콜 문제)
