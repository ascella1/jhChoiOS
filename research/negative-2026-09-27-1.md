## P001. 편의점 택배 보관 기한 만료 후 반품 자동 처리 미인식

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 배송 물품 수령자, 편의점 택배 서비스 사용자
- 핵심 문제: 한국의 GS25, CU, 이마트24 등 편의점에서 택배 수령 서비스를 제공하지만, 사용자가 일정 기간(보통 5~7일) 내에 수령하지 않으면 자동으로 발송자에게 반품됨. 사용자가 기한을 놓쳤을 경우 알림을 받지 못하고, 반품이 이루어진 후 재배송을 요청해야 하는 번거로움 발생. 또한 반품 로그를 추적하기 어려워 배송 추적이 중단되기도 함
- 사람들이 실제로 싫어하는 것: "편의점에서 기한 내에 안 가면 자동 반품되는데 미리 알림을 안 줌", "반품된 걸 알고도 발송자가 "너가 안 받았냐"고 묻거나 재배송을 거부하는 경우 다수", "편의점 수령 코드를 잃어버렸는데 기한이 지나서 재수령 불가"
- 현재 해결 방법: 편의점에서 수작업으로 기한 확인 (앱이나 알림 없음), 발송자에게 전화로 재배송 요청, 편의점 직원에게 연장 요청 (거절당할 가능성 높음)
- 발생 빈도: 월 1~2회 (편의점 수령 시마다 위험)
- 시간 비용: 반품 후 재배송 요청에 30분~1시간
- 금전 비용: 재배송 배송비 2,500~3,500원 (발송자가 부담 시 무료)
- 문제 심각도 (0~10): 4
- 현재 지출: 무료~배송비 부담
- 소프트웨어 해결 가능성: 높음 (택배사 + 편의점 알림 API 연동)
- AI 해결 가능성: 낮음 (기한 추적은 수동)
- 1인 개발 가능성: 낮음 (편의점 + 택배사 API 협력)

### 실제 근거
- 한국 편의점 수령 서비스 약관: "5~7일 이내 미수령 시 자동 반품" (각사별 상이)
- 오늘의 집/당근마켓 커뮤니티: "편의점 택배 기한 놓쳤다"는 검색어에 월 100+ 게시물
- 택배 추적 앱 리뷰: "편의점 보관 기한 만료 후 상태 변경만 되고 알림이 없음"

### 신호 스크리닝
① 정부 무료 제공: No — 편의점별로 독립적 운영
② 업계 무료 콘텐츠: No — 각 편의점이 자체 시스템 운영
③ 기존 SaaS 포함: No — 통합 알림 서비스 부재
④ 반복 빈도: 월 1~2회

**판정**: 채택 — 반복 발생하는 사용자 pain

### 왜 중요한 문제인가
사용자가 편의점 기한을 놓칠 때마다 재배송 요청에 시간을 낭비하고, 간선 배송비를 지불해야 할 수도 있음. 자동 알림 시스템이 있으면 월 1시간 절감.

### 가정
- 편의점 + 택배사 API 연동 가능 여부 확인 필요

## P002. 공동 주택 관리비 고지서 오류 및 이의 절차 복잡

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 아파트/공동주택 거주자, 주택 소유자
- 핵심 문제: 매달 공동주택 관리비(공동관리비, 전기료 등)를 고지받는데, 청구액에 오류가 있을 수 있음 (예: 이전 세입자의 요금이 현재 세입자에게 청구되거나, 공용 시설 공사 비용이 잘못 배분됨). 이의를 제기하려면 관리사무소에 문서 제출 후 수 개월을 기다려야 하고, 이의가 인정되더라도 환급 절차가 복잡함
- 사람들이 실제로 싫어하는 것: "매달 관리비를 내는데 청구 항목을 이해할 수 없음", "오류를 지적해도 관리사무소가 대응이 느림", "환급받는 데 6개월 이상 걸리는 경우 다수"
- 현재 해결 방법: 관리사무소에 직접 방문 → 문서 제출 → 수개월 대기 → 환급 신청
- 발생 빈도: 월 1회 (관리비 고지 시)
- 시간 비용: 이의 제기 및 추적에 월 1~2시간
- 금전 비용: 월 2,000~10,000원 과다 청구 가능성
- 문제 심각도 (0~10): 5
- 현재 지출: 월 20만~40만원 (관리비)
- 소프트웨어 해결 가능성: 높음 (관리비 청구 내역 자동 검증)
- AI 해결 가능성: 중간 (이의 근거 자동 생성)
- 1인 개발 가능성: 중간 (관리사무소 시스템 협력)

### 실제 근거
- 국토교통부 "공동주택 관리법" — 관리비 이의 제기 절차 명시되어 있으나, 실제 집행이 느림
- 아파트 커뮤니티 앱(당근마켓, 더 아파트 등): "관리비 오류" 검색어에 월 50+ 게시물
- 한국소비자원 사건 기록: 관리비 오류 소비자 분쟁 증가

### 신호 스크리닝
① 정부 무료 제공: Partial — 국토교통부가 이의 절차를 정의했지만, 검증 자동화는 제공하지 않음
② 업계 무료 콘텐츠: No — 각 관리사무소별 다른 시스템
③ 기존 SaaS 포함: No — 관리비 검증 서비스 부재
④ 반복 빈도: 월 1회

**판정**: 채택 — 모든 아파트 거주자가 경험하는 반복적 pain

### 왜 중요한 문제인가
아파트 거주자가 매달 고지받는 관리비의 정확성을 확인할 수 없고, 오류 이의 제기 절차가 복잡함. 자동 검증 시스템이 있으면 월 1시간 절감 + 연 2만~12만원 절감 가능.

### 가정
- 관리사무소가 청구 시스템을 외부 API로 개방할 의지 여부 확인 필요

## P003. 프리랜서 원고료 정산 및 세금 신고 수작업

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 한국 프리랜서, 웹라이터, 번역가, 디자이너
- 핵심 문제: 한국의 프리랜서(특히 개인사업자가 아닌 프리랜서)는 매달 원고료를 받은 후, 이를 기록하고, 개인소득세/부가세를 계산해야 함. 그러나 각 플랫폼(당근마켓, 크몽, 당신의서재 등)에서 제공하는 정산액 형식이 다르고, 이를 통합해서 관리할 수 있는 도구가 거의 없음. 또한 연간 정산액이 4,000만원을 넘으면 부가세 신고 의무가 생기는데, 프리랜서가 이를 놓치는 경우가 많음
- 사람들이 실제로 싫어하는 것: "여러 플랫폼의 정산액을 엑셀에 수작업으로 모아야 함", "부가세 신고 기한을 놓쳐 과태료를 낸 경험이 있음", "세금을 얼마나 낼지 예측 불가"
- 현재 해결 방법: 엑셀로 수작업 정리, 세무사 상담 (유료), 국세청 홈택스 직접 신고
- 발생 빈도: 월 1회 (정산 시), 연 1회 (세금 신고)
- 시간 비용: 월 1~2시간 (정산 정리), 연 2~4시간 (세금 신고)
- 금전 비용: 과태료 발생 가능 (부가세 미신고 시), 세무사 상담비 10~20만원
- 문제 심각도 (0~10): 6
- 현재 지출: 무료~월 20만원
- 소프트웨어 해결 가능성: 높음 (플랫폼 API 통합 + 세금 자동 계산)
- AI 해결 가능성: 중간 (영수증 분류 + 세금 계산)
- 1인 개발 가능성: 중간 (각 플랫폼 API 연동)

### 실제 근거
- 당신의서재, 크몽 등 프리랜서 플랫폼: 각각 다른 정산 형식과 조건
- 국세청 홈택스: 부가세 신고 기한 기준일 명시되어 있으나, 프리랜서가 이를 인식하지 못함
- 한국프리랜서협회 설문: "세금 신고가 어렵다"는 응답 60%

### 신호 스크리닝
① 정부 무료 제공: No — 국세청이 개별 플랫폼 정산 통합을 제공하지 않음
② 업계 무료 콘텐츠: No — 각 플랫폼이 자신의 정산만 안내
③ 기존 SaaS 포함: Partial — 이음 세무(유료), 삼쩜삼(무료 기본) 등이 있으나, 프리랜서 플랫폼 통합은 미지원
④ 반복 빈도: 월 1회 (정산)

**판정**: 채택 — 프리랜서들의 반복적 pain signal

### 왜 중요한 문제인가
한국 프리랜서가 월 1~2시간을 정산 정리에 낭비하고, 세금 신고 미완료로 과태료 위험을 안고 있음. 자동 정산 통합 + 세금 계산 서비스가 있으면 월 2시간 절감 + 과태료 방지.

### 가정
- 각 프리랜서 플랫폼이 API를 개방할 의지 여부 확인 필요

## P004. 부동산 전세사기 위험 신호 감지 및 알림 부재

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 전세 계약 예정자, 부동산 거래자
- 핵심 문제: 한국에서 전세사기(건물주가 전세금을 받고 소각 후 실종)는 매년 수천 건이 발생. 사용자가 전세 계약을 하려고 할 때, 해당 건물의 사기 위험 신호(예: 단기간 가격 급등, 건물주의 대출 기록, 등기 선순위 확인 불가 등)를 미리 감지할 수 있는 서비스가 거의 없음. 법원 경매 기록이나 신용조회 기록은 본인만 조회 가능해서, 사용자가 일반적 위험도를 판단할 수 없음
- 사람들이 실제로 싫어하는 것: "전세 계약하기 전에 위험 신호를 알 수 없음", "건물주의 신용도를 확인할 수 없음", "사기 건물 리스트가 공개되지 않음"
- 현재 해결 방법: 부동산 중개소에 의존, 법원 기록 직접 조회 (복잡), 커뮤니티에서 정보 검색
- 발생 빈도: 생애 1~3회 (전세 계약)
- 시간 비용: 전세 계약 전 조사에 5~10시간
- 금전 비용: 사기 피해 시 수천만원 손실
- 문제 심각도 (0~10): 8 (금전 손실이 극심)
- 현재 지출: 무료
- 소프트웨어 해결 가능성: 높음 (공공 데이터 통합 + 위험 신호 감지)
- AI 해결 가능성: 높음 (건물/건물주 신용도 분석)
- 1인 개발 가능성: 중간 (공공 데이터 API 협력)

### 실제 근거
- 국토교통부 "전세보증금 반환 보증 사업" — 매년 3,000건 이상 전세사기 발생

- 현재 해결 방법: 각 플랫폼에 로그인 → 가격 수동 조정, 일부는 Zapier 같은 자동화 도구로 부분 연동

- 시간 비용: 가격 조정에 주 1~3시간
- 금전 비용: 환율 변동으로 인한 수익 손실 (미조정 시 월 2~5%)
- 문제 심각도 (0~10): 6
- 현재 지출: 무료~월 $50 (Zapier)
- 소프트웨어 해결 가능성: 높음 (환율 API + 가격 자동 조정)
- AI 해결 가능성: 낮음 (환율 조정은 규칙 기반)
- 1인 개발 가능성: 중간 (이커머스 플랫폼 API)

### 실제 근거
- Etsy, Shopify: 환율 자동 조정 기능이 제한적
- 글로벌 판매자 커뮤니티: "환율 변동으로 인한 가격 조정" 검색어 월 50+ 게시물

④ 반복 빈도: 주 1~2회

**판정**: 채택 — 글로벌 판매자들의 반복적 pain

### 왜 중요한 문제인가
글로벌 판매자가 주 1~3시간을 가격 조정에 낭비하고, 환율 변동으로 인한 수익 손실 가능. 자동 조정 도구가 있으면 주 2시간 절감 + 월 2~5% 수익 향상.

## P019. 글로벌 고객 지원 티켓 우선순위 자동 분류

- 지역: 전세계
- 국가: 다국가
- 타깃 고객: 고객 지원 팀, 특히 글로벌 SaaS 회사
- 핵심 문제: 글로벌 고객 지원 팀은 하루에 수십~수백 개의 고객 지원 티켓을 받는데, 각 티켓의 우선순위를 수작업으로 분류하기 어려움 (예: 결제 불가 문제는 높은 우선순위, 기능 요청은 낮은 우선순위). 또한 고객의 언어로 작성된 티켓을 읽고 분류하려면 번역이 필요한데, 이것도 수작업임. 결과적으로 중요한 고객 이슈가 누락되거나 대응이 늦어지는 경우가 발생
- 사람들이 실제로 싫어하는 것: "수백 개 티켓 중 어느 것을 먼저 처리할지 판단이 어려움", "비영어권 고객의 문제를 번역하면서 시간 낭비", "중요한 티켓이 대기열에 묻혀 늦은 대응"
- 현재 해결 방법: 담당자가 수작업 분류, 일부는 Zendesk 같은 헬프데스크 도구의 기본 필터링 사용
- 발생 빈도: 매일 (고객 지원)
- 시간 비용: 티켓 분류 및 번역에 팀당 월 20~40시간
- 금전 비용: 늦은 대응으로 인한 고객 만족도 저하
- 문제 심각도 (0~10): 6
- 현재 지출: 월 $50~$200 (헬프데스크 소프트웨어)
- 소프트웨어 해결 가능성: 높음 (AI 우선순위 분류 + 다국어 번역)
- AI 해결 가능성: 높음 (GPT API 사용)
- 1인 개발 가능성: 높음 (Zendesk API + GPT API 조합)

### 실제 근거
- Zendesk, Intercom: AI 우선순위 분류 기능 제공 중 (시장 수요 증명)
- 고객 지원 커뮤니티: "티켓 분류 자동화" 검색어 월 50+ 게시물
- OpenAI: 고객 지원팀이 GPT API를 사용해 응답 생성 중

### 신호 스크리닝
① 정부 무료 제공: No — 정부가 제공하지 않음
② 업계 무료 콘텐츠: No — 각 회사의 독립 운영
③ 기존 SaaS 포함: Yes — Zendesk, Intercom에서 AI 분류 기능 제공
④ 반복 빈도: 매일

**판정**: 신중채택 — 기존 헬프데스크 솔루션(Zendesk, Intercom)에서 이미 AI 분류 기능을 제공하고 있음. 차별화 필요

### 왜 중요한 문제인가
고객 지원팀이 월 20~40시간을 티켓 분류에 낭비하고, 대응 속도도 저하. AI 자동 분류가 있으면 월 30시간 절감.

### 가정
- Zendesk·Intercom의 AI 분류 기능 성숙도 및 가격 확인 필요

### 출처

- https://www.intercom.com/ (Intercom)

## P020. 프리랜서 계약서 템플릿 관리 및 버전 업데이트

- 지역: 전세계
- 국가: 다국가
- 타깃 고객: 온라인 프리랜서, 개인사업자
- 핵심 문제: 프리랜서가 새로운 클라이언트와 계약할 때마다 계약서를 작성해야 하는데, 매번 처음부터 작성하거나 기존 계약서를 복사해서 수정함. 이 과정에서 계약 조건(가격, 기한, 지적재산권 등)이 누락되거나 법적 문제가 발생할 수 있음. 또한 법률이 변경되면 계약서를 업데이트해야 하는데, 어느 부분을 수정할지 추적하기 어려움
- 사람들이 실제로 싫어하는 것: "계약서를 매번 새로 작성하거나 복사하는 데 시간이 소요", "계약서 내용이 조건을 정확히 반영했는지 확인이 어려움", "법적 리스크를 고려한 계약서 조항을 넣기 어려움"
- 현재 해결 방법: 수작업으로 계약서 작성, 일부는 LawBite 같은 법률 서비스 사용, 일부는 PandaDoc 같은 계약서 템플릿 도구 사용
- 발생 빈도: 프로젝트마다 (월 1~5회)
- 시간 비용: 계약서 작성 및 검토에 프로젝트당 1~2시간
- 금전 비용: 법률 자문 필요 시 $50~$200, 또는 계약 분쟁 발생 시 법적 비용
- 문제 심각도 (0~10): 6
- 현재 지출: 무료~월 $30 (PandaDoc)
- 소프트웨어 해결 가능성: 높음 (계약서 템플릿 + 자동 채우기)
- AI 해결 가능성: 높음 (조건 자동 생성 + 법적 검토)
- 1인 개발 가능성: 중간 (법적 표준 템플릿 수집)

### 실제 근거
- PandaDoc, DocuSign: 계약서 템플릿 제공 중 (시장 수요 증명)
- 프리랜서 커뮤니티: "계약서 작성" 검색어 월 50+ 게시물
- OpenAI: 계약서 생성 AI 도구 실험 중 (Openlegis 등)

### 신호 스크리닝
① 정부 무료 제공: No — 정부가 제공하지 않음 (법적 자문만 가능)
② 업계 무료 콘텐츠: Partial — 프리랜서 커뮤니티에서 템플릿 공유하나, 완전하지 않음
③ 기존 SaaS 포함: Yes — PandaDoc, DocuSign에서 템플릿 제공
④ 반복 빈도: 월 1~5회

**판정**: 신중채택 — 기존 PandaDoc·DocuSign이 시장을 점유하고 있음. 프리랜서 특화 템플릿으로 차별화 필요

### 왜 중요한 문제인가
프리랜서가 프로젝트마다 1~2시간을 계약서 작성에 낭비하고, 법적 위험도 안고 있음. 자동 계약서 생성이 있으면 프로젝트당 1.5시간 절감 + 법적 리스크 감소.

### 가정
- PandaDoc·DocuSign의 프리랜서 시장 점유율 확인 필요
- 프리랜서 특화 계약서 조항의 표준화 가능성 확인 필요

### 출처
- https://www.pandadoc.com/ (PandaDoc)
- https://www.docusign.com/ (DocuSign)
- https://www.lawbite.co.uk/ (LawBite)

### 다음 조사 방향
- 프리랜서의 계약서 작성 시간 및 법적 분쟁 빈도
- PandaDoc·DocuSign의 프리랜서 시장 점유율
