# Idea 001. ShotFlow

## 한 줄 설명
웨딩·행사 사진작가를 위한 AI 선별·납품 자동화 도구 — 촬영 후 업로드하면 AI가 컬링하고, 스트릭이 납품 속도를 게임화한다.

## 해결하는 Pain
P014: 웨딩·행사 사진작가 — 세션당 400~2000장 촬영, 편집 8~14시간, 납품 관리 30~60분. "촬영 1일 = 편집 3일"의 번아웃.

## 제공하는 Positive Experience
- S001(탭 자동완성 중독): 업로드하면 AI가 즉시 베스트 사진을 선별 → 작가가 승인/거절만 하는 흐름 유지 경험
- S003(손실 회피 스트릭): "납품까지 남은 시간" 카운트다운 + 7일 내 납품 완료율 스트릭
- S004(데이터→정체성): 월간 "내 세션 레포트" — 평균 선별률, 납품 속도, 고객 만족도 공유 카드

## Target User
웨딩·포트레이트·행사 사진작가 (세션당 400~2000장 촬영, 월 4~15건 처리)

## 왜 설치하는가
번아웃 상태의 사진작가가 "AI가 선별해준다"는 말을 듣고 설치. 기존 Imagen AI가 있지만 납품 관리 + 게임화가 없음.

## 첫 30초
사진 폴더 업로드 → AI가 30초 안에 1200장 → 250장 선별 초안 → 화면에 "당신이 승인할 사진만 남겼어요" 표시 → 첫 체험 즉시.

## 핵심 기능
1. AI 자동 컬링 (블러·눈감음·중복 제거 + 표정 품질 스코어링)
2. 원클릭 납품 갤러리 생성 + 고객 공유 링크 자동 발송
3. 납품 완료율 스트릭 대시보드
4. 월간 "My Season Report" — 세션 수·처리 속도·고객 응답률 공유 카드

## 핵심 사용 루프 (Trigger → Action → Reward → Investment → Next Trigger)
촬영 완료 알림 → 폴더 업로드 → AI 선별 결과 확인·승인 (5~15분) → 납품 완료 스트릭 +1 → 다음 세션 업로드 기대

## 반복 사용 이유
- 세션이 있으면 반드시 써야 하는 구조 (월 4~15회)
- 스트릭이 길어질수록 "이 월 납품 속도" 기록이 쌓임
- 연말 "My Year in Shots" 레포트로 포트폴리오 SNS 공유

## Personalization
- 작가마다 선호하는 선별 기준(인물 중심 vs. 풍경 포함)을 학습
- 반복 세션일수록 AI 선별 정확도 상승

## AI 역할
- 핵심 가치: 블러·눈감음·중복 자동 제거 + 표정 품질 스코어링 (AI 없이는 8~14시간이 1시간으로 줄지 않음)
- 세션 누적 시 작가 고유 스타일 학습

## Sharing
- 월간 "My Season Report" 카드 → Instagram에 "이번 달 OO건, 납품 평균 2.3일"
- 빠른 납품 기록 클라이언트에게 보여주기 → 신뢰 자산

## Monetization
- Freemium: 월 3세션 무료 (세션당 최대 500장)
- Pro $19/월: 무제한 세션, 1세션당 2000장, 자동 이메일 납품 시퀀스
- Studio $49/월: 3인 팀 공유, 클라이언트 포털

## MVP
- AI 컬링: Google Cloud Vision API + 자체 품질 스코어링 모델
- 갤러리 공유: Cloudinary or S3 + 커스텀 링크
- 스트릭 대시보드: 단순 DB 카운터

## MVP 예상 비용
- 클라우드 API 비용: 월 5~10만원
- 개발 인프라 (Vercel + Supabase): 월 3만원
- 초기 마케팅 (웨딩 포토그래퍼 커뮤니티): 30만원
- **총 초기 비용: 약 150만원 이내**

## 가장 큰 약점
Imagen AI, Aftershoot 등 기존 AI 편집 도구 존재. 납품 관리 + 게임화가 차별화지만 인지도 획득이 관건.

## 가장 중요한 검증 가설
"AI 선별 결과를 30초 내 보여주면 사진작가가 기존 워크플로를 이탈한다" — 무료 세션 전환율이 핵심 지표.

# Idea 002. TrainerOS

## 한 줄 설명
PT 트레이너를 위한 음성 기록 + 회원 재등록 스트릭 앱 — 수업 후 15초 음성으로 세션 기록하고, 회원 이탈 전 자동으로 알려준다.

## 해결하는 Pain
P003: PT 트레이너 — 수업 후 5분 내 기록 불가, 회원 재등록 타이밍 수동 관리.

## 제공하는 Positive Experience
- S001(흐름 유지): 수업 직후 마이크 버튼 하나 → 음성 자동 기록 변환 → 세션 완료
- S003(손실 회피): "이 회원 재등록 마감 D-3" 알림 → 연락하지 않으면 잃는다는 긴박감
- S015(마찰 제거 → 자동 완성): 음성 입력 한 번이 회원 기록부, 운동 로그, 재등록 추적을 동시에 채움

## Target User
개인 PT 트레이너 (헬스장 소속 또는 프리랜서, 회원 10~30명 관리)

## 왜 설치하는가
종이 노트를 쓰다 회원 10명 넘으면 페이지를 못 찾고, 보스몬 서비스 종료로 대안을 찾는 중. "음성으로 기록"이라는 메시지에 설치.

## 첫 30초
앱 켜고 마이크 버튼 누른 뒤 "홍길동, 스쿼트 80kg 3세트 완료, 무릎 조심 코멘트" 15초 발화 → 즉시 구조화된 기록 카드 확인.

## 핵심 기능
1. 세션 후 음성 입력 → AI 자동 파싱 (운동 종목·무게·횟수·코멘트 추출)
2. 회원별 잔여 세션 + 재등록 D-Day 알림
3. 회원 공유 리포트 (매달 PDF 또는 카카오톡 링크)
4. 트레이너 월간 매출 대시보드 (회원 수 × 단가)

## 핵심 사용 루프
세션 종료 → 앱 열고 15초 음성 기록 → AI 파싱 결과 확인 → 회원 재등록 알림 수신 → 연락 → 재등록 완료 수입 확보

## 반복 사용 이유
- 하루 4~8세션이면 하루 최소 4회 사용 구조
- 회원 재등록 알림은 매달 반복되는 수입 핵심
- 월간 매출 대시보드 확인 욕구

## Personalization
- 트레이너별 전문 운동 용어 학습 (바디빌딩 vs. 필라테스 vs. 크로스핏)
- 회원별 이전 기록 기반 "이번 세션 추천 강도" 제안

## AI 역할
- 핵심: 음성 → 구조화 데이터 변환 (AI 없으면 수기 5분이 필수)
- 운동 용어 NER + 수치 추출 (한국어 특화)

## Sharing
- 회원에게 보내는 월간 리포트가 간접 홍보 ("이 앱으로 관리받는다")
- "이번 달 재등록 100% 달성" 트레이너 SNS 인증

## Monetization
- Free: 회원 5명까지
- Pro 월 9,900원: 무제한 회원, 음성 기록, 재등록 알림, 회원 공유 리포트

## MVP
- 음성 처리: OpenAI Whisper API + GPT-4o 파싱
- 백엔드: Supabase + Edge Function
- 알림: 카카오 알림톡 또는 Firebase Push

## MVP 예상 비용
- API 비용 (Whisper + GPT): 월 5만원
- Supabase: 무료~월 2만원
- 카카오 알림톡: 월 2만원
- **총 초기 비용: 약 120만원**

## 가장 큰 약점
음성 인식 오류율이 전문 운동 용어에서 높을 수 있음. 트레이너의 앱 학습 비용.

## 가장 중요한 검증 가설
"음성 15초 → 구조화 기록 변환이 실제 트레이너 워크플로에 삽입될 수 있는가" — 세션 후 실제 사용률이 핵심.

# 가장 중요한 관찰

## 오늘 발견된 제품 기회의 공통점

### 1. "음성 15초"가 가장 강력한 마찰 제거 패턴
오늘 Pain의 절반 이상이 **"현장에서 발생한 정보를 나중에 사무소에서 재입력"** 구조였다 (P008, P010, P013). 공통 해법은 현장에서 음성 15~20초 한 번으로 모든 서류를 동시에 채우는 것이다. TrainerOS, FarmNote AI, CareLog AI가 이 패턴을 공유한다.

### 2. Pain 제거 + Positive Experience의 교차가 S등급을 만든다
단순 Pain 제거만으로는 A등급이다. S등급 제품들(ShotFlow, DealLog, StaffStamp, CareLog AI, ReadStreak)은 모두 Pain 제거 위에 **손실 회피 스트릭, 데이터→정체성 변환, 커뮤니티 소속감** 중 하나 이상의 Positive Experience를 얹었다.

### 3. "매일 사용"이 가능한 Pain이 훨씬 가치 있다
P013(영업 통화 일 5~15회), P003(PT 세션 일 4~8회), P008(개호 교대 매일), P009(음식점 발주 매일)은 사용 빈도가 자연스럽게 높다. 반면 P002(부가세 연 2회), P006(계약서 월 1~수회)은 빈도가 낮아 이탈 리스크가 크다 — 이를 보완하기 위해 알림·스트릭 설계가 필수다.

### 4. 바이럴의 핵심은 "사용 결과물이 공유 가능한 형태"인가
ShotFlow(월간 세션 레포트 카드), RevenueCard(Creator Wrapped), PetChart(아이 건강 Wrapped), ReadStreak(독서 Wrapped) — 이 제품들의 공통점은 사용 데이터가 자동으로 **공유 가능한 카드**가 된다는 것이다. Spotify Wrapped의 바이럴 메커니즘이 B2B 도구에도 이식 가능함을 보여준다.
