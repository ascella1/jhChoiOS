# Idea 001. 자격증 NFT 신뢰도 시스템 (Credential NFT Marketplace)

## 한 줄 설명
국가자격증을 블록체인 기반 NFT로 발행하고, 고객 리뷰·거래 기록으로 자격 보유자의 실제 신뢰도를 형성하는 마켓플레이스.

## 해결하는 Pain
**P004 + P018 결합**: 국가자격증 위조 및 온라인 교육 수료증 신뢰성 문제

## 제공하는 Positive Experience
**S009(minne 핸드메이드 판매) 구조 차용**:
- 자격증 보유자 → 프리랜서 프로필 생성
- 고객 리뷰·완료 프로젝트 축적
- "인증된 자격 + 실제 평판"의 이중 신뢰

## Target User
- 1차: 의료기사, 건축 기술자, IT 자격증 소유자 (프리랜서 수익화 욕구)
- 2차: 기업 채용 담당자 (검증 비용 절감)

## 왜 설치하는가 (Why Install)
"내 자격증이 진짜라는 걸 한 번에 증명하고, 고객이 이미 평점을 확인한 상태로 협력하고 싶다"

## 첫 30초 (Why First Use)
자격증 사진 + 신분증 인증 → 5초 후 NFT 발급 → 바로 프로필 수익화 가능

## 핵심 기능
1. **자격증 NFT 발행**: 정부 연계 API로 자격증 진위 자동 검증 후 NFT 발급
2. **투명한 평판 시스템**: 완료한 프로젝트별 고객 리뷰 및 점수 기록
3. **신뢰도 배지**: AI가 리뷰 패턴 분석 → "신뢰 수준" 자동 결정
4. **거래 이력 블록체인 저장**: 모든 고객 피드백이 변조 불가능하게 기록

## 핵심 사용 루프
프리랜서 프로필 생성 → 고객 발주 → 프로젝트 완료 → 고객 리뷰 → NFT 신뢰도 상향 → 고가 프로젝트 수주 → 수익 증가

## 반복 사용 이유
- 매번 새 프로젝트를 받을 때마다 리뷰 추적 필요
- 신뢰도 점수가 올라갈 때마다 확인하는 쾌감
- "100점 신뢰도" 달성까지의 목표 의식

## Personalization
- AI가 프리랜서의 과거 프로젝트 유형 분석 → 유사 고객 매칭
- 고객이 과거 리뷰 패턴 분석 → "이 프리랜서가 내 프로젝트 타입에 맞는가" 자동 판정

## AI 역할
1. 자격증 이미지 분석 → 위조 판정
2. 리뷰 텍스트 분석 → 신뢰도 신호 추출 (예: "약속 날짜 지킴" vs "일정 지연")
3. 프로젝트-프리랜서 매칭: 이전 리뷰 패턴 기반 성공 확률 예측

## Sharing
- 신뢰도 배지를 LinkedIn/이력서에 공유
- "100점 신뢰 자격증 보유" 뱃지가 차별화 신호

## Monetization
1. **프리랜서 구독료**: 월 5,000원 (NFT 발급 + 고급 매칭)
2. **기업 구독료**: 월 50,000원 (채용 담당자용 검증 도구)
3. **프로젝트 수수료**: 거래액 5% (고신뢰도 거래일수록 높음)

## MVP
- 의료기사 자격증 NFT 발급 (한국보건의료인국가시험원 API 연동)
- 초기 100명 프리랜서 모집
- 간단한 리뷰 시스템

## MVP 예상 비용
- 자격증 검증 API 구축: 3천만원
- 블록체인 스마트 컨트랙트: 2천만원
- 초기 iOS/Android: 5천만원
- **총 1억원**

## 가장 큰 약점
- "NFT" 자체에 대한 부정적 인식 극복 필요
- 초기 프리랜서 모집 어려움 (계란-닭 문제)

## 가장 중요한 검증 가설
"자격증 보유자가 NFT 기반 신뢰도 시스템으로 실제로 더 높은 프로젝트 단가를 받을 수 있는가?"

## 혁신성 분석 (신규)

**기존 경쟁사와의 구조적 차이점**:
- 비교 대상 경쟁사: LegalZoom (IP 등록 자동화), 기존 프리랜서 플랫폼 (Upwork, 당근마켓)
- 우리의 차별화:
  - Upwork는 "포트폴리오"만 제공 → 우리는 "블록체인 검증된 신뢰도"
  - 기존 프리랜서 플랫폼은 중앙집중식 평점 → 우리는 "정부 공식 인증 + 평판" 이중 시스템
  - **구조적 차이**: 자격증과 거래 신뢰도를 "분리 불가능하게" 연결
- 혁신성 점수: **8/10** (기존 자격증 검증 + 블록체인이 조합이지만, 구조적으로는 완전히 새로운 신뢰도 방식)

# Idea 002. 배달점주 AI 미니게임 컨설팅 (Daily Margin Game)

## 한 줄 설명
배달 앱 점주들이 매일 1분 미니게임을 하면, AI가 실시간 POS 데이터와 연동해 마진율·재고 최적화 컨설팅을 자동 제공.

## 해결하는 Pain
**P019(소규모 가게 재고 관리)** + **P017(근무시간 추적 자동화)**

## 제공하는 Positive Experience
**S005(당신의성명 AI 진단) + S014(Headspace 스트릭)**:
- 매일 게임 플레이 → "오늘의 마진율 점수" 확인
- 스트릭 유지 → 점주 본인도 습관화

## Target User
- 배달·테이크아웃 소상공인 (연매출 2억~10억원)
- 특히 회전율 높은 고기·국밥·분식점

## 왜 설치하는가
"하루 1분으로 내 가게 마진을 개선하는 방법을 배우고 싶다"

## 첫 30초
POS 앱 연동 (쿠팡이츠/배달의민족) → AI가 어제 판매 데이터 분석 → "오늘의 미니게임" 생성 (예: "가장 안 팔린 메뉴 3개 맞히기")

## 핵심 기능
1. **실시간 POS 연동**: 배달앱 API로 매일 판매 데이터 자동 수집
2. **AI 미니게임**: 
   - 오늘 가장 이익률 높은 메뉴 맞히기
   - 재고 남은 식재료 조합 미션
   - "내일 날씨에 팔릴 메뉴" 예측 게임
3. **게임 후 컨설팅**: 게임 결과 기반 마진율 개선 제안 (예: "돼지국밥 가격을 500원 올려도 판매량 5% 감소 예상, 순이익 8% 증가")

## 핵심 사용 루프
매일 아침 게임 플레이 (1분) → 점수 확인 → 컨설팅 제안 → 실제 메뉴 조정 → 내일 판매 데이터로 효과 확인 → 게임 진행도로 재확인

## 반복 사용 이유
- 스트릭 시스템: "7일 연속 게임 클리어" 배지 해제
- "마진율 상승 그래프" 시각화: 지난달 대비 수익 증가 추적
- 매달 상위 점주에게 부스팅 알고리즘 제공

## Personalization
- AI가 점주의 평균 주문가 범위 학습 → "이 점주는 가격 상향에 민감함" → 맞춤형 제안
- 메뉴별 판매 속도 학습 → "이 점주는 회전율 중심" vs "고단가 중심" 자동 분류 후 다른 게임 난이도 제공

## AI 역할
1. 매일 전날 POS 데이터 분석
2. 게임 난이도 자동 조정 (점주 실력에 맞춤)
3. 가격·재고 변경 시뮬레이션 → 수익 예측
4. "위험한 재고" 감지 → 폐기 예방 알림

## Sharing
- 월간 "마진율 상승 TOP 100 점주" 공개 순위
- 점주들이 자신의 성장 그래프를 SNS에 공유

## Monetization
1. **구독료**: 월 9,900원 (기본 게임 + 일반 컨설팅)
2. **프리미엄**: 월 29,900원 (AI 가격책정 자동화 + 배달앱 자동 프로모션)
3. **식재료 공급처 연결 수수료**: 점주가 추천받은 식재료 구매 시 2% 마진

## MVP
- 배달의민족 500개 가게 POS 데이터 수집
- 기본 미니게임 5종류 개발
- AI 마진율 시뮬레이션 알고리즘

## MVP 예상 비용
- 배달앱 API 연동: 3천만원
- AI 마진 분석 모델: 4천만원
- 미니게임 개발: 2천만원
- **총 9천만원**

## 가장 큰 약점
- POS 데이터 정확성에 전적으로 의존 (수기 입력 많으면 부정확)
- 게임만 하고 실제 적용하지 않는 점주 많을 수 있음

## 가장 중요한 검증 가설
"AI 게임 기반 컨설팅을 받은 점주들이 실제로 월 마진율을 3% 이상 개선할 수 있는가?"

## 혁신성 분석

**기존 경쟁사와의 구조적 차이점**:
- 비교 대상: POS 시스템 (Toast, SIKSIN), 가게 관리 앱 (배달의민족 스토어)
- 우리의 차별화:
  - 기존 POS는 "데이터 기록"만 함 → 우리는 "게임을 통한 학습 + AI 컨설팅"
  - 기존 배달앱 스토어는 "판매 데이터"만 제공 → 우리는 "행동 변화"를 게임화로 강제
  - **구조적 차이**: 경영 데이터를 "추상적 컨설팅"이 아니라 "매일 게임으로 구체화"
- 혁신성 점수: **9/10** (마진율 개선 자체는 기존 개념이지만, "매일 게임으로 학습"이라는 구조는 완전히 새로움)

# Idea 003. 전세사기 피해자 자동 지원금 신청 + 커뮤니티 법률 상담

## 한 줄 설명
전세사기 피해 직후 정부 지원금 신청을 자동화하고, 피해자 커뮤니티에서 법률가·선배 피해자와 직접 상담하는 올인원 플랫폼.

## 해결하는 Pain
**P005(신혼부부 전세사기 피해 복구)**

## 제공하는 Positive Experience
**S008(Tabelog 리뷰) + S015(Slack 협업) 결합**:
- 피해 신고 → 자동 지원금 신청 서류 생성 (1시간 내)
- 커뮤니티에서 법률 자문 받음 (평균 4시간 내)
- "나만 아니라는" 공동체감

## Target User
- 전세 사기 피해자 (특히 신혼부부)
- 발생 시점: 피해 인식 후 긴급 신청 기한 내 (1개월~3개월)

## 왜 설치하는가
"피해 받은 지 1주일 내에 모든 지원금을 신청하고, 동료 피해자들과 협력해서 법적 대응하고 싶다"

## 첫 30초
1. 전세 계약서 사진 업로드
2. AI가 자동 분석 → "당신의 피해 규모: 약 3억원, 예상 지원금: 1.5억원"
3. "지원금 신청 버튼" 클릭 → 자동 서류 생성 및 관할 기관별 신청

## 핵심 기능
1. **자동 서류 생성**: 
   - 선금일보, 보증보험증권, 계약서 분석
   - 피해 규모 자동 계산
   - 주택도시기금, 금융감독청, 지자체별 신청서 자동 작성
2. **지원 기한 추적**: "D-10 남음" 알림으로 기한 놓치지 않도록
3. **커뮤니티 상담**:
   - 변호사·법률 전문가 상주
   - 같은 지역·비슷한 피해 규모의 선배 피해자 매칭
   - 공동 소송 추진 시 비용 공유

## 핵심 사용 루프
피해 인식 → 앱 설치 → 서류 업로드 (5분) → 자동 신청 (1시간) → 커뮤니티 참여 (진행형) → 지원금 수령 및 소송 추진 → 완료

## 반복 사용 이유
- 지원금 신청 기한 추적 (3개월 내)
- 소송 진행 상황 업데이트 (주 1회)
- 법률 상담 내역 저장 및 참조

## Personalization
- AI가 피해자의 지역·피해 규모별로 성공 사례 추천
- 변호사 매칭: "공동 소송 3건 경험" vs "개별 구제만 전문" 등 프로필 제공

## AI 역할
1. 계약서 OCR 및 문제점 자동 분석
2. 지원금 규모 예측
3. 가장 빠른 지원금 수령 경로 제시
4. 유사 판례 자동 검색 및 제시

## Sharing
- "지원금 수령 완료" 피해자들의 후기 공유
- 커뮤니티가 언론에 집단 민원 제기할 때 언론사 제보

## Monetization
1. **기본 무료**: 자동 신청 서류 생성
2. **프리미엄 상담료**: 전문 변호사 1회 상담 5만원 (후불제, 지원금 수령 후)
3. **소송 비용 공유 플랫폼 수수료**: 공동 소송 비용의 3%

## MVP
- 전세사기 피해 신청 서류 50가지 템플릿화
- 전문 변호사 10명 상주
- 초기 피해자 100명 모집

## MVP 예상 비용
- 법률 자료 수집 및 템플릿화: 2천만원
- 변호사 상담 플랫폼: 1천만원
- 커뮤니티 개발: 2천만원
- **총 5천만원**

## 가장 큰 약점

- 민원 진행도를 게임화 (Step 1/5: 민원 접수 완료 ✓)
- 신용등급 회복 과정을 "레벨업"으로 시각화

## Target User
- 신용불량자 (특히 오류로 인한)

   - 신용불량 등재 기록 분석

   - 각 Step 완료 시 배지 획득
4. **신용등급 회복 시뮬레이션**:
   - "만약 이 오류가 정정되면, 신용등급이 5등급에서 2등급으로 상향"
   - "2등급 달성 시 대출 가능" 목표 시각화
