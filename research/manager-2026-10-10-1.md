# Idea 001. 배달점주 실시간 손실 게임화 플랫폼 "마진 미션"

## 한 줄 설명
배달점주의 주문단가 하락/배달료 인상에 대응하는 일일 미션 게임 — 손익분기점 달성 시 보상, 친구 점주와 경쟁

## 해결하는 Pain
P001 (평균 주문단가 급락 실시간 추적 불가)
P002 (상품별 손익분기점 수동 계산)

## 제공하는 Positive Experience
S006 (게임 일일 퀘스트 + 친구 랭킹 경쟁)
S013 (Duolingo 스트릭 메커니즘)

## Target User
한국 배달앱 가맹점주 (치킨, 피자, 한식) 25~55세

## 왜 설치하는가
"이번 달 손실이 얼마나 되는지 실시간으로 알고 싶고, 대응책을 빠르게 찾고 싶다"

## 첫 30초
배달앱 연동 → 오늘 주문 3건 분석 → "2건은 손익분기점 이상, 1건은 손실" 시각화 → "오늘 미션: 손익분기점 이상 상품 20% 증가" 퀘스트 제시

## 핵심 기능
1. 배달앱 API 실시간 연동 (요기요, 배민, 쿠팡이츠)
2. 상품별 손익분기점 자동 계산 (원가 DB)
3. 일일 미션: "손익분기점 이상 상품 판매율 X% 달성"
4. 친구 점주와 실시간 순위 비교
5. 주간/월간 리포트

## 핵심 사용 루프
1. 앱 열기 (매일 아침)
2. 어제 주문 분석 확인
3. 오늘 미션 확인
4. 친구 점주 순위 확인
5. 주문 받음 → 앱이 자동 손익 계산
6. 미션 진행도 실시간 업데이트

## 반복 사용 이유
1. 스트릭 끊기기 싫음 (연속 참여 보상)
2. 친구 점주와의 경쟁
3. 실제 손실이 눈에 보이니까

## Personalization
점주별 주요 상품군 (한식/치킨/피자) 자동 감지 → 맞춤형 미션 생성
주문 단가 추세 학습 → 예상 손실 미리 경고

## AI 역할
1. 실시간 주문 이상 탐지 (주문단가 급락 감지)
2. 상품별 최적 가격 책정 추천
3. 배달료 인상 대응 시뮬레이션

## Sharing
미션 달성 스크린샷 → 카톡/네이버밴드 공유
"우리 가게 이번 달 손익분기점 달성율 95%!" 자랑
친구 점주 초대 (초대 시 두 명 모두 보너스)

## Monetization
프리미엠 기능: 상품별 가격 최적화 AI (월 9,900원)
점주 커뮤니티 광고 (다른 배달업체 도구 광고)
배달앱과 제휴 (배달료 수수료 일부 수익)

## MVP
1. 3개 배달앱 연동 (요기요, 배민, 쿠팡이츠)
2. 기본 손익분기점 계산 (고정 원가율 사용)
3. 일일/주간 미션
4. 친구 초대 시스템

## MVP 예상 비용
배달앱 API 개발: 2주
프론트엔드 (iOS/Android): 3주
백엔드 (미션 시스템, 랭킹): 2주
총 약 2,000~2,500만원

## 가장 큰 약점
1. 점주의 원가 입력이 정확하지 않을 수 있음
2. 배달앱 API 접근 정책 불명확
3. 점주가 실제로 가격을 조정하지 않으면 효과 없음

## 가장 중요한 검증 가설
"배달점주가 실제로 일일 미션을 통해 손익분기점 관리를 더 잘하고, 매월 손실을 줄일 수 있는가?"

→ 단순 "대시보드"에서 "게임화된 실시간 대응 플랫폼"으로 전환

# Idea 002. 프리랜서 신용도 네트워크 "프리버디"

## 한 줄 설명
프리랜서들이 클라이언트 연체/신용도를 실시간 공유하는 커뮤니티 + 자동 신용 점수 + 마이크로 크레딧

## 해결하는 Pain
P013 (미수금 대기 중 현금흐름 부족)
P014 (클라이언트별 연체율 추적 불가)
P020 (클라이언트 신용도 확인 어려움)

## 제공하는 Positive Experience
S017 (Discord 커뮤니티 일일 참여 + 신뢰)
S019 (Reddit 투표 기반 커뮤니티 신뢰)

## Target User
글로벌 프리랜서 (Upwork, Fiverr 활동), 25~45세, $500~$5,000 월 수익

## 왜 설치하는가
"새 클라이언트와 계약하기 전에 그 사람의 신용도를 알고 싶고, 만약 미수금이 생기면 빠르게 현금을 받고 싶다"

## 첫 30초
Upwork 프로필 연동 → 클라이언트 검색 → "신용 점수 7.5/10 (193명 평가)" + 연체 이력 공개
또는 새 클라이언트 정보 입력 → "커뮤니티 검증 대기 중"

## 핵심 기능
1. Upwork/Fiverr 프로필 자동 연동
2. 클라이언트 신용 DB (프리랜서 커뮤니티 투표 기반)
3. 연체 이력 실시간 경고
4. 미수금 마이크로 크레딧 (선할인) — 3~5% 수수료
5. Discord 커뮤니티 (직업별 채널)

## 핵심 사용 루프
1. 새 클라이언트 찾음 → 앱에서 신용도 검색
2. 신용도 낮으면 선급금 요구 또는 거절
3. 계약 체결 후 결제 지연 → 커뮤니티에 보고
4. 미수금이 있으면 "크레딧 선택지" 팝업
5. 클레딧 신청 (수수료 3~5%) → 즉시 현금화

## 반복 사용 이유
1. 매달 새 클라이언트와 일하니까 신용도 확인 습관
2. 커뮤니티에서 같은 상황인 프리랜서들과 조언 교환
3. 미수금이 발생할 때마다 필요

## Personalization
프리랜서의 업종 (개발자/디자이너/라이터) 별 클라이언트 신용도 DB 분리
과거 연체율 학습 → 위험한 클라이언트 자동 경고

## AI 역할
1. 클라이언트 신용도 자동 점수화 (결제 이력, Upwork 평점, 커뮤니티 투표)
2. 연체 패턴 분석 (어느 클라이언트가 언제 늦는가)
3. 선급금 권장도 계산

## Sharing
"이 클라이언트 연체 이력 있어" → 커뮤니티 공유
좋은 클라이언트 추천 (추천자/피추천자 모두 보너스)
신용도 높은 클라이언트 리스트 공개

## Monetization
마이크로 크레딧 수수료 (3~5%)
프리미엄 신용도 분석 (월 $9.99)
클라이언트 기업을 위한 "프리랜서 평가" B2B 판매

## MVP
1. Upwork API 연동 (프로필 및 평점 가져오기)
2. 클라이언트 신용도 커뮤니티 투표 시스템
3. Discord 서버 운영
4. 기본 마이크로 크레딧 (파트너 금융사 협력)

## MVP 예상 비용
Upwork API 통합: 1주
백엔드 (신용도 계산, 투표): 2주
Discord 자동화: 1주
금융사 협력 계약: 2주
총 약 1,500~1,800만원

## 가장 큰 약점
1. 프리랜서들이 실제로 커뮤니티에 정보 공유하지 않으면 효과 없음
2. 마이크로 크레딧 파트너 찾기 어려움
3. 잘못된 신용도 평가로 인한 법적 책임

## 가장 중요한 검증 가설
"글로벌 프리랜서가 실제로 이 커뮤니티를 신뢰하고, 신용도 정보를 활용하여 미수금 리스크를 줄일 수 있는가?"

| 사용 빈도 | 8/10 |
| 첫 사용 가치 | 8/10 |

→ 단순 "추적 도구"에서 "커뮤니티 신용 경제"로 전환

# Idea 003. 미용실 AI 예약 비서 "스타일링 AI"

## 한 줄 설명
미용실 노쇼 고객에게 AI 음성이 1시간 전 친절한 리마인더 + 예약 변경 자동화

## 해결하는 Pain
P003 (미용실 웨이팅 고객 취소/노쇼 손실)

## 제공하는 Positive Experience
S020 (음성 AI 친구/조수 매일 대화 + 개인화)
S004 (친구 습관 챌린지 — 미용실 정기 방문 습관화)

## Target User
미용실 점주 (일반 미용실, 매니큐어, 헤어샵), 특히 웨이팅이 많은 매장

## 왜 설치하는가
"월 80만~200만원 손실하는 노쇼를 줄이고, 고객과 더 좋은 관계를 만들고 싶다"

## 첫 30초
미용실 예약 시스템 연동 → 예약 고객 명단 → "오늘 노쇼율 70%→45%로 개선됨" 대시보드
또는 고객 입장: 카톡에서 "스타일리스트 지은이가 내일 오후 2시 예약을 확인했어요" AI 음성 메시지

## 핵심 기능
1. 미용실 POS/예약 시스템 연동 (당신의비즈니스, 네이버 예약 등)
2. 예약 1시간 전 AI 음성 전화 (TTS + 개인화)
3. 고객이 "가능", "변경", "취소" 선택 → 자동 처리
4. 노쇼 고객 패턴 분석 (어떤 시간대, 어떤 스타일리스트)
5. 고객별 정기 방문 습관 추적 (일일 챌린지 메커니즘)

## 핵심 사용 루프
1. 미용실이 앱에 예약 등록
2. 예약 1시간 전 AI가 고객에게 전화 → "내일 헤어컷 예정이시잖아요, 확인해주세요"
3. 고객 응답 기반 자동 처리
4. 미용실이 노쇼율 대시보드 확인
5. 정기 고객에게는 "이번 달 4번째 방문!" 인센티브

## 반복 사용 이유
미용실: 매일 예약이 있으니까 매일 사용
고객: AI 리마인더로 예약 깜빡하지 않고, 정기 방문 보상 받으니까

## Personalization
고객별 선호 스타일리스트 학습 → 같은 사람으로 배치
정기 방문 고객 감지 → "다음 예약 자동 제시"
노쇼 위험 고객 자동 감지 → 더 일찍 리마인더 (2시간 전)

## AI 역할
1. 음성 리마인더 TTS (자연스러운 톤, 고객 이름 포함)
2. 노쇼 패턴 분석 (요일, 시간대, 스타일리스트별)
3. 예약 최적화 추천 (빈 슬롯 자동 채우기)

## Sharing
미용실이 좋은 결과를 SNS에 공유 ("우리가게 노쇼율 50% 감소!")
고객이 정기 방문 배지 받으면 자랑 (인스타그램 스토리)

## Monetization
미용실당 월 19,900원 (기본 리마인더)
프리미엠 (월 49,900원): 상세 분석, 자동 재예약 추천
AI 음성 커스터마이징 (미용실 브랜드 음성): 추가 5,000원/월

## MVP
1. 3개 예약 시스템 연동 (당신의비즈니스, 네이버 예약, 포스 시스템)
2. AI TTS (Google Cloud Text-to-Speech)
3. 전화 연동 (Twilio)
4. 기본 노쇼율 대시보드

## MVP 예상 비용
예약 시스템 API: 1주
AI TTS 통합: 1주
전화 시스템 (Twilio): 1주
프론트엔드 (미용실 대시보드): 2주
총 약 1,200~1,500만원

## 가장 큰 약점
1. 고객들이 AI 전화를 받지 않을 수 있음
2. 일부 지역에서 수신거부 번호로 인식될 수 있음
3. 한국 전화 규제 (스팸 전화 기준 모호)

"AI 음성 리마인더로 미용실의 노쇼율이 실제로 줄어드는가? (목표: 70%→45% 이상)"

# Idea 004. 제조업 공급처 협력 커뮤니티 "서플라이 링크"

## 한 줄 설명
소규모 제조업들이 공급처 가격을 공유하는 Discord 커뮤니티 + AI 최적 구매 시점 추천

## 해결하는 Pain
P016 (다중 원재료 공급처 가격 추적 어려움)

## 제공하는 Positive Experience
S017 (Discord 커뮤니티 일일 참여 + 신뢰)

## Target User
소규모 제조업 (의류, 전자제품, 가구 OEM), 25~55세, 월 $5,000~$50,000 구매액

## 왜 설치하는가
"철, 플라스틱, 직물 같은 원재료 가격이 오르거나 내릴 때 빠르게 대응하고, 최적의 가격에 구입하고 싶다"

## 첫 30초
업종 선택 (의류/전자/가구) → Discord 서버 자동 입장 → "오늘 철 가격 3% 하락!" 공지
또는 구매처 검색 → "알리바바 vs 1688.com 가격 비교" 자동 집계

## 핵심 기능
1. Discord 기반 업종별 커뮤니티
2. 공급처 가격 정보 자동 수집 (Alibaba, 1688, 중국 공급처 API)
3. AI 가격 비교 + 최적 구매 시점 추천
4. 사용자들이 직접 "어제 이 공급처에서 이 가격에 샀다" 기록
5. 월간 구매 리포트 ("이번 달 절약액: $5,000")

## 핵심 사용 루프
1. Discord 채널 입장
2. 오늘의 주요 원재료 가격 공지 확인
3. "구매 계획" 작성 → AI가 "지금 사는 게 좋을까? 1주일 기다릴까?" 추천
4. 구매 후 가격 기록
5. 월말 리포트: "절약액 $5,000, 커뮤니티 내 평균보다 18% 저렴하게 구매"

## 반복 사용 이유
1. 공급처 가격이 수시로 변하니까 매일 확인 필요
2. 다른 제조업들의 구매 경험 배우기
3. 대량 구매 시 협상 데이터 필요

## Personalization
업종별 주요 원재료 자동 추적 (의류 업체는 직물, 전자 업체는 납과 구리)
구매 패턴 학습 → "당신의 구매 사이클은 보통 30일, 지금이 최적 시기입니다"

## AI 역할
1. 시계열 가격 분석 (가격 트렌드 예측)
2. 공급처별 가격 정규화 (환율, 배송료 포함한 실제 원가 계산)
3. 최적 구매 시점 추천 (머신러닝 기반)

## Sharing
좋은 공급처 발견 → Discord에 공유 (공유자/받는사람 모두 신용도 상승)
"이 달 우리 회사 절약액 Top 5" 월간 리더보드

## Monetization
프리미엄 (월 $29): 상세 가격 분석, 공급처 신뢰도 DB, 1:1 구매 컨설팅
B2B (공급사 입장): "당신의 상품에 관심 있는 제조업들" 리드 판매

## MVP
1. Discord 서버 구축 + 자동화 봇
2. Alibaba/1688 API 가격 자동 수집
3. 기본 가격 비교 및 저장
4. 커뮤니티 가격 기록 시스템

## MVP 예상 비용
Discord 봇 개발: 1주
데이터 수집 (API 통합): 2주
백엔드 (가격 저장/분석): 2주
총 약 1,000~1,300만원

## 가장 큰 약점
1. 공급처 가격 API가 실시간이 아닐 수 있음 (지연 가능)
2. 사용자들이 잘못된 가격 정보 공유할 수 있음
3. 중국 공급처 정보 수집의 법적/기술적 제약

## 가장 중요한 검증 가설
"제조업체들이 실제로 공급처 가격을 커뮤니티에 공유하고, 협력하여 원가를 절감할 수 있는가?"
