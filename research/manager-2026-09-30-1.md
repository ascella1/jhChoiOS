# Idea 001. SubscriptionGuard — 구독 통합 관리 및 자동 취소

## 한 줄 설명
모든 구독 서비스를 한곳에서 추적하고 자동갱신 취소·재설정을 관리하는 모바일 앱

## 해결하는 Pain
- 렌탈·구독 자동갱신 취소 절차가 서비스마다 다름
- 어디서 구독했는지, 언제 취소할지 모름
- 의도치 않은 중복 결제 발생

## 제공하는 Positive Experience
- 모든 구독을 한 대시보드에서 관리
- "3일 후 자동갱신" 알림 + 원클릭 취소
- 월별 구독료 절감액 시각화

## Target User
일반 2030, 월간 3개 이상 구독 서비스 사용자

## 왜 설치하는가
매달 눈에 띄지 않게 빠져나가는 돈을 제어할 수 있다는 안도감

## 첫 30초
신용카드 연동 → 자동 구독 서비스 감지 → 월 절감액 표시 → 취소/유지 선택

## 핵심 기능
1. 신용카드 API 연동으로 구독 자동 감지
2. 갱신 예정일 3일 전 알림
3. 원클릭 취소 (각 서비스 링크 제공)
4. 월별/연간 총 구독료 및 절감액 그래프

## 핵심 사용 루프
Trigger(갱신 알림) → Action(앱 열어 확인) → Reward(취소하면 돈 절약) → Investment(데이터 동기화) → Next Trigger(다음 갱신)

## 반복 사용 이유
매달 갱신 일정이 다르므로 매주 최소 1회 앱 확인

## Personalization
- 서비스별 카테고리 분류 (음식, 구독, 금융, 취미)
- 개인 취소 이력 기반 "불필요해 보이는 구독" 추천

## AI 역할
- 사용 패턴 분석 → "이 구독은 3개월 안 썼네요" 알림
- 유사 서비스 중복 결제 감지

## Sharing
친구와 "절감액" 경쟁, 가족 공유 계정

## Monetization
- 무료 기본(5개 구독까지)
- 프리미엄 월 2,990원 (무제한 구독 추적, 고급 분석)
- B2B: 가계부 앱과의 제휴

## MVP
신용카드 연동 + 주요 10개 서비스 자동 감지 + 알림 + 기본 대시보드

## MVP 예상 비용
개발 4주, 금액 3,000만원 (카드사 API 비용 포함)

## 가장 큰 약점
카드사 API 개방 여부 불확실, 암호화폐/직불 구독 미지원

## 가장 중요한 검증 가설
사용자가 월평균 4개 이상 구독 서비스를 가지고 있는가? (한국 기준 검증 필요)

# Idea 002. MedTrack Pro — 의료 진료비 & 보험금 실시간 추적

## 한 줄 설명
진료 후 심사 상태, 보험금 청구 진행도를 실시간으로 추적하고 필요 서류를 자동 안내하는 앱

## 해결하는 Pain
- 심사 결과가 언제 나올지 알 수 없음
- 보험금 청구에 필요한 서류가 불명확
- 서류 미비로 인한 반복 청구

## 제공하는 Positive Experience
- 진료 → 청구 → 심사 → 지급까지 단계별 진행상황 확인
- "부족한 서류" 사전 알림

## Target User
고액 진료 경험자, 만성질환자, 실손보험 가입자

## 왜 설치하는가
불안감 해소 + 청구 실패 방지

## 첫 30초
건강보험카드 인증 → 최근 진료 내역 자동 로드 → 심사 진행도 표시

## 핵심 기능
1. 건강보험심사평가원/보험사 API 연동으로 진행도 조회
2. 담보별 필요 서류 자동 체크리스트 생성
3. 서류 미비 감지 시 자동 알림
4. 심사 기준 예측 AI ("이 진료는 보험 적용 확률 85%")

## 핵심 사용 루프
Trigger(고액 진료) → Action(앱에서 청구 시작) → Reward(자동으로 서류 안내) → Investment(서류 수집) → Next Trigger(결과 확인)

## 반복 사용 이유
진료 후 심사 기간(10일~30일) 동안 매주 1회 이상 상태 확인

## Personalization
- 개인 보험 종류별 맞춤 서류 안내
- 자주 받는 진료 유형별 템플릿 저장

## AI 역할
- OCR로 진단서·영수증 자동 인식
- 과거 심사 데이터 기반 "이번 진료는 거부될 가능성"  예측

## Sharing
가족 계정 공유, 배우자의 진료비 공동 추적

## Monetization
- 무료 기본 (실시간 조회, 1개 담보 체크리스트)
- 프리미엄 월 4,990원 (모든 담보, AI 예측, 서류 템플릿 라이브러리)
- B2B: 보험사 고객센터 축약

## MVP
1개 보험사(건강보험) + 진행도 조회 + 서류 체크리스트

## MVP 예상 비용
개발 5주, 금액 4,000만원 (API 연동 포함)

## 가장 큰 약점
건강보험심사평가원 API 개방 필수, 개인정보 보호 규제

## 가장 중요한 검증 가설
사용자가 보험금 청구 후 결과를 알 때까지 평균 몇 번 상태를 확인하는가?

# Idea 003. DoseGuard — 약물 상호작용 & 복용 관리

## 한 줄 설명
복용 약물을 입력하면 상호작용 체크, 복용 시간 알림, 부작용 모니터링을 자동화하는 앱

## 해결하는 Pain
- 여러 병원의 약을 함께 복용할 때 위험성 미확인
- 복용 시간대 관리 복잡
- 약물 부작용 발생 후 원인 파악 어려움

## 제공하는 Positive Experience
- "이 약과 저 약을 함께 먹으면 안 됩니다" 명확한 알림
- 매일 복용 시간 자동 알림
- 부작용 발생 시 "이 약물 조합 때문일 가능성"  분석

## Target User
만성질환자(고혈압+당뇨+고지혈증), 고령층, 다중 진료 환자

## 왜 설치하는가
약물 부작용으로 인한 응급실 방문 예방

## 첫 30초
현재 복용 약 입력 → 상호작용 분석 → "안전" 또는 "위험" 표시

## 핵심 기능
1. 약물 상호작용 데이터베이스 (약학정보원 기반)
2. 복용 시간별 알림 설정
3. 복용 이력 기록 + 부작용 로그
4. AI 부작용 원인 분석

## 핵심 사용 루프
Trigger(약물 처방) → Action(앱에 입력) → Reward(안전 확인) → Investment(매일 알림 받기) → Next Trigger(약 변경)

## 반복 사용 이유
매일 약을 복용하므로 매일 1회 이상 알림 수신

## Personalization
- 개인 알레르기 이력 기반 추가 위험 경고
- 신부전/간질환 환자는 용량 조정 권고

## AI 역할
- NLP로 처방전 자동 인식
- 부작용 증상 입력 → "약물 A와 약물 B의 상호작용 가능성 72%"

## Sharing
약사, 의사와 복용 약 정보 공유 기능

## Monetization
- 무료 기본 (상호작용 체크, 기본 약물 데이터)
- 프리미엄 월 3,990원 (고급 분석, 부작용 모니터링, 의료진 공유)
- B2B: 병원·약국 협력

## MVP
약학정보원 API 연동 + 약물 입력 + 상호작용 체크 + 기본 알림

## MVP 예상 비용
개발 4주, 금액 3,000만원

## 가장 큰 약점
약학정보원 API 개방 필수, 의료기관 신뢰도 구축 필요, OTC약 데이터 부족

## 가장 중요한 검증 가설

# Idea 004. ExpensePredictor — 개인/사업 지출 자동 예측

## 한 줄 설명
차량유지비, 월세 갱신료, API 비용 등 변동성 높은 지출을 자동 예측하고 월별 예산을 제시하는 앱

## 해결하는 Pain
- 차검·정기점검 비용이 갑자기 크게 나옴
- 임대료 갱신료, 보증금 환수 일정을 깜빡함
- API 청구서가 매월 다르고 한계를 모름

## 제공하는 Positive Experience
- "내년 7월에 차검 예정, 약 80만원 필요" 미리 알 수 있음
- 월별 평균 필요 금액을 계산해 저축 목표 제시
- "이 달 API 비용이 평년 대비 150% 증가" 경고

## Target User
자영업자, 프리랜서, 소액 투자자, 스타트업 개발팀

## 왜 설치하는가
예상치 못한 대출 또는 사업 실패를 미리 방지

## 첫 30초

## 핵심 기능
1. 신용카드/은행 API로 역사 지출 분석
2. 주기적 지출 패턴 자동 감지 (차검은 2년마다, 임대료는 2년 후)
3. ML 기반 월별 필요 금액 예측
4. 실제 비용과의 편차 알림

## 핵심 사용 루프
Trigger(매달 초) → Action(앱 열어 월별 필요 예산 확인) → Reward(안심하고 저축 가능) → Investment(저축 계획 수정) → Next Trigger(다음 달)

## 반복 사용 이유
매월 초 예산 계획 시 확인, 예측 편차 발생 시 조정

## Personalization
- 자영업자용 (소비세 정산, 임금 지급일)
- 프리랜서용 (세금, 4대 보험료 주기)
- 차량 소유자용 (차종별 유지비 데이터)

## AI 역할
- 역사 지출 데이터에서 주기 자동 학습
- 인플레이션/시장 지표 반영해 비용 상승률 예측
- 이상 지출 감지

## Sharing
사업 파트너와 공동 비용 추적, 가족 예산 공유

## Monetization

- 프리미엄 월 4,990원 (전체 이력, 고급 분석, 맞춤 카테고리)
- B2B: 회계 소프트웨어 연동

## MVP

## MVP 예상 비용
개발 5주, 금액 4,000만원 (ML 모델 포함)

# Idea 005. FreelanceShield — 프리랜서 급여 에스크로우 & 분쟁 해결

## 한 줄 설명
프리랜서가 일한 만큼 확실히 받을 수 있도록 의뢰인의 급여를 앱에서 에스크로우 관리하는 플랫폼

## 해결하는 Pain

- 지연 지급이 관례가 됨

## 제공하는 Positive Experience
- "일을 완료했다"는 신호 보내기만 해도 자동으로 송금
- 급여 분쟁 시 앱 내 중재 시스템 이용 가능
- 급여 이력이 신용점수로 반영

## Target User
프리랜서, 학원 강사, 시간강사, 필라테스 강사 (200만명 추정)

## 왜 설치하는가

## 한 줄 설명
항공권, 숙박, 투어를 예약하면 자동으로 환불 정책을 분석하고, 취소 시 최적의 환불 전략을 제시하는 앱

## 해결하는 Pain
- 항공권 환불 정책이 항공사마다 다름
- 환불 가능 여부를 미리 알 수 없음
- 환불받을 때 어떤 조건을 맞춰야 하는지 복잡

## 제공하는 Positive Experience
- 예약 링크 입력 → "이 항공권은 취소 시 50% 환불 가능" 분석
- 계획이 변경되면 "지금 취소하면 60% 환불, 1주일 후면 20%" 통보
- 자동으로 환불 신청서 작성

## Target User
국제 여행자, 비즈니스 트래블러

## 왜 설치하는가
여행 계획 변경 시 손실을 최소화

## 첫 30초
항공권 예약 메일/링크 입력 → 환불 정책 분석 + 최악/최선 시나리오 표시

## 핵심 기능
1. 항공사/호텔 예약 정책 자동 인식
2. 취소 시 환불율 실시간 계산
3. "언제 취소하면 가장 많이 받나?" 최적 취소 시점 제안
4. 환불 신청 자동화

## 핵심 사용 루프
Trigger(여행 예약) → Action(예약 정보 입력) → Reward(환불 정책 명확화) → Investment(계획 변경 시) → Next Trigger(환불 신청)

## 반복 사용 이유
여행 계획 변경 시 또는 취소 시점 결정

## Personalization
- 개인 여행 이력 기반 항공사 추천
- 자주 취소하는 사용자에게 취소 보험 제안

## AI 역할
- 예약 이메일에서 환불 정책 자동 추출
- 환율·항공료 변동 추적 → "지금이 최적 취소 시점" 알림
- 유사한 상황의 사용자 경험 학습

## Sharing
친구와 여행 계획 공유, 환불 전략 팁 공유

## Monetization
- 무료 기본 (3개 예약까지)
- 프리미엄 월 4,990원 (무제한, 취소 보험, 환급 보증)

## MVP
3개 항공사 + 2개 호텔체인 환불 정책 데이터베이스 + 기본 분석

## MVP 예상 비용
개발 4주, 금액 3,000만원

## 가장 큰 약점
항공사·호텔 정책 변경 빠른 업데이트 필요, 데이터 수집 어려움, 네거티브 후기 (환불 실패 경험)

## 가장 중요한 검증 가설
사용자가 년 1회 이상 여행 계획을 취소/변경하는가?

# Idea 011. DailyWorker — 일일 근로자 급여 선불금 & 자동 정산

## 한 줄 설명
일일 근무(카페 아르바이트, 배송, 현장 일용직)를 마치면 그 날 저녁 급여를 받을 수 있고, 자동으로 정산되는 앱

## 해결하는 Pain
- 일일 근로자는 급여를 2주 후에 받음
- 생활비가 모자르면 대출을 받아야 함
- 정산 과정이 복잡하고 미정산 분쟁

## 제공하는 Positive Experience
- 저녁 11시에 근무 완료 신고 → 다음 날 오전에 입금
- 일주일 단위 정산도 가능 (월급처럼)
- "내가 번 돈"이 명확하게 계산됨

## Target User
학생 아르바이트, 일용직, 배송 라이더, 건설 노동자 (약 400만명)

## 왜 설치하는가
급여를 즉시 필요할 때 받을 수 있음 (생활 안정성)

## 첫 30초
오늘 근무 시간 입력 → 당일 벌이 표시 → "내일 아침 입금" 확인

## 핵심 기능
1. 일일 근무 시간/급여 기록
2. 고용주와 자동 동기화 (또는 수동 입력)
3. 선불금 신청 (당일 또는 다음 날 입금)
4. 자동 정산 및 세금 계산

## 핵심 사용 루프
Trigger(근무 종료) → Action(시간 입력) → Reward(급여 확인) → Investment(선불금 신청) → Next Trigger(다음 날 입금)

## 반복 사용 이유
매일 근무마다 사용

## Personalization
- 개인 급여 기준에 따른 자동 계산
- 근무처별 표준 급여 데이터 제시

## AI 역할
- 근무 시간과 급여 이력 학습 → "비슷한 일자리는 시급 12,000원" 추천
- 부정 거래 탐지

## Sharing
고용주 초대, 팀 정산 자동화

## Monetization
- 근로자 무료
- 고용주 수수료 2-3% (선불금 수수료)
- 프리미엄 고용주 월 29,900원 (팀 관리, 급여 통계)

## MVP
개인 근무 입력 + 선불금 신청 + 기본 정산

## MVP 예상 비용
개발 5주, 금액 4,000만원 (결제 시스템)

## 가장 큰 약점
고용주 채택 어려움, 자금 조달 필요 (선불금 담보), 급여 미정산 분쟁 리스크

## 가장 중요한 검증 가설
근로자가 월평균 20일 이상 일용직을 하는가? (충분한 거래량 필요)

# Idea 012. DocBot — 서류 자동 생성 & 제출 추적

## 한 줄 설명
보험금 청구, 학교 입학, 계약서 등 필요한 서류를 자동으로 생성하고 제출 상태를 추적하는 플랫폼

## 해결하는 Pain
- 각 기관마다 요구하는 서류가 다름
- 어떤 서류를 준비해야 하는지 불명확
- 서류 미비로 인한 반복 제출

## 제공하는 Positive Experience
- "보험금 청구"를 선택 → 필요 서류 체크리스트 자동 생성
- 서류 부족 감지 시 자동 경고
- "언제까지 제출해야" 데드라인 자동 설정

## Target User
보험 청구자, 부모 (학교 입학), 국제 프리랜서 (계약서), 이주자

## 왜 설치하는가
서류 준비 과정의 불안감 해소

## 첫 30초
"보험금 청구" 카테고리 선택 → 담보 종류 입력 → 필요 서류 체크리스트 표시

## 핵심 기능
1. 카테고리별 서류 템플릿 라이브러리 (보험, 학교, 계약)
2. 질문 기반 서류 자동 생성 (양식 채우기)
3. OCR로 서류 완성도 검사
4. 제출 상태 추적 (대기 → 승인 / 반려)

## 핵심 사용 루프
Trigger(서류 제출 필요) → Action(앱에서 체크리스트 작성) → Reward(자동으로 모든 서류 준비) → Investment(기관에 제출) → Next Trigger(결과 대기)

## 반복 사용 이유
서류 제출 상황이 변할 때마다 확인

## Personalization
- 보험 종류별 맞춤 서류
- 지역별 학교 입학 서류 (각 시도마다 다름)

## AI 역할
- 서류 작성 내용 자동 검증 (필수 항목 누락 탐지)
- 과거 제출 이력 학습 → 비슷한 서류 자동 생성

## Sharing
배우자와 공동 서류 작성, 변호사 상담

## Monetization
- 무료 기본 (1개 서류 템플릿)
- 프리미엄 월 3,990원 (모든 템플릿, 고급 생성)
- B2B: 보험사/학교 연동

## MVP
3개 카테고리 (보험, 학교, 계약) + 기본 템플릿 + 체크리스트

## MVP 예상 비용
개발 4주, 금액 2,500만원

## 가장 큰 약점
템플릿 업데이트 필요 (정책 변경), 법적 검증 필요, 기관과의 데이터 연동 어려움

## 가장 중요한 검증 가설
사용자가 년 2회 이상 대량 서류를 제출하는가?

# Idea 013. MoneyFlow — 해외 송금·환전 최적화 & 환율 모니터링

## 한 줄 설명
해외 송금, 환전, 정기 송금을 자동화하고 최적 환율을 추적해 "지금 환전하면 10만원 더 받는다" 알림을 주는 앱

## 해결하는 Pain
- 해외 송금 시 환율 변동이 크게 영향
- 은행 업무시간(오전 9시~오후 3시)이 맞지 않음
- 최적 환전 시점을 모름

## 제공하는 Positive Experience
- "지금 환전하면 200,000 JPY 받지만, 내일 오전 10시면 210,000 JPY 받습니다" 예측
- 환율 변동 알림 (원/엔 차이가 2% 이상 나면 알림)
- 24시간 온라인 송금 (은행 시간 상관없음)

## Target User
해외 거주 한국인, 해외 송금자, 국제 프리랜서, 유학생

## 왜 설치하는가
송금할 때마다 손실을 최소화할 수 있다

## 첫 30초
정기 송금액 설정 → 평균 환율 표시 → "좋은 환율이 오면 알림" 옵션

## 핵심 기능
1. 다중 환전 통로 (은행, 송금사, 암호화폐) 환율 비교
2. 환율 변동 추적 + 알림
3. "이 환율에서 환전하면 될까?" 실시간 조회
4. 정기 송금 자동화 (매주, 매달)

## 핵심 사용 루프
Trigger(해외 송금 필요) → Action(앱에서 송금액 입력) → Reward(최적 환율 제시) → Investment(송금 실행) → Next Trigger(환율 변동 알림)

## 반복 사용 이유
월 1회 이상 해외 송금 또는 환전 필요 시

## Personalization
- 개인 송금 패턴 학습 (매달 언제 송금하는가)
- 자주 송금하는 국가별 환율 알림 설정

## AI 역할
- 환율 변동 패턴 분석 → "월요일 오전은 환율이 낮습니다" 예측
- 최적 송금 시점 자동 추천

## Sharing
배우자와 정기 송금 공유

## Monetization
- 무료 기본 (환율 조회, 환율 알림)
- 프리미엄 월 4,990원 (정기 송금 자동화, 환전 수수료 감소)
- 거래 수수료 0.5-1%

## MVP
한국-일본 환율 모니터링 + 기본 송금 + 알림

## MVP 예상 비용
개발 5주, 금액 3,500만원 (환율 API, 결제 시스템)

## 가장 큰 약점
규제 (금융감독), 송금사 간의 협력, 환율 예측 정확도

## 가장 중요한 검증 가설
사용자가 월 평균 송금액이 100만원 이상인가?
