## P001. 직장인 부당 야근비 미지급 증거 수집 자동화

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 직장인, 특히 비정규직 및 중소기업 근로자
- 핵심 문제: 직장인의 83%가 야근을 하지만, 근로기준법상 8시간 초과 연장근로 가산수당 미지급이 만연. 2026년 1월 기준 임금체불액 1,916억원, 체불 근로자 2만1,032명 (30인 미만 사업장 68% 집중). 미지급 야근비를 청구하려면 출퇴근 기록(카드 기록, 이메일 발송시간, 메신저 기록 등)을 직접 수집하고 정리해야 함
- 사람들이 실제로 싫어하는 것: "월 20시간 야근을 해도 기본급에만 포함된다고 함", "포괄임금제를 이유로 미지급", "출퇴근 증거를 직접 모아야 함", "회사에 야근비 요청 시 낙인 우려", "3년 이내 시효 내에 소송해야 함"
- 현재 해결 방법: 출퇴근 시간 수동 기록(엑셀), 고용노동부 진정, 노무법인 상담
- 발생 빈도: 월 주 4~5회 (일상적)
- 시간 비용: 야근 월 20~40시간 (무보상) + 증거 수집 월 5~10시간
- 금전 비용: 월 50만~200만원 손실 (미지급 야근비)
- 문제 심각도 (0~10): 8
- 현재 지출: 월 300만~500만원 (기본급만)
- 소프트웨어 해결 가능성: 높음 (자동 출퇴근 기록 + 야근비 계산)
- AI 해결 가능성: 높음 (포괄임금제 위반 자동 감지)
- 1인 개발 가능성: 중간 (기업 근태 시스템 API 연동 필요)

### 실제 근거

- 고용노동부 통계 (2026년 1월): 임금체불액 1,916억원, 체불 인원 2만1,032명
- FindSemusa 노동 상담: "야근수당 안 주는데 어떻게 증거를 잡아야 하나요?" — 수천 건의 실제 질문
- Brunch 기사: "일주일에 4일 야근해도 수당을 기대할 수 없는 이유"
- HR Story: "야근수당 불편한 진실 — 83% 야근 vs 25% 수당지급"

### 신호 스크리닝

① 정부 무료 제공: Partial — 근로기준법 보장, 고용노동부 진정 가능하지만 증거 수집은 개인 책임
② 업계 무료 콘텐츠: No — 각 기업별 다른 포괄임금 규정
③ 기존 SaaS 포함: No — 야근비 자동 계산 및 증거 수집 통합 솔루션 거의 없음
④ 반복 빈도: 월 주 4~5회 (매우 빈번)

**판정**: 채택 — 반복적 pain signal + 명확한 법적 기반 + 고액 손실

### CEO Directive 고찰

"야근비 뽑기" (CEO Directive 예시) 아이디어와의 교차점: 미지급 야근비를 자동 추적 후 "미수금 추적 + 커뮤니티 신뢰도" 방식으로 재설계할 수 있음. 단순 계산 도구가 아닌 "증거 → 청구 → 법적 지원 → 커뮤니티 평판 시스템" 통합 구조로 차별화 가능.

## P002. 프리랜서 계약서·청구서 작성 수작업 부담

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 프리랜서 (개발자, 디자이너, 라이터, 번역가)
- 핵심 문제: 프리랜서가 매 프로젝트마다 계약서 작성, 청구서 생성, 송금 추적을 수작업으로 처리. 한국소비자원 2024년 분쟁 사례에 따르면 대금 지급 지연 관련 분쟁이 프리랜서 전체 분쟁의 25% 이상. 표준 계약서 없으면 작업 범위·납기·대금 지불 조건이 불명확해져 분쟁 발생. 계약서 검토, 인보이스 발행 시간이 매달 2~5시간 소비
- 사람들이 실제로 싫어하는 것: "매번 계약서를 새로 만들어야 함", "청구서 형식이 통일되지 않음", "대금 청구 후 언제 입금되는지 추적하기 어려움", "클라이언트별로 결제 조건이 다 다름"
- 현재 해결 방법: 표준 계약서 템플릿 사용, Invoicely/FreshBooks 같은 인보이스 도구, 엑셀 추적
- 발생 빈도: 월 2~4회 (프로젝트 생성 시)
- 시간 비용: 월 4~10시간 (계약서 + 청구서 + 추적)
- 금전 비용: 없음 (도구 사용 월 0~3만원)
- 문제 심각도 (0~10): 6
- 현재 지출: 월 $0~$30 (도구 사용료)
- 소프트웨어 해결 가능성: 높음 (표준 계약서 + 자동 청구서 생성)
- AI 해결 가능성: 높음 (프로젝트 설명에서 계약서 자동 생성)
- 1인 개발 가능성: 높음 (템플릿 기반)

### 실제 근거

- 한국소비자원: 대금 지급 지연 분쟁 25% 이상 (프리랜서 전체 분쟁)
- Payoneer 블로그: "글로벌 프리랜서를 위한 올바른 인보이스 작성 팁 9가지"
- FindSemusa: "계약서 없이 프리랜서로 일한 기간 동안 임금체불이 발생하면 어떻게 해야 하나요?" — 실제 질문 다수
- TILNOTE: "프리랜서 계약서 쓰는 법 2026" 가이드 필요성 언급

### 신호 스크리닝

① 정부 무료 제공: Partial — 프리랜서 SOS 상담은 제공하지만, 자동화 솔루션 없음
② 업계 무료 콘텐츠: Partial — 표준 템플릿은 있으나, 각 클라이언트별 커스터마이징 필수
③ 기존 SaaS 포함: Yes — Invoicely, FreshBooks, Wave Accounting 등 있음
④ 반복 빈도: 월 2~4회 (반복적)

**판정**: 채택 — 반복적 pain + 기존 SaaS도 완전한 자동화는 못함 (계약서 생성 약함)

### CEO Directive 고찰

"자동화 + 커뮤니티" 전략 적용: 프리랜서가 클라이언트 신뢰도 평점 커뮤니티 (결제 실적, 계약 조건 이행 여부)를 같이 볼 수 있으면, 단순 도구보다 높은 가치 제시.

## P003. 배달앱 점주 매출 대비 26% 거래비용 악순환

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 배달앱 입점 음식점주 (소형 음식점 월 매출 836만원 이하)
- 핵심 문제: 배달앱 입점 점주가 부담하는 월평균 거래비용(중개수수료·배달비·광고비)은 월 매출의 26.2%. 매출 100만원을 올리면 26만원 이상이 플랫폼에 빠져나감. 최대 45% 지출 사례도 있음. 매출은 늘지만 영업이익률은 감소하는 악순환. 차등 수수료제 도입해도 "변화 없음" 49.4%, "도움 안 됨" 35.4% (합계 84.8%)
- 사람들이 실제로 싫어하는 것: "배달앱에 의존하니까 수익성이 떨어짐", "배달앱 광고를 더 노출하려면 광고비를 더 내야 함", "수수료가 올라갈 예정", "우리가 통제할 수 없는 가격 경쟁"
- 현재 해결 방법: 자사 채널 강화 (SNS, 자사몰), 배달앱 의존도 낮추기, 수수료 협상
- 발생 빈도: 매일 (거래 발생)
- 시간 비용: 월 5~10시간 (수수료/광고 전략 수립)
- 금전 비용: 월 매출의 26% 손실
- 문제 심각도 (0~10): 8
- 현재 지출: 월 매출의 100% (기본 + 배달앱 비용)
- 소프트웨어 해결 가능성: 높음 (수익성 분석 대시보드)
- AI 해결 가능성: 높음 (메뉴별 수익성 자동 계산)
- 1인 개발 가능성: 높음 (배달앱 API 연동)

### 실제 근거

- Byline Network (2026년 6월): "작은 음식점이 배달앱 의존하면 수익성 악화된다"
- 머니투데이 (2026년 9월): "100만원 팔면 배달앱에 26만원" — 매출 26% 거래비용
- 사이다 (2026년 9월): "배달앱 입점업체, 매출 최대 45% 거래비용으로 지출"
- 한국강사신문: "배달 매출의 착시를 걷어내야 외식업의 진짜 수익이 보인다"

### 신호 스크리닝

① 정부 무료 제공: Partial — 배달앱 수수료 감시, 정책 검토 중이나 실질 해결책 없음
② 업계 무료 콘텐츠: No — 각 배달앱이 자신의 수수료만 공개
③ 기존 SaaS 포함: Partial — 배달앱 통합 관리 도구(Shoplinker 등) 있으나, 근본적 수익 개선은 못함
④ 반복 빈도: 매일 (거래 발생)

**판정**: 채택 — 반복적 pain + 고액 손실 + CEO Directive의 "마진율 컨설팅 게임화" 예시와 직결

### CEO Directive 고찰

"배달점주가 매일 1분 미니게임으로 마진율 컨설팅 받기" — 이 신호는 그 실제 근거. 점주들이 매일 수익 악화에 불만인데, 이를 역으로 "매일 최적화" 앱으로 재설계할 수 있음.

## P004. 전세보증금 반환 분쟁 처리 및 추적

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 전세 임차인, 주택 이동자
- 핵심 문제: 2025년 기준 전세보증금 반환 분쟁 약 4만7천 건. 역전세 지역에서 집주인이 새 세입자를 못 구해 보증금을 못 주는 경우 증가. 2026년 대법원 판결(2026다201978)에서 동시이행 관계 확인했으나, 실제 임차인은 내용증명 → 임차권등기명령 → 보증보험 청구 → 법적 절차를 일일이 진행해야 함. HUG 반환보증도 조건 제한(수도권 7억원 이하 등)
- 사람들이 실제로 싫어하는 것: "이사 가는데 보증금이 안 돌아옴", "집주인이 대출금 상환으로 시간 끌기", "법적 절차가 너무 복잡", "임차권등기명령 신청 방법을 모름", "HUG 보증보험 조건을 모름"
- 현재 해결 방법: 내용증명 발송, 임차권등기명령(법원), 보증보험 청구, 법무사 상담, 소송
- 발생 빈도: 이사 시점 (연 0.5~1회, 반복도 있음)
- 시간 비용: 분쟁 발생 시 5~20시간 (법적 절차 진행)
- 금전 비용: 보증금 범위 내 손실
