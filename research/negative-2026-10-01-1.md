## P001. 직장인 부당 야근비 미지급 및 증거 수집 어려움

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 직장인, 특히 비정규직 및 중소기업 근로자
- 핵심 문제: 근로기준법상 8시간 초과 연장근로에 대해 통상임금의 50% 이상 가산수당을 받아야 하지만, 실제로는 83%의 직장인이 야근을 하는 반면 4명 중 3명은 야근 수당을 받지 못하고 있음. 포괄임금제를 이유로 미지급하거나, 이를 요구하는 과정에서 회사와 분쟁 발생
- 사람들이 실제로 싫어하는 것: "월 20시간 야근을 해도 기본급에만 포함된다고 함", "야근을 강요하지만 수당을 받을 수 없음", "미지급 야근비를 청구하려면 출퇴근 기록을 직접 증명해야 함", "회사 내에서 야근비 요청 시 낙인 우려"
- 현재 해결 방법: 출퇴근 시간 기록 수집(카드 기록, 이메일 발송시간), 야근 기록 엑셀로 정리, 3년 이내 미지급분 소송 추진, 노동청 진정
- 발생 빈도: 월 주 4~5회 (일상적 야근)
- 시간 비용: 야근 월 20~40시간 (무보상)
- 금전 비용: 월 50만~200만원 손실 (미지급 야근비)
- 문제 심각도 (0~10): 7
- 현재 지출: 월 300만~500만원 (기본급만)
- 소프트웨어 해결 가능성: 높음 (자동 출퇴근 기록 및 야근비 계산)
- AI 해결 가능성: 높음 (포괄임금제 위반 자동 감지, 법적 조언)
- 1인 개발 가능성: 중간 (기업 시스템 연동 필요)

### 실제 근거
- Brunch 기사: "일주일에 4일 야근해도 수당을 기대할 수 없는 이유" — 포괄임금제의 만연
- FindSemusa 노동상담: "야근수당 안주는데 어떻게 증거를 잡아야 하나요?" — 직장인들의 실제 질문
- HR Story 블로그: "야근수당의 불편한 진실 — 수당은 받으며 일하시나요?" — 83% 야근 vs 25% 수당지급
- 근로기준법 제56조: 연장근로 시 추가수당 의무 명시

### 신호 스크리닝
① 정부 무료 제공: Partial — 근로기준법은 보장하지만, 자동 계산/증거 수집은 미제공
② 업계 무료 콘텐츠: No — 각 회사별로 다른 포괄임금 규정
③ 기존 SaaS 포함: No — 야근비 자동 계산 솔루션은 거의 없음
④ 반복 빈도: 월 주 4~5회 (일상적)

**판정**: 채택 — 실제 직장인들의 명확한 pain signal이며 법적 보호 있음

### 왜 중요한 문제인가
직장인의 83%가 야근을 하고 있지만, 상당수가 부당 미지급 상태. 야근비 자동 계산 및 추적 시스템이 있으면 월 50만원 이상 절감, 법적 분쟁 예방.

### 가정
- 기업 근태 시스템(카드기반)에서 출퇴근 데이터 추출 가능성 확인 필요
- 포괄임금제와 통상임금 계산 규정 정확히 반영 필요

## P002. 가계부 앱 은행 연동 부족으로 수작업 입력 강요

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 개인재정 관리자, 월급생활자, 프리랜서
- 핵심 문제: 시중의 가계부 앱(편한가계부, 꼬박가계부 등) 중 많은 앱이 은행과의 자동 연동 기능이 부족하거나 전혀 제공하지 않음. 신용카드·체크카드 연동이 되어도 현금 소비는 수동 입력 필수. 이 때문에 사용자는 매일 거래내역을 검토해서 일일이 입력해야 함
- 사람들이 실제로 싫어하는 것: "계좌 연결했는데도 자동 입력이 안 됨", "매번 수동으로 입력하다 보니 몇 일이 지나면 기록 누락됨", "카드 거래만 나오고 현금은 수동으로 해야 함", "은행 앱과 가계부 앱을 번갈아 봐야 함"
- 현재 해결 방법: 네이버 가계부(SMS 자동 입력 기능 제공), 전자금융 API 연동(은행권에서 제한적 제공), 수동 입력에 익숙해지기
- 발생 빈도: 매일 (매일 거래 발생)
- 시간 비용: 월 3~5시간 (거래 입력 및 분류)
- 금전 비용: 없음 (무료 또는 저가 앱)
- 문제 심각도 (0~10): 5
- 현재 지출: 무료~월 3,000원 (프리미엄 기능)
- 소프트웨어 해결 가능성: 높음 (은행 API 연동 자동화)
- AI 해결 가능성: 높음 (거래 자동 분류 및 카테고리화)
- 1인 개발 가능성: 중간 (은행 API 승인 필요)

### 실제 근거
- 뱅크샐러드 블로그: "가계부 어플 추천! 가계부 똑똑하게 잘 쓰는 법" — 자동화 부족 언급
- 마일모아 커뮤니티: "자동기입되는 가계부 앱 있을까요?" — 사용자 질문
- 네이버 가계부 공식: "스마트폰에서 받은 문자를 자동으로 입력해주며 은행 문자, 체크 및 신용카드 문자를 자동으로 입력" — 네이버 가계부만 선택지

### 신호 스크리닝
① 정부 무료 제공: No — 정부가 가계부 자동화 서비스 미제공
② 업계 무료 콘텐츠: No — 각 은행이 자신의 앱에서만 거래내역 제공
③ 기존 SaaS 포함: Partial — 네이버 가계부가 SMS 기반 자동 입력 제공하지만, 완전한 은행 API 연동은 제한적
④ 반복 빈도: 매일 (매일 거래 발생)

**판정**: 채택 — 실제 사용자의 반복적 pain signal

### 왜 중요한 문제인가
개인 재정 관리자가 매달 3~5시간을 수작업 입력에 소비. 완전한 자동화가 되면 월 5시간 절감 + 기록 정확성 향상.

### 가정
- 은행권의 오픈뱅킹 API 개방 수준 확인 필요
- 카드사와의 API 연동 가능성 확인 필요

## P003. 렌탈 서비스(정수기 등) 의무기간 후 해지비용 청구

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 렌탈 서비스 사용자(정수기, 공기청정기, 가스레인지 등)
- 핵심 문제: 정수기 렌탈 계약 시 "60개월 계약, 의무사용기간 36개월"이라는 조건이 있는데, 의무기간이 끝난 후에도 해지 시 위약금 외에 "할인받은 렌탈료 차액", "철거비", "등록비" 등이 추가 청구됨. 소비자는 의무기간이 끝나면 추가 비용이 없다고 예상하지만 실제로는 그렇지 않음
- 사람들이 실제로 싫어하는 것: "의무기간이 지났는데 왜 해지비용이 나오는가", "약관에 작은 글씨로 명시되어 있어 미리 알기 어려움", "할인받은 금액을 반환하라는 게 불공정하다고 느낌", "렌탈 계약이 쉽지만 해지가 어려움"
- 현재 해결 방법: 계약 전 약관 세밀하게 읽기, 한국소비자원에 분쟁 신청, 중도 해지료 사전 확인
- 발생 빈도: 계약 기간 만료 시 (1회성, 1~3년 주기)
- 시간 비용: 해지 절차에 1~3시간
- 금전 비용: 의무기간 후 해지 시 20만~50만원 추가 청구
- 문제 심각도 (0~10): 6
- 현재 지출: 월 3~5만원 (렌탈료)
- 소프트웨어 해결 가능성: 높음 (렌탈 계약 약관 분석 및 예상 해지비용 계산)
- AI 해결 가능성: 높음 (약관 자동 해석 및 위험 항목 표시)
- 1인 개발 가능성: 중간 (렌탈사 계약서 데이터베이스 구축)

### 실제 근거
- 한국소비자원: "정수기 렌탈 서비스 이용 중 해지 관련 비용 분쟁 증가" — 의무사용기간 후 불만 35.8%
- Edaily 기사: "렌탈 정수기 계약, 해지 비용 꼼꼼히 확인하세요"
- 다음뉴스: "정수기 렌탈 의무사용 끝났는데 해지비용 청구된다고?"
- 실제 사례: 47개월 차에 해지 시 할인받은 렌탈료와 철거비용 청구

### 신호 스크리닝
① 정부 무료 제공: Partial — 한국소비자원이 분쟁 해결 제공하지만 사전 예방은 없음
② 업계 무료 콘텐츠: No — 렌탈사가 자신의 약관만 공개
③ 기존 SaaS 포함: No — 렌탈 약관 분석 서비스는 거의 없음
④ 반복 빈도: 계약 만료 시 (1회성)

**판정**: 채택 — 실제 소비자 피해가 많고, 약관 복잡성이 높음

### 왜 중요한 문제인가
렌탈 계약자가 의무기간 후 추가 비용 청구로 분쟁을 겪음. 약관 자동 분석 도구가 있으면 사전 예방 가능.

### 가정
- 주요 렌탈사(LG, SK매직 등)의 약관 구조 파악 필요
- 해지비용 계산 규칙 표준화 필요

## P004. 어린이집 보육료 반환 및 환불 절차 복잡

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 학부모, 보육 이용자
- 핵심 문제: 정부 지원 보육료를 사용 중인 부모가 어린이집 이용을 중단할 때, 사용하지 않은 보육료 바우처를 반환받는 절차가 복잡함. 부분 퇴소(월중 퇴소) 시 일할 계산 문제, 개인 부담금의 환불 처리 복잡, 각 어린이집마다 처리 방식이 다름
- 사람들이 실제로 싫어하는 것: "남은 보육료를 받으려면 포털에서 직접 신청해야 함", "환불 시기가 불명확함", "어린이집과 정부포털 사이에 정보가 맞지 않는 경우가 있음", "휴원(병가, 휴직)할 때 보육료 복구가 느림"
- 현재 해결 방법: 어린이집 사무실에 직접 문의, 육아포털 아이사랑에서 환불 신청, 보육료 적립금 이용
- 발생 빈도: 어린이집 이용 중단 시 (분기별 1~2회 또는 연 1~2회)
- 시간 비용: 환불 신청 및 확인에 1~2시간
- 금전 비용: 보육료 환불 지연 시 개인 손실 가능

## P020. 가족 공유 캘린더 스케줄 충돌 및 정보 동기화

- 지역: 전세계
- 국가: 다국가
- 타깃 고객: 가족 단위 사용자, 부모(특히 워킹맘/워킹대디)
- 핵심 문제: 가족 구성원(부모, 자녀, 형제)이 각자의 일정(업무, 학교, 학원, 병원 예약)을 관리할 때, 공유 캘린더가 제대로 동기화되지 않으면 충돌이 발생함. 예를 들어, 엄마는 회사 회의, 아빠는 출장, 큰아이는 학원, 작은아이는 피아노 레슨이 동시에 일어날 수 있음. 또한 한 사람이 일정을 입력하지 않으면 다른 사람들이 모르고 있는 경우가 발생
- 사람들이 실제로 싫어하는 것: "아이 피아노 레슨을 아빠가 모르고 있었음", "모두의 일정이 실시간으로 동기화되지 않음", "한 사람만 일정을 입력하고 나머지는 업데이트하지 않음", "갑자기 일정이 변경되면 다른 가족원에게 알려야 함"
- 현재 해결 방법: Google Calendar, Apple Calendar, Outlook 같은 클라우드 캘린더 공유, 카톡이나 문자로 변경사항 공지, 가족 회의에서 주간 일정 검토
- 발생 빈도: 매일 (새로운 일정 발생)
- 시간 비용: 주 1~2시간 (일정 조정, 변경 공지, 충돌 해결)
- 금전 비용: 없음 (무료 서비스 사용)
- 문제 심각도 (0~10): 4
- 현재 지출: 무료 (Google/Apple 클라우드)
- 소프트웨어 해결 가능성: 높음 (실시간 동기화, 충돌 감지, 자동 알림)
- AI 해결 가능성: 중간 (최적 일정 추천)
- 1인 개발 가능성: 높음 (클라우드 캘린더 API 활용)

### 신호 스크리닝
① 정부 무료 제공: No — 정부가 가족 캘린더 서비스 미제공
② 업계 무료 콘텐츠: Partial — Google Calendar, Apple Calendar가 공유 기능 제공하지만, 가족 특화 기능은 미흡
③ 기존 SaaS 포함: Partial — Homsy, GroupCal, CalendarBridge 같은 가족 캘린더 앱이 있지만, 주류는 아님
④ 반복 빈도: 매일 (새로운 일정 발생)

**판정**: 신중채택 — 문제는 명확하지만, 이미 Google/Apple 같은 대형 플랫폼이 공유 캘린더 기능을 제공 중. 가족 특화 기능(자동 충돌 감지, 최적 시간 추천 등)으로 차별화 필요

### 왜 중요한 문제인가
가족이 일정 충돌로 인해 혼란을 겪고, 주 1~2시간을 일정 조정에 소비. 실시간 동기화 + 자동 충돌 감지 기능이 있으면 주 1.5시간 절감.

### 가정
- 가족 사용자의 실제 니즈(시간 추천, 충돌 감지)를 명확히 파악해야 함
- Google/Apple 캘린더와의 연동 가능성 확인 필요
