## Idea 001. MoneyStorm — 프리랜서 자동 정산 & 세금 게임화

**한 줄**: 프리랜서 수입을 정산하고, 세금까지 자동 계산한 후, 게임화된 "세금 챌린지"로 정산을 보상하는 앱

**해결하는 Pain**:
- P003 프리랜서 원고료 정산 수작업
- P006 소상공인 중복 영수증 관리
- P011 회사원 월급 공제항목 미리 알고 싶음

**제공하는 Positive Experience**:
- S001의 강박성: "세금을 정산하면 환급금을 받는다" 구조
- S005의 자동성: 매일 소액이 모이는 쾌감
- S019의 기록성: 연간 세금 기록 누적

**Target User**:
- 프리랜서, 개인사업자 (한국)
- 월 수입 변동 큰 사용자
- 세금 신고를 자동화하고 싶은 사람

**왜 설치/첫 30초/핵심 기능/사용 루프**:
1. 첫 설치 시: "올해 세금 얼마나 낼지 미리 보세요"
2. 첫 30초: 오늘 정산액 + "완성까지 D-7" 진행도 바
3. 핵심 기능:
   - 크몽/당신의서재/5시간 등 플랫폼 자동 연동 (API)
   - 매일 정산액 자동 합산
   - 부가세/소득세 자동 계산
   - "세금 챌린지": 매월 말까지 모든 정산 확인하면 환급금 또는 포인트
4. 사용 루프: 출금받음 → 앱 열어서 입금 확인 → 세금 자동 계산 → 점수 적립 → 월말 챌린지 완성 → 리워드

**Personalization**:
- 프리랜서 종류별 세금율 (라이터 vs 디자이너)
- 월별 수입 변동 추이 기반 "예상 환급액" 예측
- 관심 카테고리별 우선순위 알림 (부가세 신고 기한, 절세 팁)

**AI 역할**:
- 영수증 자동 분류 (사업비 vs 개인비)
- "이 달 세금 이대로면 과다하니 지출 조정하세요" 예측
- 절세 팁 자동 추천

**Sharing**:
- 연간 세금 요약 SNS 공유 ("올해 나는 X만원 세금을 냈다")
- 세금 챌린지 완성 인증

**Monetization**:
- 무료: 기본 정산 + 세금 계산
- Pro (월 2,990원): 고급 분석 + 세무사 1:1 상담 5회/년
- B2B: 소상공인 가맹점주 대상 bulk pricing

**MVP (1인 개발, 300만원)**:
- 당신의서재/크몽 API 연동만 먼저
- 엑셀 임포트 기능
- 간단한 세금 계산기
- 월별 차트
- 정산 알림

**가장 큰 약점**:
- 각 플랫폼이 API 개방 안 할 수도 있음
- 세무 정확성이 떨어지면 신뢰 상실 (세무사와 협력 필수)
- 초기 보수적인 프리랜서들의 진입 장벽

**가장 중요한 검증 가설**:
- "프리랜서들이 실제로 월별 세금 예측을 원하는가?"
- 테스트: 10명의 프리랜서에게 "예상 세액을 미리 알면 쓸 의향이 있나?" 조사
- 만약 5명 이상이 유료 구독 의향 표시하면 고GO

**경쟁 확인**: 삼쩜삼(무료 기본), 이음세무 등이 있지만, 프리랜서 플랫폼 자동 연동은 없음 → 차별화 명확

## Idea 002. SegmentKeeper — 편의점 택배 자동 알림 & 성취감 게임화

**한 줄**: 편의점 택배 수령 기한을 추적하고, 기한 내 수령하면 보너스 포인트를 주는 배송 추적 앱

**해결하는 Pain**:
- P001 편의점 택배 보관 기한 만료 미인식
- P007 일본 편의점 배송 추적 및 취소

**제공하는 Positive Experience**:
- S017의 스트릭: "기한 내에 수령했다" 기록 쌓기
- S014의 경쟁: 친구들끼리 "택배 수령 속도" 경쟁
- S001의 보상: 기한 내 수령하면 포인트 획득

**Target User**:
- 편의점 택배 자주 이용하는 사람 (월 2~4회)
- 기한을 자주 놓치는 사람
- 영포티 (편의점 수령이 익숙한 세대)

**왜 설치/첫 30초/핵심 기능/사용 루프**:
1. 첫 설치: 기존 택배 APP 연동 (배송 추적)
2. 첫 30초: "GS25 - 피크닉 바구니, 내일 오후 6시 만료 ⚠️"
3. 핵심 기능:
   - 편의점 배송 API 연동 (GS25, CU, 이마트24)
   - 수령 기한 3일/1일 전 알림
   - "오늘 수령했습니다" 체크 → 포인트 +10
   - "기한 내 수령 스트릭" 표시
4. 사용 루프: 배송 도착 → 앱 알림 → "오늘 수령" 체크 → 점수 적립 → 친구와 비교

**Personalization**:
- 자주 이용하는 편의점별 알림 강도 설정
- 출근/퇴근 시간 기반 "최적 수령 시간" 추천
- "수령 습관" 분석 (월요일 자주 놓침 → 월요일 강화 알림)

**AI 역할**:
- 배송사 API에서 자동으로 편의점 도착 감지
- "이 시간대에 수령 못하면 기한 못 지킬 확률" 예측
- 택배 종류별 수령 긴급도 (신선식품 > 의류)

**Sharing**:
- "30일 연속 기한 내 수령!" 인증
- 친구들과 "택배 수령 속도" 랭킹

**Monetization**:

## Idea 006. DailyRepeat — 습관 형성 & 금전적 리스크 결합 미니 챌린지

**한 줄**: 작은 습관(독서, 운동, 명상)을 하루 단위로 실행하면 포인트를 주고, 실패하면 참가비를 잃는 초단기 챌린지 플랫폼

**해결하는 Pain**:
- 특정 pain은 없음. 대신 **Positive Signal 분석에서 S001의 동기 구조를 극대화**

**제공하는 Positive Experience**:
- S001의 강박: "오늘 챌린지를 못 하면 돈을 잃는다"
- S017의 스트릭: "연속 5일" 성공 기록
- S014의 경쟁: 친구들과 함께 하는 챌린지

**Target User**:
- 습관 형성에 어려움을 겪는 20~40대
- 금전적 손실에 민감한 사람
- 친구들과 함께 무언가를 하고 싶은 사람

**왜 설치/첫 30초/핵심 기능/사용 루프**:
1. 첫 설치: "오늘부터 시작할 5일 습관 선택" (운동, 독서, 명상, 금연 등)
2. 첫 30초: "내일 밤 11시까지 운동 30분을 하지 않으면 5,000원을 잃게 됩니다. 계속하시겠습니까?"
3. 핵심 기능:
   - 초단기 챌린지: 1일, 5일, 7일 (14일 이상은 없음 = 부담 낮음)
   - 참가비: 1,000~10,000원 (낮게 설정)
   - 일일 체크: "오늘 습관을 했나요?" → YES/NO (사진 인증 가능하지만 의무 아님)
   - 성공하면: 참가비 돌려주기 + 추가 보너스 포인트
   - 실패하면: 돈을 잃고, 실패 사유 기록 (재시도 권유)
   - 친구 초대: "함께 하실래요?" 공유 링크
4. 사용 루프: 챌린지 선택 → 참가비 입금 → 매일 밤 알림 → "했나요?" 체크 → 성공하면 점수+, 실패하면 돈 잃음 → 5일 성공하면 환급 + 포인트

**Personalization**:
- "당신은 보통 3일차에 실패해요" → 3일 챌린지 추천
- "야식 금지 챌린지"는 저녁 8시에만 알림
- 개인별 성공률 기반 참가비 제안 (성공률 높으면 높은 참가비 추천)

**AI 역할**:
- 사진 기반 습관 인증 (운동 사진 분석 = 실제로 했나?)
- "당신의 습관 실패 패턴 분석" (언제 자주 실패?)
- "내일 실패할 확률 60%" 예측 → 미리 보강

**Sharing**:
- "5일 연속 운동 성공!" 친구에게 자동 공유
- 친구와 함께 한 챌린지 완성 축하
- "이번 주 우리팀 성공률 85%" 통계

**Monetization**:
- 무료: 기본 체크, 1회 챌린지 참가
- Pro (월 2,990원): 무제한 챌린지 + 친구 초대 추적 + AI 피드백
- 지점 기부: 실패한 돈의 10%를 자선 단체에 기부 (사용자 선택)

**MVP (1인 개발, 300만원)**:
- 5개 기본 챌린지 (운동, 독서, 명상, 금연, 물 마시기)
- 일일 체크 (YES/NO만)
- 친구 초대 (링크)

**가장 큰 약점**:

**가장 중요한 검증 가설**:

- 70% 이상이 "더 낫다"고 답하면 GO

**경쟁 확인**:
