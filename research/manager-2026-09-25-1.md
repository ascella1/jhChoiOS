# Idea 001. AllBook — 다중플랫폼 예약 통합 + 포인트 누적

## 한 줄 설명
방문미용사·온라인 강사·공인중개사를 위한 "모든 플랫폼의 예약을 한곳에서 관리하고, 매 예약마다 포인트 적립하는" 통합 대시보드.

## 해결하는 Pain
- 당근·숨고·카톡·직방 등 5개 이상 플랫폼에서 동시에 예약 수신
- 중복 예약으로 고객 불만 및 평점 하락
- 매 플랫폼마다 상태 업데이트 필요 (수작업 시간 낭비)
- 예약 확인 메시지를 깜빡해 고객 불신 초래

## 제공하는 Positive Experience
- 한 대시보드에서 모든 예약을 "동기화된 상태"로 볼 수 있는 통제감
- 예약 충돌 자동 감지 + 최적 일정 제안
- 매 예약마다 포인트 적립 (S001의 "본전 심리" 활용)
- 자동 확인 메시지로 고객 신뢰도 상승 → 평점 개선

## Target User
- 방문미용사·매니큐어 (한국 6만명+)
- 온라인 강사·튜터 (한국 10만명+)
- 소규모 공인중개사 (한국 5만명+)
- 출장 서비스 제공자
- 총 시장: 20만명+

## 왜 설치하는가
"5개 플랫폼을 일일이 확인하는 시간 절약" + "평점 개선로 수입 증가 기대"

## 첫 30초
1. 가입 후 당근/숨고/카톡 연동 (API/크롤링)
2. 기존 예약 5개 자동 로드
3. "중복 예약 감지됨" 알림 (실제 근심 해결)
4. 한국어 UI로 즉시 이해

## 핵심 기능
- 모든 플랫폼 예약을 일일 달력에 표시
- 시간 충돌 자동 감지 + "이 시간에 예약 불가" 상태 자동 푸시
- 포인트 누적 (매 예약 +100 포인트, 환금 또는 다음달 수수료 할인)
- 자동 확인 메시지 (고객 커스터마이징 템플릿)
- 월별 수익 추이 (어느 플랫폼이 실제 수익이 높은가)

## 핵심 사용 루프
예약 → 충돌 감지 → 상태 자동 동기화 → 자동 메시지 발송 → 고객 피드백 (평점 상승) → 포인트 적립 → Next 예약

## 반복 사용 이유
- 매일 새로운 예약이 들어옴
- 포인트 누적을 매일 확인하고 싶음 (S001 심리)
- 평점 개선 추이를 주 1회 모니터링

## Personalization
- 개인별 플랫폼 가중치 설정 (당근에서 70%, 숨고에서 30% 등)
- 선호 고객 자동 필터링
- 시간대별 이용량 분석 (야간 예약 집중 시 야간 요금제 제안)

## AI 역할
- 중복 예약 자동 감지 + 취소 확률 예측
- "이 시간대에 예약을 잡으면 취소율 10%입니다" 알림
- 최적 일정 제안 (스트레스 최소화)
- 평점이 내려갈 가능성 예측 + 개선 조언

## Sharing
- 포인트 달성 스크린샷 (SNS 공유)
- "평점 4.8 도달!" 공유 → 신규 고객 유입
- 친구 초대 시 포인트 보너스

## Monetization
- 기본 무료 (2개 플랫폼까지)
- 프리미엄 월 4,900원: 무제한 플랫폼, 고급 분석, 자동 메시지 맞춤화
- 포인트 환금 수수료: 3~5%
- B2B (공인중개사용 고급 버전): 월 29,900원

## MVP
- 당근·숨고·카톡만 통합 (3개)
- 기본 달력 + 충돌 감지 + 포인트
- 자동 메시지는 없음 (수작업 템플릿만)

## MVP 예상 비용
- 백엔드 개발: 400만원 (Node.js + 크롤링)
- 모바일 앱 (React Native): 300만원
- 디자인: 150만원
- **총 850만원** (1인 개발 가능하나, 플랫폼 API 연동으로 3개월)

## 가장 큰 약점
- 플랫폼 API 연동 어려움 (당근·숨고는 공식 API 미제공, 크롤링 필요)
- 크롤링 차단 위험
- 경쟁: 스케줄링 앱 (Google Calendar, Notion 타이머)은 이미 다중 입력 지원

## 가장 중요한 검증 가설
**당근·숨고를 동시에 사용하는 방문미용사가 월 평균 3회 이상 중복 예약을 경험하는가?**
- 검증 방법: 방문미용 커뮤니티 50명 설문
- 기대 결과: 70% 이상이 "중복 예약 경험 있음" 응답

# Idea 002. SalaryTransparency — 온라인 강사 급여 투명화 플랫폼

## 한 줄 설명
온라인 강사·튜터를 위한 "시간당 급여 추적 + 동료 급여 비교 + 커뮤니티" 플랫폼.

## 해결하는 Pain
- 강사마다 서로 다른 결제 구조 (시간당 vs 구독료 vs 회차별)를 추적하기 어려움
- 자신의 시간당 급여가 "공정한가" 판단 불가능
- 플랫폼별 수수료 구조 불명확 (20~40%)
- 주 10시간 일해도 월 수입이 예측 불가능

## 제공하는 Positive Experience
- "나는 시간당 5만원, 평균은 4.5만원" 같은 객관적 지표 획득 (S011 직장 후기 투명화)
- 커뮤니티에서 "너는 너무 싸게 가르친다, 올려봐" 같은 실질적 조언 받기
- 월별 수입 추이를 시각화해서 "내 스킬이 향상되고 있다" 확인

## Target User
- Preply, Verbling, iTalki, 탈잉, 숨고 강사 (국내 5만명+)
- 지역별·과목별 강사 (영어, 음악, 프로그래밍 등)

## 왜 설치하는가
"내 급여가 공정한지 알고 싶어" + "같은 강사들과 정보 공유"

## 첫 30초
1. 지난 3개월 강의 기록 CSV 업로드
2. 시간당 급여 자동 계산 (수수료 제외)
3. "당신은 평균보다 15% 높음" 피드백

## 핵심 기능
- 플랫폼별·과목별 시간당 급여 자동 계산
- 익명 커뮤니티 (같은 과목 강사와의 급여 비교)
- "너는 평균보다 높은데 수수료가 높은 게 아닐까" AI 제안
- 월별 수입 성장률 추적
- 수료 완주도 추적 (이탈 학생 vs 충성 학생 분석)

## 핵심 사용 루프
강의 완료 → 수입 기록 → 급여 추적 페이지 확인 → 커뮤니티 팁 읽기 → 다음 강의료 협상 → Next 강의

## 반복 사용 이유
- 매주 새로운 강의가 들어옴 (급여 데이터 업데이트)
- 커뮤니티에서 매일 새로운 팁 공유

## Personalization
- 강사별 이상적 강의 시간대 분석 (당신은 저녁 강의가 가장 수입이 높습니다)
- 과목별·학생 레벨별 추천 수료료

## AI 역할
- 부정당하는 급여 자동 감지 (시간당 2만원 이하)
- "너는 이 과목으로 월 200만원까지 벌 수 있을 것 같다" 예측
- 학생 이탈 원인 분석 (가격? 교과질?)

## Sharing
- "나는 월 1000시간을 가르쳤어" 배지 공유
- 급여 상승률 공유 (개인 정보 보호)

## Monetization
- 기본 무료 (매월 급여 추적)
- 프리미엄 월 2,900원: 커뮤니티 깊이 있는 분석, AI 급여 컨설팅
- B2B (강의 플랫폼용): 월 29,900원

## MVP
- CSV 업로드 → 자동 급여 계산
- 월별 그래프
- 기본 커뮤니티 (게시판)

## MVP 예상 비용
- 백엔드 (급여 계산): 200만원
- 웹 (React): 250만원
- 디자인: 100만원
- **총 550만원**

## 가장 큰 약점
- 초기 사용자 수가 작으면 "비교" 가치 낮음
- 강사 커뮤니티가 이미 에펨코리아·카페 등 오프라인 채널에 강함
- "급여 투명화"가 플랫폼의 반발 받을 가능성

## 가장 중요한 검증 가설
**온라인 강사의 30% 이상이 "자신의 시간당 급여를 모른다"고 응답하는가?**
- 검증 방법: 강사 커뮤니티 100명 설문
- 기대 결과: 60% 이상이 "정확히 모름" 응답

# Idea 003. MicroSupply — B2B 거래자 신용 관리 + 미수금 추적

## 한 줄 설명
소규모 제조업·컨설턴트를 위한 "거래처별 외상·미수금 자동 추적 + 익명 신용 점수" 플랫폼.

## 해결하는 Pain
- 거래처 A의 외상금이 얼마나 되는지 엑셀로 관리 (오류 위험)
- 회수 기한을 놓친 미수금이 계속 쌓임
- 같은 거래처와의 거래 때 "이 회사, 지난번에 60일 연체했는데 또 주문?" 같은 판단 불가능
- 소규모 업체는 외상 관리 소프트웨어 도입 비용 감당 어려움

## 제공하는 Positive Experience
- 모든 미수금이 한 대시보드에 보임 (통제감)
- 거래처 신용 점수를 보면서 거래 판단 (Amazon 리뷰 같은 신뢰감)
- "이 거래처는 항상 제때 결제한다" 같은 평판 구축

## Target User
- 소규모 하도급 제조업 (부품·금속·인쇄) — 한국 5만개+
- 1인 컨설턴트·용역사
- 소규모 무역업

## 왜 설치하는가
"외상 회수 효율 향상" + "거래처 신용 평가"

## 첫 30초
1. 지난 6개월 거래처 5개 입력
2. 미수금 자동 계산
3. "A사는 신용 4.2/5.0" 점수 표시

## 핵심 기능
- 거래처별 외상금, 회수 기한, 현재 연체일 자동 추적
- 연체 거래처에 자동 상기 메시지 (SMS/이메일)
- 거래처 신용 점수 (결제 정시율, 연체 이력) — 익명 공개
- "이 거래처와 거래한 사람들의 평가" (거래처별 리뷰)
- 미수금 회수 시 자동 알림 (거래처의 신용 점수 상승)

## 핵심 사용 루프
주문 → 결제 기한 설정 → 자동 추적 → 연체 시 알림 → 회수 → 신용 점수 업데이트

## 반복 사용 이유
- 매월 새로운 거래가 발생
- 미수금 현황을 매주 모니터링 (현금 흐름 관리)

## Personalization
- 업계별 평균 결제 기간 제시 (제조업은 60일이 평균)
- 개인 거래 패턴 분석 (당신은 60일 미만이 수익성 좋습니다)

## AI 역할
- 미수금 회수 불가 위험 예측 (이 거래처는 180일 이상 연체될 확률 30%)
- "이 거래처 신용이 하락 중입니다" 알림
- 최적 선금·외상 비율 추천

## Sharing
- 거래처 신용 점수는 "익명 공개" (산업 데이터베이스 형태)
- "나는 이 회사와 200회 거래, 97% 정시 결제" 배지

## Monetization
- 기본 무료 (거래처 5개까지, 기본 추적)
- 프리미엄 월 9,900원: 무제한 거래처, 고급 신용 분석, 자동 상기 메시지
- B2B SaaS (중소제조업용): 월 49,900원

## MVP
- 거래처별 외상금 추적 (수작업 입력)
- 기본 신용 점수 (결제 정시율만)
- 월별 리포트

## MVP 예상 비용
- 백엔드 (거래 추적): 300만원
- 웹 (React): 250만원
- 디자인: 100만원
- **총 650만원**

## 가장 큰 약점
- "신용 점수 공개"가 거래처에게 불쾌할 수 있음 (프라이버시)
- 초기 거래 데이터 없으면 신용 점수 의미 없음
- 기존 회계 소프트웨어(freee 등)도 부분 기능 제공

## 가장 중요한 검증 가설
**소규모 제조업의 50% 이상이 월 1회 이상 "미수금 회수 기한 혼동" 경험하는가?**
- 검증 방법: 제조업 협회 50개사 설문
- 기대 결과: 60% 이상이 "확인 필요" 응답

- MicroSupply (외상 추적 → 신용 점수)
- ListingLifespan (문의 누락 → AI 자동 답변 + 효율 개선)

모두 **실제 Pain 제거 + 반복 사용 동기 강화**로 이어진다.

## 2. 포트폴리오 다양성 확보

이번 10개 아이디어는 다음과 같이 분포:

**B2B 고빈도 운영 워크플로 (고비용·고수익성)**
- AllBook (방문서비스 제공자 매일 예약)
- ListingLifespan (공인중개사 매일 고객 문의)
- MicroSupply (제조업체 매월 거래 추적)

**B2B 전문직 커뮤니티 (중간 비용·중간 수익성)**
- SalaryTransparency (강사 급여 투명화)
- GigInsight (프리랜서 수익 분석)
- AsyncStandup (글로벌 팀 협업)

**B2B SaaS 관리 (높은 Pain, 높은 체계성)**
- ShopReverse (반품 + 라이브 판매)
- RetentionRx (SaaS 라이선스 추적)
- MedicalInventory (의료기기 청구)

**B2C 소비자 대상 (낮은 Pain, 높은 Viral 잠재)**
- LocalFinder (위치 기반 신상 발견)

## 3. AI 활용의 명확한 구분

**AI가 반드시 필요한 경우**
- AsyncStandup (텍스트 요약)
- ListingLifespan (자연어 질문 → 자동 답변)
- RetentionRx (복잡한 패턴 분석)

**AI가 선택사항인 경우**
- AllBook (충돌 감지는 규칙 기반도 가능)
- MicroSupply (신용 점수는 통계 기반)

**AI 없이도 가능한 경우**
- LocalFinder (사용자가 신상을 올리기만 하면 됨)

## 4. 검증 가설의 패턴

모든 아이디어가 공통으로 필요한 검증:

1. **실제 Pain 존재 확인**: "60~70% 이상이 이 문제를 겪는가?"
2. **사용 빈도 확인**: "주 1회 이상 반복되는가?"
3. **대체 솔루션 대비 우월성**: "기존 도구 대비 이 기능이 10% 이상 나은가?"

가장 확실한 검증 대상: **AllBook, ListingLifespan** (명확한 Pain, 고빈도)

## 5. MVP 비용의 일관성

모든 아이디어가 **300만~850만원** 범위의 MVP 구현 가능:

- 가장 저렴: SalaryTransparency (550만원 — 데이터 간단)
- 가장 비쌈: AllBook (850만원 — API 연동 복잡)

**평균 650만원** = 초기 자본 300만원 기준에서 **약 2배 (향후 자금조달 필요)**

하지만 주요 아이디어(AllBook, ListingLifespan, MicroSupply)는 **초기 6개월 내 수익화 가능**하므로 자금조달 환경이 따라주면 충분히 가능.

## 7. "사람들이 실제로 사용하고 싶은" vs "사업성"

- **Pain 해결력이 높은 것**: ListingLifespan, MicroSupply, RetentionRx (명확한 낭비/실수 제거)

**가장 균형잡힌 경우**: AllBook, ListingLifespan, AsyncStandup
(Pain 해결 + Positive Experience + 사용 빈도 모두 8점 이상)
