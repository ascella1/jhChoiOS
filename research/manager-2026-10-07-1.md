# Idea 001. 세금 기한 게임화 (Tax Challenge Arena)

## 한 줄 설명
세금 신고 기한을 "미니게임 챌린지"로 변환 — 절세 팁을 게임으로 배우고, 월별 절세액을 동료와 경쟁하는 리더보드 시스템

## 해결하는 Pain
- P009 (일본): 국세+지방세+사회보험료 납부 시기 불일치 → "기한을 자꾸 까먹음"
- P011 (일본): 소비세 신고 기한 경고 시스템 부족 → "기한이 지나면 연체료 5-15%"
- P002 (한국): VAT 신고 자동화 부족 → "매달 같은 신고를 수동으로"

## 제공하는 Positive Experience
- S002: 절세 아이템 자동 발굴 (매달 새로운 절세 "미니게임" 언락)
- S001: 커뮤니티 신뢰 (동료의 세금 팁 검증, 실제 절세액 공유)
- S010: 실시간 알림 ("내일 국세청 기한!" 게임 알림으로 변환)

## Target User
- 일본/한국 개인사업자, 프리랜서, 소상공인
- "세금은 의무"라고 생각하는 집단 → "세금은 게임"으로 재프레이밍

## 왜 설치하는가
"세금 신고 기한을 잊으면 연체료 5-15%인데, 이 게임 하면 기한을 절대 안 까먹고, 남들보다 더 많은 절세액도 찾을 수 있어"

## 첫 30초
- 앱 실행 → "이번 달 당신의 절세 순위: 15위 (절세액 25만원)"
- "이 절세 미니게임 풀어볼래?" → 국세청 규정 퀴즈, "올바른 답" → +절세액 보상
- 리더보드: "같은 직업 사람들 중 이번 달 절세액 1위: OOO (45만원)"

## 핵심 기능
1. **세금 기한 게임화**: 2개월/분기/년 세금 신고 기한 → 각각의 "게임 미션"
2. **절세 미니게임**: 국세청 규정 문제 풀기 → 맞으면 절세 항목 언락
3. **월별 절세액 리더보드**: "당신은 이번 달 25만원 절세했습니다" 공개 순위
4. **절세 팁 커뮤니티**: "내가 발견한 절세 꼼수" 팁 공유 → AI가 검증
5. **신고서 자동 생성**: 게임 진행하면서 쌓인 데이터로 신고서 자동 완성
6. **진도 시각화**: "올해 세금 신고 진도 70%" 체크바
7. **동료 초대**: "친구 초대하고 함께 절세 경쟁" 소셜 공유

## 핵심 사용 루프

```
Trigger → Action → Reward → Investment → Next Trigger

1. "국세청 기한 알림" → 게임 미니 퀘스트 시작
2. 퀴즈 풀이 (3-5분) → "+5만원 절세액 획득"
3. 리더보드에서 등수 상승 → "이번 달 절세 챠amp! 🎉"
4. 친구들에게 "내가 절세액 1등" 공유 → 친구도 설치
5. Next Trigger: 2주 후 "지방세 신고 기한" 알림 → 다시 게임
```

## 반복 사용 이유
- **월별**: 새로운 절세 항목이 매달 언락됨 (계절별 소비세, 지방세 기한)
- **사교성**: 동료와의 절세액 경쟁이 반복 동기 (리더보드 1위 유지)
- **게임 진행**: 년 중 "세금 챌린지" 완료도가 누적 (100% 달성 보상)

## Personalization
- **직업별**: 프리랜서 / 셀러 / 카페주 → 각 직업의 절세 항목 다름
- **지역별**: 한국 / 일본 / 싱가포르 → 각 국가 세법 별도
- **소득 규모별**: 월 300만원 프리랜서 vs 월 3000만원 셀러 → 절세액 규모 조정
- **과거 성과**: "지난달 당신은 30만원 절세했는데, 이번엔 50만원 목표?" AI 제안

## AI 역할
1. **절세 아이템 자동 감지**: 사용자의 수입 데이터 분석 → "당신은 이 항목에서 절세 가능"
2. **미니게임 자동 생성**: 국세청 규정 DB → 오늘의 퀴즈 자동 생성
3. **신고서 자동 작성**: 축적된 게임 데이터 → 세무신고 초안 자동 생성
4. **리더보드 동적 조정**: "당신의 절세액이 15만원인데, 당신 직업 평균은 25만원" 인사이트
5. **규정 업데이트**: 국세청 규정 변경 → 자동 감지해 새 미니게임 생성

## Sharing
- "내가 이번 달 절세 챠mp! 절세액 45만원🎉 당신도 이 게임 하면 절세 팁 배울 수 있어!"
- Kakao Talk, Line 공유 → 친구 초대 시 보너스 절세액 +5만원
- LinkedIn: "올해 누적 절세액 500만원" 전문성 인증

## Monetization
1. **프리미엄 게임**: "절세 심화 챌린지" 월 $5-10 (세무사 감수 절세 팁)
2. **기업 B2B**: "팀 세금 관리 리더보드" (50명+ 조직) 월 $100-500
3. **세무사 마켓플레이스**: "절세 팁 AI 검증 못 한 것" → 세무사 상담 연결 (수수료 20%)
4. **기한 알림 프리미엄**: "카톡 알림 대신 스마트워치 진동" 월 $2

## MVP
1. 기본 기한 알림 + 1개 세금 유형 미니게임 (소비세 or 소득세)
2. 간단한 리더보드 (같은 직업군만)
3. 신고서 자동 생성 기본형
4. 커뮤니티 팁 공유 1개만

## MVP 예상 비용
- 백엔드: 기한 알림 + 리더보드 DB (30만원)
- 프론트엔드: iOS/Android 기본 UI (50만원)
- 국세청 API 연동: 판례 데이터 수집 (20만원)
- AI: 미니게임 자동 생성 (10만원)
- **총 MVP: 110만원 (1-2명 개발, 6주)**

## 가장 큰 약점
1. **법률 리스크**: "이 절세 팁이 맞나?" 검증 오류 → 사용자가 과세처분 받을 수 있음
2. **규정 변경 추적**: 매년 세법 변경 → 미니게임 자동 업데이트 복잡
3. **국가별 차이**: 한국/일본/싱가포르 세법이 완전히 다름 → 초기 일본만 출시?
4. **낮은 지불 의욕**: "세금은 의무인데 게임으로 만들면 거부감" 일부 층

## 가장 중요한 검증 가설
1. **리더보드 경쟁이 세금 신고 기한 준수를 높이는가?** (기한 준수율 측정)
2. **미니게임을 풀면 실제로 절세 항목을 더 많이 발굴하는가?** (절세액 증가율)
3. **커뮤니티 팁이 AI 검증만으로 충분히 정확한가?** (세무사 검증 필요성)

# Idea 002. 클라이언트 신용도 커뮤니티 (Client Trust Network)

## 한 줄 설명
프리랜서들이 클라이언트의 결제 신뢰도를 익명으로 기록하면, 새 클라이언트를 받기 전에 커뮤니티의 "클라이언트 평판 점수"를 확인할 수 있는 역 평판 시스템

## 해결하는 Pain
- P017 (전세계): Upwork 불공정 분쟁 중재 → "클라이언트가 불공정 환불 요청할까봐 무섭다"
- P003 (한국): 계약금 에스크로 분쟁 → "계약금을 안 주는 클라이언트 판단 어렵다"
- P012 (일본): 계약서 분쟁 → "클라이언트가 계약을 변경할 위험"

## 제공하는 Positive Experience
- S016: Upwork 에스크로 추적 → "이 클라이언트 안전한가?" AI 판정
- S001: 커뮤니티 신뢰 → 프리랜서들이 클라이언트 경험담 공유
- S008: 숨겨진 이득 발굴 → "이 클라이언트는 재계약율 높다" 정보 활용

## Target User
- Upwork, Fiverr, 플레이스 등에서 일하는 글로벌 프리랜서
- "클라이언트 분쟁" 경험이 있는 프리랜서 (이들이 적극 리뷰 작성)

## 왜 설치하는가
"새 클라이언트를 받기 전에 '이 클라이언트는 신뢰도 70점'이라고 미리 알 수 있으면, 분쟁 위험을 줄일 수 있어"

## 첫 30초
- 앱 실행 → 검색창에 "client@email.com" 입력
- "이 클라이언트는 신뢰도 72점 (15건의 리뷰) - 결제 신뢰도 ⭐⭐⭐⭐ / 계약 변경 가능성 ⚠️ 낮음"
- "이 클라이언트에게 제안하시겠습니까? 위험 요소 확인하기"

## 핵심 기능
1. **클라이언트 검색**: 이메일/이름으로 클라이언트 신뢰도 조회
2. **익명 리뷰**: 프리랜서가 거래 후 "이 클라이언트 신뢰도" 평가 (1-5점)
3. **신뢰도 세부 항목**:
   - 결제 신뢰도 (기한 내 결제하는가)
   - 계약 신뢰도 (계약 변경 요청 빈도)
   - 커뮤니케이션 품질 (불공정한 요청 빈도)
   - 분쟁 이력 (환불 요청 빈도)
4. **위험 알림**: 같은 프리랜서 그룹에서 "이 클라이언트는 최근 3건 분쟁" 경고
5. **제안 전 체크**: "이 클라이언트에 제안하기 전에 신뢰도 확인" 팝업
6. **프리랜서 보호**: 분쟁 시 자동으로 커뮤니티 신뢰도 차감
7. **직업별 필터**: "웹 개발자끼리의 평가" vs "디자이너끼리의 평가" 분리

## 핵심 사용 루프

```
Trigger → Action → Reward → Investment → Next Trigger

1. "새로운 클라이언트 제안 수신" → 앱에서 신뢰도 검색
2. "신뢰도 72점, 결제는 신뢰할 수 있음" 확인
3. 제안 수락 + 거래 시작
4. 거래 완료 후 "이 클라이언트 평가" (1분) → AI가 신뢰도 업데이트
5. Next Trigger: 1주일 후 다른 클라이언트 제안 → 다시 검색
```

- **보호 의욕**: "내가 쓴 리뷰가 다른 프리랜서를 분쟁에서 보호한다"

- **국가별**: 미국 클라이언트 vs 중국 클라이언트 → 결제 신뢰도 패턴 다름
- **플랫폼별**: Upwork 클라이언트 vs Fiverr 클라이언트 신뢰도 자동 분리

4. **개인화 추천**: "당신 직업의 고수익 클라이언트는 신뢰도 높음" 인사이트
5. **분쟁 예측**: "이 클라이언트는 환율 변동기에 환불 요청율 50%" 예측

# Idea 003. 정산금 최적화 커뮤니티 (Payout Negotiation Network)

## 한 줄 설명
한국 Shopify 셀러들이 "이 결제게이트웨이는 3.2%에 협상 가능하다" 팁을 공유하면, AI가 개인별 결제게이트웨이 협상 시나리오를 자동 생성하는 커뮤니티

## 해결하는 Pain
- P001 (한국): Shopify 다중 PG 정산금 추적 및 수수료 분석 → "각 PG의 수수료가 3-4%인데 협상 가능한지 모름"
- P020 (전세계): 다중 결제 프로세서 정산 추적 → "수수료 구조가 복잡해서 최적화 불가능"

## 제공하는 Positive Experience
- S001: 커뮤니티 자동화 아이디어 공유 → "이 결제게이트웨이 협상 팁" 공유
- S004: Shopify 셀러의 정산금 자동화 신뢰 → "우리가 협상한 수수료 정보 신뢰"
- S002: 숨겨진 이득 발굴 → "이 협상으로 월 50만원 절감" 경험담

## Target User
- 월 정산액 500만원 이상 한국 Shopify 셀러
- 다중 PG를 병렬 운영하는 중소 오너

## 왜 설치하는가
"다른 셀러들이 협상한 수수료 정보를 보고, AI가 '당신도 이 PG 2.8%에 협상 가능' 알려주면, 월 50만원 이상 절감할 수 있어"

## 첫 30초
- 앱 실행 → "당신의 현재 수수료: Stripe 2.9%, PayPal 3.5%"
- "커뮤니티 팁: Stripe은 월 500만원 이상이면 2.5%에 협상 가능 (57건 확인)"
- "당신도 협상해볼래? AI 협상 안내 편지 생성하기"

## 핵심 기능
1. **현재 수수료 추적**: 각 PG의 실제 수수료 자동 계산
2. **협상 팁 커뮤니티**: "Stripe은 이 조건에서 2.5%에 협상 가능" 팁 공유
3. **협상 안내 AI**: "Stripe에 협상 요청할 때 이 내용을 강조해"
4. **협상 성공 사례**: "월 1000만원 이상 셀러는 평균 2.3% 협상 성공" 통계
5. **월별 수수료 절감액**: "지난달 협상으로 월 45만원 절감"
6. **PG 비교 대시보드**: "당신 매출 규모에서 가장 저렴한 PG는 X"
7. **자동 협상 문서**: AI가 "우리 월 매출 X, 경쟁사는 2.5%를 받는데…" 협상 편지 자동 생성

## 핵심 사용 루프

```
Trigger → Action → Reward → Investment → Next Trigger

1. 월별 정산액 확인 → "지난달 Stripe 수수료 150만원"
2. 커뮤니티에서 "Stripe 협상 팁" 조회
3. AI 협상 안내 편지 생성 → Stripe에 메일 발송
4. "협상 성공! 수수료 2.7%로 감소" 확인
5. 커뮤니티에 "성공 사례" 기록 → 다른 셀러도 참고
6. Next Trigger: 2개월 후 다음 협상 기회
```

- **국가별**: 한국 셀러 vs 일본 셀러 → 각 국가 PG 협상 관례 다름

## AI 역할
1. **수수료 자동 계산**: 각 PG API → 실제 수수료 + 환율손실 + 환전 지연 비용 통합 계산
2. **협상 팁 검증**: "이 팁이 정말 작동하는가?" AI 신뢰도 점수
3. **협상 편지 자동 생성**: "우리 월 정산 X, 경쟁사는 2.5%, 우리 평가점수 4.8/5.0 → 2.6%로 줄여달라"

5. **동료 벤치마킹**: "같은 규모 셀러의 평균 수수료는 X%, 당신은 Y%, 협상 여지 있음"

- 게임화: "현금 위기를 극복하는 게임"

## Target User
