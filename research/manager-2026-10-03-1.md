# Idea 001. MeetCredit — 회의 시간을 보상 크레딧으로

## 한 줄 설명
회의 기록을 자산화하는 직장인 마이크로 인센티브 플랫폼

## 기반 신호
- Pain: P001 (직장인 61% 번아웃, 월 40~60시간 회의)
- Positive: S005 (라이브 커머스 한정성 심리), S016 (Duolingo 스트릭)

## 혁신성
- 점수: 8/10
- 이유: 기존은 "회의 시간 최소화"(Slack, MS Teams) → 새로운은 "회의 기록을 개인 자산으로 전환"

## 해결하는 Pain
회의 과부하로 본업 집중 불가, 생산성 저하, 정신건강 악화

## 제공하는 Positive Experience
회의마다 "크레딧" 적립 → 월말 환급/카페음료 구매/팀 활동비 → 보상 심리

## Target User
대기업/중견기업 직장인, 특히 회의가 많은 화이트칼라 (20~50대)

## 왜 설치하는가
회의는 의무지만, 참석하면 개인 크레딧을 벌 수 있다는 새로운 가치 제시

## 첫 30초
앱 열기 → "이번 회의 참석" 버튼 → AI가 음성 기록 시작 → 회의 끝나면 "50 MeetCredit 획득"

## 핵심 기능
1. AI 회의 음성 자동 기록
2. 회의당 기본 크레딧 부여
3. 회의 중 적극 발언 시 보너스 크레딧 (음성 AI 감지)
4. 월간 크레딧 누적 → 선물카드/현금화

## 핵심 사용 루프
회의 약속 알림 → 앱에서 참석 등록 → AI 음성 기록 → 회의 후 크레딧 획득 → 월말 리포트 확인 → 다음 회의도 참석

## 반복 사용 이유
매 회의마다 크레딧 적립 → 스트릭 유지하려는 심리 → 월말 보상 기대

## Personalization
- 개인 회의 패턴 학습 (시간대, 유형별)
- 크레딧 가치 개인화 (선호 상품/서비스)

## AI 역할
- 음성 기록 및 발언 감지
- 회의 요약 자동 생성
- 발언량 기반 보너스 점수 계산

## Sharing
같은 팀원들 "우리 팀 이번달 크레딧 총액" 공유 → 팀 보상 경쟁

## Monetization
- B2B: 기업 라이선스 (월 직원당 2,000~5,000원)
- 수수료: 크레딧 현금화 시 10~15% 수수료
- 제휴: 카페/편의점과 제휴 상품권 판매

## MVP
- 모바일 앱 (iOS/Android)
- 음성 기록 및 발언 감지 (기존 음성 API 활용)
- 기본 크레딧 시스템
- Stripe 결제 연동

## MVP 예상 비용
200만원 (음성 API 구독, 앱 개발)

## 가장 큰 약점
기업 정보보안 규정 (음성 기록 거부), Slack/Teams와의 네이티브 통합 부족

## 가장 중요한 검증 가설
1. 직장인이 "회의 참석 보상"에 실제로 동기 부여되는가?
2. 월 크레딧 현금화 전환율 30% 이상 달성 가능한가?

# Idea 010. LiveTranslate — 라이브 방송용 AI 번역 호스트

## 한 줄 설명

## 기반 신호

## 제공하는 Positive Experience
한국어 호스트 + AI가 실시간 영어 번역 음성/자막 → 글로벌 시청자도 이해

# Idea 011. OnboardingGames — 신입사원 게임화 AI 버디

## 한 줄 설명
원격 신입사원이 AI 버디와 함께 게임을 하듯이 온보딩하는 앱

## 기반 신호
- Pain: P016 (원격 신규입사자 56% 외로움, 정보 누락)
- Positive: S002 (제타 AI 캐릭터), S016 (Duolingo 스트릭), S004 (마보 챌린지)

## 혁신성
- 점수: 8/10
- 이유: 기존은 "문서 중심 온보딩" → 새로운은 "AI 버디 + 일일 게임화 미션"

## 해결하는 Pain
신입사원이 필요한 정보를 찾기 어려움, 고립감, 높은 첫해 이직률

## 제공하는 Positive Experience
매일 "오늘의 온보딩 미션" 게임 → 클리어 시 회사 정보 습득 + 보상 배지

## Target User
원격 기업 신입사원, HR 담당자

## 왜 설치하는가
온보딩을 게임으로 즐기면서 회사 정보 자연스럽게 습득

## 첫 30초
AI 버디 소개 → "오늘의 미션: 회사 10가지 규칙 학습" → 5분 게임 시작

## 핵심 기능
1. AI 버디 (회사별 맞춤 성격)
2. 일일 온보딩 미션 (5~10분 게임)
3. 진행도 추적 (온보딩 완료율)
4. 배지/뱃지 시스템
5. 팀원 연결 (버디 시스템)
6. 챗봇 Q&A (궁금한 점 즉시)

## 핵심 사용 루프
매일 알림 → 오늘의 미션 시작 → 게임 클리어 → 배지 획득 → 다음 날 미션

## 반복 사용 이유
일일 미션 + 스트릭 유지 심리

## Personalization
신입사원의 역할/부서별 맞춤 미션

## AI 역할
회사 정보 기반으로 대화 생성, 질문에 즉시 답변, 미션 진행도 추적

## Sharing
팀원과 "나는 배지 5개 달성했어" 경쟁

## Monetization
- 기본: 무료 (기본 미션)
- Pro: 월 9,900원 (고급 AI 버디, 팀 분석)
- Enterprise: 월 50,000원 (회사 전체 신입사원 관리)

## MVP
- 모바일 앱 (React Native)
- AI 버디 (GPT 기반 대화)
- 간단한 게임 미션
- 배지 시스템

# Idea 012. BillRecorder — 자동 시간 추적 + 공정한 청구 검증

## 한 줄 설명
프리랜서 팀의 시간을 자동으로 추적하고 공정성을 검증하는 플랫폼

## 기반 신호
- Pain: P018 (시간 추적 오류로 청구 5~50% 손실)
- Positive: S015 (AI 활동 감지), S017 (협업)

## 혁신성
- 점수: 7/10
- 이유: 기존은 "수동 시간 입력" → 새로운은 "자동 감지 + 팀 검증"

## 해결하는 Pain
시간 추적 부정확, 청구 누락/오류, 팀 간 불공정한 청구 방식

## 제공하는 Positive Experience
일하는 동안 자동으로 시간 추적 → 월말 "정확한 청구서" 자동 생성

## Target User
프리랜서 팀, 에이전시, 컨설팅사

## 왜 설치하는가
시간 입력 번거로움 제거 + 청구 정확성 보증

## 첫 30초
프로젝트 선택 → 활동 자동 감지 시작 → 화면 보기로 시간 추적 확인

## 핵심 기능
1. 자동 활동 감지 (키보드/마우스 활동)
2. 프로젝트별 시간 자동 할당 (AI)
3. 팀 검증 (팀장이 청구 정확성 검증)
4. 청구서 자동 생성
5. 시간 분쟁 해결 (커뮤니티 중재)

## 핵심 사용 루프
일하기 → 활동 자동 감지 → 프로젝트 매칭 → 월말 청구서 생성 → 팀 검증 → 클라이언트 청구

## 반복 사용 이유
매일 시간 추적

## Personalization
개인별 활동 패턴 학습 (특정 활동 = 특정 프로젝트)

## AI 역할
활동 내용 분석 → 프로젝트별 시간 자동 분배 (정확도 95% 이상 목표)

## Sharing
팀원과 "이번 달 우리 청구 5% 증가" 결과 공유

## Monetization
- 기본: 무료 (개인 시간 추적)
- 팀: 월 19,900원 (팀 검증, 청구서 생성)
- Enterprise: 월 99,900원 (고급 AI, 분쟁 중재)

## MVP
- 데스크톱 앱 (Electron)
- 활동 감지 (키보드/마우스)
- 프로젝트 매칭 (간단한 규칙)
- 청구서 생성

## MVP 예상 비용
240만원

## 가장 큰 약점
