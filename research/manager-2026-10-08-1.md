# Idea 001. 셀러 신뢰도 배지 시스템 (Shield)

## 한 줄 설명

쿠팡/스마트스토어 셀러의 악성리뷰 공격을 실시간 탐지하고, "검증된 셀러" 배지로 고객 신뢰도를 복원하는 플랫폼.

## 해결하는 Pain

- P001: 경쟁사의 조직적 악성리뷰로 인한 평점 급락 (월 50만~300만원 매출 손실)
- P002: 1~2개 저평점이 전체 평균 평점을 즉각 떨어뜨려 검색 노출과 전환율 하락

## 제공하는 Positive Experience

- 크림의 진위 검증 신뢰 시스템처럼, 셀러도 "신뢰할 수 있는 판매자"라는 명시적 배지 획득
- 건강한 리뷰만으로 구성된 "검증된 평점" 대시보드 제공
- 리뷰 신고 → 자동 처리 → 배지 상태 변화를 시각화해 셀러에게 통제감 제공

## Target User

- 쿠팡/스마트스토어에서 월 매출 500만~2,000만원대 판매자
- 경쟁이 심한 카테고리(가전, 의류, 뷰티) 셀러

## 왜 설치하는가

- 악성리뷰로 인한 매출 손실이 계속되고 있는데, 플랫폼의 신고 → 처리 시간이 느림
- 자신의 신뢰도를 정량화해서 고객에게 보여주고 싶음

## 첫 30초

1. 앱 열기 → 자신의 현재 "검증된 셀러 배지 진행도" 확인 (0-100)
2. 최근 악성리뷰 자동 탐지된 건 3개, 자동 신고 대기 중
3. "지난 7일 건강한 리뷰율 94%" 시각화
→ 30초 안에: 내 신뢰도가 객관적으로 어디 있는지 알 수 있음

## 핵심 기능

1. **악성리뷰 자동 탐지**: 자연언어 처리 + 구매이력 검증으로 위험한 리뷰 자동 플래그
2. **검증된 평점 대시보드**: 악성 리뷰를 제외한 "실제 고객 만족도" 별도 표시
3. **배지 진행도**: 신뢰도가 올라가면 "실버 → 골드 → 플래티넘" 배지 획득
4. **자동 신고**: 탐지된 악성리뷰를 플랫폼에 자동 신고 (수동 신고 시간 절감)
5. **배지 표시**: 상품 페이지에 "검증된 셀러" 배지 노출 (고객 신뢰도 향상)

## 핵심 사용 루프

악성리뷰 발생 (Trigger)
↓
앱이 자동 탐지 (Action)
↓
신고 대기 상태로 표시 (Reward: 통제감)
↓
셀러가 추가 정보 제공 (Investment)
↓
배지 진행도 상승 → 다음 리뷰 공격 대비 (Next Trigger)

## 반복 사용 이유

- 경쟁 시즌(명절, 세일 시즌)에 악성리뷰 공격이 집중되면 매일 확인
- 배지가 상위 등급으로 올라가는 것을 보면서 성취감 느낌
- 매일 새로운 고객 리뷰가 들어오고, 이 중 악성 리뷰는 실시간 탐지됨

## Personalization

- 셀러별 카테고리 특화: 의류 셀러는 "색상 이상", "사이즈 틀림" 같은 카테고리별 악성 패턴 학습
- 경쟁사 공격 패턴 감지: "같은 발신자, 같은 시간대에서 계속 저평점" 같은 조직 공격 추적
- 맞춤형 방어 조언: "이 시즌에는 무료 배송 옵션 추가하면 악성리뷰 감소" 같은 인사이트

## AI 역할

- **자연언어 분석**: "배송 늦음", "상품 불량"이 정당한 불만인지, "아무 이유 없이 별점만 깎는" 악의인지 구분
- **이상 패턴 감지**: "같은 IP 대역, 시간 간격 60분, 모두 1~2별점" 같은 조직 공격 자동 포착
- **예측 기반 조언**: 과거 데이터로 "다음주 명절 세일 시즌에 악성리뷰 300% 증가 예상, 사전 준비" 제시

## Sharing

- 배지 획득 시 SNS 공유: "Noom처럼 성취감을 SNS에 공유 가능" → "우리 매장, 검증된 셀러 배지 획득!"
- 고객도 공유: "이 셀러는 검증된 배지가 있으니 안심하고 구매" 링크 공유

## Monetization

- **기본 무료**: 악성리뷰 탐지 + 기본 배지 진행도 추적
- **프리미엄 구독**: 월 29,900원
  - 우선 신고 처리 (48시간 이내)
  - 고급 패턴 분석 (경쟁사 공격 추적)
  - 맞춤형 방어 조언 API
  - 여러 플랫폼 통합 관리 (쿠팡, 스마트스토어, 11번가)

## MVP

- **Core**: 쿠팡 API 연동 → 리뷰 데이터 수집 → 간단한 NLP 규칙 기반 악성리뷰 탐지
- **기간**: 8주
- **Stack**: React 웹앱 + Node.js 백엔드 + Python NLP
- **필수 API**: 쿠팡 API, 네이버 스마트스토어 API (OpenAPI 제공)

## MVP 예상 비용

- 개발: 500만원 (프론트+백엔드+NLP 기초)
- 인프라: 월 50만원 (API 호출, DB)
- 총: 초기 500만원 + 월 50만원

**>> 300만원 이내 MVP 가능**: 간단한 규칙 기반 악성리뷰 탐지 + Figma 웹앱 (초기는 수동 신고 지원 생략)

## 가장 큰 약점

1. **플랫폼 정책 의존성**: 쿠팡/스마트스토어가 "검증된 배지"를 공식 노출해주지 않으면 고객에게 신뢰도 이점이 덜함
2. **기존 경쟁 서비스**: Helium10(아마존), 셀러인사이트 등이 이미 악성리뷰 탐지 기능 제공 중
3. **AI 정확도**: 정당한 불만을 악성으로 오분류하면 셀러 신뢰 손상 가능

## 가장 중요한 검증 가설

- **가설**: 악성리뷰 자동 탐지의 정확도가 90% 이상이어야 셀러가 신뢰하고 사용함
- **검증**: 초기 100명 셀러 대상 테스트 → 실제 탐지율 측정 → 셀러 만족도 조사

# Idea 002. 카페 수익 대시보드 (CafePulse)

## 한 줄 설명

카페 POS + 배달앱 데이터를 자동 연동해, 매일 원가율·기초원가·손익분기점을 시각화하는 웹앱.

## 해결하는 Pain

- P005: 카페 점주가 매달 손익분기점을 모르고 경영해 3~6개월 후 "이건 안 된다" 판단
- 매주 재고를 일일이 세고, 엑셀에 입력하고, 계산하는 시간 낭비 (월 5~10시간)
- 배달앱 수수료(15~20%)가 실제 수익에 얼마나 영향 미치는지 불명확

## 제공하는 Positive Experience

- 라이프업의 "연속 기록 → 누적 → 수치화" 메커니즘처럼, 매일 POS 판매량이 자동으로 수집되고
- 배달앱 주문과 온라인 주문이 시각화되며
- "오늘 기초원가율 32%, 이상적인 30%보다 높음" 같은 실시간 인사이트 제공
- 주간/월간 추세 그래프로 "지난주보다 5% 개선" 같은 성취감 제공

## Target User

- 카페 창업자, 기존 카페 점주 (특히 35평 이하 소형)
- 월 매출 1,500만~3,000만원대

## 왜 설치하는가

- "매출은 나오는데 수익이 없다"는 불안감을 해소하고 싶음
- 배달앱 수수료가 매출의 얼마나 되는지 정확히 알고 싶음
- 언제쯤 손익분기점에 도달할 수 있는지 예측하고 싶음

## 첫 30초

1. POS 기계와 배달앱 계정 연동 (최초 1회 설정)
2. 대시보드 열기 → "어제 기초원가율 33%" + 차트
3. "이상적 기초원가 30%보다 높음 / 재고 효율을 개선하세요" 제안
→ 30초 안에: 내 카페의 현재 수익성이 좋은지 나쁜지 한눈에 파악

## 핵심 기능

1. **POS 자동 연동**: Square, Posco, Payple 등 주요 POS와 API 연동
2. **배달앱 자동 수집**: 배민, 쿠팡이츠 주문 데이터 자동 수집
3. **실시간 원가 계산**: 상품별 판매가 × 수량 + 재료비 = 원가율 자동 계산
4. **기초원가 추적**: 원가율 + 인건비 = 기초원가, 이상적 30%와 비교
5. **손익분기점 예측**: "월 매출이 2,000만원 이상이면 손익분기점" 자동 계산
6. **주간 리포트**: "이번 주 기초원가 32%, 지난 주보다 +2%"

## 핵심 사용 루프

매일 가게 오픈
↓
POS에서 판매 기록 (자동 수집, Action)
↓
저녁 8시 대시보드 자동 업데이트 (Reward: 실시간 수치화)
↓
"오늘 기초원가 높음 → 내일 재고 조정" 액션 (Investment)
↓
다음날 기초원가 개선 → 성취감 (Next Trigger)

## 반복 사용 이유

- **매일**: POS 데이터가 자동으로 들어오므로, 매일 아침 "어제 수익성" 확인하는 습관 형성
- **주간**: 주간 비교를 통해 "지난주보다 개선됐나?" 확인
- **월간**: 월말에 "목표 기초원가 달성했나?" 확인

## Personalization

- **카페별 상품 구성**: 에스프레소 전문, 음료 중심, 디저트 풍부 등 카페별로 다른 "이상적 원가율" 제시
- **계절별 예측**: "한여름은 아이스 음료 비중 높아져 원가율 올라감, 대비하세요" 같은 계절 조언
- **배달앱별 분석**: "배민이 쿠팡이츠보다 수수료는 높지만 고객단가 1.2배 높음" 같은 채널별 분석

## AI 역할

- **수익 최적화 제안**: "재료 A의 주 구매가가 5% 올랐음. 가격 인상이 필요할 것 같습니다"
- **손익분기점 예측**: 과거 3개월 추세로 "현재 속도면 6개월 후 손익분기점 도달, 개선 필요"
- **상품별 수익성**: "아메리카노는 높은 회전율 + 낮은 원가율 = 최고 수익 상품" 같은 분석

## Sharing

- 주간 리포트 SNS 공유: "우리 카페, 이번 주 기초원가 목표 달성!" (성취감)
- 다른 카페 점주와의 벤치마킹 커뮤니티 (익명)

## Monetization

- **기본 무료**: POS 연동 + 기초 대시보드
- **프리미엄**: 월 29,900원
  - 상품별 수익성 상세 분석
  - AI 기반 재료 구매 최적화
  - 인건비 최적화 제안
  - 1:1 카페 경영 상담

## MVP

- **Core**: 한 가지 POS (Payple 등)와 한 배달앱(배민)만 먼저 연동
- **기간**: 6주
- **Stack**: React 웹앱 + Node.js + Python 계산 엔진

## MVP 예상 비용

- 개발: 300만원 (POS API + 배민 API)
- 초기 호스팅: 월 30만원

**>> 300만원 이내 MVP 달성 가능**

## 가장 큰 약점

1. **POS 다양성**: 카페마다 다른 POS 기계를 쓰므로 모든 POS 지원은 비용 높음
2. **수동 재료비 입력**: 자동 계산을 위해서는 초기에 모든 상품의 원가를 입력해야 함
3. **기존 경쟁 서비스**: 비더마스터(배민)가 이미 기초원가 계산 블로그 가이드 제공 중

## 가장 중요한 검증 가설

- **가설**: 카페 점주가 일일이 재료비 입력을 싫어하면 자동화 없이는 사용 불가능
- **검증**: 초기 10개 카페 대상 수동 입력으로 테스트 → 얼마나 자동화가 필요한지 확인

# Idea 003. 프리랜서 진행도 추적 & 신뢰 평가 (FreelanceShield)

## 한 줄 설명

프리랜서와 발주처가 계약 → 진행 → 완료를 단계별로 추적하고, 상호 평가로 신뢰도 배지를 획득하는 플랫폼.

## 해결하는 Pain

- P003: 프리랜서 계약서 표준화 부재, 작업 범위·수정 횟수·지급 조건 모호
- P006: PT 수수료처럼, 프리랜서도 "발주처가 잔금을 안 주는" 미수금 문제

## 제공하는 Positive Experience

- 라이프업의 "진행도 추적 + 레벨 상승" 같은 경험과 크림의 "신뢰 검증" 메커니즘 결합
- 프로젝트 진행도를 시각적으로 추적하고 (0% → 25% → 50% → 100%)
- 완료 후 발주처와 프리랜서가 상호 평가해 "신뢰도 배지" 획득
- 발주처는 "확실한 프리랜서 찾기" 쉬워짐

## Target User

- 개인 프리랜서 (SW 개발, 디자인, 영상, 번역)
- 프리랜서를 고용하는 소규모 회사

## 왜 설치하는가

- 계약서를 제대로 만드는 것이 번거운데, 자동으로 생성해주는 도구가 있으면 쓰고 싶음
- 진행 과정에서 범위 변경이 생겼을 때, 그것을 기록해두고 싶음
- 완료 후 "이 발주처는 신뢰할 수 있나?" 를 다른 프리랜서들이 평가를 보고 판단하고 싶음

## 첫 30초

1. "새 프로젝트 시작" 버튼 클릭
2. 자동 템플릿: "프로젝트 제목, 예산, 예상 기간, 수정 횟수" 입력
3. 발주처와 공유 → 발주처가 수락하면 "진행도 0%" 시작
→ 30초 안에: 표준 계약서 작성 완료 + 진행도 추적 시작

## 핵심 기능

- TVING처럼 "매일 신규 콘텐츠 배포" → 팔로워들이 매일 새로운 콘텐츠를 기대
- Lemon8처럼 시각적으로 아름다운 콘텐츠 자동 생성
- "어제 매출 800만원, 메뉴별 TOP 3는 아메리카노, 카라멜 마끼아또, 크루아상" 같은 데이터 시각화

## Target User

- 카페 점주, 음식점 주인 (개인사업자)
- Instagram, TikTok을 운영하고 싶지만 시간이 없는 사람들

## 왜 설치하는가

- POS에 판매 데이터가 있는데, 이를 SNS에 올려 홍보하고 싶음
- 매일 사진을 찍고 글을 쓸 시간이 없음
- 예쁜 콘텐츠는 어떻게 만드는지 모름

## 첫 30초

1. POS 계정과 Instagram 계정 연동
2. "오늘 어제 매출 데이터로 콘텐츠 생성하시겠습니까?" 버튼 클릭
3. 자동 생성된 콘텐츠 보기: "어제 메뉴 TOP 3 순위, 일일 매출, 베스트타임" 을 이쁜 이미지로 표시
→ 30초 안에: 매일 올릴 SNS 콘텐츠 자동 생성됨

## 핵심 기능

1. **POS 데이터 수집**: 어제의 판매 데이터 자동 수집 (매출, 메뉴별 판매량)
2. **콘텐츠 자동 생성**: "메뉴 TOP 3 랭킹", "어제 베스트 타임", "일일 매출" 등을 예쁜 이미지로 변환
3. **자동 배포**: 매일 아침 7시 자동으로 Instagram에 포스트 + TikTok 쇼츠에 영상 배포
4. **해시태그 자동 생성**: "카페", "아메리카노", "상권명" 등 자동 해시태그 생성
5. **팔로워 성장 추적**: "이번주 팔로워 100명 증가" 같은 분석

## 핵심 사용 루프

매일 가게 오픈
↓
POS에서 판매 데이터 자동 수집 (Action)
↓
매일 아침 SNS에 콘텐츠 자동 배포 (Reward: 노력 감소)
↓
팔로워들의 좋아요와 댓글 (Investment)
↓
팔로워 증가 → 신규 고객 유입 (Next Trigger)

## 반복 사용 이유

- **매일**: 매일 새로운 판매 데이터가 생기고, 자동으로 콘텐츠 생성됨
- **주간**: 주간 "최고 판매 메뉴" 콘텐츠 자동 생성
- **월간**: 월간 "베스트 메뉴" 영상 자동 생성

- **해시태그 생성**: "현재 트렌드 + 당신의 카페 특성"에 맞는 해시태그 자동 생성

## Sharing

## Monetization

- **프리미엄**: 월 19,900원
  - 매일 콘텐츠 배포
  - Instagram + TikTok + 블로그 동시 배포
  - 고급 분석 (팔로워 성장 속도, 엔게이지먼트)

4. **오버셀링 경고**: "재고 5개인데, 지난 1시간에 6개 주문 → 1개 부족"
5. **채널별 수익 분석**: "무신사는 고객단가 높으나 수수료도 높음, 자사몰은 순이익 최고"

상품 판매 (Trigger: 여러 채널에서)

## Monetization

# Idea 012. 가챠형 프리랜서 매칭 (SkillLottery)

## 한 줄 설명

프리랜서가 매일 "스킬 가챠"를 뽑으면, 그 스킬에 맞는 프로젝트가 표준 계약서로 자동 매칭되는 플랫폼.

## CEO Directive 반영

**메커니즘: 확률/추첨 득템 (가챠·SNKRS형)**

## 해결하는 Pain

- P003: 프리랜서 계약서 표준화 부재
- 프리랜서와 발주처가 매칭되는 과정이 복잡

## 제공하는 Positive Experience

- 게임의 가챠 메커니즘 (뽑기, 운의 느낌, 도파민 자극)
- SNKRS의 추첨 경험 (매일 기대감, 당첨 시 성취감)
- 확률이 낮은 "좋은 프로젝트"를 얻었을 때의 짜릿함

## Target User

- 개인 프리랜서 (SW, 디자인, 마케팅)
- 일감을 구하는 사람들

## 왜 설치하는가

- 프리랜서들은 매일 "어떤 프로젝트가 들어올까?" 기대함
- 게임처럼 "뽑기"를 통해 재미있게 일감을 찾고 싶음
- 계약서 작성 같은 번거로운 과정 없이 "뽑혔으면 바로 시작" 하고 싶음

## 첫 30초

1. 프리랜서 가입 → "나의 스킬 설정" (디자인, 웹개발 등)
2. "매일 가챠 뽑기" 버튼 클릭
3. "당첨! '웹 디자인 프로젝트 300만원, 납기 2주'" → 자동 계약서 생성됨
→ 30초 안에: 새로운 프로젝트 "뽑기" 경험 + 계약서 자동 작성

## 핵심 기능

1. **일일 가챠**: 프리랜서가 매일 1회 "스킬 가챠" 뽑기 가능
2. **확률 설정**: 나머지 것 같은 프로젝트 70%, 좋은 프로젝트 25%, 최고 프로젝트 5%
3. **자동 계약서**: 당첨되면 표준 계약서 자동 생성 (수정 가능)
4. **표준 예산**: "디자인 로고"는 항상 100~150만원 같은 표준 예산 제시
5. **즉시 수락**: 당첨 후 2시간 내 수락하면 프로젝트 진행 (거절 시 다른 프리랜서에게)

## 핵심 사용 루프

매일 아침 (Trigger)
↓
가챠 뽑기 (Action)
↓
당첨 → 흥분, 기대감 (Reward)
↓
계약서 2시간 내 수락 결정 (Investment)
↓
프로젝트 진행 → 다음날 또 가챠 뽑기 (Next Trigger)

## 반복 사용 이유

- **매일**: 매일 가챠를 뽑는 재미
- **주간**: "이번주는 좋은 프로젝트 당첨될까?" 기대
- **스트릭**: "일주일 내내 가챠 안 뽑으면 불안감"

## Personalization

- **프리랜서 등급별 확률**: 상위 등급 프리랜서는 좋은 프로젝트 확률 높음
- **스킬별 수요**: "디자인은 높은 수요, 번역은 낮은 수요" 반영

## AI 역할

- **공정한 매칭**: 프리랜서의 스킬과 프로젝트의 난이도를 매칭
- **가챠 확률 조정**: "너무 많은 프리랜서가 떨어지는 프로젝트는 확률 상향"

## Sharing

- "좋은 프로젝트 당첨!" SNS 공유 (SNKRS처럼)

## Monetization

- **거래 수수료**: 프로젝트 당 10% (프리랜서와 발주처)
- **프리미엄 구독**: 월 19,900원
  - 일일 2회 가챠 (기본 1회)
  - 특정 프로젝트 "예약권" (확률 높임)
  - 프로젝트 선택권 (뽑은 것 거절 가능)

## MVP

- **Core**: 가챠 뽑기 + 자동 계약서 + 기본 매칭 알고리즘
- **기간**: 6주

## MVP 예상 비용

- 개발: 350만원
- 호스팅: 월 25만원

## 가장 큰 약점

1. **가챠 중독성 윤리 문제**: 도박성 게임처럼 중독을 유발할 수 있음 (규제 위험)
2. **확률 투명성**: 가챠 확률이 조작되지 않았는지 확인 필요 (한국 게임 법규 참고)
3. **프리랜서 거절율**: "당첨됐으나 프로젝트가 별로라" 거절하면 신뢰도 하락

- **검증**: 프리랜서 10명 대상 프로토타입 테스트 → 가챠에 대한 반응 → 실제 프로젝트 수락률

# 가장 중요한 관찰

## 핵심 패턴

### 1. Pain의 공통점: "자동화 부재"

**20개 Negative Signal의 70%가 "이걸 손으로 하는 게 너무 번거움"**
- 카페: 원가 계산, 재고 정산
- 부동산: 매물 데이터 입력, 시세 조사
- 프리랜서: 계약서 작성, 수수료 계산
- 글로벌 셀러: 세금 계산, 규제 확인

**→ Manager 시사점**: 자동화 니즈가 매우 높지만, 기존 솔루션이 이미 많다. 차별화는 **"특화 + 사용 편의"**에서.

### 2. Positive의 공통점: "매일의 반복 사용"

**Positive Signal 15개 모두 "매일 또는 주 3회 이상 사용"**
- 라이프업: 매일 체크인
- 음악 스트리밍: 매일 새 곡
- AI 구독: 매일 사용
- 커뮤니티: 매일 접속

**→ Manager 시사점**: 높은 사용 빈도 = 높은 Retention. 1회성 서비스는 떨어진 점수.

### 3. 신뢰 메커니즘의 중요성

**Pain Signal 40%가 "신뢰 부족" 관련**
- 플랫폼 판매자 악성리뷰
