## P001. 처방약 약국 개별 가격 비교 및 최저가 확인

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 만성질환자, 정기 처방약 사용자
- 핵심 문제: 동일한 처방약(예: 혈압약, 당뇨병 약)을 받으려면 근처 약국 여러 곳에 직접 전화해서 가격을 문의해야 함. 약국마다 가격이 다르고(5천~2만원 차이), 인터넷에는 공시가격 정보가 없음. 만성질환자는 월 2~4회 약국을 방문하므로, 매번 최저가 약국을 찾기 위해 시간 낭비
- 사람들이 실제로 싫어하는 것: "약국에 전화하려면 시간이 걸린다", "같은 약인데 약국마다 가격이 다르다", "가장 싼 약국을 찾기까지 3~5곳을 전화해야 한다", "매번 다른 약국 가격을 비교해야 하는 게 귀찮다"
- 현재 해결 방법: 근처 약국 여러 곳에 직접 전화, 단골 약국 고정 이용, 배송 약국(온라인) 검색
- 발생 빈도: 월 2~4회 (정기 처방 시)
- 시간 비용: 약국 비교에 월 1~2시간 (통화, 이동)
- 금전 비용: 최저가 미탐색으로 인한 월 2만~5만원 손실
- 문제 심각도 (0~10): 5
- 현재 지출: 월 3만~10만원 (약제비)
- 소프트웨어 해결 가능성: 높음 (약국 가격 자동 수집 및 비교)
- AI 해결 가능성: 높음 (처방약 자동 인식 및 최저가 추천)
- 1인 개발 가능성: 중간 (약국 API 또는 웹 스크래핑)

### 실제 근거
- 당뇨병 환우회 커뮤니티: "매달 약값이 다르네요, 약국마다 왜 가격이 다르죠?" — 가격 편차 불만
- 건강보험심사평가원 공시: 약국별 가격 공시가 없음 (병원과 달리)
- 네이버 블로그: "약국 가격 비교하는 방법" — 직접 전화 외에는 방법 없다는 글
- 보건복지부 자료: 약사의 약가 자율설정 정책으로 인한 가격 편차 인정

### 신호 스크리닝
① 정부 무료 제공: No — 약국 가격 비교 공시 서비스 없음
② 업계 무료 콘텐츠: No — 약국 협회도 가격 비교 제공 안 함
③ 기존 SaaS 포함: No — 약국 가격 비교 앱 거의 없음
④ 반복 빈도: 월 2~4회 (정기 처방)

**판정**: 채택 — 명확한 pain signal이며, 고빈도 반복

### 왜 중요한 문제인가
만성질환자가 매달 1~2시간을 약국 가격 비교에 소비. 자동 가격 비교 플랫폼이 있으면 월 1~2시간 절감 + 월 2~5만원 절감.

### 가정
- 약국의 실시간 약가 공개 가능성 확인 필요
- 처방약 표준화 및 제네릭 포함 여부 확인 필요

- https://www.hira.or.kr/ (건강보험심사평가원)

- 만성질환자 대상 설문: 월평 약값 비교 시간

## P002. 프랜차이즈 가맹점주 월별 ROI 추적 및 본부 정산

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 프랜차이즈 가맹점주
- 핵심 문제: 프랜차이즈 계약 후 월별 매출, 원가, 로열티, 관리비 등을 정확히 추적하기 어려움. 본사에서 로열티 계산이 올바른지 확인하려면 매월 매출표와 본사 정산표를 수동으로 대조해야 함. 가맹점주들이 월 평균 5~10시간을 정산 확인에 소비. 특히 다점포 운영 시 각 점포의 ROI를 비교하기 어려움
- 사람들이 실제로 싫어하는 것: "매월 본사 정산이 맞는지 확인하려면 엑셀로 계산해야 한다", "3개 점포를 운영하는데 각 점포의 수익을 비교할 수 없다", "로열티 계산에 실수가 있어도 발견하기 어렵다", "매달 정산 대기 시간이 길다"
- 현재 해결 방법: 엑셀로 수동 정산 관리, 본사에 직접 문의, 회계사 컨설팅
- 발생 빈도: 매달 (정산 시)
- 시간 비용: 월 5~10시간 (정산 확인 및 분석)
- 금전 비용: 정산 오류로 인한 월 5만~20만원 손실 가능
- 문제 심각도 (0~10): 6
- 현재 지출: 월 200만~500만원 (가맹점 운영)
- 소프트웨어 해결 가능성: 높음 (자동 정산 확인 및 ROI 분석)
- AI 해결 가능성: 높음 (정산 오류 자동 감지)
- 1인 개발 가능성: 중간 (POS 및 본사 시스템 연동)

### 실제 근거
- 프랜차이즈 가맹점주 커뮤니티: "정산이 맞는지 확인하는 방법?" — 월별 정산 확인 불만
- 한국프랜차이즈산업협회: 가맹점주 불만 사항 중 "정산 투명성" 연도별 상위 3위 유지
- 연구보고서: 평균 가맹점주 월 5~10시간을 정산 관리에 소비

### 신호 스크리닝
① 정부 무료 제공: No — 정산 자동화 서비스 없음
② 업계 무료 콘텐츠: No — 각 본사별로 다른 정산 시스템
③ 기존 SaaS 포함: No — 프랜차이즈 정산 특화 솔루션 거의 없음
④ 반복 빈도: 매달 (정산 시)

**판정**: 채택 — 고빈도, 금전 손실 명확

### 왜 중요한 문제인가
다점포 가맹점주가 월 10시간을 정산에 소비. 자동화된 정산 추적이 있으면 월 8시간 절감 + 오류 감소.

### 가정
- POS 시스템의 API 연동 가능성 확인 필요
- 본사별 정산 방식 표준화 여부 확인 필요

### 출처
- 한국프랜차이즈산업협회 연간 보고서

### 다음 조사 방향
- 주요 프랜차이즈 본사의 정산 시스템 및 자동화 수준
- 가맹점주 대상 설문: 월평 정산 확인 시간

## P003. 택배 다중사(CJ, GS, 한진) 분산 배송 통합 추적

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 온라인 판매자, 소규모 쇼핑몰 운영자
- 핵심 문제: 소규모 쇼핑몰이 여러 택배사(CJ대한통운, GS칼텍스, 한진로지스틱스)를 사용하여 배송하면, 각 택배사의 추적 시스템이 다름. 고객이 배송 상태를 문의할 때 어느 택배사로 보냈는지 먼저 확인해야 하고, 각 택배사 앱을 따로 봐야 함. 배송 연체, 분실, 손상 등의 이슈를 통합으로 관리할 수 없음
- 사람들이 실제로 싫어하는 것: "어느 택배로 보냈는지 기억해야 한다", "각 택배사 앱을 따로 봐야 한다", "배송 연체를 한눈에 파악할 수 없다", "여러 택배사의 분실 처리를 각각 해야 한다"
- 현재 해결 방법: 엑셀로 배송 정보 기록, 각 택배사 앱 설치, 스마트로 같은 통합 배송 관리 솔루션 이용
- 발생 빈도: 매일 (배송 발생)
- 시간 비용: 월 3~5시간 (배송 추적 및 고객 응대)
- 금전 비용: 없음 (배송사 추적은 무료)
- 문제 심각도 (0~10): 4
- 현재 지출: 월 0~3만원 (배송 관리 솔루션)
- 소프트웨어 해결 가능성: 높음 (다중사 API 통합)
- AI 해결 가능성: 높음 (배송 상태 자동 요약)
- 1인 개발 가능성: 중간 (택배사 API 연동)

### 실제 근거
- 쇼핑몰 운영자 커뮤니티: "여러 택배를 쓸 때 관리 방법?" — 통합 추적 요청
- 스마트로 고객 후기: "통합 배송 추적이 도움된다" — 이미 일부 솔루션 존재

### 신호 스크리닝
① 정부 무료 제공: No — 정부 통합 배송 추적 서비스 없음
② 업계 무료 콘텐츠: No — 각 택배사가 자신의 추적만 제공
③ 기존 SaaS 포함: Partial — 스마트로 등이 있지만, 모든 택배사를 완전히 통합하지는 않음
④ 반복 빈도: 매일 (배송 발생)

**판정**: 채택 — 고빈도이며, 기존 솔루션에 개선 여지 있음

### 왜 중요한 문제인가
쇼핑몰 운영자가 월 3~5시간을 배송 추적에 소비. 완전 통합 솔루션이 있으면 월 3시간 절감.

### 가정
- 모든 택배사 API 접근성 확인 필요

### 출처
- 쇼핑몰 운영 커뮤니티

### 다음 조사 방향

## P004. 전월세 전환 시 감정평가액 협상 및 시세 비교

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 전월세 전환 임차인, 주택소유자
- 핵심 문제: 전세를 월세로 전환하거나 월세를 전세로 전환할 때, 감정평가액(또는 시세)이 매번 다르게 책정됨. 부동산 중개소마다 평가가 다르고, 세입자와 임대인 사이에서 합의가 어려움. 공식적인 시세 기준이 없어서 협상할 때 근거 자료를 찾기 어려움
- 사람들이 실제로 싫어하는 것: "중개소마다 평가가 다르다", "어느 평가를 믿어야 할지 모르겠다", "협상할 때 근거 자료가 없다", "감정평가비용(50만~100만원)을 누가 내느냐로 분쟁 발생"
- 현재 해결 방법: 여러 중개소에서 개별 평가 받기, 아파트 실거래가 정보 사이트 검색, 공인중개사 협회에 문의
- 발생 빈도: 전월세 전환 시 (연 0.5~1회)
- 시간 비용: 감정평가 준비에 2~5시간
- 금전 비용: 감정평가액 차이로 인한 월세/보증금 분쟁 (평균 500만~2,000만원)
- 문제 심각도 (0~10): 7
- 현재 지출: 감정평가비 50만~100만원
- 소프트웨어 해결 가능성: 높음 (지역별 시세 데이터 통합 및 자동 평가)
- AI 해결 가능성: 높음 (머신러닝 시세 예측)
- 1인 개발 가능성: 중간 (공개 부동산 데이터 수집)

### 실제 근거
- 전세사기 피해자 커뮤니티: "평가액이 너무 올라갔다" — 평가 분쟁 언급
- 대한감정협회: 감정평가 분쟁 증가 추세
- 부동산 중개 포럼: "감정평가 결과가 실거래와 다르다" — 신뢰도 문제

### 신호 스크리닝
① 정부 무료 제공: Partial — 정부가 실거래가 정보만 제공
② 업계 무료 콘텐츠: No — 감정평가사별로 다름
③ 기존 SaaS 포함: Partial — 부동산 시세 앱이 있지만, 전월세 전환 평가는 없음

- 소프트웨어 해결 가능성: 높음 (라이선스 자동 분석)
- AI 해결 가능성: 높음 (호환성 자동 판정)

## P020. 원격 팀 표준시간대 회의 스케줄링 최적화

- 지역: 전세계
- 국가: 다국가
- 타깃 고객: 원격 팀 리더, 분산 팀 운영자
- 핵심 문제: 전 세계에 퍼져 있는 팀이 회의 일정을 정할 때, 모든 팀원의 표준시간대(Timezone)를 고려해야 함. 예를 들어, 미국 동부(EST), 유럽(CET), 인도(IST), 호주(AEST) 직원이 한 팀이면, 누군가는 새벽 시간, 누군가는 저녁 시간에 회의에 참여해야 함. 회의 일정을 정하는 것 자체가 복잡한 협상이 되고, 기록 남기기, 녹화, 안건 배포도 각 시간대별로 고려해야 함
- 사람들이 실제로 싫어하는 것: "전세계 팀의 회의 시간을 정하기가 어렵다", "누군가는 항상 불리한 시간에 회의에 참여해야 한다", "회의 시간 공지가 각 시간대별로 달라야 한다", "녹화 후 자막을 모두 읽기 어렵다"
- 현재 해결 방법: 온라인 스케줄러(Calendly, When2Meet) 사용, 시간대 수동 계산, 회의 번갈아 예약
- 발생 빈도: 매주 (회의 예약)
- 시간 비용: 주 1~2시간 (회의 일정 조정 및 공지)
- 금전 비용: 없음 (회의 일정은 무료)
- 문제 심각도 (0~10): 4
- 현재 지출: 월 $0~$20 (스케줄러 도구)
- 소프트웨어 해결 가능성: 높음 (시간대 최적화 제시)
- AI 해결 가능성: 높음 (공정한 시간대 자동 제안)
- 1인 개발 가능성: 높음 (시간대 API)

### 실제 근거
- Hacker News: "Scheduling meetings across timezones" — 실제 토론
- Remote.co 블로그: "Managing timezone differences in distributed teams" — 팀 운영 도전

### 신호 스크리닝
① 정부 무료 제공: No — 정부 회의 스케줄 서비스 없음
② 업계 무료 콘텐츠: No — 각 회사가 자신의 방식으로 운영
③ 기존 SaaS 포함: Partial — Calendly, World Time Buddy가 일부 기능 제공
④ 반복 빈도: 매주 (회의 예약)

**판정**: 채택 — 고빈도, 원격팀의 명확한 pain signal

### 왜 중요한 문제인가
팀 리더가 주 1~2시간을 회의 일정 조정에 소비. 최적화 도구가 있으면 주 1시간 절감 + 팀 만족도 향상.

### 가정
- 시간대 최적화 알고리즘의 공정성 기준 확인 필요
