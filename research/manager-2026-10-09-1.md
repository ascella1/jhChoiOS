## Idea 001. InvoiceGuard (글로벌 프리랜서 미수금 + 자동 리마인더)

### 한 줄 설명
7,000만 글로벌 프리랜서의 71%가 겪는 미수금 문제를 자동 추적, AI 리마인더, 다중 플랫폼 통합으로 해결하는 SaaS.

### 해결하는 Pain
- P013: 글로벌 프리랜서 미수금 추적 (월 5~10시간, 연 €15K~€25K 손실)
- 보조: P015 (소규모 비즈니스 결제 통합)

### 제공하는 Positive Experience
- S002: Streaks처럼 "리마인더 스트릭" (매주 자동 청구)
- S014: Patreon처럼 "구독자 관리" (클라이언트별 계약 추적)
- S010: Pocket Casts처럼 "백그라운드 자동화" (자동 리마인더 발송)

### Target User
- 글로벌 프리랜서 (주로 Upwork, Fiverr, Toptal 사용자)
- 월 미수금 €500 이상인 개인
- 연 수입 €15K~€100K대

### 왜 설치하는가
**Primary Pain**: 월평 미수금 €1,000+ 손실을 회복하기 위해. FreshBooks($15-40/월)와 달리 미수금 자동 추적과 AI 리마인더에 특화.

### 첫 30초
1. 앱 열기 → "Upwork/Fiverr 계정 연동"
2. 자동으로 미지급 인보이스 목록 표시
3. "지금 자동 리마인더 보내기" 클릭 → 클라이언트에게 메시지 발송

### 핵심 기능
1. **플랫폼 통합**: Upwork, Fiverr, Toptal API 연동 → 미지급 인보이스 자동 수집
2. **AI 리마인더**: 1주, 2주, 1개월 차로 자동 리마인더 발송 (이메일 + SMS + 플랫폼 메시지)
3. **예측 대시보드**: "3개월 이상 미지급" 표시 및 법적 조언 ("XYZ 나라는 90일 후 부당청구 가능")

### 핵심 사용 루프
클라이언트로부터 인보이스 생성 → 플랫폼 API 자동 추적 → 1주일 후 미지급 감지 → AI 리마인더 자동 발송 → 결제 수령 또는 분쟁 기록

### 반복 사용 이유
- 매주 신규 인보이스 생성 (반복 빈도 높음)
- 월 1~2회 미수금 확인 (습관화)
- AI 리마인더가 자동으로 실행되므로 수동 개입 최소화

### Personalization
- 플랫폼별로 다른 메시지 템플릿 (Upwork용, Fiverr용, 외부 클라이언트용)
- 클라이언트별 리마인더 빈도 커스터마이징 (urgent vs normal)
- 법적 조언은 사용자의 국가/통화에 맞게 AI 생성

### AI 역할
1. **미수금 우선순위화**: 과거 지불 패턴 + 현재 경제 상황 기반으로 "이 클라이언트는 언제쯤 낼 가능성 높음" 예측
2. **자동 리마인더 작성**: 각 플랫폼/언어별 최적화된 리마인더 메시지 자동 생성
3. **법적 가이드**: "국가별 채권 추심 기한 (예: 미국 90일, EU 120일)" 제공

### Sharing
- "이번 달 미수금 €5,000 회복했어!" → 프리랜서 커뮤니티 공유 (Indie Hackers, Reddit r/freelance)
- 클라이언트 "신용도" 공개 (프리랜서 간 신뢰 정보 공유)

### Monetization
- **Freemium**: 무료로 3개 클라이언트 미수금 추적
- **Pro ($9.99/월)**: 무제한 클라이언트, 고급 리마인더, API 통합
- **Enterprise ($49/월)**: 팀 협업, 법적 지원 (변호사 상담 연결)

### MVP
4주 내 완성 물건:
1. Upwork API 통합 (미지급 인보이스 자동 수집)
2. 웹 대시보드 (미수금 목록)
3. 이메일 리마인더 자동 발송 (Template 기반)
4. 기본 통계 (총 미수금, 회수율)

### MVP 예상 비용
- Upwork/Fiverr API 통합: ₩500만
- 웹 프론트 + 백엔드: ₩1,200만
- 이메일 서비스 통합: ₩200만
- QA + 론칭: ₩600만
**총**: ₩2,500만 (약 $2,000 USD)

### 가장 큰 약점
**경쟁자**: FreshBooks ($15-40/월)가 이미 청구 관리를 제공. InvoiceSimple, Wave도 경쟁 중.
→ **차별점**: "미수금 자동 추적"에 특화 + Upwork/Fiverr API 통합 (기존 앱은 수동 입력 요구)

### 가장 중요한 검증 가설
1. 프리랜서가 "미수금 자동 추적"을 위해 월 $10 이상 지불할 의향이 있는가?
2. Upwork/Fiverr API 접근이 2026년에 개방된 상태인가? (플랫폼 정책 변경 리스크)
3. AI 리마인더 메시지가 실제로 결제율을 높이는가? (A/B 테스트 필수)

## Idea 002. ReceiptAI (소규모 사업주 영수증 자동 분류)

### 한 줄 설명
월 50~200개 영수증을 카메라로 촬영하면 AI가 자동으로 카테고리 분류 + 세금 공제 예측까지 해주는 회계 자동화 도구.

### 해결하는 Pain
- P017: 소규모 사업주 영수증 자동 분류 (월 5~10시간)
- 보조: P002 (가계부 은행 연동), P015 (결제 통합)

### 제공하는 Positive Experience
- S013: Evernote처럼 "장기 보관 + 검색" (영수증 이미지 저장)
- S004: Spotify처럼 "개인화 학습" (사용자 카테고리 패턴 학습)
- S017: Adobe Lightroom처럼 "일일 워크플로우" (아침 촬영, 점심 분류)

### Target User
- 소규모 사업주 (프리랜서, 카페 오너, 온라인 스토어 운영자)
- 월 평균 50~200개 영수증 발생
- 현재 QuickBooks, Xero, Wave 사용 중이거나 전환 예정

### 왜 설치하는가
**Primary Pain**: 월 5~10시간의 영수증 정리 자동화 + 세금 공제 실수 방지로 연 $500~$2,000 절세 가능.

### 첫 30초
1. 앱 열기
2. 카메라로 영수증 촬영
3. "자동 분류" 버튼 클릭
4. "음식 & 음료 | 2024-10-09 | $45.60" 자동 분류 + 세금 공제 가능 여부 표시

### 핵심 기능
1. **영수증 OCR**: 이미지 → 상호, 금액, 날짜 자동 인식
2. **AI 카테고리화**: "Starbucks $5" → "음식비" vs "비즈니스 미팅" 자동 판단 + 사용자 피드백으로 학습
3. **세금 가이드**: "미국: 식사비는 50% 공제 가능" 자동 표시
4. **월간 리포트**: 카테고리별 지출 + "이 카테고리 작년보다 30% 증가" 알림

### 핵심 사용 루프
영수증 촬영 → AI 자동 분류 → 사용자 확인 (2초) → 저장 → 월말 자동 리포트 생성

### 반복 사용 이유
- 매일 영수증 발생 (매일 3~5개 스캔)
- AI가 점점 더 정확해지므로 (학습 효과)
- 월말 자동 리포트가 회계사에게 유용 (업무 시간 단축)

### Personalization
- 업종별 카테고리 템플릿 (카페: 원재료, 임차료 등)
- 국가/세금 체계별 공제율 자동 계산
- 개별 클라이언트별 비용 추적 (freelancer → project#1, project#2)

### AI 역할
1. **자동 분류**: Tesseract OCR + GPT-4 Vision으로 영수증 이미지 → 텍스트 → 카테고리
2. **세금 최적화**: "이 비용은 세금 공제 가능합니다" 자동 안내
3. **이상 감지**: "이번 달 커피비가 작년 동기 대비 200% 증가했습니다" 알림

### Sharing
- "월간 비용 리포트" 내보내기 (CSV, PDF) → 회계사/세무사에게 공유
- 팀 공유: 직원이 찍은 영수증도 계정에 추가 가능

### Monetization
- **Freemium**: 월 10장 스캔 무료
- **Pro ($9.99/월)**: 무제한 스캔 + AI 분류 + 월간 리포트
- **Enterprise ($49/월)**: 팀 협업 + QuickBooks/Xero 자동 내보내기

### MVP
4주 내 완성 물건:
1. 영수증 카메라 + Tesseract OCR
2. 기본 AI 분류 (5~10개 카테고리)
3. 월간 리포트 (CSV 내보내기)
4. 간단한 통계 (총 지출, 카테고리별)

### MVP 예상 비용
- Tesseract OCR 통합: ₩300만
- GPT-4 Vision API 호출 구조: ₩400만
- 웹/모바일 프론트: ₩900만
- 백엔드 + DB: ₩600만
- QA 테스트: ₩300만
**총**: ₩2,500만

### 가장 큰 약점
**경쟁자**: Expensify ($4.99/월), Wave (무료), Quicken이 이미 부분 자동화 제공.
→ **차별점**: ReceiptAI는 "AI 분류 정확도"에 특화. 기존 도구는 금액만 인식, 범주는 수동.

### 가장 중요한 검증 가설
1. 소규모 사업주가 AI 자동 분류 정확도 80%+ 달성 시 월 $10 지불할 의향이 있는가?

3. 세금 공제 가이드가 국가별로 정확한가? (법적 리스크)

## Idea 003. OvertimeShield (한국 야근비 자동 추적 + 법적 증명)

### 한 줄 설명
포괄임금제로 착취당하는 한국 직장인의 야근시간을 자동으로 기록하고, 미지급 야근비를 자동으로 계산하며, 법적 증거로 활용 가능한 데이터를 제공하는 모바일 앱.

### 해결하는 Pain
- P001: 직장인 미지급 야근비 추적 (월 20~40시간 야근, 50만~200만원 손실)
- 보조: P002 (금융 추적)

### 제공하는 Positive Experience
- S002: Streaks처럼 "일일 체크인" (퇴근 시간 자동 기록)
- S011: 습관앱처럼 "누적 시간 시각화" (월 야근시간 그래프)
- S004: Spotify처럼 "개인화 리포트" (야근비 예상액 자동 계산)

### Target User
- 한국 직장인 (특히 중소기업, 비정규직, 신입)
- 월 20시간 이상 야근하지만 미지급 상태
- 법적 소송 또는 고용노동부 진정 고려 중

### 왜 설치하는가
**Primary Pain**: 월 50만~200만원의 미지급 야근비를 법적 증거와 함께 청구하기 위해.

### 첫 30초
1. 앱 열기
2. 회사 근태 시스템(카드기반) 또는 수동으로 출퇴근 시간 입력
3. "야근시간 자동 계산" → "이번 달 예상 야근비: ₩800,000"
4. "법적 증거서 생성하기" 클릭

### 핵심 기능
1. **자동 시간 추적**: 회사 근태 카드 API 연동 (삼성카드, 현대카드 등) 또는 수동 입력
2. **야근비 자동 계산**: 포괄임금제 위반 감지 + 통상임금 기준으로 계산
3. **법적 증거 생성**: 출퇴근 기록 → 해시값 인증 → PDF 보고서 (법원 제출 용)
4. **AI 법률 조언**: "당신의 경우 포괄임금제가 유효하지 않을 가능성 70%"

### 핵심 사용 루프

1. 소규모 사업주가 월 $10 가격으로 결제 통합을 위해 지불할 의향이 있는가?
2. 각 결제사의 API가 안정적으로 유지되는가? (정책 변경 리스크)
3. 자동 정산 최적화 알고리즘이 사업주의 신뢰를 얻을 수 있는가?

## Idea 010. FixSchedule (가족 공유 캘린더 동기화 + 스케줄 자동 조율)

### 한 줄 설명
가족 구성원들의 일정이 자동으로 동기화되고, 회의실 예약 같이 일정이 겹칠 때 AI가 자동으로 대안 시간을 제안하는 가족 캘린더 앱.

### 해결하는 Pain
- P020: 가족 공유 캘린더 동기화 오류 + 충돌 반복 (월 3~5회)
- 보조: P004 (복잡한 절차)

### 제공하는 Positive Experience
- S006: Apple Fitness+처럼 "가족 공유 기능" (5명 한 계정에서)
- S001: BeReal처럼 "일일 알림" (오늘의 가족 일정)
- S010: Pocket Casts처럼 "자동 백그라운드 동기화"

### Target User
- 자녀 1~2명 있는 가족 (학생, 부모 일정 조율 필요)
- 부부 맞벌이 가정 (일정 겹침이 자주 발생)
- 다세대 가족 (할머니/할아버지 일정도 포함)

### 왜 설치하는가
**Primary Pain**: 엄마 일정, 아빠 일정, 아이 학원 일정이 동시에 업데이트되면서 중복 예약되는 문제를 AI가 자동으로 해결하기 위해.

### 첫 30초
1. 앱 열기
2. "가족 초대 (엄마, 아빠, 아이1, 아이2)"
3. → "이번주 가족 일정" 자동 통합 표시
4. → "토요일 2시: 엄마 회의 vs 아이 피아노 동시에 예약됨" 감지 → "아빠가 아이를 데려갈 수 있나요?"

### 핵심 기능
1. **실시간 동기화**: 가족 구성원이 입력한 일정이 1초 이내에 모두에게 반영
2. **충돌 감지**: "같은 시간에 2명 이상이 약속" 자동 감지
3. **AI 일정 조율**: 충돌 시 대안 시간 자동 제안 ("엄마가 3시 30분으로 미룰 수 있을까?")
4. **일정 공유 태그**: "운전 필요", "보육 필요", "식사 준비" 등 태그로 책임자 명확화

### 핵심 사용 루프
일정 입력 → 자동 동기화 → 충돌 감지 (자동) → AI 대안 제안 → 클릭으로 수락/거절

### 반복 사용 이유
- 매일 일정 확인 (일일 루틴)
- 주 1~2회 충돌 해결 (자동으로)
- AI가 점점 더 가족의 선호도를 학습

### Personalization
- 가족 구성원별 선호 시간 학습 ("엄마는 아침을 선호", "아빠는 저녁을 선호")
- 자녀 나이별 맞춤 알림 (초등학생은 부모에게만 알림, 중학생은 자신에게도)
- 종교, 학교 주기에 맞춘 휴일 자동 입력

### AI 역할
1. **충돌 자동 해결**: "엄마의 회의는 미룰 수 있고, 아이의 학원은 안 되니 엄마가 조정" 제안
2. **예측 스케줄링**: "매주 목요일 6시에 피아노 가는데, 이번주 엄마가 회의면?" 미리 알림
3. **이동 시간 자동 계산**: "어린이집 픽업(30분) → 학원(20분 이동)" 자동 계산하여 일정 배치

### Sharing
- "이번주 가족 일정" 공유 (친척에게)
- 아이 일정만 별도 공유 (학교, 학원 알림)

### Monetization
- **Freemium**: 가족 3명까지 기본 공유 무료
- **Family ($2.99/월)**: 무제한 가족 + AI 충돌 해결
- **Premium ($4.99/월)**: Family + AI 예측 스케줄링 + 학교/학원 자동 동기화

### MVP
4주 내 완성 물건:
1. 가족 초대 시스템
2. 일정 동기화 (Google Calendar/Apple Calendar 연동)
3. 충돌 감지 + 기본 알림
4. 일정 공유 태그

### MVP 예상 비용
- 모바일 + 웹 앱 개발: ₩1,200만
- Google/Apple Calendar API 통합: ₩300만
- 실시간 동기화 인프라: ₩600만
- 백엔드: ₩500만
**총**: ₩2,600만

### 가장 큰 약점
**경쟁자**: Google Calendar, Apple Calendar가 이미 가족 공유 지원.
→ **차별점**: "AI 자동 충돌 해결" (기존은 충돌 감지만 함)

### 가장 중요한 검증 가설
1. 가족이 이 앱을 위해 월 $3 이상 지불할 의향이 있는가?
2. AI가 가족의 선호도를 정확히 학습할 수 있는가? (개인차 크므로)
3. 캘린더 동기화가 정말 실시간(1초 이내)으로 가능한가?
