# Idea 001. PlatformSync — 플랫폼별 정산 통합 대시보드

## 한 줄 설명
온라인 강사, POS 점주를 위해 여러 플랫폼의 정산 내역을 한 곳에서 추적하고, AI가 예상 수령액을 실시간 계산해주는 투명한 정산 관리 도구.

## 해결하는 Pain
- P002(온라인 강사 플랫폼별 정산 복잡), P001(POS 가맹점 수수료 투명성)
- 플랫폼마다 다른 수수료율·정산 주기로 인한 현금흐름 예측 불가능

## 제공하는 Positive Experience
- 카카오페이(S006)의 "정산이 앱 한 번에 끝난다"는 경험을 모든 프리랜서·점주에게
- 자산 추적(S011)처럼 자신의 "실제 수령액"을 실시간으로 시각화

## Target User
- 온라인 강사 (탈잉, 튜터닷컴, 클래스101, 유튜브)
- 소규모 카페·학원 점주 (POS·배달앱 연동)
- 다중 플랫폼 프리랜서 (Fiverr, Upwork, 크몽)

## 왜 설치하는가
"다음달에 얼마를 받을 수 있을까"를 정확히 알고 싶음. 엑셀 정산이 아니라 자동 추적.

## 첫 30초
- 플랫폼 계정 3개 연결 (자동 API 연동)
- 대시보드: "이번달 예상 수령액 450만원 (상세: 탈잉 250만원 - 30% 수수료, 유튜브 200만원 - 30% 수수료)"
- 수수료율별 색상 코딩 (투명한 비교)

## 핵심 기능
1. 자동 플랫폼 연동 (API): 탈잉, 튜터닷컴, 유튜브, Fiverr, Upwork, 라인웹툰, 카카오페이, 배달앱(배민, 쿠팡)
2. 수수료 내역 시각화: 플랫폼별 수수료율, 누적 차감액
3. AI 실시간 수령액 예측: "이번달 수령 예상일: 15일(탈잉), 20일(유튜브)" 자동 추적
4. 수수료 변동 알림: "유튜브 수수료 30%→35% 인상됨"
5. 통합 정산 보고서: CSV 다운로드 (세무신고용)

## 핵심 사용 루프
1. 월 초: 앱 열기 → "이번달 예상액 시각화" 확인
2. 주 단위: 수수료 알림 받기
3. 월말: 통합 정산 보고서 다운로드 → 세무사·회계에 제출

## 반복 사용 이유
- 매월 정산 시기 (자동 반복)
- 수수료 변동 알림 (주 1회 이상)
- 현금흐름 예측 불가피성 (프리랜서·점주의 필수 기능)

## Personalization
- 각 사용자의 주요 플랫폼 순서대로 정렬
- "자주 확인하는 수수료 비율" 저장
- 세무신고 방식별 카테고리 커스터마이징 (개인사업자/법인 다름)

## AI 역할
- OCR 영수증 인식 → 추가 수수료 자동 감지
- 수수료율 변화 추적 → 이상 패턴 알림 (예: 평소 2% → 5% 인상)
- 최적 플랫폼 추천 (동일 강의 기준, 어느 플랫폼이 수수료 낮은지)

## Sharing
- "나는 이번달 450만원 예상" 공유는 낮음 (민감한 정보)
- 다만 "어느 플랫폼이 수수료 낮은가" 팁 공유 가능 (커뮤니티)

## Monetization
1. **Freemium**: 플랫폼 2개까지 무료, 3개 이상 월 2,900원
2. **Pro**: 월 9,900원 - AI 수수료 예측, 세무신고 템플릿 포함
3. **B2B 학원/카페**: 월 29,000원 - 다중 직원 계정, 관리자 대시보드

## MVP
- 통합 가능 플랫폼: 탈잉, 유튜브, Fiverr, 카카오페이 4개
- 기능: 자동 수수료 계산, 월별 예상액 시각화, CSV 다운로드
- 개발: 백엔드(Node.js + API), 프론트엔드(React), DB(PostgreSQL)
- 비용: 서버/호스팅 월 50만원, API 연동 개발 200만원

## MVP 예상 비용
약 250만원 (초기 서버 인프라 + API 연동 개발)

## 가장 큰 약점
- 각 플랫폼의 API 접근 제약 (특히 배달앱: 공개 API 부재)
- 중국·미국 등 국가별로 플랫폼이 다름 (글로벌 확장 어려움)
- 기존 서비스: Stripe·Wise 같은 결제 플랫폼이 부분 기능 제공 (다만 프리랜서용이 아님)

## 가장 중요한 검증 가설

# Idea 002. TaxBot — AI 세무신고 자동 어시스턴트

## 한 줄 설명
개인사업자, 프리랜서를 위해 영수증 사진 한 장으로 AI가 세무신고 항목을 자동 분류·계산·작성해주는 모바일 앱.

## 해결하는 Pain
- P003(개인사업자 매출추적 강화), P008(일본 인보이스 작성 부담), P014(월말 회계 수작업)
- 영수증 정리·분류·세금 계산을 월 8~16시간 소요

## 제공하는 Positive Experience
- ChatGPT Plus(S013)의 "AI가 내 업무를 더 명확하게 정리해준다"는 경험
- 금융 자산 추적(S011)처럼 "내 재정 상태가 한눈에 보인다"

## Target User
- 개인사업자·프리랜서 (강사, 디자이너, 개발자)
- 소규모 자영업자 (카페, 학원, 트레이너)
- 소규모 기업 경리담당자

## 왜 설치하는가
"매년 연말정산 때 세무사 의존에서 벗어나고 싶음" + "월별 세금을 미리 예측하고 싶음"

## 첫 30초
- 영수집 사진 촬영 → AI 인식
- "이 영수증: 카테고리=식재비, 금액=45,000원, 날짜=2026-09-24"
- 자동 분류 + "이번달 누적 경비 1.2백만원, 예상 세금 50만원"

## 핵심 기능
1. OCR 영수증 인식 → 자동 카테고리화
2. 월별·분기별 재무 리포트 (매출, 경비, 예상 세금)
3. 세무신고 자동 작성 (국세청 양식 대응)
4. 세금 환급액 예측 (연말정산 전 미리 계산)
5. 이상 거래 탐지 (평소와 다른 거래 패턴)

## 핵심 사용 루프
1. 월 2~3회: 영수증 촬영 → AI 인식
2. 월말: "이번달 세금 예측" 보고서 확인
3. 연초·분기말: "세무신고 준비" 버튼 → 자동 작성

## 반복 사용 이유
- 영수증 발생 → 즉시 입력 (월 수십 장)
- 월별 세금 추적 불안감 (매월)
- 연말정산 자동화 (연 1회이지만 높은 니즈)

## Personalization
- 개인사업자/법인/일용근로자 선택
- 업종별 필요 경비 카테고리 자동 추천
- 세무신고 방식 커스터마이징 (간단신고/일반신고)

## AI 역할
- 영수증 OCR 정확도 80%+ 목표
- 자동 카테고리화 (음식점 → "식재비", 택시비 → "교통비")
- 세금 환급 가능성 분석 (기부금, 교육비 등 공제 항목 자동 감지)
- 부정 거래 패턴 탐지 (예: 월별 변동폭 의심 수준)

## Sharing
- "나는 이번달 세금 50만원 예상" 공유 낮음
- 다만 "세금 환급 200만원 받았다" 성공 사례 공유 가능 (커뮤니티)

## Monetization

2. **Pro**: 월 4,900원 - 무제한 스캔, 주별 리포트, AI 상담

## MVP

- 영수증 카테고리: 12개 (식재, 교통, 통신, 광고, 임차료 등)

# Idea 003. CreatorSync — AI 크리에이터 다중플랫폼 콘텐츠 자동화

## 한 줄 설명
YouTube, TikTok, Instagram에 동시 업로드하는 크리에이터를 위해, 하나의 영상으로 각 플랫폼별 최적화된 제목·설명·태그를 AI가 자동 생성해주는 도구.

## 해결하는 Pain
- P016(크리에이터 다중플랫폼 메타데이터 관리)
- 같은 영상을 3~4개 플랫폼에 올릴 때, 각 플랫폼별 최적 키워드·길이가 다름 (월 20~40시간 소요)

## 제공하는 Positive Experience
- Notion AI(S015)의 "내 데이터로부터 AI가 최적화해준다"는 경험
- Midjourney(S014)의 "상상이 자동으로 현실이 된다"는 경험을 메타데이터 최적화에 적용

## Target User
- 인디 크리에이터 (2개 이상 플랫폼 운영, 주 2회 이상 업로드)
- 소규모 콘텐츠 스튜디오 (3~10명)
- 개인 브랜드 매니저

## 왜 설치하는가
"영상은 하나인데, 플랫폼 3개에 맞춰 제목·태그를 따로 작성하는 게 너무 번거움"

## 첫 30초
- 영상 링크 또는 파일 업로드
- AI 분석 (영상 내용 학습)
- 자동 생성: "YouTube 최적화 제목 (60자), TikTok 해시태그 (15개), Instagram 캡션"
- 클릭 → 각 플랫폼에 바로 업로드

## 핵심 기능
1. AI 영상 분석 (내용·스타일·키워드 추출)
2. 플랫폼별 최적화 메타데이터 자동 생성:
   - YouTube: 제목 (60자), 설명 (500자), 태그 (30개)
   - TikTok: 제목 (30자), 해시태그 (15개), 트렌드 감지
   - Instagram: 캡션 (2,200자), 이모지, 해시태그 (30개)
3. 플랫폼별 썸네일 추천 (자동 크롭·텍스트 삽입)
4. 업로드 스케줄링 (각 플랫폼별 최적 시간대 제안)
5. 성과 분석 (조회수·클릭율 비교)

## 핵심 사용 루프
1. 영상 완성 → CreatorSync 업로드
2. AI 자동 최적화 (5분 소요)
3. 각 플랫폼별 메타데이터 검토 후 미세 수정 (5분)
4. 한 번 클릭 → 3개 플랫폼 동시 업로드

- 카카오페이(S006)의 "정산이 자동으로 끝난다"는 경험

- 웹/앱 개발 프리랜서

1. 에스크로 결제 (계약금 → 중간금 → 잔금, 각 단계별)
2. Scope Creep 방지 (계약서에 명시된 요청만 수락, 추가는 별도 계약)
3. 결과물 검수 프로세스 (클라이언트 승인 전까지 대금 보관)
4. 분쟁 중재 (AI 기반 계약 조건 해석)
5. 신뢰도 평가 (클라이언트의 지급 신뢰도 평점)

## 핵심 사용 루프
1. 프리랜서: 프로젝트 생성 → 클라이언트 초대
2. 클라이언트: 계약금 결제 (FreelanceShield 보관)

4. 클라이언트: 검수 → 승인 또는 수정 요청
5. 완성 후: 최종 결과물 → 클라이언트 승인 → 잔금 자동 지급

- 프로젝트마다 (프리랜서는 주 1회 이상)
