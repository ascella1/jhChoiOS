## S001. 반품 배송 앱으로 배송비 비교·선택

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 온라인 쇼핑 이용자, 의류·신발 구매자
- 사람들이 좋아하는 행동: 반품 필요 시 여러 배송업체의 배송비를 앱에서 비교하고, 가장 저렴한 옵션을 선택하는 행위. 반품 진행 상황을 실시간으로 추적
- 핵심 경험: "반품 배송비를 내 선택으로 결정하고 절약한다"는 제어감
- 핵심 감정: 경제성, 투명성, 선택권
- 사용 빈도: 월 1~2회 (반품 시)
- 반복 사용 이유: 매번 배송비를 낭비하지 않으려는 동기
- 추천 이유: "이 앱으로 반품 배송비 절약했어"
- 공유 이유: 절약한 금액을 카톡 또는 SNS에 공유
- 지불 이유: 월정액 또는 거래당 수수료 (2-3%)
- 개인화 가능성: 개인 반품 이력·배송사 선호도 학습 → 높음
- AI 활용 가능성: 반품 규정 자동 분석, 최적 배송사 추천

### 실제 근거
온라인 쇼핑 커뮤니티에서 "반품 배송비 때문에 반품 포기"라는 언급 증가. 스마트 배송 시스템 도입 요청 높음.

### 왜 사람들이 좋아하는가
반품은 피할 수 없는 경험이지만, 배송비는 제어 가능한 비용. 앱을 통해 배송비를 "선택"하는 경험은 강한 만족감 제공.

### 다른 제품으로 확장할 수 있는 요소
"배송사 선택 + 비용 최소화 + 실시간 추적"은 일반 배송, 택배 조회, 해외 배송 등으로 확장 가능.

### 시장 공백 매칭
- P001과 직접 매칭 (반품 배송비 부담 문제)
- 기존 솔루션: 없음 (각 배송사별 개별 조회만 가능)
- 기회: ✅ 높음

### 가정
- 배송사 API 개방 필요
- 고객 획득 채널: 배송 관련 커뮤니티, 온라인 쇼핑몰 파트너십

### 출처

- https://www.musinsa.com/

## S002. 카풀 신뢰도 평점 필터링으로 취소 위험 줄이기

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 출퇴근 직장인, 정시 도착이 중요한 이용자
- 사람들이 좋아하는 행동: 카풀 앱에서 기사를 선택할 때 신뢰도 평점으로 필터링해서 "취소 위험이 낮은 기사"를 명확히 볼 수 있는 행위. 정시율 90% 이상 기사만 예약
- 핵심 경험: "내 시간을 지켜줄 기사를 확신하고 선택한다"
- 핵심 감정: 신뢰감, 시간 보장감, 통제감
- 사용 빈도: 주 3~5회 (정규 카풀 이용자)
- 반복 사용 이유: 취소 경험이 없으면 같은 기사를 계속 선택
- 추천 이유: "이 기사 정말 신뢰할 수 있어"
- 공유 이유: 신뢰할 수 있는 기사 정보를 직장 동료에게 공유
- 지불 이유: 프리미엄 신뢰도 인증 (월 5,000원)
- 개인화 가능성: 개인 목적지·시간대 선호도 학습 → 높음
- AI 활용 가능성: 취소 위험 예측, 최적 기사 추천

### 실제 근거
카카오맵, 네이버맵 커뮤니티에서 "신뢰할 수 있는 기사를 구분하는 기능" 요청 다수. 기사 평점은 있지만 취소율 정보 부재.

### 왜 사람들이 좋아하는가
"누가 나를 받아줄까"에서 "누구를 선택할까"로 패러다임 전환. 선택권과 정보가 주어지면 신뢰감 증가.

### 다른 제품으로 확장할 수 있는 요소
"신뢰도 필터링 + 신뢰 인증 + 반복 선택"은 배달, 택시, 대리 운전 등 서비스 노동 전반에 적용 가능.

### 시장 공백 매칭
- P002와 직접 매칭 (기사 취소 문제)
- 기존 솔루션: 부분적 (평점은 있으나 취소율 정보 없음)
- 기회: ✅ 높음

### 가정
- 기사 취소 데이터 공개 필요
- 신뢰도 인증 시스템 개발

## S003. 공과금 자동이체 통합 관리 앱

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 이사·계좌 변경자, 재정 관리에 관심 있는 세대
- 사람들이 좋아하는 행동: 이사할 때 한 번의 앱 입력으로 모든 공과금 (전기, 수도, 가스, 인터넷, 보험 등)을 새로운 계좌로 일괄 변경하는 행위
- 핵심 경험: "10개 회사에 일일이 전화하던 일이 5분 안에 끝난다"
- 핵심 감정: 효율성, 편의성, 시간 절감의 쾌감
- 사용 빈도: 수년에 1회 (계좌 변경 시)이지만 발생 시 급박함
- 반복 사용 이유: 매번 이사할 때마다 번거로움을 피하고 싶음
- 추천 이유: "이사할 때 이 앱 꼭 써"
- 공유 이유: 이사 체크리스트에서 "필수 앱"으로 공유
- 지불 이유: 1회성 2,900원 또는 월정액 (5,000원)
- 개인화 가능성: 개인 공과금 항목 기억 → 중간
- AI 활용 가능성: 자동 양식 입력, 누락 항목 알림

### 실제 근거
이사 커뮤니티에서 "이사 후 해야 할 일 리스트"에서 공과금 변경이 가장 번거로운 항목으로 언급. 이사 정보 사이트에서 공과금 변경 단계별 가이드 필요성 높음.

### 왜 사람들이 좋아하는가
발생 빈도는 낮지만, 발생할 때의 불편함이 극심함. 시간 절감과 오류 방지는 강한 가치.

### 다른 제품으로 확장할 수 있는 요소
"여러 서비스사 일괄 변경 + 자동 양식 채움 + 진행 추적"은 주소 변경, 보험 변경, 은행 등록 등으로 확장 가능.

### 시장 공백 매칭
- P003과 직접 매칭 (공과금 자동이체 계좌 변경 번거로움)
- 기존 솔루션: 없음 (각 서비스사별 개별 신청만 가능)
- 기회: ✅ 높음

### 가정
- 각 공과금 서비스사 API 연동 필요
- 이사 커뮤니티 또는 부동산 플랫폼 파트너십

## S005. 전세금 보증보험 청구 자동화 앱

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 전세 세입자, 보험 청구자, 법적 분쟁 경험자
- 사람들이 좋아하는 행동: 전세금을 받지 못했을 때, 필요한 서류 리스트를 앱에서 확인하고, 자동으로 양식에 입력하고, 보험사에 자동 제출하는 행위
- 핵심 경험: "복잡한 보험 청구가 가이드된 몇 클릭으로 끝난다"
- 핵심 감정: 안심, 시간 절감, 법적 보호감
- 사용 빈도: 매우 낮음 (전세 계약 10건 중 1회) 하지만 발생 시 급박함
- 반복 사용 이유: 전세 재계약 시 미리 등록해 두는 습관
- 추천 이유: "전세 계약할 때 반드시 이 앱으로 보험 청구 정보 미리 등록해"
- 공유 이유: 전세 관련 커뮤니티에서 "필수 앱" 추천
- 지불 이유: 1회성 5,000원 또는 성공 수수료 (보험금의 3%)
- 개인화 가능성: 보험 상품별 필요 서류 자동 인식 → 높음
- AI 활용 가능성: 필요 서류 자동 목록화, OCR로 양식 자동 작성

### 실제 근거
전세사기 관련 보도 증가로 보증보험 청구 방법 검색 급증. 소비자센터 상담 요청 높음. 보험 청구 서류가 보험사별로 상이한 점 확인.

### 왜 사람들이 좋아하는가
발생 빈도는 매우 낮지만, 발생할 때의 스트레스가 극대화. "청구 과정의 불확실성 제거"는 높은 가치.

### 다른 제품으로 확장할 수 있는 요소
"법적 서류 자동 생성 + 보험 청구 가이드 + AI 양식 채우기"는 다른 보험 청구(의료보험, 자동차 보험 등)로 확장 가능.

### 시장 공백 매칭
- P005와 직접 매칭 (전세금 보증보험 청구 절차 복잡)
- 기존 솔루션: 없음 (각 보험사별 수동 청구만 가능)
- 기회: ✅ 높음

### 가정
- 보험사 청구 API 표준화 필요
- 법원 판결문 API 연동 필요

### 출처
- 보험사 웹사이트
- 전세사기 특별법 안내
- 소비자 센터

## S018. 건설 현장 안전 보고서 자동화

- 타깃 고객: 건설 현장 감리자, 안전담당자, 프로젝트 매니저

- 반복 사용 이유: 매일 현장에 가는 한 안전 보고 필요
- 추천 이유: "건설사 모두 이 도구 써야 한다"
- 공유 이유: 건설사 경영진에 추천
- 지불 이유: 월 50,000원 (현장 단위)
- 개인화 가능성: 현장별 위험 요소 학습 → 높음

### 다른 제품으로 확장할 수 있는 요소

## S019. 회의 자동 기록 및 음성 전환 서비스

- 지역: 전세계

- 타깃 고객: 회사원, 프로젝트 매니저, 팀 리더
- 사람들이 좋아하는 행동: 회의 중에 회의실 마이크를 켜두면, 자동으로 음성을 인식하고, 회의 끝나는 순간 회의 기록 + 액션 아이템 요약이 메일로 도착하는 경험
- 핵심 경험: "회의 후 기록을 쓸 필요가 없다"
- 핵심 감정: 시간 절감, 업무 효율화, 자동화 쾌감

- 반복 사용 이유: 회의가 지속되는 한 기록 필요
- 추천 이유: "우리 팀은 이 도구로 회의 기록 통일해"
- 공유 이유: 경영진에 도입 제안
- 지불 이유: 1회의실당 월 10,000원 또는 팀 단위 $50/월

### 왜 사람들이 좋아하는가

### 다른 제품으로 확장할 수 있는 요소
"음성 인식 + 자동 기록 + 요약"은 강의, 인터뷰, 팟캐스트 제작, 고객 상담 등으로 확장 가능.

### 시장 공백 매칭

## S020. 소매점 실시간 재고 가시성 시스템

- 지역: 전세계
- 국가: 다국가
- 타깃 고객: 소매점 주인, 재고 관리자, 체인점 운영사
- 사람들이 좋아하는 행동: 매장 선반과 창고의 재고를 앱에서 실시간으로 확인하고, 재고 부족 물품이 감지되면 자동으로 발주 제안이 오며, 재고 이동을 RFID로 추적하는 경험
- 핵심 경험: "재고 확인을 위해 창고에 갈 필요가 없다"
- 핵심 감정: 효율성, 손실 방지, 시간 절감
- 사용 빈도: 매일 (재고 확인)
- 반복 사용 이유: 재고 관리는 지속 필수
- 추천 이요: "소매점은 이 시스템 필수"
- 공유 이유: 매장 체인 경영진에 도입 제안
- 지불 이유: 매장당 월 20,000원 또는 거래당 500원
- 개인화 가능성: 매장별 판매 패턴 학습 → 높음
- AI 활용 가능성: 재고 수요 예측, 자동 발주 최적화

### 실제 근거
RFID 기술 발전으로 소매점 재고 추적 가능성 증가. 대형 매장 체인(Walmart 등)이 RFID 도입 중.

### 왜 사람들이 좋아하는가
소매점은 "재고 손실 + 품절"로 인한 매출 손실 큼. 실시간 가시성은 손실 방지 + 판매 기회 증가 동시 제공.

### 다른 제품으로 확장할 수 있는 요소
"RFID 추적 + 실시간 가시성 + 자동 발주"는 창고, 도서관, 병원 의료용품, 제조업 부품 등으로 확장 가능.

### 시장 공백 매칭
- P020과 직접 매칭 (글로벌 소규모 매장 재고 관리 RFID 미지원)
- 기존 솔루션: 부분적 (대형 체인 시스템이 있으나 소규모 매장 지원 미흡)
- 기회: ✅ 높음

### 가정
- 소규모 소매점 수: ~500만 개 (세계)
- RFID 도입율: 현재 ~5%
- 목표: 20% (2026년)

### 출처
- https://www.walmart.com/
- 소매 업계 뉴스
- RFID 기술 업체
