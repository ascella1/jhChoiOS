## Idea 001. 부당급여 뽑기 (Unfair Wage Gacha)

**한 줄 설명**
야근비·퇴직금 미지급을 자동 추적하고, 누적액에 따라 "뽑기" 형태의 청구 메커니즘

**해결하는 Pain**
- P001 (야근비 미지급): 증거 수집 자동화 + 청구 자동화
- P002 (프리랜서 청구서): 자동 청구 + 추적

**제공하는 Positive Experience**
- S021 (게임화): "뽑기" 심리 — 미지급액이 모일수록 예측 불가능한 해결 경험
- S031 (스트릭): 월 단위 미지급액 추적 누적

**Target User**
한국 중소기업 근로자, 프리랜서 (월 50~200만원 미지급 경험)

**왜 설치하는가**
야근비 미지급은 "증거 수집"이 가장 어려운데, 이 앱이 카드·이메일·메신저 자동 수집 후 자동 증거 파일 생성

**첫 30초**
- 은행/이메일 연동 → "미지급액 €XXX 적립됨" 알림
- "언제 청구할까?" 선택지

**핵심 기능**
1. 출퇴근 증거 자동 수집 (카드/이메일/메신저)
2. 포괄임금제 위반 자동 감지
3. 미지급액 누적 대시보드
4. "뽑기" 버튼 → 무작위 청구액 제안 (실제 계산값의 50~150%)
5. 커뮤니티 "블랙리스트" (미지급 회사 공개)

**핵심 사용 루프**
미지급 발생 → 증거 자동 수집 → 월 1회 "뽑기" 알림 → 청구액 확인 → 법적 조언

**반복 사용 이유**
- 매달 새로운 미지급액 누적 → "이번 달은 얼마나 나왔나" 매일 확인
- 뽑기 심리: "이번에는 큰 액수가 나올까"

**Personalization**
- 개인 포괄임금 기준 학습 → 맞춤 위반 감지
- 업직별 미지급 평균값 비교

**AI 역할**
- 증거 자동 분류 (근태 vs 업무 vs 무관)
- 포괄임금제 위반 자동 판단 (법규 학습)
- 최적 청구 타이밍 추천

**Sharing**
- "내 회사 블랙리스트 등록됨" SNS 공유
- "이번 달 €60만 뽑았다" 커뮤니티 자랑

**Monetization**
- 기본 무료: 증거 수집 + 커뮤니티
- 프리미엄 €4.99/month: 자동 청구 + 법률 자문 연결

**MVP**
- 은행 API + 이메일 수집
- 포괄임금 위반 감지 규칙 (한국 근로기준법)
- 뽑기 UI + 커뮤니티 (Supabase)

**MVP 예상 비용**
- API 비용: €200/month
- 개발: 2개월 (1인)
- 운영: €500/month

**가장 큰 약점**
- 기존 경쟁: 노무법인, 고용노동부 앱 (하지만 자동화 + 게임화 없음)
- 법적 리스크: 잘못된 청구 권고 시 책임

**가장 중요한 검증 가설**
"한국 근로자가 매달 '뽑기' 알림에 반복 접근하는가?" + "실제 미지급 환수 성공률은 얼마인가?"

## Idea 002. 프리랜서 신뢰 스코어 (Freelancer Trust Score)

**한 줄 설명**
프리랜서의 미수금을 자동 추적하면서, 클라이언트 신뢰도를 커뮤니티에서 점수화

**해결하는 Pain**
- P002: 프리랜서 청구서 + 미수금 추적
- P013: 글로벌 프리랜서 미수금 (여러 플랫폼 통합)

**제공하는 Positive Experience**
- S022: 프리랜서 미수금 자동 추적 + 악성업체 커뮤니티 (이미 검증된 신호)
- S024: 당근마켓 매너온도 (신뢰도 시각화)

**Target User**
한국·글로벌 프리랜서 (개발자, 디자이너, 라이터, 번역가) / 월 50~200만원 미수금 경험

**왜 설치하는가**
클라이언트 정보를 모르면 사기 당할 수밖에 없는데, 이 앱이 "신뢰도 점수"를 보여줌 (사전 검증)

**첫 30초**
- 클라이언트 이름 검색 → "Trust Score 75/100, 최근 결제 2일 지연" 표시
- "이 클라이언트와 거래 안 함" 옵션

**핵심 기능**
1. Upwork/Fiverr/직거래 수익 자동 통합
2. 클라이언트별 신뢰도 점수 (결제 지연, 분쟁 이력)
3. "미수금 커뮤니티": 연체 클라이언트 공개
4. 자동 리마인더: "결제 기한 24시간 전"
5. 자동 독촉: "결제 연체, 팀에 알림"

**핵심 사용 루프**
클라이언트 입력 → 신뢰도 확인 → 거래 결정 → 결제 추적 → 커뮤니티 피드백

**반복 사용 이유**
- 매 프로젝트마다 클라이언트 신뢰도 확인 필수
- 새로운 신뢰도 정보 지속 업데이트

**Personalization**
- 개인 거래 패턴 학습 (이 프리랜서가 자주 거래하는 클라이언트 타입)
- 위험도 자동 학습

**AI 역할**
- 결제 지연 패턴 분석 → 부도 위험 예측
- 거래처 신뢰도 스코어 자동 계산
- 최적 리마인더 타이밍 제안

**Sharing**
- "이 클라이언트 신뢰도 90점" 커뮤니티 평가
- "결제받았다!!" 성공 사례 공유

**Monetization**
- 기본 무료: 신뢰도 조회
- 프리미엄 €4.99/month: 자동 독촉 + 법률 자문

**MVP**
- Upwork/Fiverr/Wise API 통합
- 신뢰도 점수 계산 규칙 (결제 지연율 + 분쟁 이력)
- 커뮤니티 (Supabase)

**MVP 예상 비용**
- API 비용: €150/month
- 개발: 6주 (1인)

**가장 큰 약점**
- 이미 존재: S022에서 "엔터크레딧" 확인됨 (미수금 추적 + 커뮤니티)
- 차별화 불명확: S022와 정확히 동일한 구조

**가장 중요한 검증 가설**
"S022(엔터크레딧) vs 우리 제품의 차별화는 무엇인가?" → **조정 필요**

## Idea 003. 배달점주 매일 마진율 미니게임 (Daily Margin Mini-Game)

**한 줄 설명**
배달점주가 "매일 1분" 자신의 메뉴별 마진율을 게임처럼 최적화하는 앱

**해결하는 Pain**
- P003: 배달앱 수수료 26% (월 매출의 최대 45%)
- P007: 일본 음식점 영업이익률 8.6%

**제공하는 Positive Experience**
- S021: 배달점주 매일 1분 재주문율 확인 (CEO Directive 예시와 정확히 부합)
- S029: 급여 즉시 지급 매일 체크인 (매일 확인 습관)

**Target User**
배달앱 가맹점주, 중소 음식점 사장 (월 매출 836만원 이하)

**왜 설치하는가**
배달앱 수수료를 못 피할 수 없지만, "어느 메뉴를 팔면 이익이 날까"를 매일 실시간으로 알려줌

**첫 30초**
- "오늘 가장 이익이 높은 메뉴는? 🎮"
- 메뉴 4개 노출 + 마진율 게이지 → 탭 (5초)
- "완료! 오늘 조언: 치킨스테이크를 메인 추천으로 올리세요" → 자동 배달앱 업데이트 제안

**핵심 기능**
1. 배달앱 POS 자동 연동 (판매 데이터 실시간)
2. 식재료 가격 자동 추적 (공급사 API)
3. 메뉴별 마진율 자동 계산
4. "매일 1분 미니게임": 상위 3개 메뉴 클릭 (점수 획득)
5. 게임 점수 → 실제 마진율 최적화 조언 변환
6. 자동 배달앱 "추천 메뉴" 순서 조정

**핵심 사용 루프**
오픈 → 미니게임 (1분) → 점수 획득 → 조언 받음 → 메뉴 재정렬 → 다음날 다시

**반복 사용 이유**
- "매일 갱신되는 마진율" → 매일 확인 강제
- "점수가 높을수록 수익이 난다"는 심리
- 영업 시간 전에 "오늘의 최적 메뉴" 확인

**Personalization**
- 점주의 식재료 선호 공급사 학습
- 지역별/시간대별 메뉴 최적화

**AI 역할**
- 식재료 가격 변동 예측
- 메뉴별 수익성 실시간 계산
- 최적 메뉴 조합 추천 (경제학적 모델)

**Sharing**
- "오늘의 최고 마진 메뉴 TOP3" 카톡방에 공유
- "이번 달 누적 추가 수익 €150,000" 자랑

**Monetization**
- 기본 무료: 미니게임 + 기본 조언
- 프리미엄 €9.99/month: 
  - 자동 배달앱 메뉴 순서 재정렬
  - 공급사 가격 자동 협상 제안
  - 점주 커뮤니티 (고수 팁 공유)

**MVP**
- 배달의민족/쿠팡이츠/배긱 API 연동
- 식재료 가격 데이터 (관세청 공개 정보)
- 마진율 계산 엔진
- 미니게임 UI (웹/앱)

**MVP 예상 비용**
- 배달앱 API 협상: 시간

- 개발: 4주 (1인)
- 운영: €300/month

**가장 큰 약점**
- 배달앱 API 협력 필수 (배달의민족 승인 받아야 함)
- 기존 경쟁: Shoplinker (다중 채널 관리) — 하지만 "게임화" 없음

**가장 중요한 검증 가설**
"점주가 '미니게임'을 매일 실행하고, 실제 메뉴 개선으로 수익이 5% 이상 증가하는가?"
