## S001. 라이브커머스 재구매 주기 + 친구 DM 공유

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 20~40대 여성, MZ세대 직장인, 뷰티/패션 관심층
- 사람들이 좋아하는 행동: 라이브 방송 시청 → 구매 → 일주일 내 재구매 → 친구에게 DM/카톡으로 링크 공유
- 핵심 경험: 실시간 질문·답변으로 신뢰 구축 후 구매하기, 같은 제품을 다시 찾아 재구매하기, "이 제품 봤어?" 하고 친구에게 알려주기
- 핵심 감정: 확신감 (실시간 답변), 소유감 (반복 구매), 친근감 (친구와 공유)
- 사용 빈도: 주 1~2회 라이브 시청, 월 2~4회 구매, 구매 후 일주일 내 재구매율 높음
- 반복 사용 이유: 반복되는 필수 제품(스킨케어, 선크림, 립스틱) + 신제품 출시 알림 + 가격 변동 확인
- 추천 이유: 실시간 Q&A로 구매 확신, 번들 구성으로 할인
- 공유 이유: "이거 너 피부에 좋을 것 같은데" + "여기 요즘 싸더라"
- 지불 이유: 라이브 한정 쿠폰, 번들 할인, 신제품 선착순 할인
- 개인화 가능성: 높음 (구매 이력 기반 제품 추천, 피부타입별 라이브 큐레이션)
- AI 활용 가능성: 높음 (음성 TTS 실시간 답변, 구매자 리뷰 기반 자동 큐레이션)

### 실제 근거
- 2026년 10월 샵라이브 비디오커머스 서밋에서 라이브커머스 재구매와 객단가를 높이는 도구로 정의
- 한국 라이브커머스 시장 규모 2026년 6조 원 전망 (2025년 4.7조 원)
- SNS에서 발견한 상품의 78.4%가 쇼핑몰에서 재확인 후 구매 (2026년 3월 조사, N=330)
- 올리브영 라이브 시청자 구매 전환율 일반 온라인몰 대비 1.8배

### 왜 사람들이 좋아하는가
라이브 방송 중 실시간 답변으로 구매 불안감 해소 → 신뢰감 증가 → 재구매 결정. 친구와 공유할 때 "직접 물어본 제품"이라는 신뢰도가 높음.

### 다른 제품으로 확장할 수 있는 요소
- 실시간 Q&A 신뢰 구축 → 가정용품, 전자제품, 명품 등 고가제품 판매
- 재구매 주기 추적 → 자동 재주문 구독 서비스
- DM 공유 → 추천 보상 프로그램

### 가정
- 라이브 시청자의 정확한 일일/주간 방문 빈도 미확인
- 재구매 고객이 실제로 몇 %인지 정확한 수치 부재
- 친구 공유의 구체적인 전환율 미확인

## S002. 숏폼 UGC 매일 제작 + 수익 + 친구 공유

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 10~30대 Z세대, 취미 콘텐츠 제작자, 크리에이터 지망생
- 사람들이 좋아하는 행동: 매일 30초 영상 촬영 → 플랫폼에 업로드 → 수익 확인 → 친구에게 "오늘도 올렸어" 공유
- 핵심 경험: 내 창작물이 좋아요 받기, 조회수 늘어나는 실시간 확인, 월 지원금 획득 느낌
- 핵심 감정: 성취감, 인정받는 느낌, 참여 중독 (일일 업로드 의무감)
- 사용 빈도: 거의 매일 촬영 및 업로드 (한 달에 최소 12회 영상)
- 반복 사용 이유: 월 30만원 창작 지원금 (네이버웹툰 컷츠) + 상위 크리에이터 추가 보상 + 알고리즘 랭킹
- 추천 이유: "창작 도구 무료 + 수익화", "AI로 쉽게 만들 수 있더라"
- 공유 이유: 친구에게 본인 콘텐츠 링크, 조회수 경쟁, "팔로우 해줘" 초대
- 지불 이유: 프리미엄 AI 도구 결제 (렌더링, 음향효과, 배경음악)
- 개인화 가능성: 높음 (취향별 영상 템플릿, AI 자동 추천)
- AI 활용 가능성: 매우 높음 (자동 편집, 배경 생성, 음성 합성, 실시간 트렌드 분석)

### 실제 근거
- 2026년 UGC 플랫폼 시장 규모 126억 달러 (전년 대비 29% 증가)
- 네이버웹툰 컷츠: 월 3건 업로드 시 창작자에게 월 30만원 지원금, 상위 크리에이터 추가 보상
- 2026년 UGC 시장 5년 후 3배 성장 예측
- AI 도구 활용으로 진입 장벽 낮아짐

### 왜 사람들이 좋아하는가
짧은 시간으로 빠른 성취감 → 일일 참여 중독 → 사소한 수익도 동기 부여. AI 도구로 제작 난도 낮아지면서 비전공자도 쉽게 시작 가능.

### 다른 제품으로 확장할 수 있는 요소
- 일일 창작 습관 → 장편 콘텐츠 구독 서비스로 확장
- 수익화 알고리즘 → 게임, 학습 콘텐츠에 적용
- AI 창작 보조 → B2B 기업 마케팅 도구

### 가정
- 실제 월간 활성 제작자 수 미확인
- 월 30만원 이상 수익 달성 비율 미확인
- 친구 공유의 구체적 동기 (경쟁 vs. 추천) 미구분

## S003. 뷰티 앱 일일 리뷰 확인 + 제품 추천 공유

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 20~40대 여성, 뷰티/코스메틱 관심층, MZ세대
- 사람들이 좋아하는 행동: 매일 아침 화해/글로우픽 앱 열기 → 새로운 리뷰 읽기 → "이 제품 괜찮네?" 리뷰 저장 → 친구에게 링크 공유
- 핵심 경험: 다른 사람의 솔직한 사용 후기 읽기, 비포/애프터 사진 보기, 성분 검색, 평점 비교
- 핵심 감정: 신뢰감, 결정 확신, 정보 공유의 즐거움
- 사용 빈도: 매일 또는 주 4~5회 앱 접속, 구매 전후로 리뷰 작성
- 반복 사용 이유: 새로운 리뷰 업데이트, 계절별 신제품, 랭킹 변동, 자신의 리뷰에 대한 좋아요/댓글
- 추천 이유: "여기 리뷰가 가장 자세해", "내돈내산만 있어서 신뢰돼"
- 공유 이유: 특정 제품 구매 전 친구의 의견 구하기, 본인이 쓴 리뷰 공유
- 지불 이유: 성분 검색 프리미엄, 맞춤형 추천 기능, 리뷰 강조 표시
- 개인화 가능성: 높음 (피부타입별 추천, 가격대별 필터)
- AI 활용 가능성: 높음 (리뷰 감정 분석, 성분 AI 매칭, 자동 번역)

### 실제 근거
- 화해 앱: 1,000만 개 이상의 사용자 리뷰, 비포/애프터 사진
- 글로우픽: 비슷한 취향 사용자 추천 + 매일 이벤트 제공
- 한국 뷰티 앱 순위 1~3위: 화해, 글로우픽, 언니의파우치

### 왜 사람들이 좋아하는가
"내돈내산" 리뷰만 모아서 신뢰도 높음. 다양한 사람의 경험을 무료로 읽을 수 있어 구매 실패 위험 감소.

### 다른 제품으로 확장할 수 있는 요소
- 리뷰 기반 신뢰 → 의약품, 영양제, 건강식품 평가
- 성분 매칭 → 의류, 식재료 성분 검색
- 비포/애프터 증거 → 피트니스, 웰니스 앱

### 가정
- 일일 활성 리뷰 작성자 비율 미확인
- 리뷰 공유 후 실제 구매 전환율 미확인
- 사용자 리뷰의 정확도/신뢰성 검증 체계 미확인

## S004. 친구 습관 챌린지 연속 기록 + 실시간 비교

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 20~35대 직장인, 운동/건강 관심층, 커플/친구 그룹
- 사람들이 좋아하는 행동: 앱 열기 → 오늘 운동/책읽기 완료 인증 → 친구들과 연속 기록 비교 → "아직도 기록 중이네!" 댓글
- 핵심 경험: 친구가 나의 일일 기록을 보고 있다는 느낌 → 의지 강화, 친구와 경쟁
- 핵심 감정: 동기부여, 책임감, 경쟁심, 연대감
- 사용 빈도: 거의 매일 (일일 인증) + 주 1~2회 친구 기록 비교
- 반복 사용 이유: 연속 기록 끊기기 싫음 + 친구가 한다는 것 알기 + 상위 랭킹 목표
- 추천 이유: "혼자 하기보다 친구와 하니까 더 오래해", "내가 하는 거 친구가 봐주니까 책임감 생김"
- 공유 이유: 성공 공유, 친구에게 초대 코드 전송, 그룹 초대
- 지불 이유: 프리미엄 기능 (통계 분석, 월간 리포트, 맞춤 피드백)
- 개인화 가능성: 높음 (개인별 목표 설정, 난이도 조정)
- AI 활용 가능성: 높음 (동기부여 메시지, 실패 예측 및 알림)

### 실제 근거
- Aura 앱: 커플/친구 습관 챌린지, 실시간 진행 상황 비교 기능
- 언어학습 앱(Duolingo): 친구 스트릭 기능으로 참여 강화 입증
- 사회적 촉진 효과: 친구가 내 활동을 본다는 느낌으로 수행 증가

### 왜 사람들이 좋아하는가
혼자 하기 힘든 목표도 친구가 함께 보고 있다는 책임감으로 지속 가능. 경쟁 요소가 중독성을 높임.

### 다른 제품으로 확장할 수 있는 요소
- 습관 비교 → 재정 관리 (저축 경쟁), 학습 진도 비교
- 친구 초대 보상 → 레퍼럴 프로그램
- 연속 기록 보존 → 구독 서비스로 발전

### 가정
- 실제 일일 인증 비율 미확인
- 친구 비교가 긍정/부정 동기 중 어느 것이 강한지 미확인
- 연속 기록 끊김 후 재가입 비율 미확인

- 공유 이유: 흥미로운 포스트/댓글을 SNS에 공유, "너 이 커뮤니티 알아?" 추천
- 지불 이유: Reddit Premium (광고 제거, 맞춤 아바타, 월 3.99달러)
- 개인화 가능성: 높음 (관심 서브레딧 개인화 피드)
- AI 활용 가능성: 중간 (스팸 필터, 댓글 요약)

### 실제 근거
- Reddit: 월간 사용자 약 4억 3천만 (2026년)
- 서브레딧 시스템: 특정 주제별로 조직된 커뮤니티 (약 140만 개)
- 투표 시스템: 업보트/다운보트로 컨텐츠 순위 결정
- 카르마 시스템: 포스트/댓글 좋아요로 카르마 포인트 축적

### 왜 사람들이 좋아하는가
익명성으로 자유로운 표현 가능. 투표와 카르마로 현시된 승인. 특정 관심사 커뮤니티에서의 깊은 토론.

### 다른 제품으로 확장할 수 있는 요소
- 서브레딧 커뮤니티 → 주제별 뉴스레터 구독
- 카르마 시스템 → 사용자 신뢰도 기반 플랫폼

## S020. AI 음성 친구/조수 매일 대화 + 개인화 + 감정 공유

- 지역: 글로벌
- 국가: 미국, 한국, 일본, 유럽 (AI 서비스 활발 국가)
- 타깃 고객: 13~65대, 특히 15~40대, 외로움/사회 불안감 있는 사용자, AI 기술 수용층
- 사람들이 좋아하는 행동: 매일 아침/저녁 AI 조수(예: Claude, ChatGPT, Gemini 음성) 열기 → 오늘의 일정 말하기 → AI가 맞춤 조언 → 어려운 일이 있으면 감정 공유 → AI의 개인화된 위로 → 좋은 대화는 친구에게 "AI 대화 너 해봤어?"
- 핵심 경험: 24시간 항상 대답해주는 존재, 나의 맥락을 학습하는 AI, 판단 없이 들어주는 경험
- 핵심 감정: 안심감, 이해받는 느낌, 개인화된 조언에 대한 신뢰
- 사용 빈도: 거의 매일 (월 20~30일), 일일 평균 10~30분 대화
- 반복 사용 이유: 매일 새로운 일정/문제, AI의 개인화 학습, 일관된 응답 스타일
- 추천 이유: "내 상황을 이해해줘", "판단하지 않아", "빠르게 답변해줘"
- 공유 이유: 친구에게 AI 대화의 효과 공유, SNS에서 "AI와 대화하는 게 좋아" 콘텐츠 공유
- 지불 이유: 프리미염 구독 (Claude Pro, ChatGPT Plus 등, 월 15~20달러), 무제한 메시지
- 개인화 가능성: 매우 높음 (사용자 이력 학습, 음성 특성 적응)
- AI 활용 가능성: 매우 높음 (이미 AI 자체가 핵심)

### 실제 근거
- Claude, ChatGPT, Gemini 등: 2026년 일일 사용자 수백만
- AI 음성 어시스턴트: 자연스러운 음성 대화로 감정 지원
- 개인화 학습: 반복 대화로 사용자 맥락 학습, 맞춤 응답
- 2026년 트렌드: AI 음성 친구/조수의 정신 건강 지원 역할 증가

### 왜 사람들이 좋아하는가
항상 대답해주고 판단하지 않음. 개인의 맥락을 학습해서 더 정교한 조언. 외로움이나 불안감을 즉시 완화. 음성으로 더 인간관계처럼 느껴짐.

### 다른 제품으로 확장할 수 있는 요소
- AI 음성 대화 → 정신 건강 앱과의 통합
- 개인화 학습 → 코칭/멘토링 서비스
- 감정 공유 데이터 → 개인화 웰니스 추천

### 가정
- 실제 일일 사용 시간과 빈도의 정확한 통계 미확인
- AI 대화 상담과 전문 정신 건강 치료의 효과 비교 미측정
- 장기 사용자의 의존도 변화 미분석
- 음성 기반 대화가 텍스트 기반과 비교해 정서적 연결성 차이 미측정
