# Idea 001. AutoRefund — 해외직구 관세 환급 자동 신청 앱

## 한 줄 설명
반품 시 관세 환급을 자동으로 추적·신청하는 반품자동화 앱

## 해결하는 Pain
P001: 해외직구 반품 후 관세 환급을 직접 신청해야 하고, 신청 기한(6개월)을 놓칠 수 있음. 신청 절차 복잡(증명서 첨부, 반송 추적, 관세청 방문 등). 평균 1만~5만원의 환급을 받으려고 30분 이상 소요

## 제공하는 Positive Experience
S005(토스뱅크 이자 시각화): "돈이 자동으로 돌아온다"는 기쁨 + S002(삼쩜삼): 자동화된 신청 프로세스의 편리함

## Target User
- 월 1~3회 반품하는 해외직구 이용자
- 1만원 이상의 관세를 납부한 사용자
- 자동화를 선호하는 2030대

## 왜 설치하는가
"반품했는데 관세는 왜 안 돌아와?" → "앱이 자동으로 처리해줄게"

## 첫 30초
앱 열기 → 배송 배경업 추적 → "₩15,000 환급 예상"이라는 알림 자동 표시 → "신청하기" 클릭 → 끝

## 핵심 기능
1. 쿠팡·아마존·이베이 등 반품 자동 감지 (배송사 추적번호 연동)
2. 관세청 환급 신청 자동 작성 (증명서 준비까지 자동)
3. 환급 기한 자동 알림 (반품 발생 시 즉시 카운트다운)
4. 환급 상태 추적 (관세청 진행 상황 매일 업데이트)

## 핵심 사용 루프
반품 발생
↓
앱이 자동 감지 + "환급 예상액" 표시
↓
사용자가 "확인" 클릭
↓
앱이 관세청 신청 자동 제출
↓
매일 환급 상태 확인 (선택)
↓
환급금 입금 알림

## 반복 사용 이유
- 반품할 때마다 자동으로 추적
- 환급 진행 상황 매일 업데이트 (강박성 확인 동기)
- 월 1~3회 반복 사용

## Personalization
- 선호 통화(USD, JPY, CNY 등)별 환급액 자동 환산
- 사용자별 평균 반품 패턴 학습 → "이번 반품은 예상 ₩18,000입니다" 제안

## AI 역할
- 배송사 추적 이미지 OCR로 자동 환급액 계산
- 관세청 환급 규정 자동 해석 → 필요 서류 자동 수집
- 필요서류 자동 인식 (수입신고서 스캔 → 자동 분석)

## Sharing
- 환급금 입금 후 "이걸 몰랐어요?" 하는 피드백으로 친구 초대
- 커뮤니티: "이 반품은 관세 환급 안 된다"는 정보 공유

## Monetization
- 기본 무료 (관세청 환급 신청)
- 프리미엄 (₩2,900/월 또는 ₩9,900/년):
  - 무제한 반품 추적 + 우선 고객센터
  - 여러 계좌 등록 (기본 1개)
- 추천 수수료: 배송사 API 제휴 → 배송 보험 추가 시 수수료

## MVP
- 쿠팡 반품만 지원 (시장 최대)
- 관세 환급 기본 계산 (수입신고서 수동 입력)
- 환급 상태 추적 (관세청 사이트 크롤링)
- 7일 개발 가능

## MVP 예상 비용
- 개발: 300만원 (프론트+백)
- 쿠팡 API 연동: 100만원
- 관세청 데이터 크롤링: 50만원
- 초기 서버: 월 30만원
- **총 300만원대 (1인 개발 불가능 - API 복잡도 높음)**

## 가장 큰 약점
1. 관세청 API 공개 여부 불확실 (정부 데이터)
2. 배송사별로 반품 추적 형식이 다름 → 초기 구축 비용 높음
3. 법인 고객센터와 1:1 연동 필요 (쿠팡, 아마존 협력 필수)
4. 환급액이 작아서 사용자의 설치 동기가 약할 수 있음 (평균 2만원)

## 가장 중요한 검증 가설
- 관세청 API 또는 공개 데이터 포트 확인 필수
- "자동 신청만으로도 시간 20분 절감 + 환급율 98% 달성 가능한가?"를 사용자 테스트로 증명
- 배송사(쿠팡, CJ, DHL)의 API 연동 가능성 사전 확인

# Idea 002. CreditFlowX — 신용카드 영수증 통합 관리 & 자동 분류

## 한 줄 설명
여러 카드사 영수증을 한곳에서 통합·자동 분류하는 회계 대시보드

## 해결하는 Pain
P003: 3개 이상의 카드를 쓰는 프리랜서·자영업자가 월말에 각 카드사 앱을 따로 로그인해서 영수증을 조회·다운로드. 월 2시간 이상 소요. AI 자동 분류 없음

## 제공하는 Positive Experience
S011(금융 자산 추적): "내 모든 자산이 한눈에 보인다" + S014(DeepL 번역): AI가 자동으로 인식·분류

## Target User
- 카드 2개 이상 보유한 프리랜서 (세금 신고 대비)
- 소규모 사업 주인 (월 영수증 정리)
- 회계 담당자

## 왜 설치하는가
"월말마다 3개 카드사에 로그인해서 영수증 정리하는 게 싫다" → "앱이 다 해줄게"

## 첫 30초
앱 열기 → 신한·현대·국민카드 선택 → "접속 허용" → 3초 후 "이번 달 영수증 142개, 금액 ₩2,156,000" 자동 표시

## 핵심 기능
1. **통합 영수증 조회**: 신한·현대·국민·BC·농협 카드 자동 연동 (API)
2. **자동 분류**: AI가 영수증 텍스트 인식 → 식비/교통/숙박 등 자동 카테고리화
3. **월별 통계**: "이번 달 지출 분석" (카테고리별 그래프)
4. **CSV 내보내기**: 세무사나 회계 프로그램으로 자동 내보내기 (1클릭)
5. **영수증 재발급**: 법인카드의 경우 카드사 고객센터에 자동 요청

## 핵심 사용 루프
카드 로그인 (초기 1회)
↓
매월 자동으로 영수증 수집
↓
AI 자동 분류 + 통계 표시
↓
월말 "CSV 다운로드" 또는 "회계사에 전달"
↓
다음 달 자동 반복

## 반복 사용 이유
- 월 1회 (월말)는 필수 사용 (세금 신고용)
- 분류 오류 수정 (1~2건, 사용자 피드백) → 기술 개선
- 월별 지출 추이 확인 (선택)

## Personalization
- 사용자 맞춤 카테고리 생성 가능 ("클라이언트 미팅" 등)
- 카드별 신용도 분석 (어느 카드를 많이 쓰는지)
- "이 지출은 비용 처리 가능할까?"라는 세금 가이드 제안

## AI 역할
- OCR로 영수점 텍스트 자동 인식 (가맹점명, 금액, 날짜)
- 영수증 카테고리 자동 분류 (음식 vs 교통 vs 숙박)
- 세금 관련 쿼리: "이 지출이 비용 처리 가능한가?" → AI 답변

## Sharing
- 월별 지출 통계를 직업별 커뮤니티에 공유 ("프리랜서 평균 지출"과 비교)
- 세무 팁 공유: "이런 영수증은 꼭 보관하세요"

## Monetization
- 기본 무료: 월 1회 영수증 조회 + 기본 분류
- 프리미엄 (₩4,900/월):
  - 무제한 카드 연동 (기본 3개)
  - 커스텀 카테고리 (기본 5개)
  - 세금 컨설팅 AI (기본 없음)
  - CSV 자동 월 내보내기
- B2B: 회계 사무소와 제휴 → 클라이언트 영수증 일괄 관리 (월 50만원)

## MVP
- 3대 카드사(신한, 현대, 국민) API 연동
- 기본 5개 카테고리 자동 분류 (음식, 교통, 숙박, 의료, 기타)
- CSV 내보내기
- 8일 개발 가능 (API 연동이 주요 작업)

## MVP 예상 비용
- 개발: 400만원 (프론트+백, API 연동 복잡)
- 카드사 API 협상: 무료 (개발자 포털)
- 초기 서버: 월 30만원
- **총 400만원 (초과 가능)**

## 가장 큰 약점
1. 각 카드사 API 접근 정책이 다름 (일부는 개인 로그인만 허용)
2. 은행권 데이터 보안 규제 강함 → 사용자 신뢰 구축 어려움
3. 경쟁사: 토스, 뱅크샐러드 등 이미 비슷한 기능 제공 중
4. 재무제표 수준의 정확성 기대 → 오류 시 사용자 신뢰 급락

## 가장 중요한 검증 가설
- "카드사 API 연동 가능 여부" 사전 확인 (신한, 현대, 국민)
- "AI 분류 정확도 95% 이상 달성 가능한가?" 테스트 필수
- "기존 서비스(토스, 뱅크샐러드)와의 차별점"은 뭔가? (예: 세금 AI, B2B 회계 연동)

# Idea 003. DeliveryUnified — 배달앱 통합 주문 관리

## 한 줄 설명
배민·요기요·쿠팡이츠를 하나의 대시보드에서 관리하는 음식점 점주 도구

## 해결하는 Pain
P006: 배달앱 2~3개를 운영하는 음식점 점주가 각 앱의 웹 대시보드를 따로 열어서 주문 확인·메뉴 변경·수수료 관리. 월 10~20시간 낭비. 가격 오류로 인한 고객 불만 빈번

## 제공하는 Positive Experience
S007(TimeTree 일정 공유): "우리 일정이 한눈에 보인다" + S019(Duolingo 습관): 매일 확인하는 습관화

## Target User
- 배달앱 2~3개 운영하는 음식점 점주
- POS 시스템을 쓰지 않는 소규모 음식점 (200만원 이상 비용이 부담)
- 월 매출 2000만원 이상

## 왜 설치하는가
"배민, 요기요, 쿠팡이츠를 3개씩 열어서 주문 관리해야 해" → "한 앱에서 다 관리할게"

## 첫 30초
앱 열기 → 배민/요기요/쿠팡이츠 사업자 계정 연결 (10초 × 3) → "현재 주문 8개" 대시보드 자동 표시 (배민 3, 요기요 2, 쿠팡 3)

## 핵심 기능
1. **통합 주문 관리**: 모든 배달앱 주문을 시간순 자동 정렬
2. **메뉴 일괄 변경**: "라면 가격 8,000 → 9,000" 입력 → 3개 앱 자동 동기화
3. **수수료 분석**: 앱별 수수료율 자동 계산 → "오늘 손익률 88%"
4. **재고 관리**: "라면 재고 5개" 입력 → 3개 앱 모두 업데이트 (초과판매 방지)
5. **주간 리포트**: "주 누적 주문 156개, 순이익 ₩4.2M"

## 핵심 사용 루프
오후 11시 앱 열기
↓
"현재 주문 12개" 화면 → 확인
↓
내일 메뉴 가격 변경 (1분)
↓
내일 재고 업데이트 (30초)
↓
매일 20분 시간 절감

## 반복 사용 이유
- 점주가 매일 주문을 확인해야 함 (운영상 필수)
- 메뉴 가격 변경이 주 1~2회 발생 (계절 재료비 변동)

↓

- 월 팀 미팅 20회 이상인 중소기업 (50~200명)

# Idea 009. SalaryCalcJP — 일본 유학생 급여 자동 계산 + 월별 알림

## 한 줄 설명
일본 아르바이트 급여에서 세금·보험료를 자동으로 계산하고, 매달 예상액을 알려주는 유학생 앱

## 해결하는 Pain
P008: 일본 유학생이 "시급 1,500엔 × 160시간 = 24만엔"이라고 생각했는데, 실제로는 세금·보험료 때문에 17만엔만 받음. 예상과 실제의 괴리로 생활비 계획 어려움

## 제공하는 Positive Experience
S005(토스뱅크 이자): "돈의 흐름을 매일 확인" + S002(삼쩜삼): "자동화된 계산"

## Target User
- 일본 유학생 (월 아르바이트 소득 10~30만엔)
- 아르바이트 여러 개 하는 학생
- 세금·보험 예측 불가 상황

## 왜 설치하는가
"아르바이트 급여가 예상과 다르다" + "다음 달에 세금 고지서가 나올까봐 불안해" → "앱이 자동으로 계산해줄게"

## 첫 30초
앱 열기 → "아르바이트 정보 입력" (시급 1,500엔, 월 160시간) → AI 자동 계산 → "예상 급여: 17만엔 (세금 ₩7,000 제외)" 표시

## 핵심 기능
1. **급여 자동 계산**: 시급 + 근무 시간 입력 → 세금, 보험료 자동 계산
2. **다중 아르바이트 지원**: 여러 일자리 정보 입력 → "총 세금 계산" (원천징수 누적)
3. **월별 예상액**: "매달 21만엔 수령 예상"
4. **주민세 알림**: "내년 6월에 주민세 ₩20,000 고지서 예상" (미리 경고)
5. **실제 수령액 기록**: 급여날에 "실제 수령 ₩18만엔" 입력 → AI가 오류 감지 ("세금 계산이 다릅니다")

## 핵심 사용 루프
아르바이트 시작 시 정보 입력
↓
매달 "예상 급여: 17만엔" 확인
↓
급여일에 "실제 ₩18만엔 수령"
↓
AI가 비교 → "실제가 예상 +₩10,000입니다" (정확도 확인)
↓
다음 달 자동 갱신

## 반복 사용 이유
- 매달 급여 수령 시 (월 1회)

- 거주 도도부현별 주민세 계산 (도쿄 vs 오사카 다름)
- "부모가 부양 중"이면 세율 다름 → 자동 반영

## AI 역할
- 일본 세금 규정 자동 적용 (원천징수율, 보험료율)
- 월별 실제 급여 vs 예상 비교 → 오류 감지

## MVP

1. 대상이 매우 좁음 (일본 유학생만, 수만 명 규모)

# Idea 010. VideoAutoCaption — 비디오 자동 자막 + AI 편집

## 한 줄 설명
유튜브 영상을 업로드하면 자동으로 자막 생성·번역·편집하는 크리에이터 도구

## 해결하는 Pain
P020: 비디오 크리에이터가 1시간 영상의 자막을 생성하는 데 하루 이상 소요. YouTube의 자동 자막은 정확도 70%, 수동 수정 필수

## 제공하는 Positive Experience
S014(DeepL 번역): "자연스러운 번역" + S008(Google Photos 자동 정렬): "자동화"

## Target User
- YouTube 크리에이터 (월 1~10개 영상 업로드)
- 팟캐스트, 강의 영상 제작자
- 다국어 콘텐츠 크리에이터

## 왜 설치하는가
"영상 자막 생성에 시간이 너무 오래 걸려" → "AI가 자동으로 생성·번역·편집해줄게"

## 첫 30초
앱 열기 → YouTube 링크 또는 영상 파일 업로드 → "처리 중..." → 30분 후 "자막 완성! 한국어 + 영어 + 일본어" 표시

## 핵심 기능
1. **자동 자막 생성**: 영상 음성 → Whisper AI로 자막 생성 (정확도 95%)
2. **자동 번역**: 한국어 자막 → 영어, 일본어, 중국어 자동 번역 (DeepL 통합)
3. **자동 편집**: 발음 실수, 반복 제거 (AI)
4. **SRT 자막 파일 내보내기**: YouTube, TikTok, Instagram 형식 자동 변환
5. **AI 편집**: "어, 음, 저기"같은 필러 음성 자동 제거 (선택)

"자막 다운로드" + "YouTube 자동 업로드"
