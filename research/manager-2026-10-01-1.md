# Idea 001. 야근팍팍 — 미지급 야근비 자동추적 & 일일 리포트

## 한 줄 설명
출퇴근 자동 연동, 매일 야근비 시각화, 법적 증거 자동생성.

## 해결하는 Pain
P001: 직장인의 83%가 야근하지만 75%는 야근비를 받지 못함. 증거 수집과 청구 절차가 복잡하고, 회사 내 낙인 우려로 요청 자체가 어려움.

## 제공하는 Positive Experience
S001, S014: 앱테크처럼 매일 "오늘의 미지급 야근비"를 확인하는 의례감 + Streaks처럼 "누적 미지급 시간" 스트릭 유지

## Target User
비정규직/중소기업 근로자, 월 20시간 이상 야근하는 직장인 (특히 20~40대)

## 왜 설치하는가
현재 방법은 엑셀 수동정리 → 회사와 분쟁 → 소송. 이 앱은 "자동 기록 + 법적 근거 제시 + 청구 템플릿" 제공. 직장 내 낙인 없이 객관적 증거 수집 가능.

## 첫 30초
1. "당신의 회사는 포괄임금제입니까?" 선택
2. 회사 근태시스템(카드기반) 또는 휴대폰 GPS 선택 연동
3. 즉시 "당신의 미지급 야근비: ₩50만원(지난 3개월)" 표시

## 핵심 기능
1. **자동 출퇴근 추적**: 회사 근태 카드, 모바일 GPS, 이메일 발송시간 자동 수집
2. **포괄임금제 위반 감지**: 누적 야근시간이 법적 한계를 넘으면 자동 경고
3. **미지급액 자동계산**: 통상임금 기준, 50% 가산수당 자동 계산
4. **증거 자동정리**: 출퇴근 기록 + 야근시간 + 미지급액 → PDF 리포트
5. **법적 조언 AI**: "언제까지 청구 가능한가?", "회사와 분쟁 시 단계별 절차" 제시

## 핵심 사용 루프
Trigger: 퇴근 시 앱 자동 실행
→ Action: 오늘의 야근 2시간 기록 확인
→ Reward: "이번 주 미지급비 ₩15만원 증가" 시각화 + 스트릭 +1
→ Investment: 매달 데이터 축적 (6개월 = 증거 자료 완성)
→ Next Trigger: 내일도 퇴근 후 확인 → "미지급액이 ₩50만원 넘으면 청구하자"는 목표

## 반복 사용 이유
- 매일 새로운 야근 기록이 쌓임
- 누적액이 커질수록 "본전 뽑으려면 청구해야 한다"는 심리
- 주간/월간 리포트로 진행 상황 시각화
- "이제 충분한 증거가 모였나?" 체크 루틴

## Personalization
- 회사별 포괄임금 규정 자동 학습 (AI가 해당 회사의 최근 판례 수집)
- 직급/부서별 평균 야근시간 비교
- 개인의 야근 패턴 분석 (월~금 야근 집중, 특정 프로젝트 시기 증가 등)

## AI 역할
1. **포괄임금제 위반 자동 감지**: 법적 판례 + 현황 비교 → "당신의 회사는 불법적입니다" 판정
2. **미지급액 예측**: 6개월 누적 데이터로 "내년 연봉에서 ₩200만원 손실 예상" 제시
3. **법적 조언**: "근로기준법 56조에 따르면...", "노동청 진정 vs. 소송" 단계별 가이드

## Sharing
- 친구/동료에게 "내 미지급액 비교" 공유 (프라이빗 그룹)
- "이번 달 야근비 청구 성공했어" 후기 SNS 공유 (익명)
- 회사별 포괄임금 위반율 통계 공개 (일종의 사회 공시)

## Monetization
**Free Tier**: 3개월 데이터 자동 추적, 기본 미지급액 계산
**Pro (₩4,900/월)**: 
- 12개월 데이터 보관
- 법적 조언 AI 무제한
- 회사와 분쟁 시 변호사 상담 연결 (5회/월, 제휴)
- PDF 리포트 자동 생성
**Enterprise (₩99,000/년 회사 라이선스)**:
- HR팀이 직원 야근관리 대시보드
- 규정 자동 준수 모니터링

## MVP
1. **기본 추적**: 수동 입력 + 카드 기반 자동 연동 (국민카드 등 주요 회사만)
2. **계산 엔진**: 포괄임금제 위반 여부 판정 (법적 DB 기반)
3. **리포트 생성**: PDF 다운로드
4. **법적 가이드**: 자주 묻는 질문(FAQ) 형식

## MVP 예상 비용
₩2,000,000 ~ ₩2,800,000
- 백엔드(DB, 계산 엔진): ₩800,000
- 모바일 앱(iOS/Android): ₩1,000,000
- 법적 DB 정리(변호사 자문): ₩500,000
- 카드사 API 연동(기술): ₩400,000

## 가장 큰 약점
1. **회사 근태시스템 API 개방**: 대부분의 회사가 폐쇄적이므로, 초기에는 "수동 입력"에 의존해야 함. 이는 사용자 진입 장벽을 높임.
2. **법률 변수**: 판례가 계속 바뀌므로, AI 법적 조언의 정확성 유지가 어려움.
3. **회사의 반발**: 직원이 이 앱을 사용하면 회사와의 관계가 악화될 수 있다는 우려 (낙인 심리).

## 가장 중요한 검증 가설
"직장인이 증거 수집의 자동화만으로도 실제로 야근비를 청구할 용기를 낼 것인가?"
- 검증: 초기 베타 사용자 100명 대상 설문 → "청구 의향" 80% 이상이면 성공

# Idea 002. 똑똑한 통장 — 스마트 가계부 + AI 절감조언

## 한 줄 설명
은행 자동연동, 일일 소비분석, 맞춤 절감 제안.

## 해결하는 Pain
P002: 가계부 앱 은행 연동이 부족해서 사용자가 매일 수작업으로 입력해야 함. 현금 소비는 수동 입력 필수. 월 3~5시간 낭비.

## 제공하는 Positive Experience
S004, S008: 마이쉽단의 "AI 영양사가 내 몸을 위한 식단 제안"처럼, 이 앱은 "AI 재무 어드바이저가 당신의 소비 습관을 분석해 절감 방법 제안"

## Target User
월급생활자, 프리랜서, 개인사업자 (특히 저축 목표 있는 20~40대)

## 왜 설치하는가
현재: 은행 앱 + 카드 앱 + 가계부 앱 3개를 번갈아 봐야 함. 이 앱: 모든 게 자동이고, "당신은 왜 이렇게 카페에 자주 가는가?" 같은 AI 인사이트 제공.

## 첫 30초
1. 주요 은행/카드 선택 (국민, 우리, 신한, KB, 현대, 삼성 등)
2. 카카오페이/네이버페이 자동 연동
3. 즉시 "지난 30일 지출 ₩1,234,567 (평균 ₩1,050,000 vs 당신)" 표시

## 핵심 기능
1. **완전 자동 연동**: 은행 + 신용카드 + 체크카드 + 전자지갑 자동 수집
2. **AI 자동 분류**: 각 거래를 "카페", "교통", "의류", "외식" 등으로 자동 태깅 (오분류는 수동 수정)
3. **일일 절감 팁**: "오늘 카페비 ₩50,000 (평균 ₩25,000)? 집에서 커피하세요" 개인화된 알림
4. **소비 패턴 분석**: "당신은 월요일에 외식비가 30% 많습니다" + 원인 분석
5. **절감 목표 추적**: "이번 달 외식 줄이기" 목표 설정 → 진행률 실시간 업데이트

## 핵심 사용 루프
Trigger: 오전 8시 자동 실행 (또는 지출 발생)
→ Action: "어제 지출 ₩45,000, 당신 카테고리별 평균과 비교"
→ Reward: "이번 달 목표(외식 50% 절감)를 이대로면 달성!" + 스트릭 유지
→ Investment: 매일 소비 기록 축적 → AI가 더 정확히 학습
→ Next Trigger: 내일도 확인 → "절감 목표 달성하면 보상 포인트"

## 반복 사용 이유
- 매일 새로운 거래가 자동으로 들어옴
- "절감 목표"라는 명확한 목표가 있음
- "본달은 꼭 외식을 50% 줄여야 한다"는 심리
- 친구들과 비교 가능 (그룹 비교 기능)

## Personalization
- 개인의 소비 카테고리별 평균값 학습 (나이, 직급, 지역 기준 벤치마크 제공)
- "당신은 주말에 가구에 자주 지출합니다" → "홈데코 관심사 감지 후 추천"
- 계절별/이벤트별 소비 변화 패턴 학습 (명절, 휴가 시 예상 지출 증가 알림)

## AI 역할
1. **자동 분류**: 거래 설명글만 읽고 카테고리 + 서브 카테고리 자동 태깅
2. **절감 제안**: "당신의 카페비가 평균보다 80% 높습니다. 이 3곳의 카페를 줄이면 월 ₩150,000 절감 가능합니다" (맞춤형)
3. **이상거래 감지**: "이 거래는 사기 가능성이 있습니다" 자동 경고
4. **미래 예측**: "만약 현재 속도로 지출하면, 월말에 ₩2,000,000 적자입니다"

## Sharing
- 친구에게 "이번 달 나는 외식 30% 줄였어" SNS 공유
- "절감 챌린지" 그룹 만들기 (친구 5명 대상, 누가 가장 많이 절감했는지 경쟁)
- 가족 공동 계좌 공유 (부모-자녀 재정 건강도 공유)

## Monetization
**Free**: 30일 데이터, 기본 분류, 주간 리포트
**Plus (₩3,900/월)**: 
- 무제한 데이터 보관
- AI 절감 조언 무제한
- 소비 패턴 분석 (월/분기/연 기준)
- CSV 다운로드
**Premium (₩9,900/월)**: 
- 변호사 상담 연결 (신용카드 분쟁)
- 절감 목표 달성 시 캐시백 (제휴 은행)
- 투자 팁 제공 (절감액으로 투자하기)

## MVP
1. **주요 은행 연동**: 카카오뱅크, 국민은행, 우리은행 자동 연동
2. **자동 분류**: 사용자 수동 입력 학습 기반 AI (초기 50개 거래는 수동 분류)
3. **일일 리포트**: 지출 요약 + 이전 달 대비
4. **절감 목표**: 카테고리별 목표 설정 + 진행률

## MVP 예상 비용
₩2,500,000 ~ ₩3,200,000
- 백엔드(은행 API 연동): ₩1,000,000
- AI 분류 엔진: ₩800,000
- 모바일 앱: ₩900,000
- 은행 협력 초기화: ₩400,000

## 가장 큰 약점
**기존 경쟁사**: 네이버 가계부 (SMS 자동 입력), 뱅크샐러드 (자산 통합), 마이데이터 (은행 연동 표준).
- 네이버 가계부는 이미 월 사용자 수백만

## 가장 중요한 검증 가설
"AI 절감 조언이 실제로 사용자의 행동 변화(지출 감소)를 유도할 것인가?"

# Idea 003. 약관박사 — 렌탈계약 AI 해석 & 위험요소 자동감지

## 한 줄 설명
계약서 사진 → AI 해석 → 숨겨진 해지비용 노출.

## 해결하는 Pain
P003: 렌탈 계약(정수기, 공기청정기 등)에서 의무사용기간 후에도 숨겨진 해지비용이 청구됨. 약관이 복잡해서 사전에 알기 어려움. 평균 20~50만원 손실.

## 제공하는 Positive Experience
S002: AI가 프로필 사진을 여러 스타일로 변환하듯이, 이 앱은 "복잡한 약관을 사람이 이해할 수 있는 언어로 변환"

## Target User
렌탈 서비스 사용자 (정수기, 공기청정기, 가스레인지, 의류 렌탈 등), 특히 40~50대 가정주부/부모

## 왜 설치하는가
계약 전에 사진 1장 찍으면, 한글로 "해지 시 예상 비용 ₩30만원"이라고 명시. 법적 분쟁 시 증거로 제출 가능.

## 첫 30초
1. "렌탈 계약서 사진 찍기" 버튼 클릭
2. 카메라로 계약서 촬영 (2~3장 자동으로 스캔)
3. 즉시: "의무사용기간 후 해지 시 예상 비용: ₩30만원" + "위험 조항 3가지 표시"

## 핵심 기능
1. **자동 문서 스캔**: 사진 여러 장 → OCR → 전체 약관 텍스트 추출
2. **AI 약관 분석**: 해지비용, 위약금, 초과금 등 핵심 항목 자동 추출
3. **위험도 점수**: 1~10점 (10이면 "높은 위험")
4. **비용 시뮬레이션**: "12개월 계약, 8개월 후 해지하면?" → 정확한 예상 비용 계산
5. **비교 분석**: 같은 제품을 다른 렌탈사에서 계약했다면 비용 비교

## 핵심 사용 루프
Trigger: 렌탈 계약 결정 전
→ Action: 계약서 사진 찍어서 앱에 업로드
→ Reward: "당신이 놓친 ₩30만원 비용 발견!" 팝업 + 명확한 해석
→ Investment: 데이터 축적 (사용자가 선택한 렌탈사, 상품, 계약 조건)
→ Next Trigger: "이 계약이 정말 필요한가?" 재검토 → 약간의 비용 절감

## 반복 사용 이유
- 가정에서 렌탈 서비스는 여러 개 (정수기 + 공기청정기 + 가스레인지)
- 계약 갱신 시점마다 재확인 필요
- 친구에게 "이 렌탈사는 해지비용이 많아" 공유 가능

## Personalization
- 지역별 렌탈 비용 표준 비교 (서울 vs 지방)
- 개인의 계약 히스토리 기반 "당신은 보통 2년 후 해지합니다" 추천
- "당신 같은 가정은 보통 이 정도 비용이 발생합니다" 벤치마크

## AI 역할
1. **약관 해석**: 법률 용어 → 일반인 언어 자동 번역 ("포괄 가산금"이 뭔지 설명)
2. **위험도 평가**: "이 조항은 법적으로 논쟁의 여지가 있습니다" 표시 (한국소비자원 판례 기반)
3. **비용 계산**: 초과금, 위약금, 할인분 반환 등을 정확하게 계산
4. **대체 제품 추천**: "이 렌탈사 대신 이곳은 해지비용이 ₩10만원입니다"

## Sharing
- 친구에게 "이 렌탈사는 위험해" 경고 공유
- SNS에 "렌탈사는 이렇게 선택하세요" 팁 공유
- 한국소비자원에 정보 제출 (집단소송 시 증거)

**Pro (₩4,900/월)**:

**Enterprise (₩50,000/년)**:

## MVP
1. **OCR 엔진**: 계약서 사진 → 텍스트 추출 (Google Vision API 활용)
2. **핵심 추출**: "해지비용", "의무사용기간", "위약금" 등 키워드만 추출
3. **대시보드**: 추출된 정보를 표로 정리
4. **비용 계산**: 간단한 공식 기반 (초기에는 수동 규칙)

## MVP 예상 비용
₩1,800,000 ~ ₩2,400,000
- 백엔드(OCR + 데이터 추출): ₩1,000,000

# Idea 004. 수금쌤 — 프리랜서 미수금 추적 & 자동 리마인더

## 해결하는 Pain

## Target User
글로벌 프리랜서 (개발자, 디자이너, 라이터, 번역가), Upwork/Fiverr 사용자

현재: Upwork 앱 + Fiverr 앱 + FreshBooks 앱 + 은행 앱 4개를 확인. 이 앱은 모든 것을 통합하고, "입금이 늦어지면 자동 리마인더" 발송.

4. **현금흐름 분석**: "당신의 평균 결제 주기는 30일입니다" + "다음 입금 예상일: 10월 15일"
5. **부도 클라이언트 감지**: "이 클라이언트는 3회 연체했습니다" 경고

## 핵심 사용 루프
Trigger: 오전 9시 자동 알림

## Personalization

## AI 역할
1. **자동 리마인더 최적화**: 클라이언트의 응답 시간을 학습해서 "언제 연락할지" 최적화

# Idea 005. 비자러 — 노매드 비자 자동 체크리스트 & 요구사항 통합

## 한 줄 설명
목표 국가 선택 → 비자 요구사항 자동 수집 → 맞춤 서류 체크리스트.

## 해결하는 Pain
P014: 디지털 노매드는 비자 신청 준비에 10~20시간 소비. 나라마다 다른 요구사항, 서류 번역 비용 $200~$1,000, 공증 복잡. 서류 거절로 재신청하는 경우도 많음.

## 제공하는 Positive Experience
S002, S013: AI가 프로필을 자동 생성하고 아바타 영상을 자동 제작하듯이, 이 앱은 "비자 준비 전 과정을 자동화"

## Target User
디지털 노매드, 원격 근무자, 해외 장기 출장자

## 왜 설치하는가
현재: 대사관 웹사이트 방문 → 요구사항 수동 정리 → 각 서류별로 개별 준비 → 번역사 연결 → 공증. 이 앱은 "모든 것이 체계화"되어, 서류 거절 확률 낮춤.

## 첫 30초
1. "어디로 갈 계획인가요?" 선택 (포르투갈, 태국, 에스토니아, 크로아티아 등)
2. "당신의 직업은?" 선택 (프리랜서, 샐러리맨, 창업가)
3. 즉시: "포르투갈 D7 비자 요구사항 18가지" 체크리스트 표시

## 핵심 기능
1. **자동 요구사항 수집**: 60+ 노매드 비자 국가의 최신 요구사항 자동 크롤링 (대사관 웹사이트)
2. **개인화 체크리스트**: 직업/상황별로 필요한 서류만 필터링
3. **서류 준비 단계별 가이드**: "1단계: 여권 사본", "2단계: 소득증명 (옵션 A/B/C)"
4. **번역 연결**: 필요한 서류를 사진 찍으면, 번역사 연결 (정가 제시)
5. **공증 예약**: 공증소 위치 + 예약 링크

## 핵심 사용 루프
Trigger: "새로운 비자를 신청해야 한다" 결정
→ Action: 앱 열어서 국가 선택 → 체크리스트 확인
→ Reward: "모든 서류가 준비되었습니다! 이제 대사관에 신청할 수 있습니다" 완료 표시
→ Investment: 서류별로 1주일씩 준비 (상담사 도움 받을 수 있음)
→ Next Trigger: 비자 승인 후 → "다음 비자 갱신은 1년 후"

## 반복 사용 이유
- 노매드는 보통 2~3년마다 비자 갱신 필요
- 새로운 국가로 이동할 때마다 새 비자 신청
- 비자 상태 추적 ("승인 대기", "승인됨", "만료 예정")

## Personalization
- 개인 상황별 필요 서류 필터링 (프리랜서 vs. 피고용인)
- "당신은 지난 3년간 4개 비자를 신청했고, 평균 25일 걸렸습니다"
- 국가별 처리 시간 예측

## AI 역할
1. **자동 요구사항 업데이트**: 대사관 웹사이트 매주 자동 크롤링 → 변경사항 감지
2. **서류 검증**: 사진으로 찍은 여권을 업로드하면, "크기, 선명도, 배경색이 정상입니다" 확인
3. **번역 최적화**: 필요한 부분만 번역하도록 가이드 (전체 번역 비용 절감)
4. **거절 예측**: "당신의 소득증명 형식이 이 국가에서는 거절될 확률이 40%입니다"

## Sharing
- 노매드 커뮤니티에 "포르투갈 D7 체크리스트" 공유
- "이 비자 대사관은 빠르다/느리다" 정보 공유

## Monetization
**Free**: 1개 국가 체크리스트 + 기본 가이드
**Pro (₩6,900/월)**: 
- 60+ 국가 무제한
- 번역사 연결 (할인가)
- 개인 상담사 1회/월
**Premium (₩14,900/월)**: 
- 변호사 상담 (비자 거절 시)

## MVP

₩1,500,000 ~ ₩2,200,000
- 백엔드(DB + 크롤링): ₩800,000
- 모바일 앱: ₩700,000
- 초기 비자 요구사항 리서치: ₩400,000

## 해결하는 Pain

## 제공하는 Positive Experience
S001 + S008: 앱테크의 "매일의 작은 행동이 누적되는 만족감"처럼, 이 앱은 "이사의 여러 단계(견적 → 배송 → 정착)가 자동으로 연결"

## Target User

# Idea 010. 영상쌤 — 유튜브 자막 + 메타데이터 자동화

유튜브 크리에이터, 팟캐스터, 교육자

1. 유튜브 영상 링크 붙여넣기 (또는 MP4 업로드)
2. 언어 선택
3. "자막 생성 중..." → 1분 후 "자막 + 섬네일 + 제목 준비됨"

## 핵심 기능
1. **자동 자막 생성**: 음성 → 텍스트 (한글, 영어 등)
2. **자동 번역**: 원본 자막 + 주요 언어 5~10개 자동 번역
3. **섬네일 AI 생성**: 영상의 "임팩트 있는 장면" 자동 감지 + 텍스트 오버레이 추가
4. **제목 추천**: 영상의 핵심 내용 → "클릭유도" 제목 5개 제안

→ Reward: "자막, 섬네일, 제목 모두 준비됨! 이제 업로드만 하세요" (10분 절감)
→ Investment: AI 생성 콘텐츠 검토 (5분) + 필요시 수정
→ Next Trigger: 주간/월간 "조회수 분석" → 다음 영상 개선에 반영

2. **일일 건강점수**: 모든 지표를 통합해 "오늘의 건강점수" 계산 (0~100)
3. **패턴 분석**: "당신은 월요일에 수면이 부족합니다" + "이유: 야근?"
4. **AI 조언**: "이번 달 수면이 부족하면, 다음달 감염병 위험 20% 증가할 수 있습니다"
5. **개인화 목표**: "당신은 월 5kg 감량이 목표입니다. 현재 추세는 3kg/월입니다. 운동을 20% 늘려야 합니다"

## 핵심 사용 루프
Trigger: 아침 7시 자동 알림
→ Action: "오늘의 수면·운동·식사 기록 5분" (스트릭 유지)
→ Reward: "건강점수 85 + 스트릭 15일 유지" 표시
→ Investment: 매일 기록 (스마트워치 자동 + 수동 5분)
→ Next Trigger: 내일도 기록 → "30일 스트릭 달성하면 달성률 분석 리포트"

## 반복 사용 이유
- 매일 새로운 데이터 누적 → 스트릭 유지 심리
- "월말에 나의 건강을 평가해봅시다" 반복

## Personalization
- 개인의 기초대사량 + 활동량 기반 "당신의 적정 칼로리"
- "당신은 보통 야근 다음날 수면이 부족합니다" → 야근 후 "충분히 쉬세요" 알림
- "당신의 체질: 마른 체형인데 근력이 부족합니다" → "근력 운동 권장"

## AI 역할
1. **식사 인식**: 사진으로 찍은 음식 → 자동 영양정보 인식
2. **패턴 분석**: 6개월 데이터 → "당신의 건강 패턴" 시각화
3. **예측**: "현재 추세대로면 3개월 뒤 체중은?" 예측
4. **맞춤 조언**: "당신의 야근이 수면을 방해합니다. 10분 운동으로 수면질 개선 가능합니다"

## Sharing
- 친구와 "건강 점수 비교" (장난스럽게)
- "이번 달 나는 건강점수 평균 80점" 소셜미디어 공유
