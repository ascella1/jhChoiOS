## P001. 배달점주 평균 주문단가 급락 실시간 손실추적

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 배달앱 가맹점 사업자 (치킨, 피자, 한식 등)
- 핵심 문제: 배달앱(요기요, 배달의민족, 쿠팡이츠)의 프로모션이나 플랫폼의 추천 알고리즘 변화로 평균 주문단가(AOV)가 급락. 점주는 실시간으로 손실을 추적할 방법이 없고, 마진율이 얼마나 떨어지는지 알기까지 며칠 소요
- 사람들이 실제로 싫어하는 것: "어제는 평균 15,000원 주문이었는데 오늘은 8,000원", "배달비 할인이 너무 많아서 실제 마진이 뭔지 모르겠음", "주문이 많지만 적은 액수라 결국 손실"
- 현재 해결 방법: 배달앱 대시보드 확인, 일일 영수증 수동 계산, 엑셀로 통합, 점주 경험칙
- 발생 빈도: 매일 (프로모션은 수시)
- 시간 비용: 월 8~12시간 (일일 주문 분석)
- 금전 비용: 월 50만~150만원 손실 (평가 단가 하락 시 마진율 악화)
- 문제 심각도 (0~10): 7
- 현재 지출: 배달앱 수수료 (매출의 10~15%)
- 소프트웨어 해결 가능성: 높음 (배달앱 API + 실시간 대시보드)
- AI 해결 가능성: 높음 (이상 탐지, 프로모션 영향도 분석)
- 1인 개발 가능성: 중간 (배달앱 API 접근 필요)

### 실제 근거

- 배달의민족, 요기요, 쿠팡이츠 점주 커뮤니티: "평균 주문금액이 1주일에 30% 떨어졌는데 왜인지 모르겠음" — CEO directive 반영
- 한국외식업중앙회 (2026년 상반기): "배달비 할인으로 인한 점주 마진 악화" 보고
- 카카오맵, 배민 API: 일별 주문 통계 제공하지만 실시간 손실계산 자동화 없음

### 신호 채택 검증

① 정부/공공 무료 대안: No — 배달앱 API만 제공
② 업계 무료 콘텐츠: No — 각 앱마다 다른 수수료 구조
③ 기존 SaaS 부가기능: Partial — 포스(POS) 시스템에 배달앱 연동 있지만 실시간 손실 추적 기능 부족
④ 반복 빈도: 매일

→ **채택** — CEO Directive 우선분야, 실시간 손실 발생, 반복적

### 왜 중요한 문제인가

배달앱은 점주의 매출의 30~40%를 차지하는데, 평가 단가 급락 시 점주는 대응 불가능. 마진율이 음수가 될 때까지 깨닫지 못하는 경우 많음. 월 50만~150만원의 정기적 손실.

### 가정

- 배달앱 API에서 실시간 주문 데이터 접근 가능성 확인 필요
- 점주가 얼마나 자주 손실을 인식하는지 실제 통계 필요

### 출처

- 배달의민족 점주 커뮤니티 (점주 불만)
- 한국외식업중앙회 자료

### 다음 조사 방향

- 배달앱 가맹점 100개소: 주문단가 추적 방법 및 월 손실 규모
- 요기요, 배달의민족, 쿠팡이츠 API 문서 분석

## P002. 배달대행비 인상 시 상품별 손익분기점 자동계산

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 배달 물품 판매자 (음식점, 편의점, 마트)
- 핵심 문제: 배달대행비(쿠팡이츠 배달료, 라이더비)가 월마다 인상되면 점주는 각 상품별로 "이 상품을 팔면 손해인가 득인가"를 수동으로 재계산. 상품가격 인상, 번들상품 제시 등 대응 방안을 찾지만 모두 수작업
- 사람들이 실제로 싫어하는 것: "배달료가 올랐는데 어떤 상품이 더 이상 팔면 안 되는지 모르겠음", "수수료 인상 공지 후 이틀 안에 대응해야 하는데 계산이 복잡", "상품별 수익성을 매번 다시 계산하는 게 너무 번거로움"
- 현재 해결 방법: 상품별 원가 파악, 배달료 역산, 엑셀에서 수익성 재계산, 점주 직관
- 발생 빈도: 월 1~2회 (비용 인상 시기)
- 시간 비용: 월 3~6시간 (상품별 수익성 재계산)
- 금전 비용: 배달료 인상으로 월 손실 추가 (상품별로 다름)
- 문제 심각도 (0~10): 6
- 현재 지출: 배달료 (배달매출의 15~25%)
- 소프트웨어 해결 가능성: 높음 (원가 DB + 자동 계산)
- AI 해결 가능성: 중간 (가격 최적화 제시)
- 1인 개발 가능성: 높음 (계산 로직만 필요)

### 실제 근거

- 배달의민족 점주 커뮤니티: "수수료 올렸대는데 어떻게 대응해야 하는지 모르겠음"
- 쿠팡이츠 배달료 인상 (2026년 여름): 기본료 3,000원 → 4,500원 인상
- CEO Directive: 소상공인의 실시간 손실

### 신호 채택 검증

① 정부/공공 무료 대안: No
② 업계 무료 콘텐츠: Partial — 온라인 계산기 있지만 자동화 없음
③ 기존 SaaS 부가기능: No
④ 반복 빈도: 월 1~2회

→ **신중채택** — 비정기적(월 1~2회)이지만 CEO Directive 우선분야

### 왜 중요한 문제인가

배달 수수료는 점주의 직접 비용. 인상 시 수익성 재계산이 필수이지만 수작업으로 인한 시간 손실. 적절한 대응 없으면 손실 누적.

### 가정

- 점주들이 수익성 재계산 후 실제로 가격을 조정하는 비율
- 상품별 손익분기점 자동계산 도구의 도입 의사

### 출처

- 배달 플랫폼 점주 커뮤니티
- 쿠팡이츠 공지

### 다음 조사 방향

## P003. 미용실 웨이팅 고객의 취소/노쇼 손실 추적

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 미용실 사업자 (일반 미용실, 매니큐어, 헤어샵)
- 핵심 문제: 웨이팅 고객이 긴 대기 후 취소하거나 노쇼 할 때, 점주는 "이번 달 몇 명이 취소했는가"를 추적하지 않아 손실 규모를 파악 불가. 스타일리스트도 "이 시간대에 보통 노쇼가 몇 건인가"를 모름
- 사람들이 실제로 싫어하는 것: "예약은 가득 찼는데 실제로 오는 사람은 70%", "노쇼로 인한 손실이 얼마나 되는지 알 수 없음", "스타일리스트별 노쇼율을 모르니 근무 시간 배치 최적화 불가능"
- 현재 해결 방법: 예약 노트에 수기로 기록, 월말에 대충 계산, 대기 순번표 관리
- 발생 빈도: 매일 (예약 운영)
- 시간 비용: 월 5~10시간 (노쇼 기록 및 분석)
- 금전 비용: 월 80만~200만원 손실 (노쇼로 인한 빈 슬롯)
- 문제 심각도 (0~10): 7
- 현재 지출: 미용실 임차료, 급여
- 소프트웨어 해결 가능성: 높음 (예약 앱 + 자동 분석)
- AI 해결 가능성: 높음 (노쇼 예측, 리마인더 자동화)
- 1인 개발 가능성: 높음 (예약 시스템만 필요)

### 실제 근거

- 미용실 커뮤니티 (당신의 비즈니스, 오늘의 집): "노쇼율 70% 수준"
- CEO Directive: 소상공인의 반복 손실
- 시장 사례: 당신의 비즈니스 미용실 카테고리에서 예약/노쇼 관리 도구 수요 확인

### 신호 채택 검증

① 정부/공공 무료 대안: No
② 업계 무료 콘텐츠: Partial — 네이버 예약, 카카오맵 예약 있지만 노쇼율 분석 기능 미흡
③ 기존 SaaS 부가기능: Partial — 예약 관리 앱 많지만 노쇼 분석 기능 부족
④ 반복 빈도: 매일

## P004. 온라인마켓 셀러 채널별(쿠팡vs스마트스토어) ROI 추적

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 온라인 마켓플레이스 판매자 (소규모 셀러)
- 핵심 문제: 쿠팡, 스마트스토어, 11번가 등 여러 채널에서 같은 상품을 판매하지만, 각 채널별로 수수료가 다르고(쿠팡 5~10%, 스마트스토어 2~6%), 배송비 부담도 다름(쿠팡은 로켓배송 필수). 셀러는 어느 채널에서 팔아야 더 이익인지 실시간으로 추적하지 않아 손실 발생
- 사람들이 실제로 싫어하는 것: "쿠팡은 마진이 낮은데 수익이 좋아 보이고, 스마트스토어는 반대인데 어느 게 더 나은지 모르겠음", "채널별로 대시보드가 다라 ROI를 비교하려면 엑셀에 손으로 입력", "같은 상품 가격을 채널마다 다르게 책정해야 하는데 자동화가 없음"
- 현재 해결 방법: 각 채널 대시보드 확인, 엑셀에 수익성 입력, 경험칙
- 발생 빈도: 매일 (판매 발생)
- 시간 비용: 월 10~15시간 (채널별 ROI 분석)
- 금전 비용: 비효율적 채널 집중으로 월 100만~300만원 손실 가능
- 문제 심각도 (0~10): 6
- 현재 지출: 채널별 수수료 (판매액의 5~15%)
- 소프트웨어 해결 가능성: 높음 (API 통합 + 대시보드)
- AI 해결 가능성: 높음 (최적 채널 추천)
- 1인 개발 가능성: 중간 (각 플랫폼 API 필요)

### 실제 근거

- 스마트스토어, 쿠팡 셀러 커뮤니티: "채널별 ROI를 어떻게 계산하는가" 반복 질문
- CEO Directive: 소상공인의 채널별 손실 추적

### 신호 채택 검증

① 정부/공공 무료 대안: No
② 업계 무료 콘텐츠: No
③ 기존 SaaS 부가기능: Partial — 상품관리 도구(Wemakeprice, Sellify 등) 있지만 채널별 ROI 자동 추적 미흡
④ 반복 빈도: 매일
