## P001. 해외직구 반품 후 관세 환급 수동 신청 절차

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 국제 배송 물품 구매자, 직구 이용자
- 핵심 문제: 해외직구 상품 반품 시 이미 납부한 관세를 받으려면 관세청에 별도 환급 신청을 해야 하는데, 신청서 작성·증명서 첨부·반송 추적 등 모든 과정이 수동. 신청 기한이 6개월(수입신고 완료일로부터)로 정해져 있어 기한을 놓치는 경우 다수
- 사람들이 실제로 싫어하는 것: 환급 받을 돈(보통 1만~5만원)을 받으려고 복잡한 신청 절차를 거쳐야 함, 신청 기한 사전 공지 없음, 관세청 웹사이트가 아닌 다양한 경로로 신청해야 함
- 현재 해결 방법: 관세청 모바일 앱(모바일관세청) 또는 웹사이트 직접 방문해 환급 신청, 택배사에 반송 추적 번호 요청
- 발생 빈도: 월 1~3회 (반품 발생 시점)
- 시간 비용: 신청 시 10~30분, 추적 및 확인에 주 1회 이상
- 금전 비용: 환급받지 못하면 월 1~5만원 손실
- 문제 심각도 (0~10): 4
- 현재 지출: 무료 (관세청 서비스)
- 소프트웨어 해결 가능성: 높음 (자동 환급 추적 및 리마인더)
- AI 해결 가능성: 중간 (환급 기한 자동 계산, 필요 서류 자동 정렬)
- 1인 개발 가능성: 낮음~중간 (관세청 API 연동 필요)

### 실제 근거
- 대한민국 관세청 공식 안내: "해외직구 물품의 관세환급 신청절차" — 신청자가 수입신고번호, 반송 택배사 추적번호 등을 직접 수집해 신청해야 함
- 소비자 사례(소비자24): "해외직구 가방의 과도한 반품 배송비 조정 요구" — 환급 기한을 놓친 사용자들의 분쟁 사례 기록
- 토스뱅크 해외직구 환급 가이드: "반품 후 관세 환급받기"에서 "자동 환급이 아니라 직접 신청해야 함" 명시

### 신호 스크리닝
① 정부 무료 제공: Yes (관세청 환급 자체는 무료) — 그러나 신청 자동화는 제공하지 않음
② 업계 무료 콘텐츠: No — 각 쇼핑몰별로 환급 정책이 다르고, 표준 가이드 없음
③ 기존 SaaS 포함: No — 배송 추적 서비스는 있지만 환급 추적 서비스는 미흡
④ 반복 빈도: 월 1~3회 (반품 발생 시)

**판정**: 채택 — 직구 이용자가 증가하는 상황에서 반복적인 수동 신청 pain

### 왜 중요한 문제인가
직구 이용자가 월 1~3회 반품할 때마다 복잡한 환급 신청을 거쳐야 하고, 기한을 놓치면 납부한 세금을 잃게 되는 상황. 각 플랫폼에서 자동 환급 안내가 없어 사용자가 직접 찾아서 신청해야 함.

### 가정
- 관세청 API가 공개되어 있는지 확인 필요
- 배송 추적사 API와 통합 가능한지 확인 필요

## P002. 휴대폰 요금제 비교 및 자동 갱신 기한 관리

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 휴대폰 사용자, 특히 요금제 자동 갱신 미인식 고객
- 핵심 문제: 휴대폰 구매 시 약정 기간(보통 2년) 후 자동으로 더 비싼 기본료로 갱신되는데, 갱신 기한이 명확하지 않거나 사용자가 놓치는 경우가 많음. 갱신 후에도 더 싼 요금제로 변경 신청이 복잡함
- 사람들이 실제로 싫어하는 것: "요금제 약정이 끝났는데 왜 자동으로 더 비싼 요금을 내는가", 통신사별로 요금 체계가 달라 비교 어려움, 갱신 기한 사전 알림 부재
- 현재 해결 방법: 통신사 고객센터 직접 전화, 커뮤니티에서 정보 검색, 요금제 비교 앱(모요플랜, 알뜰폰허브) 이용
- 발생 빈도: 2년마다 (약정 만료 시)
- 시간 비용: 갱신 기한 확인 및 변경 신청에 월 2~3시간
- 금전 비용: 자동 갱신 미인식 시 월 3~5만원 추가 손실
- 문제 심각도 (0~10): 5
- 현재 지출: 월 3만~9만원 (요금제별)
- 소프트웨어 해결 가능성: 높음 (요금제 비교 및 자동 알림)
- AI 해결 가능성: 중간 (최적 요금제 자동 추천)
- 1인 개발 가능성: 중간 (통신사 API 제한)

### 실제 근거
- 모요플랜(Moyoplan): "알뜰폰 요금제 비교" 서비스 운영 중 — 사용자가 수동으로 요금제를 비교해야 함
- MSN 뉴스(2026): "이제 요금제 바꾸세요, 통신사가 알려준다 — 6개월 유지 끝나면 자동 알림" — 정부가 최근 갱신 기한 자동 알림을 강제하기 시작했지만, 여전히 사용자 미인식 많음
- 소비자 포럼: "폰 요금 자동이체 과납 문제" — 과납 후 환불받는 과정이 복잡하다는 불만

### 신호 스크리닝
① 정부 무료 제공: Partial — 2026년부터 갱신 기한 자동 알림 강제 중이지만, 요금제 비교 자동화는 미흡
② 업계 무료 콘텐츠: No — 각 통신사가 자신의 요금제만 안내
③ 기존 SaaS 포함: Partial — 모요플랜, 알뜰폰허브가 있지만 기존 계약의 갱신 기한을 자동 추적하지는 않음
④ 반복 빈도: 2년마다 (약정 만료 시)

**판정**: 신중채택 — 이미 비교 서비스가 있고, 정부가 기한 알림을 강제 중. 그러나 "현재 계약의 갱신 기한 자동 추적 + 최적 요금제 추천"은 아직 없음

### 왜 중요한 문제인가
2년마다 자동 갱신되는 휴대폰 요금제는 대다수 사용자가 관심 없이 지나가는데, 이미 비교 서비스가 많아서 pain이 감소 추세. 다만 "현재 계약" 정보를 자동으로 파싱해서 최적 대안을 추천하는 서비스는 부재.

### 가정
- 사용자가 통신사 앱·고객센터에서 계약 정보를 쉽게 내보낼 수 있는지 확인 필요

## P003. 신용카드 영수증 카드사별 중복 조회 및 관리

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 신용카드 사용자, 프리랜서, 자영업자
- 핵심 문제: 여러 카드사의 신용카드를 사용하는 경우, 각 카드사의 웹사이트 또는 앱에 로그인해서 영수증을 따로따로 조회해야 함. 통합 플랫폼이 없어 수작업 정리 필요. 법인카드의 경우 영수증 재발급 절차도 카드사별로 다름
- 사람들이 실제로 싫어하는 것: "3개 카드사 영수증을 받으려고 3번 로그인 해야 함", 월말 회계 정산 시 영수증 모으는 데만 1시간 이상 소요, 영수증 종류별로(신용카드/체크카드/배신) 정렬이 번거로움
- 현재 해결 방법: 각 카드사별 웹사이트/모바일앱에서 이용내역 조회 → 개별 다운로드 → 엑셀 정리, 법인카드는 카드사별 고객센터 전화 후 재발급 요청
- 발생 빈도: 월 1회 (월말 회계 정산 시)
- 시간 비용: 월 1~2시간 (영수증 수집 및 분류)
- 금전 비용: 영수증 분실 시 재발급 비용 또는 미처리 손실
- 문제 심각도 (0~10): 5
- 현재 지출: 무료~월 5만원대 (법인카드 관리료)
- 소프트웨어 해결 가능성: 높음 (통합 영수증 대시보드)
- AI 해결 가능성: 높음 (영수증 자동 분류 및 카테고리화)
- 1인 개발 가능성: 중간 (각 카드사 API 연동)

### 실제 근거
- 신한카드 공식 가이드: "영수증 정보 확인하기" — 각 카드사별로 조회 경로가 다름을 시사
- 에어서플라이 블로그: "법인카드 영수증 재발급, 카드사별 3분 해결 가이드" — 카드사마다 재발급 절차가 다르다는 명시
- 실무자 불만(스팬딧): "법인카드 영수증을 잃어버렸을 때 정산 방법" — 영수증 재발급 절차의 복잡성과 시간 소요 언급

### 신호 스크리닝
① 정부 무료 제공: No — 국세청이 영수증 관리를 강제하지만, 통합 조회 서비스는 미제공
② 업계 무료 콘텐츠: No — 각 카드사가 자신의 영수증만 관리
③ 기존 SaaS 포함: No — 통합 영수증 관리 서비스 부재
④ 반복 빈도: 월 1회 (월말 회계)

**판정**: 채택 — 실제 회계 담당자들이 매월 반복하는 pain

### 왜 중요한 문제인가
자영업자, 프리랜서, 중소기업 회계 담당자가 월별로 여러 카드사의 영수증을 따로 조회하고 정리하는 데 시간을 낭비. 통합 대시보드가 있으면 월 2시간 절감.

### 가정
- 각 카드사가 API를 공개하는지 확인 필요
- 사용자의 카드 정보 보안 문제 처리 방안 필요

## P004. 부동산 중개소 매물 관리 스프레드시트 수작업

- 지역: 한국
- 국가: 대한민국
- 타깃 고객: 부동산 중개사, 소규모 매물 관리업체
- 핵심 문제: 부동산 매물 정보(주소, 면적, 가격, 거래 상태, 연락처)를 스프레드시트(엑셀)로 수작업 관리. 매물이 추가/제거될 때마다 수동으로 입력/삭제. 여러 명이 동시에 같은 파일을 수정할 때 충돌 발생. 지도 연동·사진 관리가 미흡

## P008. 일본 유학생 아르바이트 급여 계산 시 세금·보험료 예측 불가

- 금전 비용: 갱신료 월세 1개월분 (보통 10~20만엔)

- 소프트웨어 해결 가능성: 중간 (디지털 계약 및 갱신 관리)
- AI 해결 가능성: 낮음 (갱신료 협상은 수동)

- 국가: 다국가
- 타깃 고객: 온라인 프리랜서 (개발자, 디자이너, 라이터)
- 핵심 문제: 프리랜서가 클라이언트로부터 프로젝트를 받을 때, 계약서에 "3회 수정"이라고 명시했어도 클라이언트가 계속 추가 수정을 요청하는 경우(Scope Creep). 프리랜서는 거절하기 어려워 무료로 추가 작업을 하게 되고, 연평균 $15,000~$25,000 손실을 경험하는 경우가 많음

- 현재 해결 방법: 계약서에 상세히 명시, 추가 작업 비용 청구 (일부), 클라이언트와 명확한 소통
- 발생 빈도: 프로젝트마다 다양 (평균 프로젝트 당 20~30% 추가 작업)
- 시간 비용: 월 40~80시간 (무료 추가 작업)

- 문제 심각도 (0~10): 8
- 현재 지출: 무료 (추가 작업)
- 소프트웨어 해결 가능성: 높음 (scope 관리 및 변경 추적 플랫폼)
- AI 해결 가능성: 중간 (계약서 자동 분석 및 scope creep 감지)
- 1인 개발 가능성: 높음 (프로젝트 관리 SaaS 형태)

## P020. 비디오 크리에이터 자막 생성 YouTube 처리 일 소요

- 지역: 전세계
- 국가: 다국가
- 타깃 고객: 콘텐츠 크리에이터, YouTube·TikTok 운영자
- 핵심 문제: 비디오 크리에이터가 YouTube에 영상을 업로드하면, YouTube의 자동 자막 생성 기능이 작동하는데 보통 며칠이 걸림. 특히 음질이 좋지 않거나 빠르게 말하는 경우 정확도가 떨어짐. 따라서 크리에이터는 수동으로 자막을 작성하거나 타사 도구(Zubtitle, VEED, Rev.ai 등)를 사용해서 시간을 낭비
- 사람들이 실제로 싫어하는 것: "YouTube 자동 자막이 며칠이 걸림", "정확도가 70~80% 정도라 수정이 필요", "TikTok·Instagram에 올리려면 각각 자막을 따로 추가해야 함"
- 현재 해결 방법: YouTube 자동 자막 기다림 (며칠), Rev.ai·Happy Scribe 같은 타사 자막 생성 도구 사용 (유료), 수작업 자막 작성
- 발생 빈도: 영상 업로드마다 (주 1~5회)
- 시간 비용: 영상당 10분~1시간 (자막 생성·검수)
- 금전 비용: 월 $30~$100 (자막 생성 도구 구독)
- 문제 심각도 (0~10): 4
- 현재 지출: 월 $0~$100 (자막 도구 구독)
- 소프트웨어 해결 가능성: 높음 (빠른 자막 생성 + 다국어 지원)
- AI 해결 가능성: 높음 (음성 인식 + 자동 번역)
- 1인 개발 가능성: 중간 (음성 인식 API 연동)

- GhostCut: "Generate Accurate Subtitles for TikTok Videos" — 자막 생성 도구 다수 존재 암시
- Zubtitle: "Add Subtitles to TikTok Videos (Automatically!)" — 자동 자막 생성 수요 확인

② 업계 무료 콘텐츠: Yes — YouTube 자동 자막이 무료로 제공되지만, 속도와 정확도가 낮음
③ 기존 SaaS 포함: Yes — Zubtitle, VEED, Rev.ai, HappyScribe 등 다수 존재
④ 반복 빈도: 주 1~5회 (영상 업로드)

**판정**: 신중채택 — 이미 Zubtitle·VEED·Rev.ai 같은 경쟁사가 있고, 시간 비용도 영상당 10분~1시간으로 상대적으로 낮음. 그러나 "초고속 처리", "다언어 자동 번역", "플랫폼별 최적화" 같은 차별화가 있을 수 있음
