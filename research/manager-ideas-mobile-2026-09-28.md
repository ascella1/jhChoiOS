## 🔥 Hot Ideas (70+ Score)

### 1️⃣ Expense Auto-Logger (82)
영수증을 찍으면 AI가 자동으로 분류하고, 월별 경비를 그래프로 보여주는 앱. 기존 Concur/Expensify는 여전히 수동 검토 필요한데, 이건 완전 자동화. 다국어 지원으로 글로벌 기업 시장 공략 가능. **유일한 S-grade 아이디어.**

### 2️⃣ Return Express (77)
온라인 쇼핑 반품의 배송료 비교 + 환불 상태 실시간 추적. MyFitnessPal처럼 자동 계산하고, Strava처럼 진행도를 보여줌. 쿠팡이 일부 상품만 지원하므로 "모든 플랫폼 통합"이 강점.

### 3️⃣ Supplier Payment Guardian (75)
중소기업의 공급업체 대금 지급을 자동 추적하고, 기한 5일 전 알림. 현재 스프레드시트로 관리하는 회사들의 Pain이 매우 크고, 매일 사용하는 B2B 제품이라 고정 수익화 가능.

### 4️⃣ Ride Reliability Shield (73)
기사 신뢰도 점수 + 취소 0 스트릭을 보고 카풀을 선택. Habicat의 스트릭처럼 "이 기사는 30일 취소 안 함"을 시각화해서 기사 선택 기준을 명확하게 함. 기존 앱(카카오맵)과 다르게 "취소율 특화".

### 5️⃣ Meeting Transcript Sync (73)
회의를 자동으로 녹음·전사·요약해서 모두에게 배포. 기업은 속기사 고용 안 해도 되고, Otter.ai/Fireflies.ai보다 "완전 자동화" 강조. Zoom 플러그인이라 진입장벽 매우 낮음.

### 6️⃣ Real-Time Reservation Sync (71)
배민·다이닝코드의 모든 식당 테이블을 한 앱에서 실시간으로 본 후 예약. 이중예약 완전 차단. 직장인 점심 시간이 정해져 있어서 주 3회 자동 사용 유도 가능.

### 7️⃣ Insurance Claim Speedrun (71)
보험 청구 서류를 AI가 자동 작성해주고, 진행 상황을 실시간 추적. 발생 빈도는 낮지만 발생 시 심각도가 높음 (심리적 고통). 기존 경쟁사 거의 없음.

### 8️⃣ Freelancer Escrow Safe (70)
프리랜서 선급금을 자동 에스크로에서 관리하고, 분쟁 시 자동 중재. 금전적 손실을 완전히 차단할 수 있어서 프리랜서들의 신뢰 구축 가능. 하지만 금융 규제 진입장벽 높음.

## ⚠️ Weak Points

각 아이디어의 가장 큰 약점 (심사할 때 주의):

1. **Expense Auto-Logger**: OCR 정확도 95% 이상이어야 실용적 (손글씨·언어 다양성 문제)
2. **Return Express**: 배송사·판매처 API 개방 거부 가능성 (협상 복잡)
3. **Supplier Payment Guardian**: 기존 Xero/FreshBooks 고정고객에서 이탈 어렵기 (잠금 효과)
4. **Ride Reliability Shield**: 카카오맵·네이버맵이 자체 취소율 기능 추가하면 경쟁 불리 (큰 기업의 빠른 모방)
5. **Meeting Transcript Sync**: Otter.ai/Fireflies.ai 이미 강하고, 기업의 회의 녹음 거부 가능 (GDPR)
6. **Real-Time Reservation Sync**: 여러 앱 동시 운영하는 식당이 테이블 수동 업로드 거부 (API 통합 비용)
7. **Insurance Claim Speedrun**: 자동 양식 작성이 법적 조언으로 간주될 수 있음 (법무사 협력 필수)
8. **Freelancer Escrow Safe**: CrowdWorks/Lancer.jp가 이미 에스크로 제공 (이탈 유도 어려움)
9. **Work Hours Autopilot**: 직원 감시 우려로 기업 도입 거부 (프라이버시 이슈)
10. **Shift Pay Calculator**: 편의점 점주들의 스마트폰 사용 낮음 (대상층 나이 높음)
11. **Quick Account Recovery**: 게임사 자체 복구 시스템 강화 중 (경쟁 심화)
12. **Unified EHR Network**: HIPAA 준수 비용·시간 극도로 높음 + 병원 데이터 개방 거부
13. **Student Finance Aggregator**: 학기당 1회만 사용 + 환율 예측 정확도 70% 수준

### 가장 많이 발견된 Pain
1. **자동화 부재** (P012, P014, P018, P019): 서류·계산·기록이 수작업
2. **정보 분산** (P003, P004, P013, P015): 여러 플랫폼 개별 관리
3. **불확실성** (P001, P002, P005, P009): "언제 끝날까?" 추적 불가능
4. **프로세스 복잡** (P005, P010, P011): 단순해 보이지만 단계가 많음

### 가장 많이 발견된 Positive
1. **일일 의례화** (Wordle, BeReal, Chess.com): 매일 같은 시간에 반복 사용 강제
2. **자동화 + 시각화** (MyFitnessPal, Strava): 행동이 자동으로 기록되고 그래프로 표시
3. **RPG 게임화** (Habicat, Finch): 추상적 목표를 구체적 성장으로 변환
4. **공유 기반 커뮤니티** (Vinted, Depop, Goodreads): 개인 기록 → 친구 공유 → 비교 동기

### 핵심 인사이트
**"Pain은 수작업과 불확실성, Positive는 완전 자동화와 시각화"**

따라서 가장 유망한 제품은:
- ✅ 기존 수작업 100% 제거 (버튼도 안 누르기)
- ✅ 매일 또는 주 3회 이상 반복 사용
- ✅ 진행도를 그래프·숫자로 시각화
- ✅ 기존 경쟁사보다 자동화 수준 10배 높음

**Expense Auto-Logger가 모든 조건 만족** → S-grade.
